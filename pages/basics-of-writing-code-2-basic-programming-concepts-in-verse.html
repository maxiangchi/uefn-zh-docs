编写代码基础 2：Verse 基本编程概念

本课介绍表达式、值、结果、求值、运算符、关键字、类型与字面量等 Verse 基本编程概念。

英文原标题：Basics Of Writing Code 2 Basic Programming Concepts In Verse · 查看英文原文 · 社区翻译镜像，仅供学习

前置主题：要理解和使用本页内容，请确保你已熟悉以下主题：
  • 第 1 课：基本编程术语

准备好再来一份编程知识大餐了吗？接下来的内容会更有嚼劲！

代码由什么组成

表达式

表达式（expression）是能产生结果的最小代码单元。例如，1+2 就是一个表达式，程序运行时会输出 3。

Print("{1 + 2}")

Print 是一个内置函数，告诉程序把括号里的东西显示出来。在这里，"{1 + 2}" 告诉程序先计算 1 + 2 等于多少，打开日志时就会打印出这个和。

值

值（value）是程序运行时所用的信息。比如数字或文本都是值。

结果

当表达式执行并输出一个值时，这个值就是结果（result）。

求值

求值（evaluate）指执行表达式以产生值的过程。注意 evaluate 和 value 来自同一个词根。

运算符

运算符（operator）是表示运算（operation）的符号，比如加法（+）或大于（>）。

一只猫加一只猫大于一只老鼠。

表达式的组成部分

前面你学过：表达式是能产生结果的最小代码单元。

进一步展开：表达式是由运算和值组合而成、求值后输出结果的东西。

下面是名为 if .. else 的表达式的用法。

if (MiceCaught > 0):
    Print("Win!")
else:
    Print("Lose!")

结果是“Win!”或“Lose!”。

意思是：如果（if）抓到了一只或多只老鼠，玩家就赢了——否则（else），一只没抓到，玩家就输了。

关键字

有些词是 Verse（Verse）语言内置的，附带着非常具体的动作，它们叫关键字（keyword）。

在上面的例子里，if 是一个关键字，表示必须满足某个条件（如果抓到一只老鼠……）。另一个关键字 else 表示如果条件不满足，就产生另一个结果。

Verse 使用关键字让写程序更轻松，因为每个关键字里都浓缩了大量“程序应该做什么”的信息。

关键字在 Verse 中是保留给其特定内置用途的，所以你不能用这些词给其他东西命名。下一课会细讲这一点！

运算

运算（operation）是可以对数据执行的操作或过程。这些运算用符号表示，叫运算符。运算符操作的数据（比如数字）叫操作数（operand）。

常见运算符举例：

运算符作用
加法 ++ 把两个数字加在一起。
减法 -- 用第一个数减去第二个数。
乘法 ** 把两个数相乘。
除法 // 用第一个数除以第二个数。
相等 == 检查两边是否相等。例如：
if (MiceCaught = MiceInArea):
    Nap()
else:
    LookForMice()
查询 ?? 检查某种特定类型的值是否为真。

运算符还有很多，这里先从这些入门！

类型与值

到目前为止，你已经知道：值是程序做事所需的信息，而运算可以作用于这些信息（数据）。

类型（type）说明程序可以对存储的值做哪种运算。

每种类型都有特定的运算与之关联，而这些运算又要求特定种类的值。

类型有很多种，下面是最常见的几种。

类型作用值
logic这种类型的值只能是真或假，不能取中间值，也不能两者都是。如果你听说过布尔逻辑（开/关或 0/1），这就是 Verse 中的等价物。true / false
int整数（integer）是整数（whole number）（不是分数），int 就是 integer 的缩写。所以 int 类型的值必须是整数（正数或负数），比如 1、-30 或 777。带小数的值请用 float。整数
float这种类型用于非整数的值，比如小数。例如 1.25 就是 float 类型。之所以叫 float（浮动），是因为小数点位置不固定，可以在数字串中“浮动”到需要的位置。例如 10.25、1.375、12.0 都是 float。注意 12.0 表示的是一个整数值。所有整数都可以写成 float——1 写成 1.0，777 写成 777.0——但 float 只有是整数时才能写成 int。带小数点的数字
string这种类型用于任何文本，可以是字母、数字、标点、空格，甚至表情符号 😻。例如在修改并运行你的第一个 Verse 程序中，Print("Hello, world!") 就是打印一个内容为 "Hello, world!" 的字符串。字母、数字、标点、空格、表情符号

字面量

字面量（literal）是 Verse 编程语言中不变的值，比如数字或其他字符。只有当你确定某个值永远不变时，才适合用字面量。

例如对于 logic 类型，只有两种可能字面量：true 和 false，因为它们的值不会变。真永远是真，假永远是假。

下一课会进一步学习字面量及其用法。

总结

  • 代码执行（运行）时，其中的表达式会被求值。
  • 求值会产生结果。
  • 关键字是 Verse 中附带特定动作的特殊单词。
  • 值是程序做事所用的信息。
  • 类型说明程序可以对值做哪种运算。
  • 字面量是不会变化的值。
