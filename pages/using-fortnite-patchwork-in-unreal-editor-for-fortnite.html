在 UEFN 中使用 Fortnite Patchwork

与 Fortnite Creative 一样，你可以在 UEFN 岛屿上使用 Fortnite Patchwork 设备，核心差异在于连线方式与可用 Verse 启用和禁用设备。

英文原标题：Using Fortnite Patchwork in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

就像在 Fortnite Creative 中一样，你可以在 UEFN 岛屿上使用 Fortnite Patchwork 设备。所有 Patchwork 设备的运作方式与 Creative 中完全相同，设备选项也一致。在 UEFN 与在 Creative 中使用 Patchwork 的核心差异在于连接线缆的方式，以及可以使用 Verse 来启用与禁用设备。

如果你还不熟悉 Patchwork，请查看在 Fortnite Creative 中用 Patchwork 作曲。这里有多份资源帮你开始即兴演奏，还有一些很酷的示例，展示如何在岛屿上使用 Patchwork。

在内容浏览器中查找 Patchwork 设备

你可以直接在内容浏览器（Content Browser）中按产品名 Patchwork 搜索 Patchwork 设备，也可以在设备（Devices）文件夹中找到列出的全部 Patchwork 设备。

通过细节面板设置设备选项

所有 Patchwork 设备都在细节面板（Details Panel）中提供一定程度的选项；不过根据设备不同，完整选项与旋钮可能只能在实时编辑模式下访问与调节。

在 UEFN 中，启动实时编辑（Live Edit）之前可以先做好以下准备：

  • 将要使用的设备放置到视口中。
  • 在细节面板中使用音频 / 音符 / 调制输出（Audio/Note/Modulator Out）部分设置并连接所有设备。
  • 放置并连接扬声器（Speaker），以便会话开始后能听到音频。
  • 放置并配置音乐管理器（Music Manager），设置速度与调性等共享设置。

设置完成后，启动实时编辑会话即可开始即兴演奏！会话开始后，在创建模式与游玩模式下都能听到音频。如果希望玩家也能操作 Patchwork 设备，记得通过物品生成器（Item Spawner）或其他方式加入 Patchwork 工具。

获取 Patchwork 工具

Patchwork 工具（Patchwork tool）在 UEFN 中不可用，部分原因是 UEFN 界面的设置方式所致。

进入创建模式后，Patchwork 工具会自动装备到你的快捷栏。如果从编辑模式开始，只需在岛屿上放置一个 Patchwork 设备，Patchwork 工具就会出现在你的物品栏中。

你可以取消勾选启动会话下拉菜单中的自动开始游戏（Auto Start Game），让会话自动以创建模式启动。

连接设备

在 UEFN 中编辑时，你可以通过细节面板中的用户选项 - 端口连接（User Options - Port Connections）部分将设备连接在一起，需要选择线缆与端口连接。此外，连接设备时，可选设备列表会自动筛选出彼此兼容的设备。

目前，将设备连接在一起后，线缆在 UEFN 编辑器中不会直观地连线显示，你也听不到任何音频。你需要在 Fortnite 中启动实时编辑会话，才能看到并听到一切正常工作。

下面的示例使用鼓音序器（Drum Sequencer）、鼓播放器（Drum Player）与扬声器（Speaker）制作一段基础节拍。

要将这些设备连接在一起，先从鼓音序器开始。

  • 选中鼓音序器，在细节面板中找到“用户选项 - 端口连接”部分。
  • 展开顶部下拉菜单设置 音符输出（Note Out）选项。在本例中，你要将鼓音序器的线缆连接到鼓播放器。
  • 在鼓播放器上，将 音符输出（Note Out）设为扬声器（Speaker），端口设为音频输入端口 1（Audio Input Port 1）。
  • 扬声器已连接到鼓播放器，现在可以开始了！
