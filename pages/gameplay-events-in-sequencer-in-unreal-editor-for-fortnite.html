在 Sequencer 中使用 Gameplay 事件

用 Sequencer 中的 Gameplay 事件，在游玩过程中的精确时刻触发设备功能，无需依赖一连串设备事件的链式反应。

时机就是一切，尤其是当你希望设备在特定时刻执行特定功能时。通常，触发功能需要以复杂方式设置多个设备或触发器，甚至要用 channel（频道）设备把游戏机制、功能与视觉表现串起来。

有了 Sequencer 中的 Gameplay 事件（Gameplay Events in Sequencer），你可以在游玩过程中的精确时刻触发设备功能。

Sequencer 中的 Gameplay 事件不支持 Verse 编写的自定义设备。该功能仅适用于内容浏览器 Device 文件夹中的设备。

计时事件（Timing Events）

使用Sequencer可以简化事件计时流程，让功能准时触发，而不必依赖一连串设备事件的链式反应。这对节奏游戏很有帮助，也适合执行那些高度依赖玩家掐准时间走位避险的游戏机制。

配置触发器（Configuring the Triggers）

在 Sequencer 中设置 gameplay 事件之前，必须先创建 Level Sequence，并把Cinematic Sequence 设备拖入视口（viewport）。

  • 在内容浏览器（Content Browser）中右键，选择过场动画（Cinematics） > Level Sequence。
  • 为 Level Sequence 缩略图命名。
  • 双击缩略图打开 Sequencer。
  • 点击 +Track，选择 Actor to Sequence > Add Device，或在搜索框中搜索该设备。
  • 点击设备名称旁的 + 图标，从轨道（Track）下拉菜单中选择 Gameplay Events。
  • 在 Gameplay Event 上添加关键帧（keyframe）。
  • 在时间轴上右键该关键帧，选择 Properties，打开 Key 菜单。
  • 在 Time 字段填入你希望触发设备 gameplay 功能的时间。
  • 从 Gameplay Event Function Property 下拉菜单中选择该设备的 gameplay 事件。

    Gameplay Event Function Property 列表中的设备功能与所选设备的功能一致。

  • 保存 Level Sequence。

播放 Level Sequence（Playing the Level Sequence）

当 Cinematic Sequence 设备播放 Level Sequence 时，在 Sequencer 中设置的设备事件就会在 Gameplay 事件 Time 字段设定的时刻触发。

你可以决定：让 Cinematic Sequence 设备在游戏开始时自动播放 Level Sequence，或将其设为由其他设备（如触发器（Trigger）或限时目标（Timed Objective）设备）触发后再播放。

  • 在大纲视图（Outliner）或视口（Viewport）中选中 Cinematic Sequence 设备。
  • 点击 Sequence 选项的空白字段，选择一个 Level Sequence。
  • 取消勾选 Autoplay 以关闭自动播放。只有当你打算用其他设备触发 Cinematic Sequence 设备的播放功能时才这样做。
  • 点击 Play Function 用户选项中的 Array + 图标。
  • 从顶部 Play Function 下拉菜单中选择一个设备。
  • 从事件（Event）下拉菜单中选择一个事件。

除非想修改 Level Sequence 的其他用户选项，否则保留默认值即可。

你可以向一个 Level Sequence 添加多个设备，并为每个设备设置单个或多个错开的触发时刻。

你甚至可以让一个（或多个）设备在一段时间内按固定时间间隔多次触发。
