Verse 单口喜剧俱乐部模板

Verse 单口喜剧模板用椅子、输入触发器、角色与过场动画序列设备打造喜剧俱乐部演出。本教程讲解岛屿设置、设备配置与驱动整场演出的 Verse 代码。

英文原标题：Verse Standup Comedy Club Template In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

本教程是 Verse 单口喜剧（Verse Stand-Up）模板的配套文档，该模板展示了如何在喜剧俱乐部中使用支持社交与电影化体验的设备：

  • 使用精细的 MetaHumans Animator 资产与角色设备（Character devices）
  • 用输入触发器设备（Input Trigger devices）在玩家输入绑定上触发玩法事件
  • 用椅子设备（Chair device）将玩家固定在原地观看演出

一个 Verse 设备负责整场演出，Verse 代码的关键概念将在下文讲解。

Verse Stand-Up 模板位于 UEFN（Unreal Editor for Fortnite）的功能示例（Feature Examples）分区。

使用的设备：

  • 1 x 椅子（Chair）
  • 4 x 输入触发器（Input Trigger）
  • 4 x 角色（Character）
  • 6 x 过场动画序列（Cinematic Sequence）

本教程使用的 Verse 概念包括：

  • 订阅（Subscriptions）
  • If 语句（If Statements）
  • 数组（Arrays）
  • 过场动画序列（Cinematic Sequences）
  • 椅子设备 API（Chair device API）
  • 输入触发器设备 API（Input Trigger device API）

请注意，设备交互的大部分修改设置都是用 Verse 代码完成的，因此大多数设备的修改后用户选项看起来会比较精简。

椅子设备

玩家走进喜剧俱乐部，会看到灯光舞台前有一把椅子，系统会提示坐下。坐在椅子上可将玩家固定在原地，并启动贯穿后续体验的一系列事件。

椅子设备修改后的用户选项（User Options）如下：

选项值说明
椅子模型（Chair Model）自定义（Custom）本体验中椅子实际被设为不可见，再用 Fortnite 椅子道具替换，以更好融入俱乐部环境。
交互角度（Interaction Angle）180 度决定从椅子正面两侧可交互的角度。
交互半径（Interaction Radius）1.2 米决定玩家可进入椅子的距离。

输入触发器设备

输入触发器设备（Input Trigger device）与椅子设备相辅相成。它将玩家输入绑定到多种操作，每次玩家按下重映射后的按钮都会触发。输入触发器配置为让玩家在演出进行中切换镜头。

该设备包含十二个可选输入。选定输入后，可以添加 HUD 描述来说明新输入的作用。

该设备修改后的用户选项（User Options）如下，每个设备绑定不同的输入与 HUD 描述，因为它们绑定到不同的过场动画序列设备。

选项值说明
创意模式输入（Creative Input）自定义 5（疾跑）（Custom 5 (Sprint)）定义该设备监听的输入。
HUD 描述（HUD Description）“上一个镜头”（"Previous Camera"）向玩家解释新输入的作用。
已注册玩家行为（Registered Player Behavior）需要注册（Require Registration）REQUIRE REGISTRATION：玩家必须被该设备注册并计数才有资格；ADD REGISTERED：玩家可被注册或计数；IGNORE REGISTERED：玩家必须被计数但不能被注册。

角色设备

角色设备让你可以直接与玩家或场景中的其他角色互动。本模板使用四个角色，在台上表演流程中轮换。

角色设备修改后的用户选项（User Options）如下：

角色（Character）选择角色（Pick a character）决定显示哪个角色。
自定义待机（Custom Idle）坐姿（Sitting）为角色选择自定义待机姿势。
随机待机起始（Random Idle Start）是（True）决定待机是否从随机位置开始。

主角坐在后台楼梯上，其余角色在后面的小房间等候。

尝试从角色（Character）下拉菜单更换不同角色皮肤，看看它们在舞台上的效果！

本模板使用导入的 MetaHuman 动画。有关这些动画如何捕捉与导入的更多信息，请参阅导入 MetaHuman 动画（Importing MetaHuman Animations）页面。

过场动画序列设备

六个过场动画序列设备让坐在椅子设备中的玩家可以从多个角度观看演出。

本页不详细介绍过场动画序列的制作。更多信息请参阅Sequencer 与 Control Rig页面，更深入的内容可查看 如何在虚幻引擎中制作电影（How To Make Movies in Unreal Engine）。

该设备唯一的修改是加载的过场动画序列。

Verse 如何驱动整场演出

本模板使用 Verse 在玩家坐上椅子设备时开演，并将其镜头切换到名为 TV 模式（TV mode）的电影化视角。玩家还可以在多个镜头间切换，并回到 TV 模式（TV mode）或自由视角（Free Look）以获得不同的观看体验。

使用 Verse Explorer 在项目中新建 Verse 设备（Create a new Verse Device），命名为 show_template_device.verse，并将其拖入模板。双击 Verse 文件，在 Visual Studio Code 中打开。

你已在模板中设置好帮助演出运行的设备，现在将在代码（code）中引用这些设备。

向 show_template_device 文件添加以下字段：

  • 首先，在 show_template_device 类（class）定义上方添加名为 log_show_template_device 的 log_channel。
# Create a custom log channel for the show_template_device. This helps with log filtering in complex games with lots of log sources.
log_show_template_device := class(log_channel){}
# A Verse-authored creative device that can be placed in a level
show_template_device := class(creative_device):
  • 在 show_template_device 类定义顶部添加使用 log_show_template_device 通道的日志记录器，以便分辨哪些 Print() 语句来自该设备。
# A Verse-authored creative device that can be placed in a level
show_template_device := class(creative_device):
    # Logger that uses custom log channel.
    Logger:log = log{Channel := log_show_template_device}
  • 一个名为 TheChair 的可编辑（editable）椅子设备，玩家坐上它即开演。
# The chair device the player should sit in.
@editable TheChair:chair_device = chair_device{}
  • 两个可编辑过场动画序列设备（cinematic sequence devices） MainSequence 与 TVModeSequence。MainSequence 是驱动关卡中角色设备动画与音频的过场动画，TVModeSequence 将玩家镜头切换到跟随 MainSequence 多角度切换的观看模式。
# The sequence that drives animation and audio on the character device in the level.
@editable MainSequence:cinematic_sequence_device = cinematic_sequence_device{}
# The sequence that drives the TV mode sequence for viewing in the level.
@editable TVModeSequence:cinematic_sequence_device = cinematic_sequence_device{}
  • 一个名为 CameraSwitches 的可编辑 cinematic_sequence_device 数组（array），存放演出期间玩家可切换的各个镜头。
# A list of alternative camera sequences that are provided to view from during the main sequence.
@editable CameraSwitches:[]cinematic_sequence_device = array{}
  • 四个可编辑 input_trigger_device，分别处理玩家切换镜头模式的输入。ReturnToFreeLook 回到默认镜头，ReturnToTVMode 回到 TVModeSequence，NextCamera 与 PreviousCamera 在 CameraSwitches 数组的过场动画间切换。
# An input trigger that will return us to free look while in the chair.
@editable ReturnToFreeLook:input_trigger_device = input_trigger_device{}
# An input trigger that will return us to TV mode when appropriate in the chair.
@editable ReturnToTVMode:input_trigger_device = input_trigger_device{}
# An input trigger that will choose the next camera while in the chair.
@editable NextCamera:input_trigger_device = input_trigger_device{}
# An input trigger that will choose the previous camera while in the chair.
@editable PreviousCamera:input_trigger_device = input_trigger_device{}
  • 一个名为 CurrentSequence 的可选过场动画序列设备变量（variable），若 TVModeSequence 等正在播放则保存其引用。你不希望多个角色用过场动画同时播放，因此切换到新序列时可用它关闭当前序列。
# The alternative camera sequence that is playing if valid.
var CurrentSequence:?cinematic_sequence_device = false
  • 两个名为 MainSequencePlaying 与 InTvMode 的逻辑变量，分别跟踪 MainSequence 与 TVModeSequence 是否正在播放。
# Helps us track when the main sequence on the character device is playing.
var MainSequencePlaying:logic = false
# When we are in TV mode.
var InTVMode:logic = false
  • 一个名为 CurrentCameraIndex 的 int 变量，跟踪 CameraSwitches 数组中当前播放的过场动画索引。
# Keeps track of what camera we are viewing when using other cameras besides TV Mode.
var CurrentCameraIndex:int = -1
  • 五个可选 cancelable 变量，跟踪模板中引用的所有事件（events）的订阅。当玩家切换镜头、回到自由视角或 TV 模式、退出椅子设备时，需要运行不同的函数（functions）。本教程稍后会将这些函数订阅（subscribe）到触发它们的事件，并保存每个订阅的引用，以便不再需要时取消。
# Subscriptions to all the events we listen for while running.
var ReturnToFreeLookSubscription:?cancelable = false
var NextCameraSubscription:?cancelable = false
var PrevCameraSubscription:?cancelable = false
var ReturnToTVModeSubscription:?cancelable = false
var ChairExitSubscription:?cancelable = false
  • 在 Visual Studio Code 中保存脚本并编译（compile），以更新关卡中的 Verse 设备。
  • 在模板中选中 show_template_device，在细节（Details）面板中将脚本中的每个设备引用指定到关卡中的对应设备，包括各个输入触发器与过场动画序列。

触发序列

演出在玩家坐上椅子设备时开始，你需要在玩家入座后启动过场动画。按以下步骤在玩家坐上椅子时触发主序列，并启动 TV 模式供玩家观看。

  • 向 show_template_device 类添加新函数 RunSequence()，接收开演的代理（agent）并启动 MainSequence 与 TVModeSequence。为 RunSequence() 添加 suspends 修饰符使其异步运行，以便与其他代码并发（concurrently）运行，玩家切换镜头视角时不会打断 RunSequence() 代码。
# Handles running the main sequence which runs the character and TV mode sequences for viewing and then calls a function to await finishing.
RunSequence(Agent:agent)<suspends>:void =
  • 在 RunSequence() 中先调用（call） Sleep() 等待一秒，让玩家入座动画播完再开演。然后在 MainSequence 上调用 Play()，并将 MainSequencePlaying 设为 true。
# Sleep for a second because we just entered the chair and the animation to sit takes a moment.
Sleep(1.0)
# Run the Main sequence on the character device and the TV mode viewing sequence.
Logger.Print("Main Sequence Playing")
set MainSequencePlaying = true
MainSequence.Play()
  • 在 TVModeSequence 上调用 Play() 并传入开演的代理，将其镜头切换为电影化视角。将 InTVMode 设为 true，并调用等待 MainSequence 结束的新函数 AwaitMainSequenceEnding()（下一步设置）。完整的 RunSequence() 代码应如下所示。
# Handles running the main sequence which runs the character and TV mode sequences for viewing and then calls a function to await finishing.
RunSequence(Agent:agent)<suspends>:void =
    Sleep(1.0)
    Logger.Print("Main Sequence Playing")
    set MainSequencePlaying = true
    MainSequence.Play()
    TVModeSequence.Play(Agent)
    set InTVMode = true
    spawn{AwaitMainSequencingEnding(Agent)}
  • 向 show_template_device 类添加新函数 AwaitMainSequencingEnding()，接收来自 RunSequence() 的 agent。该函数同样需要 <suspends> 修饰符，以便在后台运行并在 MainSequence 结束时触发。
# When the main sequence finishes, we clear the flag so that if the player sits back down, it will play again.
AwaitMainSequencingEnding(Agent:agent)<suspends>:void =
  • 在 AwaitMainSequencingEnding() 中对 MainSequence.StoppedEvent() 调用 Await()。MainSequence 结束后将 MainSequencePlaying 设为 false，并用椅子的 Eject() 函数将玩家请出椅子。完整的函数应如下所示。
# When the main sequence finishes, we clear the flag so that if the player sits back down, it will play again.
AwaitMainSequencingEnding(Agent:agent)<suspends>:void =
    MainSequence.StoppedEvent.Await()
    Logger.Print("Main Sequence Ended")
    set MainSequencePlaying = false
    # Kick the player out of the chair after the performance
    TheChair.Eject(Agent)
  • 向 show_template_device 类添加 DoReturnToTVMode() 与 DoReturnToFreeLook() 两个新函数，分别处理玩家回到 TV 模式与自由视角的逻辑（logic），先留空，稍后填充。
# Returns us to our TV viewing mode sequence by checking where the main sequence is and aligning our playback to that point.
DoReturnToTVMode(Agent:agent):void =
    Logger.Print("Return to TV Mode")
# Determine if we are in TV mode or another camera sequence and return control to the main player camera.
DoReturnToFreeLook(Agent:agent):void =
    Logger.Print("Return to Free Look")
  • 向 show_template_device 类添加新函数 OnSeated()，接收坐上 TheChair 的代理。
# This function handles the player sitting down and starting up the performance if it isn't already running and setting up the input triggers.
OnSeated(Agent:agent):void =
    Logger.Print("Player sat down")
  • 在 OnSeated() 中，若 MainSequence 尚未播放，则生成 RunSequence() 并传入坐上椅子的代理；否则用同一代理调用 DoReturnToTVMode()。
OnSeated(Agent:agent):void =
    Logger.Print("Player sat down")
    # If the main sequence is not playing, run it; otherwise return to TV mode.
    if (MainSequencePlaying = false):
        spawn{RunSequence(Agent)}
    else:
        DoReturnToTVMode(Agent)
  • 向 show_template_device 类添加新函数 OnChairExited()，接收退出椅子的玩家，逻辑稍后填充。
# Handles the player leaving the chair and removing access to the input triggers.
OnChairExited(Agent:agent):void =
    Logger.Print("Player got up")
  • 在 OnBegin() 中将 TheChair.SeatedEvent 订阅到 OnSeated() 函数。此后每当有玩家坐上 TheChair，演出即会运行。
# Runs when the device is started in a running game.
OnBegin<override>()<suspends>:void =
    Logger.Print("Standup Template device started")
    TheChair.SeatedEvent.Subscribe(OnSeated)

在 Visual Studio Code 中保存脚本、编译，并在 UEFN 工具栏点击启动会话（Launch Session）试玩模板。运行时坐上椅子设备应能开演并将玩家镜头设为电影化模式，演出结束后玩家应被请出椅子。

切换镜头

演出期间，坐在 TheChair 中的玩家可以在多个镜头视角间切换，由不同的过场动画序列处理。按以下步骤设置切换这些序列的逻辑。

  • 向 show_template_device 类添加新函数 DoCameraSwitch()，接收要切换镜头的代理，以及 CameraSwitches 中过场动画索引对应的 int。
# Switches us between camera sequences, stopping current ones and moving to the next one on the list.
DoCameraSwitch(Agent:agent, Value:int):void =
  • 在 DoCameraSwitch() 中用 if 语句获取 CameraSwitches 数组中 Value 索引处的过场动画，然后检查 CurrentSequence 是否包含过场动画，若有则调用 Stop() 停止当前播放的序列。
DoCameraSwitch(Agent:agent, Value:int):void =
    if (CameraSwitch := CameraSwitches[Value]):
        Logger.Print("Switching Cameras to {Value}")
        # Stop any currently playing other camera sequence.
        if (PlayingSequence := CurrentSequence?):
            PlayingSequence.Stop(Agent)
  • 在 CameraSwitch 上调用 Play() 播放新镜头序列，将 CurrentSequence 设为当前播放的序列，最后用 Register() 为该代理注册 ReturnToTVMode 与 ReturnToFreeLook 输入触发器，以便在观看其他镜头时返回这些模式。完整的 DoCameraSwitch() 函数应如下所示。
DoCameraSwitch(Agent:agent, Value:int):void =
    if (CameraSwitch := CameraSwitches[Value]):
        Logger.Print("Switching Cameras to {Value}")
        if (PlayingSequence := CurrentSequence?):
            PlayingSequence.Stop(Agent)
        CameraSwitch.Play(Agent)
        set CurrentSequence = option{CameraSwitch}
        ReturnToTVMode.Register(Agent)
        ReturnToFreeLook.Register(Agent)
  • 要在上一个与下一个镜头间切换，需设置两个非常相似的函数 DoNextCamera() 与 DoPreviousCamera()。先填充下一个镜头的逻辑：向 show_template_device 类添加新函数 DoNextCamera()，接收要切换镜头的 agent。
# Switches to the next camera on our list, or the first if we are in TV mode.
DoNextCamera(Agent:agent):void =
    Logger.Print("Next Camera")
  • 在 DoNextCamera() 中检查玩家当前是否处于 TV 模式。若是，则 Stop() TVModeSequence，将 InTVMode 设为 false，并将 CurrentCameraIndex 设为 -1（因为接下来要取 CameraSwitches 数组中的下一个镜头，即索引 0）。
# If we are currently viewing from TV Mode, end that sequence and clear values.
if (InTVMode?):
    TVModeSequence.Stop(Agent)
    set InTVMode = false
    set CurrentCameraIndex = -1
  • 然后根据当前镜头的索引算出下一个镜头：将新变量 NextCameraValue 设为 CurrentCameraIndex + 1 与 CameraSwitches.Length 的 Mod，把 NextCameraValue 钳制在 0 到 CameraSwitches 长度之间的值（value），防止越界。得到 NextCameraValue 后将其赋给当前镜头索引，并调用 DoCameraSwitch() 传入 agent 与 CurrentCameraIndex。完整的 DoNextCamera() 函数应如下所示。
# Switches to the next camera on our list, or the first if we are in TV mode.
DoNextCamera(Agent:agent):void =
    Logger.Print("Next Camera")
    if (InTVMode?):
        TVModeSequence.Stop(Agent)
        set InTVMode = false
        set CurrentCameraIndex = -1
    NextCameraValue := Mod(CurrentCameraIndex + 1, CameraSwitches.Length)
    set CurrentCameraIndex = NextCameraValue
    DoCameraSwitch(Agent, CurrentCameraIndex)
  • 要切换到上一个镜头，向 show_template_device 类添加名为 DoPreviousCamera() 的新函数，将 DoNextCamera() 的代码复制进去。检查 TV 模式时将 CurrentCameraIndex 设为 0 而非 -1，并将 NextCameraValue 改为 CurrentCameraIndex - 1 与 CameraSwitches.Length 的 Mod。完整的 DoPreviousCamera() 函数应如下所示。
# Switches us to the previous camera on the list or last camera if we are leaving TV mode.
DoPreviousCamera(Agent:agent):void =
    Logger.Print("Prev Camera")
    if (InTVMode?):
        TVModeSequence.Stop(Agent)
        set InTVMode = false
        set CurrentCameraIndex = 0
    PrevCameraValue := Mod(CurrentCameraIndex - 1, CameraSwitches.Length)
    set CurrentCameraIndex = PrevCameraValue
    DoCameraSwitch(Agent, CurrentCameraIndex)

当玩家坐在 TheChair 中并通过 CameraSwitches 观看其他镜头时，可以回到 TV 模式或自由视角。前面已设置 DoReturnToFreeLook() 与 DoReturnToTVMode() 空函数，现在填充它们。

  • 在 DoReturnToFreeLook() 函数中检查玩家当前是否处于 TV 模式，若是则 Stop() TVModeSequence 并将 InTVMode 设为 false。对 CurrentSequence 同样处理：若包含过场动画则调用 Stop() 并设为 false。
# If TV Mode is active, stop it.
if (InTVMode?):
    TVModeSequence.Stop(Agent)
    set InTVMode = false
# If we are playing another viewing experience, stop it.
if (TempSeq := CurrentSequence?):
    TempSeq.Stop(Agent)
    set CurrentSequence = false
  • 然后用 Register() 为该代理注册 ReturnToTVMode 输入触发器，并 Unregister() ReturnToFreeLook 触发器（已在自由视角时无需再返回自由视角）。完整的 DoReturnToFreeLook() 函数应如下所示。
# Determine if we are in TV mode or another camera sequence and return control to the main player camera.
DoReturnToFreeLook(Agent:agent):void =
    Logger.Print("Return to Free Look")
    if (InTVMode?):
        TVModeSequence.Stop(Agent)
        set InTVMode = false
    if (TempSeq := CurrentSequence?):
        TempSeq.Stop(Agent)
        set CurrentSequence = false
    ReturnToTVMode.Register(Agent)
    ReturnToFreeLook.Unregister(Agent)
  • DoReturnToTVMode() 函数逻辑更多，因为回到 TV 模式时需从 MainSequence 当前时间点启动 TVModeSequence。先检查调用时玩家是否已在 TV 模式，若是则直接 return。再检查 CurrentSequence 是否包含过场动画，若有则 Stop() 并设为 false。
# If we are already in TV mode no need to return to it.
if (InTVMode?):
    return
# If we have another camera sequence playing, stop it and clear values.
if (TempSeq := CurrentSequence?):
    TempSeq.Stop(Agent)
    set CurrentSequence = false
  • 然后获取 MainSequence 的播放进度并从同一位置启动 TVModeSequence：调用 GetPlaybackTime() 获取 MainSequence 播放时间存入 CurrentSeekTime，用 SetPlaybackTime() 设置 TVModeSequence 播放时间，再 Play() 并传入代理，最后将 InTVMode 设为 true。
# Figure out where the main sequence is and start TV mode at the same spot.
CurrentSeekTime := MainSequence.GetPlaybackTime()
TVModeSequence.SetPlaybackTime(CurrentSeekTime)
TVModeSequence.Play(Agent)
set InTVMode = true
  • 最后 Unregister() 该代理的 ReturnToTVMode 输入触发器，并 Register() ReturnToFreeLook 触发器。完整的 DoReturnToTVMode() 函数应如下所示。
# Returns us to our TV viewing mode sequence by checking where the main sequence is and aligning playback.
DoReturnToTVMode(Agent:agent):void =
    Logger.Print("Return to TV Mode")
    if (InTVMode?):
        return
    if (TempSeq := CurrentSequence?):
        TempSeq.Stop(Agent)
        set CurrentSequence = false
    CurrentSeekTime := MainSequence.GetPlaybackTime()
    TVModeSequence.SetPlaybackTime(CurrentSeekTime)
    TVModeSequence.Play(Agent)
    set InTVMode = true
    ReturnToTVMode.Unregister(Agent)
    ReturnToFreeLook.Register(Agent)

将所有内容关联起来

上一部分设置了大量函数，现在要把它们与调用它们的各个输入触发器关联起来。

  • 在 OnSeated() 中 Register() 该代理的 ReturnToFreeLook、NextCamera 与 PreviousCamera 输入触发器（玩家刚坐下时最初可用的触发器），再将各输入触发器订阅到对应函数，设置 ReturnToFreeLookSubscription、NextCameraSubscription 与 PreviousCameraSubscription，同理设置 ReturnToTVModeSubscription 与 ChairExitSubscription。
# Register for the input trigger for free look and subscribe to the pressed event when sitting.
ReturnToFreeLook.Register(Agent)
set ReturnToFreeLookSubscription = option{ReturnToFreeLook.PressedEvent.Subscribe(DoReturnToFreeLook)}
# Register for the input trigger for the next camera and subscribe to the pressed event when sitting.
NextCamera.Register(Agent)
set NextCameraSubscription = option{NextCamera.PressedEvent.Subscribe(DoNextCamera)}
# Register for the input trigger for the previous camera and subscribe to the pressed event when sitting.
PreviousCamera.Register(Agent)
set PreviousCameraSubscription = option{PreviousCamera.PressedEvent.Subscribe(DoPreviousCamera)}
# Register for TV mode return and chair exit.
ReturnToTVMode.Register(Agent)
set ReturnToTVModeSubscription = option{ReturnToTVMode.PressedEvent.Subscribe(DoReturnToTVMode)}
set ChairExitSubscription = option{TheChair.ExitedEvent.Subscribe(OnChairExited)}
  • 向 show_template_device 类添加新函数 CancelSubscription()，接收可选 cancelable 值。在 CancelSubscription() 中检查 Subscription 是否有值，若有则 Cancel()。完整的函数应如下所示。
# Cancel a subscription if it is valid.
CancelSubscription(Subscription:?cancelable):void =
    if (SubscriptionToCancel := Subscription?):
        SubscriptionToCancel.Cancel()
  • 玩家退出椅子时，需停止其身上当前播放的序列，并取消其注册的输入触发器订阅。在 OnChairExited() 函数中，像 DoReturnToFreeLook() 一样检查玩家是否处于 TV 模式，以及 CurrentSequence 是否包含过场动画，若有则分别调用 Stop()，并将 InTVMode 设为 false、CurrentSequence 设为 false。
# Stop the TV camera view when we leave the chair if it is active.
if (InTVMode = true):
    TVModeSequence.Stop(Agent)
    set InTVMode = false
# Stop the camera sequence we were using if it is active when we leave the chair.
if (TempSeq := CurrentSequence?):
    TempSeq.Stop(Agent)
# Clear whatever the current sequence was when we leave the chair.
set CurrentSequence = false
  • 将每个订阅传入 CancelSubscription() 函数取消所有玩家订阅，并 Unregister() 该玩家的所有输入触发器（离开椅子后不应再使用这些按钮）。完整的 OnChairExited() 函数应如下所示。
# Handles the player leaving the chair and removing access to the input triggers.
OnChairExited(Agent:agent):void =
    Logger.Print("Player got up")
    if (InTVMode = true):
        TVModeSequence.Stop(Agent)
        set InTVMode = false
    if (TempSeq := CurrentSequence?):
        TempSeq.Stop(Agent)
    set CurrentSequence = false
    CancelSubscription(ReturnToFreeLookSubscription)
    CancelSubscription(NextCameraSubscription)
    CancelSubscription(PrevCameraSubscription)
    CancelSubscription(ReturnToTVModeSubscription)
    CancelSubscription(ChairExitSubscription)
    ReturnToFreeLook.Unregister(Agent)
    NextCamera.Unregister(Agent)
    PreviousCamera.Unregister(Agent)
    ReturnToTVMode.Unregister(Agent)

在 Visual Studio Code 中保存脚本、编译，并在 UEFN 工具栏点击启动会话（Launch Session）试玩模板。试玩时坐上椅子设备应能开演，演出期间可在 TV 模式、自由视角与多个其他镜头角度间切换，回到 TV 模式时 TV 模式序列应与主序列对齐，演出结束后应回到自由视角并退出椅子。
