使用按钮设备

你可以使用按钮设备(Button Device)激活其他设备。默认状态下按钮不执行任何操作，但只要配置得当，玩家与其交互即可激活另一台设备。

英文原标题：Using Button Devices in Fortnite Creative · 查看英文原文 · 社区翻译镜像，仅供学习

你可以使用按钮(Button)设备激活其他设备(devices)。在默认(default)状态下，按钮不执行任何操作，但只要将其配置为与其他设备协同工作，玩家与按钮交互时，按钮即可激活另一台设备(device)。

关于如何找到按钮设备，请参阅使用设备(Using Devices)。

寻找更多灵感？请参阅按钮设备设计示例(Button Device Design Examples)，激发你的想象力！

如果在岛屿上使用了同一设备的多个副本，为它们重命名(rename)会很有用。选择与设备用途相关的名称，既便于记住每台设备的作用，在使用事件浏览器(Event Browser)查找特定设备时也更方便。

设备选项

要将按钮与另一台设备配对，需要为玩家与按钮的交互指定事件绑定(event binding)。相关设置请参阅直接事件绑定。

你可以通过以下选项配置该设备。

默认值以粗体显示。

选项取值说明
交互时间(Interact Time)即时(Instant)、选择时长决定激活设备所需的交互时长。
激活队伍(Activating Team)任意(Any)、选择队伍编号表示哪个队伍可与按钮交互。使用箭头选择队伍，或点击输入框输入队伍编号。
反选队伍(Invert Team Selection)开(On)、关(Off)若开启，除所选队伍外的所有队伍均可使用该设备。
允许的职业(Allowed Class)任意(Any)、无职业(No Class)、选择职业决定哪个职业可与设备交互。使用箭头选择职业，或点击输入框输入职业编号。
反选职业(Invert Class Selection)开(On)、关(Off)若开启，除所选职业外的所有职业均可使用该设备。
可触发次数(Times Can Trigger)无限(Infinite)、选择数字按钮被触发(triggered)后被禁用(disabled)之前，可被触发的次数。使用箭头选择，或点击输入框输入数字。
延迟(Delay)即时(Instant)、选择秒数按钮被触发后等待多久再发送信号。使用箭头选择，或点击输入框选择时长。
重置延迟(Reset Delay)即时(Instant)、选择秒数按钮发送信号后，多长时间内无法再次被触发。使用箭头选择，或点击输入框选择时长。
触发音效(Trigger Sound)启用(Enabled)、禁用(Disabled)按钮被触发时播放的音效。
游戏开始时启用(Enabled at Game Start)启用(Enabled)、禁用(Disabled)游戏开始时按钮是否自动启用。
交互文本(Interaction Text)输入文本玩家靠近按钮并注视时显示的文本，文本框限 64 个字符。
游戏中可见(Visible During Game)是(Yes)、否(No)若希望按钮在游戏中通常可见，选择“是”。你也可以将按钮设为不可见，并将其附加到道具(prop)上，看起来就像是该道具激活了另一台设备，此时请选择“否”。
交互半径(Interaction Radius)按钮(Button)、选择尺寸若按钮在游戏中可见，选择按钮(Button)；若按钮不可见，则需指明玩家与按钮所附道具交互的最大距离。使用箭头选择距离，或点击输入框输入数字。

直接事件绑定

以下是该设备的直接事件绑定(direct event binding)选项。

函数(Functions)

函数(function)监听设备上的事件，然后执行操作。

  • 对于任一函数，点击该选项，再选择设备(Select Device)，从设备(Device)下拉菜单中访问并选择。
  • 选定设备后，点击选择事件(Select Event)，将设备绑定到会触发该设备函数的事件上。
  • 若多个设备或事件触发同一函数，点击添加(Add)按钮新增一行，并重复上述步骤。
选项说明
收到信号时启用(Enable When Receiving From)启用按钮。
收到信号时禁用(Disable When Receveing From)禁用按钮。

事件(Events)

直接事件绑定使用事件作为发送端，事件通知另一台设备执行函数。

  • 对于任一事件选项，点击该选项(option)，再选择设备(Select Device)，从设备(Device)下拉菜单中访问并选择。
  • 选定设备后，点击选择函数(Select Function)，将计时器绑定到该设备的一个函数上。
  • 若一个事件触发多个函数，点击添加(Add)按钮并重复操作。
选项说明
交互时发送事件至(On Interact Send Event To)当玩家与按钮交互时，向关联设备发送事件。
