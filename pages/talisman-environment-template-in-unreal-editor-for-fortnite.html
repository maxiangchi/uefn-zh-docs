Talisman 环境模板

Talisman: Environment 模板展示了在 UEFN 中创建高度精细、逼真环境的最佳实践。本页介绍其在模块化构建、内存优化、光照与材质等方面用到的关键技术。

英文原标题：Talisman Environment Template In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

本页面是 Talisman: Environment 模板的配套文档，该模板展示了创建高度精细、逼真环境的最佳实践。Talisman 使用模块化构建与优化最佳实践，在 Unreal Editor for Fortnite（UEFN）（Fortnite 虚幻编辑器）中创建。

你可以在项目浏览器（Project Browser）的功能示例（Feature Examples）分区中找到该模板。

在 Fortnite 中输入岛屿代码（Island Code）7100-3544-3074，即可游玩曾在 2024 年游戏开发者大会（Game Developers Conference）上展示的 Talisman 体验。

本概览将带你了解 Talisman 项目在创建过程中遇到的优化挑战，以及每个挑战是如何被解决的：

  • 管理项目与运行时内存限制
  • 使用自定义 UI 元素
  • 照亮大空间
  • 网格体设计与构建
  • 使用动态材质控制设计材质
  • 使用环绕摄像机设备

由于该模板需要运行在所有可用平台上，Talisman 的资产与美术风格必须符合UEFN 的内存与项目大小限制要求。对于采用更精细美术风格的项目，这会带来以下几项挑战：

  • 项目大小：游戏中的高精度资产可能体积很大，而 UEFN 有 400 MB 的项目大小限制。
  • 运行时内存限制：UEFN 有 100,000 内存单位的流送内存限制，同一时间显示在屏幕上的资产、自定义地形与设备数量都会受到限制。
  • 所有受支持平台的质量：这些限制确保你的 UEFN 体验能面向所有 Fortnite 支持平台的全部玩家开放。

UEFN 支持多种技术来满足这些要求，包括细节级别（Levels of Detail，LOD）、分层细节级别（Hierarchical Levels of Detail，HLOD）、世界分区（World Partition）、关卡实例化（Level Instancing）和数据层（Data Layer）。

应用最佳实践

Talisman: Environment 模板旨在展示多种最佳实践与流程，把 3A 级的真实感带入 Unreal Editor for Fortnite。该模板使用以下最佳实践来管理项目与流送内存、优化性能：

  • 创建模块化、轻量的自定义内容。
  • 使用面加权法线改善硬表面几何体的外观。
  • 使用网格体贴花为网格体添加细节。
  • 以配置最低的目标平台为基准构建体验，再从此出发添加功能。
  • 最小化非 Nanite 网格体的绘制调用。

创建模块化、轻量的自定义内容

Talisman 环境使用套件拼装（kitbashing）构建，这是一种模块化建模技术：复用模块化环境中已有的网格体，对其重新利用以创建新资产。通过复用资产，美术师减少了一次性网格体的数量，从而缩小了项目体积。

传统做法是：把高细节、高面数的网格体烘焙映射到低面数网格体上，用独特的烘焙法线贴图（normal map）在两者之间保留细节。这种方法需要额外的纹理贴图，会增大项目体积、运行时开销大，而且在套件拼装流程中扩展性不好。

项目改用带面加权法线的中面数网格体来节省内存，并使用网格体贴花（Mesh Decal）添加小细节。

更多信息请参阅网格体设计与构建。

为所有目标平台构建体验

Fortnite 需要运行在多种平台上。为确保你的内容在每种设备上都给玩家带来最佳体验，重要的是在开发时兼顾所有平台，再针对高端平台叠加额外功能。

例如，Nanite 虚拟化几何体（Nanite virtualized geometry）能帮助各平台渲染高细节网格体并提升性能，但它只适用于运行 DirectX 12 的 PC 等部分高端设备。因此，优化内容、让它在所有平台上都流畅运行仍然很重要。

在使用非 Nanite 网格体时最小化绘制调用

绘制调用（draw call）是指在每一帧告诉图形 API 要绘制什么、如何绘制的过程。Nanite 会按需把几何体流送进场景，从而绕过标准的绘制调用。对于非 Nanite 网格体，场景中的以下每一项都会引发一次绘制调用：

  • 每个单独的网格体。
  • 网格体上的每种材质。
  • 每盏灯光。
  • 每个投射的阴影。

Talisman: Environment 模板同时使用了 Nanite网格体和非 Nanite 网格体。为在使用非 Nanite 网格体的同时优化性能，场景中的绘制调用数量通过以下方式被降到最低：

  • 移除非关键网格体。
  • 移除非关键网格体贴花。
  • 移除投射阴影的灯光，改用光照函数（light function）补光。

管理项目与运行时内存限制

运行时内存管理（memory management）与项目大小管理是在 UEFN 中制作任何项目的关键环节。Talisman: Environment 通过以下方式应对这些挑战：

  • 收窄项目范围。
  • 复用自定义资产。
  • 管理运行时内存。

收窄项目范围

为满足 400 MB 项目大小限制，MetaHuman 角色已被移到 Talisman: MetaHuman 模板中。你可以在项目浏览器（Project Browser）的功能示例（Feature Examples）分区找到该模板。要了解 UEFN 中的 MetaHuman，请参阅Talisman: MetaHuman 模板（Talisman: MetaHuman template）。

细节级别

构建 Talisman 的每个网格体都使用了三种细节级别（Levels of Detail，LOD），以把项目控制在 100,000 流送内存单位预算之内。

LOD 网格体使用 UEFN 的自动 LOD 工具自动生成，并分配给特定的画质等级。关于在 UEFN 中使用细节级别的更多信息，请参阅设置细节级别（Setting the Level of Detail）。

运行时内存管理

Talisman: Environment 模板使用一套自定义流送方案，该方案用数据层（Data Layer）和Sequencer把关卡控制在 100,000 内存单位流送预算之内。货舱区等区域的垂直高度以及走廊的长度，意味着飞船装不进世界分区（World Partition）流送网格。

为克服这一限制，项目把数据层（Data Layer）与 Sequencer 结合，根据玩家位置加载、卸载飞船区域。

每个房间都有各自对应的数据层，飞船各处分布着变异区（Mutator Zone）设备，它们会在关卡序列（Level Sequence）中触发事件。玩家穿过关卡时，这些事件会加载、卸载飞船的不同部分。变异区（Mutator Zone）被策略性地布置在飞船各处，以免被玩家察觉。

该方案与多人游戏体验不兼容。数据层（Data Layer）与关卡序列（Level Sequence）已包含在模板中，但变异区（Mutator Zone）已被移除，使模板适配多人游戏。

使用自定义 UI 元素

该模板使用 Verse 显示自定义任务图标挂件，并在玩家与起始房间的控制台交互时播放音频。

当玩家使用乘员舱语音按钮（Crew Quarters VO Button）设备时，starting_sequence_device.verse 脚本文件会执行以下操作：

using { /Fortnite.com/Devices } using { /Verse.org/Simulation } using { /Fortnite.com/Characters } using { /UnrealEngine.com/Temporary/UI } using { /UnrealEngine.com/Temporary/Diagnostics }
  • 如果欢迎音频仍在播放，则取消欢迎音频。
  • 启用飞船小地图，帮助玩家探索 Talisman。
  • 显示自定义 quest_icon_widget UI 挂件蓝图。
  • 播放一段声音片段。

关于使用 Verse 自定义 UEFN 项目的更多信息，请参阅Verse 编程入门指南（Verse Programming Onboarding Guide）。

照亮大空间

Talisman 使用Lumen 全局光照（Lumen global illumination）照亮环境，为玩家提供遍布飞船的阴影与准确的间接光照。

Lumen 为不受直接光照的物体提供环境光遮蔽与全局光照。Lumen 虽然是创建光照方案的强大工具，但为最大化性能，优化环境仍然很重要。Talisman: Environment 模板在使用 Lumen 的同时做了多项优化。

关卡中所有间接受光静态网格体的投射阴影都被关闭。这些网格体的阴影由 Lumen 出色地提供，因此关闭投射阴影（Cast Shadows）属性在不损失画质的前提下提升了性能。

投射阴影还通过光照函数与部分顶灯的条纹纹理来补充。

自发光灯板的 Lumen 噪点与灯光闪烁，通过为每块灯板搭配一盏不投射阴影的聚光灯来降低。

每块灯板的自发光值被调低，并用一盏不投射阴影的聚光灯补光。每盏聚光灯的作用半径都很小，在提供额外光照的同时，看起来光仍然来自灯板。

环境光照还通过让每盏灯都使用尽可能小的最大绘制距离进一步优化。该设置会在无需渲染时把灯光从视野中剔除。

在照亮 Talisman 的全过程中还使用了光照复杂度（Lighting Complexity）可视化工具。

该视口视图模式以颜色着色显示关卡中影响几何体的非静态光源数量，有助于跟踪光照的性能开销。该可视化工具对最小化关卡中的灯光重叠、控制性能开销很有帮助。

网格体设计与构建

Talisman 精细的室内环境使用套件拼装（kitbashing）与中面数自定义网格体创建。套件拼装是一种强大的技术，它在最小化项目所需资产数量的同时，仍能复用、组合网格体来创建新几何体。

项目中的每个网格体都运用了多种不同技术，在不增加额外几何体的情况下改善资产外观。

面加权法线（face weighted normal）是一种把模型顶点法线与较大的平面对齐的技术，可以在不降低性能的情况下改善着色。

螺栓、品牌标识、破损等细节使用网格体贴花（Mesh Decal）添加。这些贴花使用自定义 UV 把复杂几何体投影到表面上，能够包裹拐角或沿样条拉伸，同时保持外观不变。

使用动态材质控制设计材质

纹理与材质往往是任何 UEFN 项目中体积最大的部分。为进一步缩小项目体积，模板对纹理与材质采用动态方案，避免使用独特的纹理贴图。最终成果采用程序化工作流：用顶点色（Vertex Color）把环境光遮蔽、曲率与遮罩数据存到网格体上，再用存储的数据应用、混合材质。

顶点色数据

最好避免为每个资产使用独特的纹理贴图，改为用顶点色（Vertex Color）把环境光遮蔽、曲率与纹理遮罩数据打包进每个网格体。Talisman 的网格体在设计时配有支撑几何体与足够的网格体密度（每平方英寸多边形数），以在顶点色之间提供平滑渐变，从而在材质之间形成干净的过渡。

数据按以下方式存储：

图（Map）颜色通道（Color Channel）
环境光遮蔽（Ambient Occlusion）红色
曲率（Curvature）绿色
材质 ID 遮罩（Material ID Mask）蓝色

关于顶点色绘制的更多信息，请参阅顶点色材质（Vertex Color Material）。

每个网格体上的材质槽再用来定义网格体的哪部分接受特定材质。关于材质槽的更多信息，请参阅FBX 材质管线（FBX Material Pipeline）。

动态材质控制

Talisman 的网格体组合使用了五种主要材质类型：

  • 金属
  • 涂装金属
  • 塑料
  • 橡胶
  • 织物

每种材质都依赖同一个主材质，该主材质使用世界对齐平铺纹理与用户定义参数生成结果。这样美术师可以在全船复用相同材质，把材质的总体内存开销控制在很低水平。

灰尘、划痕与其他磨损痕迹也包含在主材质中，并使用参数驱动遮罩应用到网格体上。这些参数使用自定义图元数据存放在网格体上。

使用环绕摄像机设备

环绕摄像机（Orbit Camera）设备提供跟随玩家角色、但玩家可自由旋转观察的视角。模板使用该设备，让玩家能在第三人称视角与模拟第一人称视角之间切换。

玩家可以使用环绕摄像机（Orbit Camera）设备在三种不同视角之间切换。

这是通过 camera_switch_mode_device Verse 脚本实现的。

# This file handles swapping between different cameras when an input is pressed. using { /Fortnite.com/Devices } using { /Verse.org/Simulation } using { /Fortnite.com/Characters } using { /UnrealEngine.com/Temporary/Diagnostics }

Verse 代码监听玩家触发目标创意输入（Target Creative Input）动作（默认映射为鼠标右键或手柄左扳机），然后执行以下操作：

  • 从摄像机堆栈中移除当前摄像机。
  • 获取 Cameras 数组中的下一台摄像机。
  • 把新摄像机添加到代理（agent）。
  • 如有需要，隐藏玩家角色。
  • 如有需要，取消隐藏玩家角色。
