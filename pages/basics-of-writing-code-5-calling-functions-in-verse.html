编写代码基础 5：在 Verse 中调用函数

本课学习用表达式组合出可复用的函数、函数调用的写法，以及方法与类的入门概念。

英文原标题：Basics Of Writing Code 5 Calling Functions In Verse · 查看英文原文 · 社区翻译镜像，仅供学习

前置主题：要理解和使用本页内容，请确保你已熟悉以下主题：
  • 第 4 课：编写简单代码

到目前为止，你已经学会创建常量和变量来存储和使用值，也学会了用 if 表达式以及 and、or 等决策运算符在代码中做决策。

现在是时候学习如何编写可以在程序中轻松复用的代码了。

还记得第 2 课里讲过：表达式是能产生结果的最小代码单元吗？还记得当表达式执行并输出一个值时，输出的那个值就是结果吗？

你可以利用这一点让代码更高效。

表达式可以和其他表达式组合成函数（function），函数可以在代码中反复使用，而不用每次都重写它的逻辑。

在函数中使用表达式

函数（function）（也叫例程（routine））是可复用的代码，用于说明如何执行某个动作，或如何根据输入产生输出。

函数由组合起来的表达式构成。

要定义一个函数，你需要：

  • 一个唯一的名字，即标识符（identifier）。
  • 将产生的信息类型（type）。
  • 函数被调用时要做什么。

函数的基本语法如下：

name() : type = codeblock

下一课会详细介绍代码块（code block），现在你只需要知道：代码块就是用来放组成函数的那些表达式的地方。

函数与函数调用

函数本质上就是你起了名字的一系列表达式。

程序通过调用（calling）函数的名字来使用函数。调用会唤起（invoke）（激活）该函数，这就是函数调用（function call）。

这意味着：你不用一遍遍重复写函数里的所有表达式，而是把它们打包成一个有名字的函数；之后每次在程序中调用它，计算机都会回头找到这个函数并执行其中的表达式。

举个例子：与其让 CoinsPerMousetrap 永远等于 100，不如写一段代码，每次运行时随机选一个值来改变它。

在下面的例子中，该表达式被设为用 GetRandomInt(1, 10) 生成一个 1 到 10 的随机数。

分解如下：

GetRandomInt()

这是 Verse（Verse）中的内置函数，顾名思义——生成一个随机整数。

1, 10

表示它能生成的数字范围。如果你写 20, 50，就会生成 20 到 50 的数字。注意范围要写在 () 里，而 () 是这个表达式名字的一部分。

这是函数调用，因为它告诉计算机去调用那个函数，按你设定的 1 到 10 范围取一个随机整数。

当你想在代码中使用函数时，可以按名字调用它。每次调用 GetRandomInt() 都会生成一个新的随机数。

你可以用它随机改变捕鼠器的价格：

using { /Fortnite.com/Devices }
using { /Verse.org/Simulation }
using { /UnrealEngine.com/Temporary/Diagnostics }
using { /Verse.org/Random }
OnBegin<override>()<suspends> : void =
    # Initialize Coins to 500. Because it is a var, you can change it later.
    var Coins : int = 500
    # Initialize CoinsPerMousetrap with a random integer between 1 and 100

注意上面示例几乎每行代码都有注释，解释这行代码做了什么。无论是你过段时间回头看，还是其他程序员想补充或修改你的代码，这都很有帮助。

方法

还记得第 2 课讲过类型决定了存放在变量或常量里的值可以执行哪些运算吗？类型还有其他作用。

类型有属于自己的运算，也有属于自己的函数。这些函数叫方法（method），必须用特殊方式调用。

普通函数直接写名字调用即可（比如 Print() 或 GetRandomInt()），而方法调用（method call）必须以变量（或常量）名开头，后跟一个 .，再写方法名。例如，在变量 Cat 上调用方法 Pounce() 要写成：

Cat.Pounce()

类

类（class）是用来创建具有相似行为和属性的事物的模板。类是复合（composite）类型，意味着它由来自其他类型的一组数据打包而成。

定义类之后，该类的数据可以被任何子类（subclass）继承（inherit）。

而方法就是依附在类上的函数。正因如此，不是每个方法都适用于每种类型：方法必须在该类型的类定义中声明，或在该类型继承的类中声明。如果现在还没完全理解，别担心——这只是快速入门，后面还会深入讲类。

总结

  • 函数是起了名字的表达式序列，可以复用。
  • 函数也叫例程。
  • 函数能省时间、减少错误，因为你不必反复输入（或维护）多行相同的代码。
  • 当你在一行代码中复用函数时，用的就是函数调用。
  • 方法是属于某种类型的函数，必须在该类型的变量或常量上调用。
  • 类是复合类型，可以把来自其他类型的数据组合起来，再把行为和属性共享给子类。
