Telekineticon 念力抓取器

Telekineticon 是一件可以悬浮并移动道具的物理道具，用它可以制作农场收集、温馨搬家等物理玩法，乃至复杂的平台跳跃物理解谜。

英文原标题：Telekineticon in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

注：本文介绍的是实验性（Experimental）功能，使用了该功能的项目无法发布。

Telekineticon（念力抓取器）是一件物理道具，可以把岛屿上任意位置的道具悬浮起来并移动。你可以用它制作简单的物理 gameplay 循环，比如农场模拟器里的收集物品，或者温馨搬家 RPG。

也可以用它搭建复杂物理解谜的积木，服务于平台跳跃游戏。

使用 Telekineticon（Telekineticon），只要你与道具的距离在抓取范围（grab range）内、且不超过断开距离（break distance），就能悬浮起绝大多数启用了物理的道具。也就是说，你必须离道具足够近才能拿起它，拿起之后一旦离它太远，抓取就会断开。例如道具卡在了门框上而你还在往前跑，抓取最终就会断开；牵引光束被物体挡住也会导致断开。

抓取范围与断开距离都是可自定义的 Verse 参数，可以调整 Telekineticon（Telekineticon）的行为，让它最适合你的项目。

其他可调参数还包括保持朝向（hold orientation）、抓取点类型（hold point type）和抓取刚度（hold stiffness）。

保持朝向（Hold orientation）决定道具是保持被拿起时的朝向，还是会在半空中受力（比如蹭到墙）时跟着旋转。

保持朝向：抓取时（As Grabbed）

保持朝向：无（None）

抓取点类型（Hold point type）决定 Telekineticon（Telekineticon）抓住道具的哪个位置：可以是开火瞬间准星指着的位置，也可以是道具的质心。

如果玩家必须把道具摆到特定位置才能完成任务（比如拿起钥匙插进钥匙孔），抓取点与朝向就非常重要。

抓取刚度（Hold stiffness）调整拖动道具的手感。你可以把它想象成用绳子拖着物体走和用铁钳夹着物体走的区别：都能把物体挪动，但操控感完全不同。调整抓取刚度可以改变玩家完成任务的难度。

下一节你会学到如何在 UEFN 中启用 Telekineticon（Telekineticon），之后还会用学到的知识创建一个可以用物理解开的简单解谜。

使用 Verse 启用 Telekineticon

本教程需要 IDE，例如 Visual Studio Code。

配置 Fortnite 虚幻编辑器

开始之前，你的岛屿必须启用物理。步骤如下：

  • 在大纲（Outliner）中选中 Island Settings（岛屿设置）设备。
  • 在细节面板（Details Panel）的 Physics（物理）分组下，勾选 Enable Physics (Beta)（启用物理（测试版））。

同时，编辑器还必须启用自定义物品与背包（Custom Items and Inventory）。步骤如下：

  • 在编辑器主工具栏选择项目 > 项目设置（Project > Project Settings）。
  • 在项目设置（Project Settings）窗口搜索 Custom Items and Inventory（自定义物品与背包）并勾选复选框。

下一节你将用 Verse 为岛屿接入 Telekineticon（Telekineticon）。

为岛屿添加 Telekineticon

按以下步骤添加 Telekineticon（Telekineticon）：

  • 在编辑器主工具栏选择 Verse > Verse 资源管理器（Verse > Verse Explorer）。
  • 在 Verse 资源管理器（Verse Explorer）页签右键点击岛屿根节点（你的岛屿名称），选择创建 Verse 文件（Create Verse File）。
  • 在创建 Verse 脚本（Create Verse Script）窗口选择 Verse 设备（Verse Device），并在设备名称（Device Name）中输入 Telekineticon_example。

设备名随便起都可以，但要使用本教程提供的代码，就必须用这个名字。

  • 点击创建空文件（Create Empty）。
  • 在 Verse 资源管理器（Verse Explorer）页签双击刚创建的 .verse 文件，它会在 VS Code 中打开。
  • 在 VS Code 中粘贴下面的 Verse 代码。
using { /Fortnite.com/Devices } using { /Fortnite.com/Items } using { /Verse.org/Simulation } using { /Verse.org/SceneGraph } using { /UnrealEngine.com/Itemization } TCategory<public><localizes>:message := "Telekineticon Parameters Examples" Trigger_tooltip<public><localizes>:message := "A trigger device to add the telekineticon item to the player inventory." GrabRange_tooltip<public><localizes>:message := "The distance, in cm, objects can be grabbed. If `0.0` or a negative value is provided, there is no range."
  • 点击构建（Build），看到构建成功的确认信息即可。
  • 在内容浏览器（Content Browser）中找到项目文件夹，把新的 Verse 设备拖入视口。
  • 点击名为 Telekineticon Example 的 Verse 设备，在细节面板（Details Panel）中找到 Trigger 参数，通过下拉菜单或吸管工具指定 Trigger。

如果岛屿里已经有多个 Trigger，记得选对那一个。

点击启动会话（Launch Session）测试设备。

踩上触发器后，Telekineticon（Telekineticon）就会出现在背包里。不过此时对着岛屿上的道具左键点击还没有任何反应，因为你还没有给任何道具启用物理。下一节就来做这件事。

创建物理解谜

物理解谜经常包含这样一个简单任务：把物体放到按钮上，然后发生点什么。本节你要搭建一个 Trigger：当道具落到上面时升起一个平台，让玩家够到战利品。

给道具启用物理

启用物理的步骤如下：

  • 在内容浏览器（Content Browser）中选中要用的道具，在细节面板（Details Panel）点击 +添加（+Add）按钮。
  • 搜索并选择 Fort Physics。
注：物理道具无法造成原生伤害。添加物理组件后，道具原有行为（如岩浆）会被覆盖。

关于给道具添加物理的更多信息，见物理入门（Getting Started with Physics）。

创建触发器

创建触发器的步骤如下：

  • 从内容浏览器（Content Browser）把 Trigger（触发器）设备拖入视口。
  • 在细节面板（Details Panel）的用户选项 > 高级（User Options > Advanced）下，勾选 Triggered by Physics Props（可被物理道具触发）。

创建移动平台

创建移动平台的步骤如下：

  • 从内容浏览器（Content Browser）拖一个道具到视口，把它当作平台。
  • 从内容浏览器（Content Browser）拖一个 Prop Mover（道具移动器）到视口。
  • 在细节面板（Details Panel）的 Prop Selection（道具选择）旁选择 From Reference（来自引用）。
  • 在 Prop Reference（道具引用）下选择你的平台。
  • 在用户选项（User Options）下取消勾选 Should Move from Start（开局即移动）。
  • 在高级（Advanced）下设置：
  • 玩家碰撞行为（On Player Collision Behavior）设为继续（Continue）。
  • 碰撞玩家伤害（Player Damage on Collision）设为 0。
  • 路径完成动作（Path Complete Action）设为往返（Ping Pong）。
  • 在用户选项 - 函数（User Options - Functions）下，找到 Start（启动）旁的 +（添加）按钮并点击。
  • 选择你的触发器。
  • 在下拉菜单中选择 On Triggered（被触发时）。

现在，当玩家把物理道具丢到触发器上时，平台就会移动。接下来可以调整 Prop Mover（道具移动器）的速度、距离、移动方向，以及 Telekineticon（Telekineticon）的各项参数，让它们最适合你自己的项目。
