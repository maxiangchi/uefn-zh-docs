使用忍者神龟（TMNT）岛屿

坏蛋们小心了，忍者神龟在 UEFN 与 Fortnite 创意模式中登场！借助全新的 TMNT 资产，打造包含喜爱的角色、环境与道具的动作体验。

英文原标题：Working With TMNT Islands In Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

前置主题：要理解和使用本页内容，请先熟悉以下主题：访问品牌内容（Accessing Brand Content）。

坏蛋们小心了，忍者神龟（Teenage Mutant Ninja Turtles）在 Unreal Editor for Fortnite（UEFN，Fortnite 虚幻编辑器）与 Fortnite 创意模式中登场！借助全新的 TMNT 资产，你可以打造包含喜爱的角色、环境与 TMNT 世界道具的动作体验。无论是在纽约街头打造史诗大战，还是在下水道设计终极训练道场，UEFN 都能让你借助有史以来最知名的 IP 之一制作游戏。

使用品牌（Brands） > TMNT 下的基础地图创建项目，即可获得三个定制模板、完整的 TMNT 角色阵容，以及丰富的 TMNT 主题预制件与图库（prefabs and galleries）。每项资产都为无缝融入 Fortnite 生态而设计，为你的项目带来标志性的 TMNT 风味。

你可以在 UEFN 内容浏览器的 TMNT 文件夹和游戏内创意物品库中访问这些资产。

创建、试玩测试并打磨好岛屿后，就可以向世界分享你的创意了！发布前请确保岛屿符合忍者神龟品牌规则（Teenage Mutant Ninja Turtles Brand Rules）。

TMNT 岛屿模板

让你的体验更上一层楼！探索街机（Arcade）、次元 X 起始（Dimension X Starter）与城市起始（City Starter）模板。每个模板都经过精心设计，点燃你的想象，让你忍不住大喊"Cowabunga!"。

次元 X 起始（Dimension X Starter）岛屿提供异世界风貌的地貌，是打造多维 TMNT 冒险的完美起点。在外太空旋转的天空下雕琢荒芜的地貌（Sculpt the barren landscape），布设黏液（ooze）池。

次元 X 起始岛（Dimension X Starter Island）

街机模板（Arcade template）展示了一款复古街机横版卷轴游戏，包含经典 TMNT 敌人、环境障碍与自定义玩家界面（user interfaces）。街机（Arcade）教程会带你逐步搭建玩法的每个元素，为玩家带来妙趣横生的体验。

街机模板（Arcade Template）

城市起始模板（City Starter template）运用多种视觉手法，将 TMNT 世界的卡通魅力展现得淋漓尽致。教程教你运用关卡设计、后期处理与自定义灯光等游戏设计元素，让体验在视觉上更上一层楼。

发布 TMNT 岛屿

发布 TMNT 岛屿与通过创作者门户发布其他 Fortnite 创意岛屿流程相同。要了解从 UEFN 发布的流程，请参阅发布项目（Publishing Projects）。

在 UEFN 与创意模式中使用 TMNT 角色

在 UEFN 与创意模式中，凡是能使用角色外观（character outfits）的地方，都可以生成所有可用的 TMNT 角色，包括四位标志性的神龟、盟友与可怕的反派。在 UEFN 与创意模式中使用以下设备，即可开始创作玩法、制作过场动画，借助全套 TMNT 角色打造全新玩法体验。

  • 守卫生成器（Guard Spawner）
  • 角色设备（Character Device）
  • NPC 生成器（NPC Spawner）

要在角色设备（Character Device）或守卫生成器（Guard Spawner）设备中使用 TMNT 角色，前往细节（Details）面板，使用角色外观（Character Cosmetic）下拉菜单。

要在 NPC 生成器中使用，先创建新的NPC 角色定义（NPC Character Definition），再使用角色外观 NPC 修改器（Character Cosmetic NPC Modifier）。

TMNT 角色生成器

鼠怪（Mouser）NPC

与 TMNT 角色阵容一同推出的还有鼠怪（Mouser）。这种敌方 NPC 拥有独特的动画、玩法与音频，专为 TMNT 主题体验打造。鼠怪属于 NPC 生成器（NPC Spawner）设备的一部分，该设备仅在 UEFN 中可用。

按以下步骤将鼠怪添加到场景，先创建 NPC 角色定义（NPC Character Definition）：

  • 在内容抽屉（Content Drawer）中，导航到你的项目文件夹。
  • 右键点击文件夹空白处，选择人工智能（Artificial Intelligence） > NPC 角色定义（NPC Character Definition）。
  • 为角色定义命名，然后双击缩略图编辑 NPC 属性。
  • 在角色类型下拉菜单中选择鼠怪（Mouser）。

你可以使用 NPC 角色定义（NPC Character Definition）资产或 NPC 生成器（NPC Spawner）设备将鼠怪放入场景。

  • 将角色定义拖入地图。
  • 将 NPC 生成器设备拖入地图，然后在细节面板中添加你的角色定义。

要了解该设备与角色定义的更多信息，请参阅NPC 生成器设备（NPC Spawner Devices）与NPC 角色定义（NPC Character Definitions）。
