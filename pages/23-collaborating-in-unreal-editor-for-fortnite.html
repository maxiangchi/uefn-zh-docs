在 UEFN 中协作

多人共建同一个 UEFN 项目：用版本控制协同编辑，同步团队项目，授予编辑与复制权限。

英文原标题：Collaborating in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

多人可以使用 UEFN 的版本控制（version control）系统，在同一个 Unreal Editor for Fortnite（UEFN）项目（project）上协作。要编辑不属于你的 UEFN 项目，你必须加入该项目所属的团队。

要在 UEFN 中创建团队，点击项目（Project） > 与团队共享（Share with Team），随后会打开创作者门户（Creator Portal）。

不能与未满 18 周岁的人在 UEFN 项目上协作。

团队与团队项目管理的更多内容，请参阅在创作者门户创建团队。

编辑可以在 UEFN 和与之对应的创意模式岛屿上同时进行（创意模式侧可编辑的程度有限），Live Edit 会话期间的更改会即时呈现在 UEFN 和创意模式两侧。

在项目中打开资产（asset）后，编辑前必须先检出（check out）。如果该资产正被他人检出，UEFN 不会让你访问；但任何未被协作队友检出的资产，你都可以访问。

提交更改后，项目保存在 UEFN 中。只要在本会话中打开过资产，即使没有编辑，UEFN 也会要求你先保存并提交这些资产，否则不允许退出。

协作会话期间在创意模式中所做的编辑，只能从 UEFN 保存。

UEFN 中受版本控制的团队项目，对分配到该项目的全体团队成员可见。团队成员可以在项目浏览器（Project Browser）的项目下拉菜单中选择自己的团队，打开团队项目。团队项目从创作者门户分配给团队成员，当项目分配给团队后，就可以在 UEFN 中打开了。

在 UEFN 中打开并编辑团队项目之前，务必先同步团队项目。

先创建并命名一个新项目，再添加 Lore 版本控制。项目打开后，你就可以向视口添加设备与道具并保存了。

点击关卡编辑器工具栏（level editor toolbar）中的 Launch Session > Start Game，在 Fortnite 创意模式客户端中试玩你的岛屿。

连接建立后，朋友或同事可以从 Fortnite 大厅左侧的社交面板选择你的名字，点击加入小队（Join Party） > 加入（Join），加入试玩会话。他们会自动接入 Live Edit 会话，并能用自己的 Fortnite 创意模式对项目做编辑。

保存时，在 UEFN 右下角点击启用版本控制（Enable Source Control），选择提交内容（Submit Content），签入 Live Edit 会话期间的所有更改。

同步团队更改

同步全部更改：

  1. 打开 UEFN，在项目浏览器界面选择团队项目（Team Projects）。
  2. 选择要同步的团队项目，你会收到本地副本版本过期的警告。

需要同步的团队项目，缩略图角落会有一个云形图标。

  1. 打开项目，选择同步项目更改的位置。

同步项目耗时从几秒到几分钟不等，取决于更改的数量与文件大小。

文件同步成功后，就可以开始在这个项目上工作了。

团队项目完成、准备发布时，点击项目菜单（Project menu） > 上传到私有版本（Upload to Private Version），确认更改并保存项目。UEFN 会把项目上传到创作者门户，你可以在此发布岛屿。

更多信息请参阅发布 UEFN 项目。

编辑会话中掉线

Live Edit 会话期间网络可能中断。一旦发生，客户端与 UEFN 中的界面都会显示断开状态。如果继续在 UEFN 中工作，客户端会保持禁用，直到你重新接入会话，但编辑仍可进行。

在 UEFN 中完成编辑后，再次点击运行按钮即可保存项目并重连客户端。项目会在客户端中刷新，呈现你在 UEFN 中取得的进展。

团队项目发布的相关信息，请参阅发布 UEFN 项目。

在你的岛屿上授予编辑与复制权限

你可以授权朋友和同事访问并互动你创建的 UEFN 岛屿体验。注意他们只能在会话期间访问下载到的内容，离开后该岛屿对他们不再可用。

选中要邀请的人，选择邀请加入小队（Invite to Party）。

按 Tab 键，选择我的岛屿（My Island），再选择权限（Permissions）选项卡。朋友加入小队后，他的玩家代号（gamertag）会显示在该页面上。

把他的权限从游玩（Play）改为编辑与复制（Edit and Copy）。

现在朋友可以从自己的创意模式中心穿过你的金色裂缝，出生到你的岛屿上。会话期间他可以移动岛屿上的自定义资产，但不能更改材质，也不能使用 UEFN 中的特效。

获取他人岛屿的编辑与复制权限

如果你要加入创建了新体验的朋友，按以下步骤操作。

启动 Fortnite 客户端，加入朋友的小队（party），目的地设为创意模式（Creative）。所有玩家准备（ready up）后，按下开始（Play）。

出生到创意模式中心后，你会看到两道金色裂缝：你自己的和朋友的。朋友的玩家名会显示在他传送门所通岛屿名称的上方。

走近传送门时，你会看到该传送门的内容正在烘焙、准备下载。

下载完成后跳入传送门。

上岛后，房主需要像上一节你为他操作那样，为你授予飞行、编辑与复制权限。
