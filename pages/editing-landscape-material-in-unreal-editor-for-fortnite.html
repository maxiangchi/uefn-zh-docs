编辑地形材质

UEFN 为自定义地形提供多种材质实例，可用 Landscape Mode 的 Paint 工具编辑地形表层。本页介绍选择材质实例、绘制地形，以及从零创建自定义地形材质的完整流程。

英文原标题：Editing Landscape Material In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

Unreal Editor for Fortnite（UEFN）（Fortnite 虚幻编辑器）为自定义地形提供多种不同的材质实例，你可以用地形模式（Landscape Mode）创建自定义地形。地形模式（Landscape Mode）中的绘制（Paint）工具提供编辑地形表层的方法。请从以下材质实例中为你的地形选择：

  • MI_Landscape_Chpt2（Apollo）
  • MI_Landscape_Chpt4（Asteria）
  • MI_Fortnite_Customizable_01

Chapter 2 材质实例是经典 Fortnite 大逃杀地形材质（material）。Chapter 4 地形材质来自 Fortnite 大逃杀第四章。

两款大逃杀材质实例都会创建带花草的草原，并模拟风吹过草地的效果。除这些特性外，Chapter 4 材质实例会自动生成小灌木，并用 Niagara 模拟风中飘动的树叶与飞舞的蝴蝶。

Customizable 材质实例是扁平材质。对该材质使用地形模式（Landscape Mode）中的绘制（Paint）工具，可以创建湿草地、泥土斑块等效果。

选择 Customizable 材质实例

使用地形模式（Landscape Mode）为你的岛屿创建自定义地形。创建地形的管理（Manage）阶段决定自定义地形的大小，并指定地形材质。

从材质（Material）下拉菜单选择材质实例，上文提到的材质实例与许多其他地形材质类型都可以在这个下拉菜单中找到。

要为地形材质创建自定义外观，请从下拉菜单选择 MI_Fortnite_Customizable_01。这会把可自定义材质设为地形网格体的材质，再用绘制（Paint）阶段工具为每一层打开材质实例编辑器。通过编辑图层信息，可以改变图层外观。

关于创建自定义地形的更多信息，请参阅创建自定义地形（Create a Custom Landscape）教程。

绘制地形材质

  • 使用三种主要材质实例之一创建新地形。
  • 选择各个地形流送代理，用你创建的自定义地形材质更换其材质。
  • 点击地形模式（Landscape Mode）各阶段中的绘制（Paint）。
  • 向下滚动到图层（Layers）。
  • 从列表选择任意图层，绘制到地形上。
  • 从图层列表选择 Layer7，这会在内容浏览器中打开所有图层材质实例。

绘制（Paint）工具中有些图层被锁定，专供样条使用。当你用样条创建路径或道路时，这些材质会用于样条网格体。

创建自定义地形材质

创建带多个图层的自定义地形材质，配合绘制（Paint）工具编辑地形。你将创建包含三个图层（泥土、岩石、砾石）的材质。先创建文件夹存放材质，在新文件夹内右键创建材质缩略图。

基础层

双击材质缩略图打开材质图表。图表打开后，添加以下材质节点：

  • Constant 3Vector 节点
  • Constant 节点
  • SetMaterialAttributes 节点
  • Texture Sample 节点

选择 Constant 3 Vector 材质节点并添加颜色。现在可以创建你的节点网络（node network）了：

  • 在材质图表中选择第一个 SetMaterialAttributes 节点。
  • 点击细节（Details）面板数组（Array）字段中的 + 图标，创建基础颜色（Base Color）数组槽。
  • 重复第 2 步三次，再创建三个数组槽。在细节（Details）面板添加数组槽的同时，SetMaterialAttributes 节点上会增加相同的数组输入。
  • 编辑数组槽，选中以下数组：
    • Base Color
    • Specular
    • Roughness
    • Normal
  • 把 Constant 节点的值改为 0.5。
  • 从 Constant 节点拖出连线，接到 SetMaterialAttributes 节点的高光（Specular）输入。
  • 再次从 Constant 节点拖出连线，接到 SetMaterialAttributes 节点的粗糙度（Roughness）输入。
  • 从 Constant 3Vector 节点的白色引脚拖出连线，接到 SetMaterialAttributes 节点的基础（Base）输入。
  • 选择 Texture Sample 节点。
  • 在 Material Expression Texture Base 字段的 Texture 槽添加 T_Asteria_Mud_01_N 法线纹理。
  • 从 Texture Sample 节点的 RGB 输出引脚拖出连线，接到 SetMaterialAttributes 节点的法线（Normal）输入。

这就是未绘制任何图层时显示在地形上的基础（Base）材质。

图层一

下一个节点网络是地形材质图层，位于地形基础材质层之下的目标图层（Target Layer）中。该网络使用优化节点——地形图层切换（landscape layer switch），让未绘制该图层的地形组件少承担数据开销。

添加以下材质节点：

  • Constant 3Vector 节点
  • Constant 节点
  • SetMaterialAttributes 节点
  • Texture Sample 节点
  • Landscape Layer Switch 节点
  • Blend MaterialAttributes 节点
  • Landscape Layer Sample 节点，并命名为 Layer 1

选择 Constant 3 Vector 材质节点并添加颜色。现在可以创建你的节点网络了：

  • 在材质图表中选择第一个 SetMaterialAttributes 节点。
  • 点击细节（Details）面板数组（Array）字段中的 + 图标，创建基础颜色（Base Color）数组槽。
  • 重复第 2 步三次，再创建三个数组槽。在细节（Details）面板添加数组槽的同时，SetMaterialAttributes 节点上会增加相同的数组输入。
  • 编辑数组槽，选中以下数组：
    • Base Color
    • Specular
    • Roughness
    • Normal
  • 把 Constant 节点的值改为 0.5。
  • 从 Constant 节点拖出连线，接到 SetMaterialAttributes 节点的高光（Specular）输入。
  • 再次从 Constant 节点拖出连线，接到 SetMaterialAttributes 节点的粗糙度（Roughness）输入。
  • 从 Constant 3Vector 节点的白色引脚拖出连线，接到 SetMaterialAttributes 节点的基础（Base）输入。
  • 选择 Texture Sample 节点。
  • 在 Material Expression Texture Base 字段的 Texture 槽添加 T_Asteria_RockCliff_03_N 法线纹理。
  • 从 Texture Sample 节点的 RGB 输出引脚拖出连线，接到 SetMaterialAttributes 节点的法线（Normal）输入。
  • 从 SetMaterialAttributes 节点拖出连线，接到 BlendMaterialAttributes 节点的 B 输入。
  • 从 Landscape Layer Sample 节点拖出连线，接到 BlendMaterialAttributes 节点的 Alpha 输入。

Landscape Layer Sample 节点为地形工具中可绘制的目标图层命名。

该材质节点必须是地形材质的一部分，才会显示在绘制（Paint）工具的图层下。

该节点自动采样同名的地形图层遮罩纹理及其对应通道。

新建地形 LayerInfo 资产时，该材质技术要求在使用绘制（Paint）工具时把图层设为地形模式（Landscape Mode）中的非权重混合图层（Non Weight-Blended Layer）。

  • 从基础层的第一个 SetMaterialAttributes 节点拖出连线，接到 BlendMaterialAttributes 节点的 A 输入。
  • 从基础层的第一个 SetMaterialAttributes 节点拖出连线，接到 Landscape Layer Switch 节点的 LayerNotUsed 输入。
  • 选择 Landscape Layer Switch，在细节（Details）面板把参数名（Paramter Name）改为 Layer 1。
  • 从 BlendMaterialAttributes 节点拖出连线，接到 Landscape Layer Switch 节点的 Layer Used 输入。

上图使用转接（reroute）节点保持材质图表整洁。转接节点不是完成本教程必需的。关于节点连接的更多知识，请参阅虚幻引擎文档中的连接节点（Connecting Nodes）。

图层二

下一个节点网络位于图层一之下的图层。该网络同样使用 Landscape Layer Switch，让未绘制该图层的地形组件少承担数据开销。

添加以下材质节点：

  • Constant 3Vector 节点
  • Constant 节点
  • SetMaterialAttributes 节点
  • Texture Sample 节点
  • Landscape Layer Switch 节点
  • Blend MaterialAttributes 节点
  • Landscape Layer Sample 节点，并命名为 Layer 2

选择 Constant 3 Vector 材质节点并添加颜色。现在可以创建你的节点网络了：

  • 在材质图表中选择第一个 SetMaterialAttributes 节点。
  • 点击细节（Details）面板数组（Array）字段中的 + 图标，创建基础颜色（Base Color）数组槽。
  • 重复第 2 步三次，再创建三个数组槽。在细节（Details）面板添加数组槽的同时，SetMaterialAttributes 节点上会增加相同的数组输入。
  • 编辑数组槽，选中以下数组：
    • Base Color
    • Specular
    • Roughness
    • Normal
  • 把 Constant 节点的值改为 0.5。
  • 从 Constant 节点拖出连线，接到 SetMaterialAttributes 节点的高光（Specular）输入。
  • 再次从 Constant 节点拖出连线，接到 SetMaterialAttributes 节点的粗糙度（Roughness）输入。
  • 从 Constant 3Vector 节点的白色引脚拖出连线，接到 SetMaterialAttributes 节点的基础颜色（Base Color）输入。
  • 选择 Texture Sample 节点。
  • 在 Material Expression Texture Base 字段的 Texture 槽添加 T_Asteria_FrozenGravel_01_N 法线纹理。
  • 从 Texture Sample 节点的 RGB 引脚拖出连线，接到 SetMaterialAttributes 节点的法线（Normal）输入。
  • 从 SetMaterialAttributes 节点拖出连线，接到 BlendMaterialAttributes 节点的 B 输入。
  • 从 Landscape Layer Sample 节点拖出连线，接到 BlendMaterialAttributes 节点的 Alpha 输入。
  • 选择 Landscape Layer Switch，在细节（Details）面板把参数名（Paramter Name）改为 Layer 2。
  • 从 BlendMaterialAttributes 节点拖出连线，接到 Landscape Layer Switch 节点的 Layer Used 输入。
  • 从第一个 Landscape Layer Switch 节点拖出连线，接到第二个 BlendMaterialAttributes 节点的 A 输入。
  • 从第一个 Landscape Layer Switch 节点拖出连线，接到第二个 Landscape Layer Switch 节点的 LayerNotUsed 输入。

由于图层二在这里与图层一之后混合，图层二会绘制在图层一之上。使用无权重混合图层（No-Weight Blend Layer）时，绘制（Paint）工具中目标图层（Target Layer）的排列顺序无关紧要。

要完成材质，请选择主材质节点，在细节（Details）面板打开使用材质属性（Use Material Attributes）。

再从 Layer 2 Landscape Layer Switch 拖出连线，接到主材质节点（Main Material Node），即完成自定义地形材质。

主材质节点采用你为材质指定的名称。

使用自定义地形材质

现在可以用自定义材质在已创建的地形上绘制现有地形。在大纲（Outliner）面板选择 Landscape Streaming Proxy。

在细节（Details）面板把自定义材质赋给地形材质（Landscape Material）槽。

从选择（Selection）下拉菜单切换到地形模式（Landscape Mode），在地形各阶段中选择绘制（Paint）。在这里，你的新材质及其所有图层会与其他地形材质一起显示在目标图层（Target Layers）菜单中。

使用自定义材质前，必须把每个自定义图层都转为非权重混合图层：选择 + 图标 > 非权重混合图层（Non Weight-Blend Layer） > 保存（Save），对自定义材质的每一层重复此步骤。

现在选择自定义材质即可绘制地形。

结果

至此，自定义地形材质已经创建完成并可用于绘制，你的地形可以呈现泥土、岩石、砾石多层混合的自定义外观。
