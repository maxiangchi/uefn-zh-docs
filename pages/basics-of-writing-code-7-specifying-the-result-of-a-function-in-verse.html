Verse 代码基础 7：指定函数的返回值

函数可以在调用时返回一个值，这个值就是结果（result）。本课将学习如何在函数签名（function signature）中指定返回类型，并使用返回（return）关键字提供结果。

英文原标题：Basics of Writing Code 7: Specifying the Result of a Function in Verse · 查看英文原文 · 社区翻译镜像，仅供学习

前置知识

要理解和使用本页内容，请确认你已熟悉以下主题：

  • 第 6 课：在 Verse 中定义函数

函数可以执行操作。函数能做的一件事，就是在你调用它时返回一个值。这个值就是结果（result）。

例如，当你调用 GetRandomInt(1, 10) 时，你会期望得到一个 1 到 10 之间的随机整数。

要改变你希望从函数中获得的值的类型，需要修改函数签名（function signature）中的类型。例如：

GetNumberOfMousetrapsYouCanAfford() : int

在这个例子中，GetNumberOfMousetrapsYouCanAfford() 的返回类型是 int，因此每当你在代码中调用 GetNumberOfMousetrapsYouCanAfford() 时，都可以期望它返回一个整数。

GetNumberOfMousetrapsYouCanAfford() : float

另一方面，如果你把类型改为 float，它就会返回另一种类型的值。

当函数指定了返回类型后，函数主体（函数体，代码块，code block）必须产生与该类型匹配的结果。如果不匹配，代码将无法编译——也就是说会出现编译器错误。准备好学习如何避免这种情况了吗？

结果与返回

结果（result）就是函数在执行（运行，execute）时返回（return）的值。

第 2 课介绍过关键字（keyword），它们是 Verse 内置的特殊单词，每个关键字都附带了非常明确的行为。

在 Verse 中，返回（return）也是一个关键字（keyword），它告诉函数提供紧跟在 return 关键字之后的表达式所产生的值，作为函数的结果。

MyFunction() : int = return 5
OnBegin<override>()<suspend> : void = MyFunction() # result is 5

在上面的例子中，当调用 MyFunction() 时，这段代码将返回（return）值 5。

省略 return 并不会破坏你的函数，但显式写出 return 是良好的编程习惯。如果你想进一步了解，请参阅 Functions（函数）相关文档。

提前返回（Early Returns）

当程序执行到 return 表达式时，程序会立即退出函数代码块。这意味着，如果你把 return 表达式放在其他代码之前，后面的代码将不会执行。当满足某个指定条件、需要提前退出函数时，这种写法非常有用。

下面的函数会根据 CoinsPerMousetrap 更新 Coins 变量。但是，Coins 变量必须为正值才能购买捕鼠器。如果 Coins 为负数，函数会打印一条错误消息并立即返回，因为此时再运行函数体中的其余代码已经没有意义。

事实上，如果没有 return，函数会错误地继续扣减 Coins 的值，而且永远不会提示 Coins 为负数的问题。

var Coins : int = -10
CoinsPerMousetrap : int = 100
BuyMousetrap() : void =
    if (Coins < 0):
        Print("Error: Coins set to negative value")
        return
    set Coins = Coins - CoinsPerMousetrap
    Print("Mousetrap bought! You have {Coins} coins left.")

提前使用 return 退出函数也可能引入缺陷，因此必须谨慎使用。例如，在下面的代码中，由于 return 会在 Print("Mousetrap bought! You have {Coins} coins left.") 之前运行，函数将永远不会打印 Coins 的新值。

var Coins : int = 500
CoinsPerMousetrap : int = 100
BuyMousetrap() : void =
    if (Coins < 0):
        Print("Error: Coins set to negative value")
        return
    set Coins = Coins - CoinsPerMousetrap
    return
    Print("Mousetrap bought! You have {Coins} coins left.")

如果代码中存在提前 return，代码仍然可以通过编译，但 Visual Studio Code 会警告你：return 之后的表达式将不会运行。

无有效结果的函数使用空类型（Void for Functions with No Useful Result）

有时候你需要结果，有时候则不需要。

如果你还记得第 2 课中的类型（type），你可能还记得每种类型都需要特定种类的值。下面的列表非常简短。Verse 使用很多类型，但以下是最常见的几种，也是使用变量和常量的基础。

类型说明取值
logic该值类型只能为真或假。true / false
int整数是整数（不是分数），int 即 integer（整数）的缩写。整数
float该类型用于非整数的值，例如分数。带小数点的数字
string该类型用于任何文本，可以是字母、数字、标点、空格，甚至表情符号。😻字母、数字、标点、空格、表情符号

当你创建的函数不需要产生结果时，可以把函数的返回类型设为 void（空类型）。

这意味着代码块中的最后一个表达式可以产生任意类型的值，而不会引发编译器错误，因为该函数的类型已被设为空类型（void）。

对于返回类型为 void 的函数，你仍然可以使用 return 关键字——只不过不需要在 return 关键字后面提供值。

小结

  • 结果（result）是调用函数时从函数中获得的返回值。
  • 在代码块中，最后一个表达式将产生结果（result）。
  • 要改变函数中值（value）的类型，需要修改函数签名（function signature）中的类型（type）。
  • 返回（return）是一个关键字，它告诉函数提供紧随其后的表达式所产生的值。
  • 提前返回（early return）是指在代码块结束之前使用 return 关键字。这会导致程序立即退出该代码块，不再运行块中剩余的代码。
  • 空类型（void）表示函数的值不会在其他地方使用，或者说不值得特别处理。你可以把不需要产生结果的函数类型设为 void。
