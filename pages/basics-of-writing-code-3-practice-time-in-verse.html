编写代码基础 3：练习时间（Verse）

假设你正在制作一款魔法药水游戏：本练习将带你声明并初始化玩家生命值、伤害量与治疗量，动手区分 Verse 中的常量（Constant）与变量（Variable），并用 Print() 在日志中验证结果。

英文原标题：Basics Of Writing Code 3 Practice Time In Verse · 查看英文原文 · 社区翻译镜像，仅供学习

前置主题：阅读本页前，请确认你已熟悉 第 3 课：存储与使用信息（Lesson 3: Storing and Using Information）。

假设你正在制作一款带有魔法药水（Magic Potion）的游戏。药水有不同的效果——可以治疗玩家，也可以伤害玩家。你需要声明并初始化一些常量（Constant）与变量（Variable），用来保存玩家生命值，以及药水造成的伤害量或治疗量。

但哪些应该是常量，哪些应该是变量呢？

var PlayerHealth : float = 100.0
PotionDamageAmount : float = 20.0
PotionHealAmount : float = 10.0

这里修改的变量与常量并不会真正影响你的 Fortnite 角色生命值，不过在后面的课程中，你会学到具体的做法！

玩家的生命值会随着游戏进行、使用不同的药水而变化。一想到变化，就应该想到变量（Variable）。

另一方面，在游戏过程中去改变药水造成的伤害量或治疗量并没有什么意义，所以它们应该声明为常量（Constant）。

如果你现在写代码去改变 PlayerHealth 变量，却不在日志中打印点什么，就无法判断代码是否生效。为了验证效果，请声明并初始化下面这个字符串常量和字符串变量。注意文本末尾与最后一个英文引号之间要加一个空格。

PlayerStatusText : string = "Player health now "
var EffectOnPlayerText : string = "damaged "

现在可以改变玩家的生命值了。要改变变量的值，必须在表达式开头使用 set 关键字。PotionDamageAmount 应该从 PlayerHealth 中减去，所以使用 - 运算符。

set PlayerHealth = PlayerHealth - PotionDamageAmount

PlayerHealth 变化之后，你需要看到证据！调用下面两行 Print() 即可。

Print("The Player was {EffectOnPlayerText + ToString(PotionDamageAmount)}")
Print("{PlayerStatusText + ToString(PlayerHealth)}")

看起来像是在对字符串做数学运算，实际上你是在用 + 运算符拼接字符串，这称为拼接（Concatenation）。ToString() 函数会把你的 float 型变量和常量转成 string 版本，这样 Print() 才能使用它们。

现在运行这段代码，你应该会看到打印出的两行新内容：

The Player was damaged 20.0
Player health now 80.00

接下来请你自己动手，对 PotionHealAmount 做同样的事情。

  • 使用正确的关键字和运算符来改变 PlayerHealth。
  • 你还需要修改 EffectOnPlayerText 变量，让打印出来的句子通顺合理。
  • 最后，打印出玩家生命值受到了怎样的影响，以及当前的生命值。先自己尝试，如果需要帮助，再看下面的代码。
set PlayerHealth = PlayerHealth + PotionHealAmount
set EffectOnPlayerText = "healed "
Print("The Player was {EffectOnPlayerText + ToString(PotionHealAmount)}")
Print("{PlayerStatusText + ToString(PlayerHealth)}")

完整脚本

以下是本课使用的完整脚本框架：

using { /Fortnite.com/Devices }
using { /Verse.org/Simulation }
hello_world_device := class(creative_device):
    # Runs when the device is started in a running game
    OnBegin<override>()<suspends> : void =
        PotionDamageAmount : float = 20.0
        PotionHealAmount : float = 10.0
