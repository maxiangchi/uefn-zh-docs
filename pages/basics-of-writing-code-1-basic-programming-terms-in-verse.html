写代码基础 1：Verse 基本编程术语

学会用 UEFN 进入 Verse 之后，下一步是掌握基本编程术语。本课从最基础的概念讲起：程序、Verse、编译、算法、源代码与机器代码、错误与 Bug，帮你为后续课程打好语境与连贯基础。

英文原标题：Basics of Writing Code 1 Basic Programming Terms in Verse · 查看英文原文 · 社区翻译镜像，仅供学习

前置主题

要理解并使用本页内容，请确保熟悉以下主题：

  • 修改并运行你的第一个 Verse 程序（Modify and Run Your First Verse Program）

既然你已经知道如何用 UEFN 进入 Verse，下一步是确保你对基本编程术语有良好的理解。

本课从非常基础的内容讲起。即使你已经知道这些术语，也请花一分钟在这里复习。有时后面的课程会引用前面的内容，因此保持课程之间的语境与连贯性是好事。

什么是程序

程序（program）是一组指令，告诉计算机如何做事。程序告诉计算机如何接收输入（receive input）（进入的信息）与返回输出（return output）（出去的信息）。

Verse

Verse 是一种为电子游戏与模拟而设计的编程语言，非常适合游戏专属需求。

Verse 程序做什么

Verse 程序解决问题。

但计算机非常较真，就像与灯神签契约，你得到的东西与你要求的分毫不差，分毫不差。

当程序员想当然地假设会发生什么，而没有给出精确指令时，就会出错。

编译

程序写出来是为了让人类理解，但计算机需要把程序翻译成计算机理解的东西。

这由编译器（compiler）完成，它将程序从人类可读语言转换（编译（compiles））为机器语言。

算法

算法（algorithm）是为解决问题或完成任务而编写的一组指令，可以把它看作程序应如何工作的模型。

到喂猫时间了？喂猫算法可能是：

  • 从架子上拿一罐猫粮。
  • 拿起猫碗放在台面上。
  • 在碗旁放一把勺子。
  • 打开猫粮罐头。
  • 用勺子盛到猫碗里。
  • 把碗放到猫够得着的地方。
  • 等待 12 小时，然后重复。

这些步骤若顺序错乱，可能导致猫吃不上饭。按顺序执行，就能得到一只开心吃饱的猫。

猫吃上饭了！

当算法重复执行时，就称为循环（loop）。

猫每天喂两次，天天如此。这个过程处于循环中，会一直运行直到被打断。（如果过程失败，猫会提交一份报告——一份大声的口头报告。）

在 Fortnite 创意模式中，当你用设备搭建游戏机制时，就是在搭建算法。玩家如何达成游戏目标？哪个设备推进 gameplay？哪个设备阻挡？如果用错设备或顺序用错会怎样？

Verse 编程是将算法转换为计算机能理解的指令、创建游戏机制的好方法。一旦你“学会歌词”，曲调就会又快又有趣——你还有机会创造 Fortnite 创意模式中没有的机制！

测试算法

渴了吗？看看算法在现实生活中如何运作。

  • 为泡一杯好茶或咖啡写出算法。
  • 严格按你的算法冲泡这杯饮品。
  • 茶泡好尝过之后，好喝吗？
  • 如果好喝，你的算法就完成了。
  • 如果不好喝，你需要调试步骤，找出遗漏或做错的步骤，然后
  • 迭代（Iterate）（带着一处或多处设计改动重复）一次又一次，直到得到完美的一杯。

源代码与机器代码

源代码（Source code）（简称代码（code））是程序员编写的程序。之所以叫源代码，是因为它是程序被编写时的版本——是程序的源头。机器代码（Machine code）是程序被编译为计算机能理解的东西之后的结果。

代码与程序可互换使用，程序员有时也被称为码农（coders）。

执行

当计算机执行程序中的步骤时，就是在运行（runs）或执行（executes）该程序。代码未按预期执行，或编译失败，说明代码中有错误（errors）。

代码中的错误

代码中的错误有两种表现方式：

  • 编译器错误（Compiler errors）——代码无法编译为计算机能理解的语言。
  • Bug——代码编译成功，但程序运行不符合预期。

编译器错误

编译器错误最常见的原因是不正确的语法（syntax）。（我们稍后会谈 Bug。）每种编程语言都遵循一套精确的规则，称为语法。（这些规则因程序而异，但本系列课程聚焦 Verse 语法。）

语法是词语与符号的组合方式，让编译器能理解并编译程序员的指令。

语法涵盖代码中可用的词语与符号，以及它们必须如何排列，编译器才能成功编译。

在英语中，主语（名词）| 谓语是标准语法，主语在前、谓语在后。句子 "Kitty sleeps" 符合这些语法规则。但如果你说 "Sleeps kitty"，别人可能会疑惑你在说什么。在编程中更是如此，还记得本课开头的灯神契约吗？

还记得灯神契约吗？

Verse 代码区分大小写。意思是该大写而没有大写，或不该大写却大写了，Verse 都会将其视为语法错误，代码无法编译。空格的用法也必须与语法所示一致，这一点同样重要。

语法正确的表达式语法错误的同一表达式
Print("Hello, world!")Print("Hello, World!"

第二个示例中有编译器错误，因为缺少右括号 )。

语法错误属于编译器错误，因为它们阻止代码成功编译。

Bug

Bug 是程序能执行，但做了奇怪或意外的事。

语法关乎词语与符号及其排列方式，而语义（semantics）关乎这些代码行实际意味着什么。

例如在英语中，基本句子由主语与谓语构成，主语是谁或什么，谓语是主语（名词）在做什么或是什么状态。

主语（名词）| 谓语（语法）并没有传达 Kitty sleeps（语义）的含义。

代码含义上的错误会产生 Bug。

正确的表达式有 Bug 的同一表达式
# If at least one mouse is caught, you win if (MiceCaught > 0): Print("Win!") else: Print("Lose!")# If at least one mouse is caught, you win if (MiceCaught > 1): Print("Win!") else: Print("Lose!")

第二个示例中有 Bug，因为 MiceCaught 必须大于 1 才会执行 Print("Win!") 表达式。

另一种理解方式是看程序执行时发生了什么，结果符合预期吗？还是出问题了？

在上面右侧的示例中，玩家抓住一只老鼠却不能获胜，因为代码要求抓住大于一只老鼠才能获胜。如果只有一只老鼠可抓，就永远达不成胜利条件。因此程序能正常编译，结果却不是你（或玩家）想要的。

总结

  • 程序通过确定如何输入与输出信息，告诉计算机如何做事。
  • 计算机非常较真，你告诉它做什么它就精确执行——即使你告诉错了。
  • 程序必须从人类语言编译为计算机语言。
  • 算法是一种模型，展示程序应如何工作。
  • 源代码是人类可读写的东西，机器代码是计算机能理解并执行的东西。
  • 语义是代码的含义。
  • 语法是编写代码的规则集。
  • 编译器错误是阻止程序编译的错误。
  • Bug是代码编译成功，但程序运行不符合预期的情况。

练习时间！

  • 第 1 课：练习时间！练习编写算法，直到熟练掌握其运作方式。
