物品组件（Item Component）

在自定义物品与物品栏系统中，item_component 是一个定义物品“是什么、不是什么”的类；只有带该组件的实体才会被视为物品并正确加入物品栏。

英文原标题：Item Component in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

注：这是一项 Beta 功能，欢迎学习使用，但在正式发布作品时请谨慎使用。

在自定义物品与物品栏（Custom Items and Inventories）系统中，item_component 是一个定义物品“是什么、不是什么”的类。关于如何为实体（entity）添加组件（component），请参阅使用实体与组件（Working with Entities and Components）。

只有带 item_component 的实体才会被视为物品。没有该组件的实体无法被正确加入物品栏，自定义物品与物品栏的大量功能也可能无法正常工作。

  • 文中提到“物品（item）”，指的就是带 item_component 的实体。
  • 文中提到“物品栏（inventories）”，指的就是带 inventory_component 的实体。

类定义（Class Definition）

为实体挂载 item_component，该实体就成为一个物品（item）。物品拥有若干可被其他组件利用的属性：

  • 可被物品栏操作；
  • 可被拾取和丢弃；
  • 可被装备（equip）与卸下（unequip）。

你还可以通过挂载更多组件来赋予物品更多功能，以暴露不同特性与基础 Fortnite 玩法；也可以编写自己的自定义 Verse 组件。更多信息请查阅 Verse API 中的 item_component API 参考。

完整的自定义物品与物品栏组件列表，请参阅组件（Components）。

物品组件（Item Component）

为该预制件赋予 item_component 后，它就可以作为物品存入物品栏了。

Verse：物品（Verse: Items）

item_component 包含可通过 Verse 使用的字段、函数（functions）和事件（events）：

  • GetParentInventory[]——让物品可以找到自己的父级物品栏；
  • Categories——item_category 数组，可用于分类与描述物品；
  • Equip()、Unequip() 与 IsEquipped[]——用于管理物品的装备状态；
  • ChangeEquippedEvent——每当调用 Equip() 或 Unequip() 时，就会在该物品组件上触发此事件；
  • ChangeInventoryEvent——监听物品在不同物品栏之间的移动。

示例（Example）

实体必须带物品组件才能作为物品发挥作用。预制件编辑器（Prefab editor）中可编辑的属性有限，要充分发挥该组件的作用，你需要使用 Verse。

using { /Fortnite.com/Devices }
using { /Verse.org/SceneGraph }
using { /Verse.org/Simulation }
using { /UnrealEngine.com/Itemization }

# 该设备会在玩家加入游玩空间（Playspace）时为所有玩家创建一个物品。
# 物品创建后会自动拾取到玩家物品栏中。
item_giver_device := class(creative_device):
    OnBegin<override>()<suspends>:void = ...

通过派生 item_component 子类，可以轻松为物品添加功能。派生类可以修改基础属性，也可以添加专属于你的体验的新函数与新字段。

using { /UnrealEngine.com/Itemization }
using { /Fortnite.com/Itemization/FortniteItemCategories }

custom_item_component := class(item_component):
    # 可以用 Fortnite 和/或自定义物品分类填充 Categories 数组。
    # 例如这里使用了 Resource（资源）物品分类类型。
    Categories<override>:[]item_category = array{Resource}
