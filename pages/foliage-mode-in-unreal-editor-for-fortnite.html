UEFN 中的植被模式（Foliage Mode）

植被模式提供了一种在地形上快速创建森林与树林的方法，用植被工具为项目添加树木、灌木、花草，打造逼真的景观。

英文原标题：Foliage Mode In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

植被模式（Foliage Mode）提供了一种在地形上快速创建森林与树林的方法，打造逼真的景观。使用植被工具决定如何在项目中添加树木、灌木、花草等。该编辑模式与景观模式（Landscape Mode）配合使用。

工作原理

要进入植被模式，点击选择模式（Selection Mode）下拉菜单并选择 Foliage Mode，视口窗口左侧会打开植被模式面板。（关于该模式的深入介绍，请参阅虚幻引擎的植被模式（Foliage Mode）文档。）

要使用植被模式工具，先打开内容浏览器（Content Browser），然后把选中的植被静态网格体（static meshes）从 Environment > Foliage 文件夹拖入网格体列表（Mesh List）。你可以添加的不只是树木或草地——任何类型的静态网格体都可以加入网格体列表。

植被模式也支持导入的静态网格体。植被模式不支持 Fortnite 道具（Props），因为这类元素带有蓝图脚本，会像被风吹动一样摇摆树木与灌木，而静态网格体则完全静止。

在为关卡灰盒（greyboxing）规划植被摆放位置时可以使用植被模式。先用建模模式（Modeling Mode）创建简单形体，再把形体加入网格体列表并绘制到地形上，预览植被的整体效果。

植被工具

植被模式使用可缩放的工具，你可以为每个工具单独设置偏好，也可以为网格体列表中的全部植被按植被类型统一调整。

选择（Select）

把静态网格体拖入网格体列表以在项目中使用，或用搜索栏搜索特定的静态网格体。

点击 +Foliage 按钮，从下拉菜单中选择静态网格体，或创建使用网格体实例化（mesh instancing）的新静态网格体资产，用于非交互植被。

全选（All）

选中项目中全部使用植被模式工具放置的静态网格体。

你可以用它创建所选植被的副本并移动副本，或直接移动全部所选植被。

取消选择（Deselect）

取消选择项目中全部使用植被模式放置的静态网格体。

无效项（Invalid）

选中无效的植被实例。

这些植被网格体未与数据层对齐，悬浮在其上方。利用该工具可以避免地形上方出现漂浮的植被。

套索（Lasso）

框选一片已放置的植被或已加入网格体列表的植被，选中后可以复制或移动套索圈住的植被。

绘制（Paint）

用地形绘制网格体列表中选中的植被。

绘制设置决定绘制时应用到地形的静态网格体的分布与数量。

重新应用（Reapply）

从网格体列表中选择一个或多个网格体，修改世界中已放置植被实例的设置：

  • 选择重新应用工具（Reapply tool），然后在网格体列表中选择要应用更改的植被类型。
  • 在 Foliage Details 部分进行修改。
  • 把更改绘制到关卡中的植被实例上。

单个（Single）

在单个位置绘制单个植被实例。

如果网格体列表中有多个静态网格体，选中单个工具时会在同一位置一次性应用全部网格体。

填充（Fill）

用选中的植被填满目标地形块，也可作用于为地形创建的其他静态网格体。

擦除（Erase）

从地形上擦除选中的植被。

如果你不想擦除全部植被，可以取消勾选不希望从场景中擦除的植被。

移除（Remove）

从地形上移除全部选中的植被。

移动（Move）

把选中的植被移动到当前关卡。

该工具与数据层（Data Layers）配合，先识别植被所在的数据层，再提供将其移动到另一数据层的方法。

绘制工具

使用绘制工具缩放、旋转植被，向项目中添加植被，功能远不止于此。

画笔选项

  • 画笔大小（Brush Size）——决定画笔的大小。
  • 绘制密度（Paint Density）——决定画笔范围内静态网格体实例的数量与间距。
  • 擦除密度（Erase Density）——按住 Shift 键擦除植被时保留植被的密度。
  • 单实例模式（Single Instance Mode）——在鼠标光标处绘制单个植被实例。
  • 放置到当前关卡（Place in Current Level）——把植被网格体放置到当前关卡，还是放置到被绘制网格体所在的关卡。

过滤器

  • 景观（Landscape）——在景观上放置植被。
  • 静态网格体（Static Meshes）——在静态网格体上放置植被。
  • BSP——在 BSP 上放置植被。
  • 植被（Foliage）——在另一个植被网格体上放置植被。
  • 半透明（Translucent）——在半透明几何体上放置植被。
  • +Foliage——选择要加入项目的静态网格体。
  • 网格体（Mesh）——当前选中的静态网格体。
  • 组件类（Component Class）——植被实例使用的组件类。你可以创建 FoliageInstancedStaticMeshComponent 的蓝图子类来实现自定义行为，并在此指定该类。
  • 覆盖材质（Override Materials）——添加新的材质数组以覆盖植被实例。
  • Nanite 覆盖材质（Nanite Override Materials）——为植被实例添加新的 Nanite 材质覆盖数组。

绘制

  • 密度 / 1Kuu（Density / 1Kuu）——按此密度放置植被实例，单位为每 1000×1000 单位面积的实例数。
  • 半径（Radius）——植被实例之间的最小距离。
  • 单实例模式覆盖（Single Instance Mode Override）——在单实例模式下绘制时，用于覆盖检测与其他实例碰撞的默认设置的选项。
  • 单实例模式半径（Single Instance Mode Radius）——单实例模式下用于检测与其他实例碰撞的半径。
  • 缩放（Scaling）——指定绘制时植被实例的缩放行为。
  • X 缩放（Scale X）——指定应用于植被实例 X 轴缩放属性的最小到最大缩放范围。
  • Y 缩放（Scale Y）——指定应用于植被实例 Y 轴缩放属性的最小到最大缩放范围。
  • Z 缩放（Scale Z）——指定应用于植被实例 Z 轴缩放属性的最小到最大缩放范围。
  • 按通道的顶点色遮罩（Vertex Color Mask by Channel）——使用颜色通道（RGBA）为植被实例创建顶点遮罩。

放置

  • Z 偏移（Z Offset）——指定应用于植被实例 Z 轴位置偏移的最小到最大范围。
  • 对齐法线（Align to Normal）——植被实例的角度是否偏离垂直方向以匹配所绘制表面的法线。勾选对齐法线且不勾选随机偏航（Random Yaw）时，实例会旋转，使 +X 轴指向下坡方向。
  • 平均法线（单组件）（Average Normal Single Component）——平均法线时是否丢弃来自其他命中组件的法线。
  • 随机偏航（Random Yaw）——勾选后，植被实例绕垂直轴应用随机偏航旋转。
  • 随机俯仰角（Random Pitch Angle）——可为每个实例在原始角度基础上应用指定度数以内的随机俯仰调整。
  • 地面坡度角（Ground Slope Angle）——仅在与水平面夹角处于指定角度范围内的表面上放置植被实例。
  • 高度（Height）——放置植被实例的有效海拔范围，用世界坐标 Z 的最小值与最大值指定。
  • 包含的景观图层（Inclusion Landscape Layers）——若指定图层名称，在景观上绘制时仅限绘制有指定图层的景观区域生成植被。
  • 排除的景观图层（Exclusion Landscape Layers）——若指定图层名称，在景观上绘制时排除未绘制指定图层的景观区域。
  • 与世界碰撞（Collision with World）——勾选后，每个实例放置前会与现有世界几何体做重叠测试。
  • 平均法线采样数（Average Normal Sample Count）——平均法线时，在命中位置周围使用的射线追踪数量。

实例设置

  • 可移动性（Mobility）——应用于植被组件的可移动性属性。
  • 剔除距离（Cull Distance）——使用 PerInstanceFadeAmount 材质节点时实例开始淡出的距离。设为 0 表示禁用该选项。当整个聚合超过该距离时，聚合会被完全剔除、不再渲染。
  • 投射阴影（Cast Shadow）——控制植被是否投射阴影。
  • 影响动态间接光照（Affect Dynamic Indirect Lighting）——控制植被是否向光传播体积注入光照。仅在 CastShadow 为 true 时使用。
  • 影响距离场光照（Affect Distance Field Lighting）——控制该图元是否影响动态距离场光照。仅在 Cast Shadow 为 true 时使用。
  • 投射动态阴影（Cast Dynamic Shadow）——控制在非预计算阴影下植被是否投射阴影。仅在 Cast Shadow 为 true 时使用。
  • 投射静态阴影（Cast Static Shadow）——植被是否从投射阴影的光源投射静态阴影。仅在 CastShadow 为 true 时使用。
  • 投射接触阴影（Cast Contact Shadow）——对象是否投射接触阴影。仅在 CastShadow 为 true 时使用。
  • 光照贴图分辨率（Light Map Resolution）——覆盖静态网格体中定义的光照贴图分辨率。
  • 碰撞预设（Collision Presets）——选择碰撞预设。你可以在项目设置（Project Settings）中设置该数据。
  • 自定义可导航几何体（Custom Navigable Geometry）——若图元影响导航网格，应调用 DoCustomNavigableGeometryExport() 导出该图元的可导航几何体。
  • 半透明排序优先级（Translucent SortPriority）——决定半透明对象的优先级。
  • 按双面投射阴影（Cast Shadow as Two Sided）——该植被是否按双面材质投射动态阴影。
  • 接收贴花（Receives Decals）——植被是否接收贴花。
  • 光照贴图类型（Lightmap Type）——控制该组件使用的光照贴图类型。
  • 用作遮挡体（Use as Occluder）——勾选后，植被会渲染预通道以遮挡其他图元，并能正确接收 DBuffer 贴花。勾选该设置可能带来负面的性能影响。
  • 光线追踪可见（Visible in Ray Tracing）——勾选后，静态网格体在光线追踪中可见。
  • 计算世界位置偏移（Evaluate World Position Offset）——勾选后，在静态网格体 LOD 中计算世界位置偏移。
  • 世界位置偏移禁用距离（World Position Offset Disable Distance）——设置世界位置偏移被禁用的距离。
  • 光照通道（Lighting Channels）——为光照选择 0-2 的通道。
  • 渲染 CustomDepth 通道（Render CustomDepth Pass）——为 true 时，植被在 CustomDepth 通道中渲染（通常用于描边）。
  • CustomDepth 模板写入掩码（Custom Depth Stencil Write Mask）——模板缓冲写入使用的掩码。
  • CustomDepth 模板值（CustomDepth Stencil Value）——在 CustomDepth 通道中向模板缓冲写入该 0-255 值。需要在项目设置中设置或 r.CustomDepth = 3。

可扩展性

  • 启用密度缩放（Enable Density Scaling）——该植被类型是否受引擎可扩展性系统中植被可扩展性设置的影响。对不影响玩法游戏的细节网格体启用，对重要的内容禁用。通常，对无碰撞的小网格体（草地）启用，对有碰撞的大网格体（树木）禁用。
  • 启用加载时丢弃（Enable Discard on Load）——启用 CVarFoliageDiscardDataOnLoad 时是否丢弃该植被类型。
  • 启用剔除距离缩放（Enable Cull Distance Scaling）——该植被类型是否受引擎 "foliage.CullDistanceScale" 设置的影响。

虚拟纹理

  • 绘制到虚拟纹理（Draw in Virtual Textures）——引擎将实例绘制到的运行时虚拟纹理数组。网格体材质也需要设置为输出到虚拟纹理。Draw in 控制该组件是否同时在主通道与虚拟纹理中绘制。
  • 虚拟纹理跳过 Mip（Virtual Texture Skip Mips）——为该图元渲染运行时虚拟纹理时跳过的低层 mip 数量。数值越大，在运行时虚拟纹理中的有效绘制距离越短。该剔除方式不考虑图元大小与虚拟纹理尺寸。

HLOD

  • 包含在 HLOD 中（Include in HLOD）——勾选后，植被包含在 HLOD 绘制中。
