直接事件绑定入门

直接事件绑定（direct event binding）让设备之间可以直接通信：用事件（event）与函数（function）替代频道（channel），工作流更直观，复杂多样的游戏机制得以实现。

英文原标题：Getting Started with Direct Event Binding in Fortnite Creative · 查看英文原文 · 社区翻译镜像，仅供学习

直接事件绑定（direct event binding）将扩展你在创意模式（Creative）中能实现的效果。有了直接事件绑定，设备之间可以直接通信，工作流更加直观，你可以更自由地追逐自己的设计想法。切换到这套系统，是创造更复杂、更多样游戏机制的下一步。

为什么设备通信方式正在改变

直接事件绑定系统消除了频道（channel）通信系统固有的限制。你再也不用担心达到频道数量上限。由于设备通过事件绑定直接通信，在设计岛屿时无需提前规划频道分配。当你复制粘贴设备时，也无需编辑它们来更改频道分配——原来设置的事件与函数会原样带到副本上。

事件与函数介绍

设备不再发送与接收信号，而是使用事件（event）与函数（function）。当设备被激活，或玩家执行某个动作时，就是一个事件的例子。事件会触发其他设备执行特定动作或设定特定条件，而这个动作或条件就是函数。你需要把一个设备上的事件绑定到另一个设备上的函数。在大多数情况下，原来的发送端（transmitter）选项如今对应事件，原来的接收端（receiver）选项如今对应函数。

直接事件绑定如何工作

直接事件绑定不再分配频道，而是使用设备名称来指定多个设备之间发生的事件与函数。设备会自动获得唯一标识符，但那只是一串字母与数字的组合，因此，为设备起一个有意义、具描述性的名称非常重要。

转换现有岛屿

直接事件绑定目前是可选加入（opt-in）系统，但最终会成为默认系统。当你想把现有岛屿转换到新系统时，建议先复制一份岛屿，在副本上测试转换效果。

一旦把岛屿从频道系统转换到直接事件绑定系统，就无法再切回频道系统！重置岛屿也不会把它切回频道系统。

要把现有岛屿切换到新系统，打开我的岛屿（My Island）并点击工具（Tools）选项卡，找到事件系统（Event System）设置并点击转换（Convert）。

这次自动转换会为所有未命名的设备分配唯一 ID（一串随机的字母与数字）。在频道系统中相连的设备，会在转换过程中自动以事件与函数的形式连接起来。

当你打开设备的自定义（Customize）面板查看选项时，会看到事件（Events）选项卡和函数（Functions）选项卡，取代原来的频道（Channels）选项卡，岛屿上设备之间的连接就在这里查看。

直接事件绑定的更多优势

直接事件绑定系统极大地加快了你搭建岛屿的工作流，还能帮你一次性完成重要修改。

举个例子：假设你设置了一个按钮（Button）设备，当玩家与按钮交互时打开一盏可自定义灯光（Customizable Light）。在事件（Events）选项卡中，你选择了事件交互时发送事件（On Interact Send Event To）；在该事件下方，你选择了可自定义灯光（Customizable Light）设备，并在设备旁选择了打开（Turn On）作为函数。

如果你想再加一个按钮来关灯，只需复制粘贴第一个按钮设备，然后前往事件（Events）选项卡，点击打开（Turn On）打开菜单，从列表中选择关闭（Turn Off）即可！随后你可以把两个按钮设备重命名为 开灯（Light On）和关灯（Light Off），一目了然。

使用频道系统时，你也可以复制粘贴设备——但必须逐个编辑，改成不同的频道配对。如果游戏机制高度复杂、涉及多个设备，这会耗费大量时间；一旦搞混，修复起来还要花更多时间。

而使用直接事件绑定，需要改动的地方更少，工作速度更快；创建大型互连设备组也容易得多，你的游戏得以用上更精妙的游戏机制。没有了频道，也就没有频道数量上限需要时刻记挂与绕开。无论复制粘贴单个设备还是一整组，都不必担心频道限制。
