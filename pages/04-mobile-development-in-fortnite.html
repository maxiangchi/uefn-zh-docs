移动端开发

为移动端设计、测试与优化岛屿：触屏控制、移动端预览、性能优化与远程调试工具入口。

英文原标题：Mobile Development in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

在 Unreal Editor for Fortnite（UEFN）中面向移动端开发，让你有机会触达 Fortnite 庞大且跨平台的玩家群体。这是一条可扩展的路径，无数独立开发者与工作室都在经由这条路径打造视觉出众的移动端游戏，并受益于 Fortnite 的基础设施与发现（discovery）系统。

借助 UEFN 的移动端开发工具与 API 对输入的支持（例如触摸手势与可点击的 HUD 控件），你可以打造对移动端友好的游戏。

本节中的页面为你提供为移动端游玩设计、测试与优化岛屿所需的资源。以移动端硬件为前提，适配更小的屏幕、更低的功耗预算、不同的宽高比与触摸界面将成为优先事项，所以请做好移动优先（mobile-first）的思考准备！

配置移动端触摸输入

要了解如何配置移动端触摸输入，请参阅输入系统（Inputs）章节。

移动端开发指南

本节包含以下页面，覆盖从设计、优化到预览、触屏控制的完整移动端流程：

  • 面向移动端的 Fortnite 游戏设计（Designing for Mobile）——了解移动端设计原则与最佳实践，打造引人入胜的移动端体验。
  • 移动端优化（Mobile Optimization）——了解为移动平台优化岛屿的关键最佳实践。
  • 在 UEFN 中使用移动端预览会话（Mobile Preview）——在 Unreal Editor for Fortnite 中准确模拟你的移动端体验。
  • 开发者可自定义触屏控制（Developer Customizable Touchscreen Controls）——为 HUD 控制器（HUD Controller）设备指定 UMG 布局，重新放置、换肤或隐藏默认的 Fortnite 触屏控制。
  • 可点击的自定义 HUD 控件（Tappable Custom HUD Widgets）——把货币计数器、奖励通知或背包图标等 HUD 元素变为功能性触屏按钮。
  • Fortnite 中的 Unreal Engine Remote 应用（Unreal Remote App）——在 UEFN 中启动移动端预览会话（Mobile Preview session）时，在开发工作站上测试来自 iOS 或 Android 设备的移动端输入。
