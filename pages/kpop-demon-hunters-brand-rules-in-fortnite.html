KPop 猎魔团（KPop Demon Hunters）在 Fortnite 中的品牌规则

在 Fortnite 创意模式与 UEFN 中使用 KPop 猎魔团模板和资源搭建岛屿时，必须遵守以下品牌规则与相关责任要求。

英文原标题：Kpop Demon Hunters Brand Rules In Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

在 Fortnite 创意模式（Fortnite Creative）与 UEFN（Unreal Editor for Fortnite）中，使用专用模板与资源（assets），打造 KPop 猎魔团（KPop Demon Hunters）岛屿吧！

在使用 KPop 猎魔团资源与岛屿时，你需要承担相应的责任并满足相关期望。下面是创建 KPop 猎魔团岛屿的一系列准则。

Huntr/x NPC

使用 KPop 猎魔团模板的规则

若要使用 KPop 猎魔团模板进行搭建，除Fortnite 开发者规则（Fortnite Developer Rules）以及《变现协议（Monetization Agreement）》等其他现有协议之外，你还必须遵守以下规则。

KPop 猎魔团品牌规则

在使用 KPop 猎魔团模板搭建、并推广使用了 KPop 猎魔团模板的岛屿时，你必须遵守 Fortnite 开发者规则、所有其他相关协议以及以下规则，否则将受到强制措施，包括下文所述的处置。

  • KPop 猎魔团角色限制。你只能使用 UEFN 中正式提供给你的 KPop 猎魔团角色。不得将任何其他 KPop 猎魔团相关角色导入 UEFN，也不得在你的岛屿中使用它们。
  • KPop 猎魔团环境资源与道具限制。不得创建或导入意在复制电影或其他授权媒体内容的的环境资源或道具。我们鼓励你使用 UEFN 原生建模工具，对提供给你的 Fortnite 资源与 KPop 猎魔团资源进行混搭（mashup）。
  • 不得在岛屿中使用 KPop 猎魔团官方原声音乐。这些曲目的使用权不包含在本计划中，你不得将其收录进你的体验。
  • 不得出售、许可或再分发 KPop 猎魔团角色或资源。不得单独出售、许可或再分发任何 KPop 猎魔团角色或资源，也不得将其作为数据库、市场的一部分（或以其他方式）出售、许可或再分发，以免第三方能够以独立文件的形式访问、下载、提取或利用任何 KPop 猎魔团角色或资源。
  • 不得修改。不得在 UEFN 之外编辑、修改或更改任何 KPop 猎魔团角色或资源。对 KPop 猎魔团角色与资源，只能使用我们为其提供的 UEFN 自定义功能。
  • 不要打广告、说教或搞竞选宣传。不得将 KPop 猎魔团角色或资源用于任何产品或服务的广告、推广，也不得用其支持敏感话题（例如政治或宗教组织）、与之保持一致或就其发表声明。
  • Netflix 拥有并保留所有 KPop 猎魔团角色与资源的全部权利与所有权。这包括其中的一切知识产权。你对任何 KPop 猎魔团角色与资源的使用，均不授予你对任何 KPop 猎魔团角色、资源、内容或其衍生作品的所有权。

KPop 猎魔团品牌规则由 Epic Games 与 Netflix 共同执行。Netflix 可就违反 KPop 猎魔团品牌规则的岛屿向 Epic Games 举报。

如果发现你的岛屿违反 KPop 猎魔团品牌规则，你的内容将被移除，且该岛屿将无法获得互动参与分成（engagement payout）奖励。若屡次违反 KPop 猎魔团品牌规则，你将失去 KPop 猎魔团模板的使用权限。持续违反这些规则可能导致更严厉的限制，甚至终止你的账号。

将现有岛屿转换为 KPop 猎魔团岛屿

Epic Games 可能会提供一个选项，允许开发者将现有岛屿转换为 KPop 猎魔团岛屿。如果你想转换现有岛屿，请参阅将你的岛屿转换为品牌岛屿（Converting Your Island Into a Brand Island）。

切勿将 KPop 猎魔团资源与第三方 IP 混用

KPop 猎魔团岛屿已按协议配好了符合品牌要求的 KPop 猎魔团资源以及你获准使用的资源，此外还有 Epic Games 拥有或许可的特定资源。IP 合作伙伴许可协议明确规定：即使已获得该 IP 所有者的许可，你也不得将 KPop 猎魔团资源与其他第三方知识产权（IP）混合使用。只要遵守 Fortnite 开发者规则、上列 KPop 猎魔团品牌规则及所有其他相关协议，你可以导入并使用你拥有全部权利的资源；你也可以使用 Epic Games 直接提供给你的其他资源，但来自其他 IP 合作伙伴计划合作方（如乐高®（LEGO®）岛屿）的资源除外。

若违反本规则，你的岛屿可能无法获得互动参与分成奖励，并可能被移出生态系统或停用。持续违反本规则可能导致更严厉的限制，甚至终止你的账号。

KPop 猎魔团岛屿的盈利

Netflix 向你提供其内容的有限许可，允许你使用其批准的 KPop 猎魔团资源。这能让你把官方授权的 KPop 猎魔团体验带入 Fortnite 生态系统，为 Fortnite 社区创造新型岛屿。作为回报，你必须遵守 IP 合作伙伴许可协议（含 KPop 猎魔团品牌规则）、Fortnite 开发者规则、社区准则及所有其他相关协议的条款。唯一获准的 KPop 猎魔团资源与功能，是通过指定模板获取的那些。

作为 Netflix 许可你使用 KPop 猎魔团资源创建 KPop 猎魔团岛屿的对价，你同意将岛屿总分成中的 15% 分给 Netflix。Epic Games 将从你的互动参与分成中自动扣除该金额并分配给 Netflix，剩余部分归你所有。当你同意 IP 合作伙伴许可协议时，即表示同意这一流程。

该 IP 目前不支持岛内交易（In-island transactions）。

恶魔 NPC

推广你的 KPop 猎魔团岛屿

在为岛屿制作媒体素材时，请参阅推广你的 Fortnite 岛屿（Promoting Your Fortnite Island）中列出的准则。确保图片与视频如实反映你创建的岛屿或玩法机制，不要抄袭其他游戏或开发者。推广 KPop 猎魔团岛屿时，必须遵守 KPop 猎魔团品牌规则、Fortnite 开发者规则（Fortnite Developer Rules）、社区准则及其他相关协议（例如 Fortnite 开发者规则第 3 条）。推广内容与信息必须与这些规则协议中的内容规则保持一致，并适合岛屿目标受众的年龄。

缩略图、大厅背景图与视频

你可能已经注意到，部分 KPop 猎魔团品牌规则同样适用于推广素材。以下是针对推广素材中 KPop 猎魔团品牌规则的具体指引。

你可以：

  • 在缩略图、大厅背景图与视频中，使用 UEFN 提供给你的 KPop 猎魔团角色与资源，前提是遵守现有准则。
  • 在岛屿名称中使用“KPop Demon Hunters”“Huntrix”“Huntr/x”“Saja Boys”与“Honmoon”。

你不可以：

  • 在岛屿的缩略图、大厅背景图、视频或推广素材中使用 KPop 猎魔团电影中的任何图片、主视觉、音乐或营销物料。
  • 在岛屿的缩略图、背景图或视频中使用第三方 IP。
  • 声称或暗示你的岛屿与 Netflix 或 KPop 猎魔团品牌存在关联或获得其背书。
  • 在岛屿缩略图中使用任何 KPop 猎魔团徽标或风格近似的徽标。
  • 在岛屿名称、描述或推广图片中使用任何 Netflix 徽标或属于 Netflix 的商标。例如，不得添加 Netflix 的“N”徽标，或任何体现 Netflix 徽标、商标使用的内容。
  • 使用任何 KPop 猎魔团演员的姓名、形象或肖像，以及任何意在唤起其联想的其他图片。但游戏内装饰品（cosmetics）的使用不在此限。

你的岛屿在 Discover 中的展示

在创作者门户（Creator Portal）中，KPop 猎魔团岛屿会在发布过程中自动打上“KPop Demon Hunters”标签，该特别标签将显示在产品详情页中。

创作者制作的 KPop 猎魔团岛屿会像其他 Fortnite 岛屿一样出现在 Discover 中，也可被搜索到。
