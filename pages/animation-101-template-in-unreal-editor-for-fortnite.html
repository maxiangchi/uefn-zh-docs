UEFN 中的 Animation 101 模板

通过 Animation 101 模板快速学习骨骼网格体动画，了解 UEFN 中的动画设备、工具与工作流。

英文原标题：Animation 101 Template in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

Animation 101 模板是学习如何为骨骼网格体制作动画的快捷途径。

该模板展示了 UEFN 中当前可用的动画设备、工具、资产与工作流全貌。

它还把接入这些设备和工具所需的部分资产打包好，放在内容浏览器（Content Browser）中供你直接使用。

本模板将带你开启一段博物馆之旅，学习骨骼网格体以及如何使用动画网格体（Animated Mesh）设备，或控制绑定（Control Rig）与定序器（Sequencer）为它们制作动画。

你可以在项目浏览器（Project Browser）的项目模板（Project Templates）分区找到该模板。

本教程将带你走遍整个模板并讲解其中的内容。

骨骼网格体（Skeletal Mesh）

进入游戏后，你会看到一个 Fortnite 人体模型的骨骼网格体。骨骼网格体是可以用动画网格体设备或定序器中的控制绑定来驱动的模型。

骨骼网格体是播放动画的主要资产。

在内容抽屉（Content Drawer）的 Mannequin 下，你可以找到组成人体模型的各种资产。

把 FN_Mannequin 骨骼网格体拖入岛屿时，会如上图所示生成一个 FortSkeletalMeshActor。

在细节（Details）面板中，你可以把人体模型网格体换成其他任意骨骼网格体，也可以更换材质。

在博物馆的走廊里，你会看到播放着不同动画的骨骼网格体。

你可以实例化动画，这会创建一个骨骼网格体 Actor 并关联一段要播放的动画。你也可以更换骨骼网格体和动画。

从 Animations 文件夹拖入一段动画序列时，会像第一个例子一样创建一个使用 FN_Mannequin 骨骼网格体的 FortSkeletalMesh，同时关联一段动画序列。

为骨骼网格体应用动画后，细节（Details）面板中会显示以下设置。

  • 循环（Looping）：决定动画是否循环播放。
  • 播放（Playing）：决定动画是否在游戏/编辑模式下播放。
  • 初始位置（Initial Position）：未播放时动画停留在哪一帧。
  • 播放速率（Play Rate）：设置动画速度，1.0 = 100%。

为保证一致性，你可以决定实例化的动画序列是否播放。

动画网格体设备（Animated Mesh Device）

剧院里陈列着与动画网格体设备配对的骨骼网格体。

使用动画网格体设备，可以让骨骼网格体播放多种不同的动画，并通过按钮（Button）设备等触发器暂停或倒放动画。

动画网格体设备的用户选项与函数

动画网格体设备提供了与基础骨骼网格体 Actor 相同的控制选项，还可以绑定事件，告诉该设备在游戏中何时播放、暂停或倒放。

你可以使用桌上的按钮设备触发这些事件进行演示。

没有该设备的骨骼网格体（例如入口处那些）在游戏过程中不可更改。要在游戏过程中更精细地控制动画，请使用动画网格体设备。

骨骼网格体不会与玩家、世界或其他骨骼网格体发生碰撞。

过场动画序列设备（Cinematic Sequence Device）

沿楼梯而上，你会找到过场动画序列（Cinematic Sequence）设备，以及一个触发一小段过场动画的按钮。

与按钮交互后，它会激活过场动画序列设备的播放（Play）函数，你就可以在游戏中观看这段序列。

你可以使用过场动画序列设备回放在定序器中构建的关卡序列（Level Sequence）。

要添加自己的过场动画，必须位于项目文件夹中。

要制作自己的过场动画，请在 UEFN 的内容抽屉（Content Drawer）中找到项目文件夹，点击 +添加（+Add），滚动到过场动画（Cinematics）并点击关卡序列（Level Sequence）。

双击新建的关卡序列即可打开定序器。

定序器用于编辑关卡序列，可以控制过场动画播放什么、何时播放、在哪里播放以及播放多久，此外还有许多其他功能。

要体验定序器的功能，请在 UEFN 内容抽屉（Content Drawer）中进入 Sequences 文件夹，选择 MuseumFlyThrough 并双击，在定序器中打开。

你也可以通过窗口（Window）菜单的过场动画（Cinematics）选项卡访问定序器。

控制绑定（Control Rig）

控制绑定（Control Rig）可以自定义动画，还能叠加道具、视觉特效等内容。

双击 MuseumFlyThrough 序列缩略图打开定序器，你可以在此修改该序列、打造自己的版本。该定序器包括：

  • 一条运镜剪辑轨道，用于制作运镜动画和机位切换

点击图片放大。

双击控制绑定（Control Rig）缩略图可打开控制绑定编辑器。

  • 三个控制绑定（Control Rigs）

点击图片放大。

接下来，打开内容抽屉（Content Drawer）的 Mannequin 文件夹，选择 Meshes 文件夹，把 FN_Mannequin_ControlRig 拖到岛屿上。

UEFN 随后会进入动画模式，并自动把该 Actor 加入当前激活的序列，或新建一个序列。

使用控制绑定可以在控制绑定编辑器中创建新的控制器和动画来制作动画。

在内容抽屉（Content Drawer）中双击控制绑定（Control Rig）会打开绑定图表（Rig Graph），你可以在其中按需添加或修改控制器。

你也可以用控制绑定和定序器手工制作动画。

按以下步骤制作一段新动画。

  • 从 Mannequin > Meshes 文件夹把控制绑定（Control Rig）拖入项目。定序器随即打开，角色会在视口中被选中。
  • 添加一条变换轨道（Transform Track）。定序器会自动应用控制绑定控制器（Control Rig Controls）过滤器。
  • 在面板中选择一个控制器，肢体上会出现一个轴心点。
  • 按回车（Enter）或点击轨道上的关键帧图标创建关键帧。
  • 把肢体摆成新姿势。
  • 向前拖动播放头，重复上述操作。
  • 把动画保存为动画序列。可观看这段YouTube 视频了解更多。

要修改已有动画，请在定序器（Sequencer）中选择烘焙到控制绑定（Bake To Control Rig），再选择你的绑定。

可使用虚幻引擎控制绑定（Control Rig）文档的这一章节，学习如何绑定角色并创建动画。

你甚至可以把道具附加到动画网格体上。
