在 UEFN 中使用调音台（Audio Mixer）设备

使用调音台（Audio Mixer）设备，像专业调音台一样动态、自动地控制游戏整体混音：既可调节武器、脚步声等 Fortnite 自带声音，也可通过控制总线调节自定义声波与声音提示。

英文原标题：Using Audio Mixer Devices in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

使用调音台（Audio Mixer）设备，像专业调音台一样，对游戏整体混音进行动态、自动的分组音量控制。

通过调音台，你既可以调节 Fortnite 中已有的声音（如武器、角色脚步声、载具），也可以使用控制总线（control buses）和控制总线混音（control bus mixes）来调节自定义声波（sound waves）与声音提示（sound cues）的音量。

Fortnite 创作模式（Fortnite Creative）中也可以直接使用调音台，更多信息请参阅调音台设备（Audio Mixer Device）。

可直接跳转到按持续时间激活混音，按分步指南在你的岛屿上短时激活一个混音。

控制总线

当声音被设置为使用控制总线（control bus）后，该总线上的所有声音就可以在控制总线混音（Control Bus Mix）中一起调制。

以下控制总线可用于控制 Fortnite 中默认出现的各类声音的音量：

控制总线名称说明
CB FortAmbient用于设置 FN 环境音的音量。
CB FortExplosions用于设置 FN 爆炸声音的音量。
CB FortFootstep用于设置角色脚步声的音量。
CB FortGadgets用于设置与 FN 创意模式小工具和设备相关声音的音量。
CB FortGlobal用于设置所有 FN 声音的音量。
CB FortHitNotify用于设置与玩家受击相关的声音的音量。
CB FortImpacts用于设置 impact 碰撞声音的音量。
CB FortJam Volume用于控制 Jam 曲目的音量。
CB FortMusic用于设置音乐的音量（包括表情音乐）。
CB FortPatchwork Volume用于设置 Patchwork 设备的音量。
CB FortVehicles用于设置载具声音的音量（不含引擎声）。
CB FortVehicles Engine用于设置载具引擎的音量。
CB FortWeapon用于设置武器的音量。

你也可以创建自己的控制总线。创建控制总线：

  • 在内容浏览器（Content Browser）中，选中项目内容文件夹，点击 +添加（+Add）按钮，或在内容浏览器的空白处右键打开上下文菜单。
  • 在创建高级资产（Create Advanced Assets）分区中，点击音频（Audio）> 调制（Modulation），再点击控制总线（Control Bus）。
  • 为新的控制总线（control bus）输入名称。
  • 打开该 控制总线（Control Bus）资产，将参数（Parameter）设为音量（Volume）。

要在自定义音频资产上使用控制总线，必须在声波资产上设置控制总线。该声波仍可用于声音提示，效果同样生效。

为声波添加控制总线：

  • 在内容浏览器（Content Browser）中，打开要加入控制总线的声波。
  • 在“调制（Modulation）”下，将音量路由（Volume Routing）设为覆盖（Override）。
  • 勾选调制（Modulate）复选框。
  • 在音量调制器（Volume Modulators）数组中添加一个或多个控制总线（control buses）。

控制总线混音

控制总线混音（Control bus mixes）将一组控制总线放在一起，为其中每条控制总线定义音量。

创建控制总线混音：

  • 在内容浏览器（Content Browser）中，选中项目内容文件夹，点击 + 添加（+ Add）按钮，或在内容浏览器的空白处右键打开上下文菜单。
  • 在创建高级资产（Create Advanced Assets）分区中，点击音频（Audio）> 调制（Modulation），再点击控制总线混音（Control Bus Mix）。
  • 为新的控制总线混音（control bus mix）输入名称。

也可以直接从调音台（Mixer）设备创建控制总线混音。

控制总线混音包含一个混音阶段（mix stages）数组，每个混音阶段有以下参数：

参数说明
总线（Bus）一条控制总线，可以是 Fortnite 定义的总线，也可以是用户创建的总线。
值（Value）激活混音时，路由到该控制总线的声音应缩放到的音量。
启动时间（Attack Time，秒）启动（Attack）是激活混音时应用该混音所需的时间（秒）。
释放时间（Release Time，秒）释放（Release）是停用混音时应用该混音所需的时间（秒）。

查找并放置设备

  • 打开内容浏览器（Content Browser）。
  • 打开 Fortnite 文件夹索引列表。
  • 打开 设备（Devices）文件夹。
  • 选择调音台（Audio Mixer）设备，将其点击拖入视口（viewport）。
  • 在大纲视图（Outliner）面板中选择调音台（Audio Mixer）设备。
  • 在细节（Details）面板中配置调音台（Audio Mixer）设备的用户选项（User Options）。

用户选项

该设备在激活时应用控制总线混音，你可以为该设备配置以下值：

选项值说明
混音（Mix）None，选择一个控制总线混音设备激活时应用的控制总线混音。

直接事件绑定

UEFN 中的设备使用事件绑定（Event Binding）相互通信。要在 UEFN 中为设备设置直接事件绑定（direct event binding）：

  • 在大纲视图（Outliner）面板中选择该设备。
  • 打开细节（Details）面板。
  • 导航到用户选项 - 函数（User Options-Functions）。
  • 为某个函数添加一个数组元素。
  • 选择要交互的设备（device）。
  • 设置该设备执行的函数（function），以向调音台（Audio Mixer）发送触发。

函数

函数（function）告诉所选设备：当触发设备执行动作时，它需要做什么。

选项值说明
激活混音（Activate Mix）点击添加（Add）图标选择设备，再选择事件（event）。当所选设备与事件触发调音台设备时，激活控制总线混音。
停用混音（Deactivate Mix）点击添加（Add）图标选择设备，再选择事件。当所选设备与事件触发调音台设备时，停用控制总线混音。
收到时注册玩家（Register Player When Receiving From）点击添加（Add）图标选择设备，再选择事件。当事件发生时，将触发玩家注册到该设备。
收到时注销玩家（Unregister Player When Receiving From）点击添加（Add）图标选择设备，再选择事件。当事件发生时，将触发玩家从该设备注销。
收到时注销所有玩家（Unregister All Players When Receiving From）点击添加（Add）图标选择设备，再选择事件。当事件发生时，将所有玩家从该设备注销。

  • 将一个调音台设备拖到你的岛屿上。
  • 创建一个名为 audio_mixer_device_example 的新 Verse 设备。学习如何在 Verse 中创建新设备，请参阅使用 Verse 创建你自己的设备（Create Your Own Device Using Verse）。
  • 打开 Verse 资源管理器，双击 audio_mixer_device_example.verse，在 Visual Studio Code 中打开脚本。
  • 粘贴上面的代码，编译后将该 Verse 创作的设备拖到你的岛屿上。
  • 在大纲视图（Outliner）中选择你的 Verse 设备。
  • 在该设备的细节（Details）面板中，将 AudioMixerDevice 的对象引用指定为岛屿上的调音台设备。你可以用吸管工具在视口中拾取设备，也可以用下拉框搜索该设备。
  • 保存项目并点击启动会话（Launch Session）。

按持续时间激活混音

在这个示例中，我们来为躲猫猫游戏做个原型：玩家寻找藏身点时脚步声静音，计时器耗尽后一切恢复正常！测试本示例需要以下四个设备：

  • 玩家生成点（Player Spawner）
  • 调音台（Audio Mixer）
  • 计时器（Timer）
  • 回合设置（Round Settings）
  • 选择调音台（Audio Mixer）设备并拖入视口。
  • 在细节（Details）面板中，在总线（Bus）字段中指定 CBFortFootstep。
  • 将推子值（Fader Value）设为 0.0。
  • 勾选游戏开始时激活（Activate on Game Start）。
  • 选择一个计时器（Timer）设备并拖入场景。
  • 根据你的岛屿需要自定义设备设置。在本示例中，时长（Duration）设为 30.0。
  • 选择并拖入回合设置（Round Settings）设备。本示例使用默认选项。
  • 再次选择调音台（Audio Mixer）设备，前往用户选项 - 函数（User Options - Functions）分区。
  • 点击 + 为激活混音（Activate Mix）添加一个数组元素。
  • 选择回合设置（Round Settings）设备，并选择 On Round Start（回合开始时）选项。
  • 点击 + 为停用混音（Deactivate Mix）添加一个数组元素。
  • 选择计时器（Timer）设备，并选择 On Success（成功时）选项。
  • 点击启动会话（Launch Session）测试你的游戏！回合开始时，在 30 秒计时器耗尽之前，你应该听不到脚步声。
