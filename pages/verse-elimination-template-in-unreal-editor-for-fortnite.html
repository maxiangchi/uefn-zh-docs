UEFN 中的 Verse 淘汰赛模板

在 Verse 淘汰赛（Verse Elimination）中，玩家每次淘汰对手都会获得一套不断变化的配装。本进阶 Verse 模板将展示映射（Map）容器、数组以及 Fort_character 的 EliminateEvent 事件订阅等 Verse API 的用法。

英文原标题：verse-elimination-template-in-unreal-editor-for-fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

在 Verse 淘汰赛（Verse Elimination）中，玩家将使用一套每次淘汰都会变化的配装进行战斗。这些机制是通过将物品授予器（Item Granter）设备等设备关联到 Verse 设备来实现的。

这个进阶 Verse 模板将向你展示以下 Verse API 的用法：

  • 映射（Map）容器类型
  • 数组（Arrays）
  • Fort_character 的 EliminateEvent 事件订阅

  • 创建新项目并修改岛屿设置（Island Settings）以搭建游戏。
  • 设置设备。

创建新项目并设置游戏

  • 打开 UEFN（Unreal Editor for Fortnite），创建一个新的空项目。
  • 在大纲视图（Outliner）中选择 IslandSettings 设备，找到用户选项 - 游戏规则（User Options - Game Rules）。
  • 按下表所示修改用户选项。
选项值说明
被淘汰玩家的物品（Eliminated Player's Items）保留（Keep）玩家重生时将保留其配装。
允许丢弃物品（Allow Item Drop）否（False）游戏期间玩家无法从物品栏丢弃物品。
环境破坏（Environment Destruction）关闭（Off）游戏期间环境不会被破坏。

设置设备

本教程使用以下设备：

  • 若干 × 物品授予器（Item Granters）
  • 1 × 结束游戏设备（End Game Device）
  • 若干 × 玩家出生点（Player Spawn Pad）

物品授予器设备

使用物品授予器（Item Granter）设备向玩家授予武器。通过直接事件绑定将物品授予器连接到 Verse 设备后，Verse 脚本可以打乱武器的顺序，并在每次淘汰时授予武器。

你可以使用任意数量的物品授予器，只要将它们关联到 Verse 设备数组中，游戏就能相应扩展。

在内容抽屉（Content Drawer）中，前往 Fortnite > 设备（Devices），将物品授予器拖到地图上。

要设置此设备，按如下配置用户选项（User Options）：

选项值说明
物品定义（Item Definition）挑选一件武器每个物品授予器设备选择一件不同的武器。

结束游戏设备

使用结束游戏（End Game）设备在满足条件时结束回合。当淘汰数达到特定阈值时，Verse 脚本将激活此设备以结束回合。

此设备使用默认设置即可。

玩家出生点

你可以使用玩家出生点（Player Spawn Pads）让玩家出生到地图上。将出生点均匀分散在地图各处，确保玩家不会扎堆出生。

此设备使用默认设置即可。

添加 Verse 脚本

按此添加以下 Verse 脚本，首先使用 @editable 函数引用设备。

你可以按书写顺序复制代码，脚本中附有注释以便理解。

using { /Fortnite.com/Devices }
using { /Fortnite.com/Characters }
using { /Fortnite.com/Game }
using { /Verse.org/Simulation }
using { /Verse.org/Simulation/Tags }
using { /Verse.org/Random }
using { /UnrealEngine.com/Temporary/Diagnostics }

elimination_game_device := class(creative_device):

以上代码展示了变量定义。

OnBegin<override>()<suspends>:void=
    # 可以使用此变量，根据体验中物品授予器的数量来扩展获胜所需的淘汰数
    set NumberOfEliminationsToWin = WeaponItemGranters.Length
    Print("Number of Weapon Item Granters: {WeaponItemGranters.Length}")
    # 随机打乱授予武器的顺序
    set WeaponItemGranters = Shuffle(WeaponItemGranters)
    # 获取体验中的所有玩家
    AllPlayers := GetPlayspace().GetPlayers()

以上代码展示了设置获胜所需淘汰数这一游戏规则的逻辑，物品授予器数组的顺序会被打乱。

玩家会被加入一个映射，以跟踪他们的进度以及下一次应授予哪件物品。

# 处理玩家被淘汰时的事件
OnPlayerEliminated(Result:elimination_result):void=
    Print("Player Eliminated")
    EliminatingCharacter := Result.EliminatingCharacter
    if (FortCharacter := EliminatingCharacter?):
        if (EliminatingAgent := FortCharacter.GetAgent[]):
            GrantNextWeapon(EliminatingAgent)

以上代码是玩家被淘汰时触发的事件，淘汰者将被授予下一把武器。

# 检查是否已产生获胜者；若没有，则授予下一件武器
GrantNextWeapon(Agent:agent):void=
    if (var CurrentItemNumber:int = AgentMap[Agent]):
        if (IsVictoryConditionMet(CurrentItemNumber) = true):
            EndGame(Agent) # 已经获胜，结束游戏
        else:
            # 游戏尚未结束
            set CurrentItemNumber = CurrentItemNumber + 1
            if (ItemGranter := WeaponItemGranters[CurrentItemNumber - 1]):
                ItemGranter.GrantItem(Agent)

以上代码是判断授予淘汰者哪把武器、以及其是否已拿到最后一把武器从而结束比赛的逻辑。

# 检查胜利条件是否达成并返回结果
IsVictoryConditionMet(EliminationNumber:int)<transacts>:logic=
    if:
        EliminationNumber = NumberOfEliminationsToWin
    then:
        return true
    else:
        return false

以上代码是检查胜利条件是否达成的逻辑。

EndGame(Agent:agent):void=
    EndGameDevice.Activate(Agent)

以上代码展示了为获胜玩家调用结束游戏设备的逻辑。

设置 Verse 设备

Verse 设备通过使用直接事件绑定连接的物品授予器数组，控制结束游戏和在淘汰时授予武器。

编译 Verse 脚本，然后在内容抽屉（Content Drawer）中找到你的设备，将 Verse 设备拖到地图上不显眼的位置以自定义设置。

使用此设备通过直接事件绑定关联到所需设备，以便 Verse 脚本引用它们。

在设备的详细信息（Details）面板中，参照上图配置设置，使每个引用设备与之对应。

要设置此设备，按如下配置用户选项（User Options）：

选项值说明
EndGameDevice结束游戏设备（End Game Device）将 Verse 设备关联到结束游戏设备。
WeaponItemGranters - 0物品授予器（Item Granter）将物品授予器关联到 Verse 设备。
WeaponItemGranters - 1物品授予器 2（Item Granter2）将物品授予器关联到 Verse 设备。
WeaponItemGranters - 2物品授予器 3（Item Granter3）将物品授予器关联到 Verse 设备。
WeaponItemGranters - 3物品授予器 4（Item Granter4）将物品授予器关联到 Verse 设备。

选择启动会话（Launch Session）来测试你完成的关卡。
