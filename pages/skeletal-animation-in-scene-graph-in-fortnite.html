场景图中的骨骼动画

学习在场景图（Scene Graph）中使用实验性的骨骼动画（Skeletal Animation）功能，需要 UEFN 41.00 或更高版本，Verse API 仍可能变更，且目前无法发布使用了该功能的岛屿。

英文原标题：Skeletal Animation in Scene Graph in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

注意：请学习使用这项实验性（Experimental）功能，但在正式发布作品时请谨慎使用。

该功能需要虚幻编辑器 Fortnite 版（UEFN，Unreal Editor for Fortnite）41.00 或更高版本。在该功能处于实验阶段期间，本文涉及的 Verse API 仍可能发生变化，且目前无法发布使用了该功能的岛屿。

启用场景图动画

这是一项可以在项目设置（Project Settings）中启用的实验性功能。启用后，你的项目即可编译下文的代码语法与示例。

要在项目中启用场景图动画（Scene Graph Animation），请按以下步骤操作：

  • 在 UEFN 中打开项目设置（Project Settings）。
  • 前往实验性功能（Experimental）分区。
  • 勾选 Scene Graph Animation（场景图动画）复选框以启用它。
  • 当 UEFN 显示以下确认消息时：
    • "Enabling Scene Graph Animation may break compatibility with your existing Verse code and cause it to fail compilation."
  • 确认以启用该功能。

如果你手头有正在进行中的项目，启用该功能后可能需要修复 Verse 编译错误。

启用该选项会改变编辑器为项目生成的 Verse 资产摘要（asset digest）。开启后，项目中的每个动画资产都会以 skeletal_animation 的具体子类形式暴露给 Verse，这正是 PlaySkeletalAnimation 得以工作的前提。关闭时这些子类不存在，该 API 也不可用。对于仍需要 animation_sequence 实例才能工作的旧版 API，这些实例现在会以名称后缀 _asset 的形式暴露。

实体的前置条件

要在实体（entity）上成功调用 PlaySkeletalAnimation，该实体必须满足：

  • 挂载了 mesh_component（网格体组件）。
  • 该 mesh_component 必须引用骨骼网格体（Skeletal Mesh）资产，而非静态网格体（Static Mesh）。

如果实体没有 mesh_component，或其 mesh_component 对应的是静态网格体，调用将会失败。

骨骼动画 API

使用以下 Verse 类、方法和结构体，在场景图（Scene Graph）中控制骨骼动画。

skeletal_animation

skeletal_animation<public> := class(modifier(skeleton))

skeletal_animation 是一种修改器（modifier）：当它被加入网格体骨架（skeleton）修改器栈时，会逐帧基于底层动画资产生成姿势。

创作者无需手写 skeletal_animation 的子类。启用场景图动画选项后，项目中的每个动画序列资产都会自动暴露为 skeletal_animation 的具体子类。

例如，位于 Character/Animations/Idle 的动画序列资产，在 Verse 中会显示为类 Character.Animations.Idle。要播放该动画，只需构造它的实例（例如 Character.Animations.Idle{}）并传给 PlaySkeletalAnimation。

(Entity:entity).PlaySkeletalAnimation

(Entity:entity).PlaySkeletalAnimation<public>(Animation:skeletal_animation, ?EaseInWindow:easing_window = easing_window{}, ?EaseOutWindow:easing_window = easing_window{})<decides><transacts> : play_skeletal_animation_result

在实体的骨骼网格体上添加指定动画作为修改器，并用一个过渡（easing）修改器包裹它，使其平滑地淡入、淡出。

参数名类型默认值说明
Animationskeletal_animation—skeletal_animation 具体子类的实例。实际使用时就是由项目中某个动画资产自动生成的类，构造后传入（例如 MyAnim{}）。
?EaseInWindoweasing_windoweasing_window{}可选项，控制淡入。默认的 easing_window{} 为 0.3 秒的 EaseInOut 曲线。
?EaseOutWindoweasing_windoweasing_window{}可选项，控制返回句柄执行淡出时的淡出效果。淡出时可通过向 EaseOut(...) 传入窗口来覆盖它。

play_skeletal_animation_result

play_skeletal_animation_result<public> := struct:
    Animation : skeletal_animation
    Easeable : easeable

PlaySkeletalAnimation 的返回值。

字段类型说明
Animationskeletal_animation实际播放的动画实例（与传入 PlaySkeletalAnimation 的值相同）。
Easeableeaseable可用于淡出该动画、覆盖淡出窗口或立即取消的句柄，见下文“结束动画”。

结束动画

结束正在播放的动画有三种方式，三种方式都作用于 PlaySkeletalAnimation 返回的 play_skeletal_animation_result 中的 Easeable 字段。

写法行为适用场景
Playing.Easeable.EaseOut(false)使用传给 PlaySkeletalAnimation 的 ?EaseOutWindow 淡出。最常见的情况：在播放时配好淡出，之后不再操心。
Playing.Easeable.EaseOut(option{easing_window{...}})使用传入的窗口淡出，覆盖调用 PlaySkeletalAnimation 时设置的淡出窗口。合适的淡出取决于运行时上下文时，例如被打断的动作与自然结束需要不同的混合。
Playing.Easeable.Cancel()立即移除动画，等价于 EaseOut(option{easing_window{Duration := 0.0}})。需要立即移除动画，或玩家看不到变化时。

由于 Cancel() 以零时长淡出的方式移除动画，最终姿势会直接弹回到底层基础姿势。如果被取消的动画正是玩家当前看到的权重最高的修改器，这一跳变会表现为一帧的抽动。当被取消的动画不可见时（例如已被更高优先级的动作动画完全混合覆盖掉的待机排队动画），适合使用 Cancel()；当动画可见时，请使用带非零 Duration 的 EaseOut，让过渡呈现为混合而非跳变。

示例

动画类名（例如 Character.Animations.Idle）来自包含对应资产的项目自动生成的摘要（digest）；在你自己的项目中，请替换为你的资产实际生成的模块名与类名。

使用默认过渡播放动画

最简单的调用，两个过渡窗口都默认为 0.3 秒的 EaseInOut 混合。

OnTrigger(Entity:entity)<transacts>:void =
    # Idle 由项目中的动画序列资产自动生成，
    # 位于与资产路径对应的模块下。
    Entity.PlaySkeletalAnimation[Character.Animations.Idle{}] or false

调整过渡窗口

传入显式的 easing_window 即可控制混合。第一次调用完全禁用过渡，第二次调用使用 0.5 秒的自定义三次贝塞尔曲线淡入。

# 即时切换——无淡入也无淡出。
Entity.PlaySkeletalAnimation[
    Character.Animations.RunFwd{},
    ?EaseInWindow := easing_window{Duration := 0.0},
    ?EaseOutWindow := easing_window{Duration := 0.0}
] or false
# 半秒自定义曲线淡入；淡出保持默认。
Entity.PlaySkeletalAnimation[
    Character.Animations.RunFwd{},
    ?EaseInWindow := easing_window{Duration := 0.5}
] or false

easing_window 还有一个 Offset 字段，可相对动画内部时间轴延迟过渡窗口的开始。

保留结果句柄，稍后结束动画

保存返回的 play_skeletal_animation_result，稍后用它的 Easeable 字段结束动画，下例演示了全部三种结束方式。

OnPlay(Entity:entity)<suspends>:void =
    if:
        Playing := Entity.PlaySkeletalAnimation[
            Character.Animations.IdleBreak{},
            ?EaseInWindow := easing_window{Easing := Easing.Ease, Duration := 1.0}
        ]
    then:
        Sleep(3.0)
        # (a) 使用播放时传入的窗口淡出。
        Playing.Easeable.EaseOut(false)
