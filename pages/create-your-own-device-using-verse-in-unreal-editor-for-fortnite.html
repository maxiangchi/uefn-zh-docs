在 UEFN 中使用 Verse 创建你自己的设备

学会 Verse 代码基础后，接下来在 UEFN 中创建 Verse 自制设备，把它添加到关卡并运行起来。

英文原标题：Create Your Own Device Using Verse in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

在从零学习 Verse 代码基础（Learn the Basics of Writing Code in Verse）中，你学会了创建变量（variables）和函数（functions）。对 Verse 代码基础有了一些了解后，接下来看看如何在 Fortnite 虚幻编辑器（Unreal Editor for Fortnite，UEFN）中用 Verse 创建设备并与之交互。

使用 Verse 创建新设备

按以下步骤在 UEFN 中创建 Verse 自制设备（Verse-authored device）：

  • 在 UEFN 中打开项目，然后在菜单栏（Menu Bar）中前往 Verse > Verse 资源管理器（Verse > Verse Explorer）。
  • 在Verse 资源管理器（Verse Explorer）中右键点击项目名称，选择向项目添加新的 Verse 文件（Add new Verse file to project），打开创建 Verse 脚本（Create Verse Script）窗口。
  • 在创建 Verse 脚本窗口中点击 Verse 设备（Verse Device），将其选为模板。
  • 把设备名称（Device Name）输入框里的文字改成你的设备名，完成命名。本例中设备命名为 my_first_device。
  • 点击创建（Create），创建 Verse 文件。
  • 在 Verse 资源管理器中双击 Verse 文件名，用 Visual Studio Code 打开并编辑。

把 Verse 设备添加到关卡

按以下步骤把 Verse 设备添加到关卡并运行代码：

  • 把 Verse 设备拖入关卡之前，必须先编译（compile）代码。在菜单栏（Menu Bar）中前往 Verse > 构建 Verse 代码（Verse > Build Verse Code）。
  • 你的设备会出现在 CreativeDevices 文件夹中，本例中设备名为 my_first_device。
  • 把设备拖入关卡（level），试玩时就会运行它的代码。
  • 在工具栏点击启动会话（Launch Session）来试玩（playtest）项目，并在提示时保存。这会打开你的 Fortnite 客户端（client），在主菜单（Main Menu）点击开始游戏（Start Game）即可运行代码。

后续步骤

用 Verse 创建好设备并添加到关卡后，可以跟着下面这些指南，学习为设备添加功能：

  • 可编辑属性（Editable Properties）
    学习如何把 Verse 自制设备的属性暴露出来，并在 Unreal Editor for Fortnite 中修改。
  • 编写设备交互（Coding Device Interactions）
    用 Verse 编写自定义函数与行为，让它们在事件发生时运行。
  • Verse 标签（Verse Tags）
    在游戏运行时用 Verse 查找所有带 Verse 标签的对象。

教程

下面的指南展示了如何用 Verse 自制设备搭建游戏，不妨逐一探索：

  • 为道具移动制作动画（Animating Prop Movement）
    学习用 Verse 为糖豆人障碍赛的道具移动制作动画。
  • 创建你自己的 NPC 医疗兵（Create Your Own NPC Medic）
    用 Verse 代码创建自定义 NPC 医疗兵。
  • 自定义回合逻辑（Custom Round Logic）
    学习保存跨回合持久的信息，并在多回合游戏结束或玩家离开会话时重置持久数据。
  • 循环消失的平台（Disappearing Platform on Loop）
    用 Verse 创建周期性出现、消失的平台。
  • 触碰消失的平台（Disappearing Platform on Touch）
    用 Verse 创建玩家触碰后消失、并在随机秒数后重现的平台。
  • 用 Verse 打造游戏内排行榜（Make Your Own In-Game Leaderboard in Verse）
    创建跨对局追踪玩家数据的游戏内排行榜。
  • 移动目标标记（Moving Objective Marker）
    用 Verse 创建移动的目标标记。
  • 使用社交协同 API 的小队玩法（Party-Based Gameplay Using the Social Synergy API）
    学习用社交协同 API 在 Verse 中读取小队成员，打造奖励组队游玩的 gameplay。
  • 持久玩家数据（Persistent Player Statistics）
    学习创建在游戏会话之间保存的持久玩家数据。
  • 同步消失的平台组（Synchronized Disappearing Platforms）
    用 Verse 通过一个设备创建按顺序依次出现、消失的一组平台。
  • 标签灯光解谜（Tagged Lights Puzzle）
    用 Verse 自制设备创建解谜：玩家要找到灯光开关的正确组合才能生成物品。
  • 队伍多人平衡（Team Multiplayer Balancing）
    用 Verse 在运行时以及玩家加入游戏时平衡队伍。
  • 用镜头切换玩家视角（Transitioning Player Point of View with Cameras）
    学习玩家开门时切换镜头，打造区域之间的过渡。
  • 竞速赛 Verse 持久化模板（Speedway Race with Verse Persistence Template）
    学习为竞速游戏添加本地排行榜与回合专属逻辑！
  • 队伍淘汰赛（Team Elimination Game）
    用 Verse 创建多人竞技游戏模式，让队伍轮换使用一系列武器晋级。
  • 计时赛：披萨追击（Time Trial: Pizza Pursuit）
    用 Verse 创建游戏：玩家必须在时间耗尽前取餐并送达披萨！
  • 三方潜入（Triad Infiltration）
    用 Verse 创建非对称平衡队伍的多人竞技游戏。
  • Verse 爆破模板（Verse Detonation Template）
    把 Verse 与爆破物设备结合，制作可供玩家拆除的炸弹。
  • Verse 淘汰模板（Verse Elimination Template）
    用 Verse 与物品授予器设备打造不断变化的配装。
  • Verse 跑酷模板（Verse Parkour Template）
    用 Verse 创建跑酷游戏，自定义你的 gameplay。
  • 派对游戏（Party Game）
    跟着本教程创建满是迷你游戏的派对游戏岛屿！
