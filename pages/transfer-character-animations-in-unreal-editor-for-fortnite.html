迁移角色动画（IK 重定向）

用 IK Rig 定义角色骨骼、用 IK Retargeter 映射动画，把动画从一个骨骼网格体转移到另一个，可在 Sequencer 与 Animated Mesh 设备中使用。

英文原标题：Transfer Character Animations in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

IK Rig 定义角色，IK Retargeter 定义动画映射。创建 IK Rig 资产（asset）的过程称为角色化（Characterization），即把骨骼网格体（skeletal mesh）定义为肢体与接触点，确保动画贴合接收资产的骨骼。

用这些工具可以轻松把动画从一个骨骼网格体转移到另一个。IK Rig 用于选定源骨骼网格体的骨骼组，把该网格体（mesh）的动画投射（graph）到 IK Retargeter 资产上。

转移流程从新建 IK Rig 资产开始，因为该资产用于定义运动骨骼；骨骼定义好后，就可以为新动画资产映射运动。

该流程会为目标角色基于源动画生成新的动画资产。不走这个流程，就无法把源角色上的动画直接指派给目标角色。

跟随本教程，你将用 UEFN 中的 FN_Mannequin 资产练习重定向工作流，该资产位于动画新手（Animation Starter）模板中。

打开 UEFN 并创建新项目，务必在特性示例（Feature Examples）中选择 Animation Starter 模板。

点击图片放大。

要让流程顺畅，必须确保：

  • IK Rig 目标资产与源骨骼网格体尺寸大致相当；
  • 开始时目标资产与源资产使用相同姿势；
  • 在目标资产上试玩（playtest）动画，确保播放流畅、无需进一步编辑。

在内容浏览器（Content Browser）中创建文件夹存放动画资产，建好后即可导入自定义动画。

要进一步了解 IK Rig 与 IK 重定向，请参阅虚幻引擎文档中的 IK Rig。

创建 IK Rig 资产（Create an IK Rig Asset）

打开在内容浏览器中创建的文件夹，点击内容浏览器导航栏的 Import（导入）导入动画，从文件中选中动画并点击打开（Open） > 全部导入（Import All）。

点击图片放大。

与动画相关的所有文件都会导入该文件夹：

  • 骨骼网格体；
  • 材质（Materials）；
  • 动画。

用 IK Rig 选中源骨骼网格体的骨骼，创建重定向链（Retarget Chain）与新的可选 IK Rig 资产。IK Rig 资产建好后，就可以把动画投射到 IK Rig Retarget 资产上，在 Sequencer 中使用自定义动画。

  • 在内容浏览器中右键，选择动画（Animation） > 重定向（Retargeting） > IK Rig，创建 IK Rig 资产与重定向链的缩略图；也可以右键已导入的骨骼网格体缩略图来创建 IK Rig。
  • 重命名该缩略图。
  • 双击缩略图打开 IK Rig 编辑器；
  • 在 Preview Skeletal Mesh 下拉菜单搜索已导入的骨骼网格体，把骨骼加入编辑器。
  • 在 Rig Element 列表中选中髋部/骨盆骨骼，右键选择 Set Retarget Root。这块骨骼承载角色的主要运动；
  • 在 Rig Element 列表中选中骨骼，右键选择 New Retarget Chain，在弹窗中按需重命名骨骼组。

    可以一次多选骨骼，按组而非逐块选中。按 Rig Element 列表中的分支分组：手臂只需从肩膀抓到拇指，就能选中整条手臂。

双足网格体的骨骼组应按以下顺序创建：

  • 重定向根（Retarget Root）——髋部与骨盆区域；
  • 脊柱（Spine）；
  • 颈与头（Neck and Head）；
  • 右锁骨（Right Clavicle）；
  • 左锁骨（Left Clavicle）；
  • 手臂与手（左右）；
  • 腿与脚（左右）。
  • 点击 ADD CHAIN 把骨骼组加入 IK 重定向链列表，重定向列表应如下图所示。
  • 所有骨骼加入 IK 重定向链列表后点击 Save。

接下来要把动画投射到 IK Retarget 资产上，才能在其他骨骼网格体上使用自定义动画。

创建 IK Retargeter 资产（Create an IK Retargeter Asset）

IK Retargeter 资产用于把自定义动画投射到目标网格体上生成新动画。新资产可用于：

  • Sequencer——用该资产录制动画；
  • Animated Mesh 设备——创建可触发的动画序列。

用 IK 重定向工作流创建新动画资产：

  • 在内容浏览器中右键，选择动画 > 重定向 > IK Retargeter，创建 IK Rig Retargeter 资产缩略图；也可以右键已导入的骨骼网格体缩略图来创建。
  • 重命名该缩略图。
  • 双击缩略图打开 IK Retargeter 编辑器；
  • 从 Source IK Rig Asset 下拉菜单选择刚创建的 IK Rig 资产，UEFN 会自动把源资产填入 Source Preview Mesh 字段与视口（viewport）。
  • 从 Target IK Rig Asset 下拉菜单选择 IK_FN_Mannequin，UEFN 会自动把 FN_Mannequin 资产填入 Target Preview Mesh 字段与视口。
  • 在 Target Mesh Offset 字段中向右拖动，把 FN_Mannequin 资产平移（translate）到所创建 IK Rig 资产旁边。你会发现源资产与目标资产姿势略有偏差，锁骨区域可能多了一块骨骼；
  • 在 Chain Mapping 面板下的 Auto-Map Chains 下拉菜单选择 Clear Mapping > Map All (Exact)，清除目标网格体多余的骨骼。
  • 选择 Asset browser 面板 > 你导入的动画，即可看到目标资产播放该动画。

此时动画可能已经在目标网格体上播得很好了：好的话保存并导出动画；还差一点的话，可能需要先把目标网格体的重定向姿势调到与源网格体一致，再投射动画。

修改网格体姿势（Change the Mesh Pose）

让源姿势匹配，目标网格体更容易把动画准确投射到骨骼上。

要修改目标网格体姿势，需下载与源资产默认姿势匹配的姿势；没有的话，就自己做一个匹配源资产的默认姿势动画。

姿势准备好后，继续修改目标资产的网格体姿势：

  • 从 Show Retarget Pose 菜单选择 Showing Retarget Pose，两个网格体都会回到默认姿势。
  • 选择 Create > Import From an Animation Sequence，从下拉菜单选择 FN_Mannequin_TPose。FN_Mannequin 资产仅 Animation Starter 模板提供。
  • 把姿势重命名为 Tpose，Sequence Frame 选 0；
  • 选择 Import As Retarget Pose，FN_Mannequin 会以 Tpose 站在源网格体旁边。
  • 在摆好姿势的目标资产上重新播放重定向动画，应该流畅了；
  • 选择 Export Selected Animations 导出动画，打开 Batch Export Retargeted Animations 窗口。
  • 在 Add Prefix 字段填写重定向动画的新名称，点击 Export。其他字段可填可不填。

动画会导出到所选文件夹。现在你可以在 Animated Mesh 设备与 Sequencer 中使用该动画了。
