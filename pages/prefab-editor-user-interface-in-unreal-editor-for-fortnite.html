预制件编辑器用户界面

预制件编辑器由菜单栏、两条工具栏和三个主要区域组成：逐项了解菜单、工具栏、视口、大纲视图与细节面板的用法。

英文原标题：Prefab Editor User Interface in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

预制件编辑器（Prefab Editor）由菜单栏、两条工具栏和三个主要区域组成。

点击图片放大。

编号说明
1菜单栏（Menu Bar）
2工具栏（Toolbar）
3视口（Viewport）
4大纲视图面板（Outliner Panel）
5细节面板（Details Panel）
6底部工具栏（Bottom Toolbar）
  • 点击面板角落的 X 关闭面板；
  • 从 Window 菜单打开面板。

菜单栏（Menu Bar）

点击图片放大。

文件（File）

  • 最近资产（Recent Assets）——下拉菜单列出最近打开和查看过的资产；
  • 保存（Save）——保存对预制件的修改；
  • 另存为（Save As…）——把预制件另存为新名称。

编辑（Edit）

  • 撤销（Undo）——撤销在预制件编辑器中的上一步操作；
  • 重做（Redo）——回到撤销之前的状态；
  • 撤销历史（Undo History）——查看完整撤销历史。

资产（Asset）

  • 在内容浏览器中查找（Find in Content Browser…）——定位到关联资产并在内容浏览器窗口中选中；
  • 引用查看器（Reference Viewer）——启动引用查看器，显示所选资产。

窗口（Window）

  • 视口（Viewport）——开关视口窗口；
  • 细节（Details）——开关细节选项卡；
  • 大纲视图（Outliner）——开关大纲视图选项卡；
  • 过场动画（Cinematics）——打开下拉菜单，包含：
    • Take Recorder——打开 Take Recorder 主界面；
    • Takes Browser——打开 Take 浏览器界面；
    • 内容浏览器（Content Browser）——打开一系列内容浏览器；
    • 消息日志（Message Log）——打开消息日志选项卡；
    • 输出日志（Output Log）——打开输出日志选项卡；
    • 加载布局（Load Layout）——打开下拉菜单，包含：
      • 默认编辑器布局（Default Editor Layout）——切换为当前虚幻引擎布局；
      • UE4 经典布局（UE4 Classic Layout）——切换为虚幻引擎 4 经典布局；
      • 导入布局（Import Layout）——导入编辑器布局设计；
      • 保存布局（Save Layout）——打开下拉菜单，包含：
        • 布局另存为（Save Layout As…）——把当前布局存为新的编辑器布局；
        • 导出布局（Export Layout）——导出正在使用的布局；
        • 移除布局（Remove Layout）——打开下拉菜单，包含：
          • 移除所有用户布局（Remove All User Layouts）——移除你自定义的所有布局。
    • 全屏（Enable Full Screen）——开关编辑器全屏视图。

工具（Tools）

  • 查看更改（View Changes）——打开对话框显示当前更改；
  • 提交内容（Submit Content）——打开对话框，提供内容与关卡的签入选项；
  • 同步内容（Sync Content）——把所有未保存的关卡与资产存盘，再从版本控制下载最新版；
  • 连接版本控制（Connect to Revision Control）——连接到版本控制。

帮助（Help）

  • 开发者社区（Dev Community）——在浏览器中打开开发者社区链接；
  • 学习库（Learning Library）——在浏览器中打开虚幻引擎视频学习库；
  • 论坛（Forums）——在浏览器中打开开发者社区论坛；
  • 代码片段（Snippets）——在浏览器中打开代码片段仓库；
  • 关于虚幻编辑器（About Unreal Editor）——打开窗口，显示编辑器版本与你使用的平台信息；
  • 致谢（Credits）——打开滚动窗口，列出参与编辑器工作的所有人；
  • 访问 UnrealEngine.com（Visit UnrealEngine.com）——在浏览器中打开虚幻引擎文档站。

工具栏（Toolbar）

工具栏收录常用工具快捷按钮，下表列出各工具及其功能。

图标说明
保存对预制件的编辑。
打开内容浏览器，浏览最近使用的资产。

视口（Viewport）

视口显示正在编辑的预制件。

预制件编辑器视口与 UEFN、UE 中的视口功能大体相同。

大纲视图面板（Outliner Panel）

大纲视图面板收录组成预制件的实体层级，包括其他预制件及其实体层级。

在大纲视图选项卡中右键实体，打开大纲视图下拉菜单。

大纲视图下拉菜单（Outliner Dropdown Menu）

  • Add Entity——向预制件或所选实体添加新实体；
  • Delete——从预制件删除该实体；
  • Copy——复制预制件层级中的实体；
  • Paste——把复制的实体粘贴到层级中所选资产上；
  • Duplicate——在层级中 SimulationEntity 下复制该实体；
  • Frame Selected——视口居中到所选资产。

细节面板（Details Panel）

细节面板收录大纲视图中所选实体的全部组件卡片。

编号选项说明
1+Add Component向实体添加更多组件。
2实体图标（Entity Icon）向预制件添加另一个实体。
3组件卡片（Component Card）组件卡片提供该组件的可编辑选项。对组件默认选项的修改会自动把组件选项旁的覆盖开关切换为 Override。
4组件状态（Component Status）组件状态有 3 种：
  • 无覆盖（No Override）；
  • 内部覆盖（Override Inside）；
  • 唯一覆盖（Unique Override）。
5组件覆盖（Component Override）显示该组件选项的覆盖状态。

属性覆盖（Property Overrides）

可以覆盖单个组件选项：切换组件选项旁的按钮，从下拉菜单选择操作。

  • Override Property——覆盖该属性选项；
  • Clear Override——把该属性选项恢复原状。

组件卡片下拉菜单（Component Card Dropdown Menu）

点击组件卡片控制按钮，打开组件卡片下拉菜单。

  • Override Component——覆盖该组件；
  • Clear Override——把该组件恢复原状；
  • Remove Component——从层级中移除该组件。

底部工具栏（Bottom Toolbar）

该工具栏收录常用工具按钮，下表列出各工具及其功能。

点击图片放大。

图标说明
打开内容抽屉，访问导入或创建的资产。
输出日志（Output Log）显示预制件的稳定性。
显示预制件的保存状态。
打开版本控制（Revision Control）下拉菜单，包含：
  • View Changes——打开对话框显示所有近期更改；
  • Submit Content——提交更改的选项；
  • Check Out Modified Files——打开对话框签出文件；
  • Connect to Revision Control…——连接到版本控制系统。
