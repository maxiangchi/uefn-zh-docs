Walker NPC 模板（行尸走肉宇宙）

用 UEFN 中的 Walker NPC 学习模板认识行尸敌人类：包含公告牌、开关与玩法示例，学习行尸设置、武器玩法与关卡设计场景。

英文原标题：TWDU Walker NPC Template in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

一大群致命的行尸（Walkers）正从行尸走肉宇宙（The Walking Dead Universe）蹒跚走进 Fortnite 岛屿。用虚幻编辑器 Fortnite 版（UEFN）中的 Walker NPC 学习模板来认识这种敌人类，并学习如何把它们融入岛屿关卡设计，打造独特体验。该模板包含公告牌、开关与玩法示例，可在编辑器中边学边练。

把本指南作为模板的配套读物，深入学习以下内容：

  • Walker NPC 设置；
  • 武器玩法；
  • 使用 Walker NPC 的关卡设计场景；
  • 镜头选择；
  • 即插即用的血量与选中武器自定义 UI；
  • Heavy Linework（重线条）后期处理效果。

上手（Getting Started）

按以下步骤访问该模板：

  • 打开 UEFN；
  • 在项目浏览器（Project Browser）中选择 品牌模板（Brand Templates）> 行尸走肉宇宙（The Walking Dead Universe）> Walker NPC；
  • 创建新项目。

Walker NPC 模板仅在 UEFN 中可用。不过，你可以在 Fortnite 创意模式中使用行尸走肉宇宙的通用空岛屿及其功能集。要创建 Walker NPC，必须使用 UEFN 才能访问 NPC 生成器（NPC Spawner）设备和 NPC 角色定义（NPC Character Definition）。

要获得最佳模板体验，请同时使用编辑器和一个 Fortnite 游戏客户端实例（session/会话）。在 Fortnite 会话中，你可以看到行尸的实际表现、试用武器、阅读编辑器内指南。

在 live edit（实时编辑）模式下工作，按公告牌说明添加物品并推送更改，而不必反复开关游戏客户端。启用 live edit 模式：在工具栏点击 Launch Session 下拉菜单，打开 Live Edit 开关。

要进一步了解推送更改与 live edit 模式，请参阅试玩测试你的岛屿（Playtesting Your Island）。

行尸设置（Walker Setup）

第一个演示区带你认识行尸与新武器。跟随编辑器内指南，熟悉行尸独特的动画、玩法与音效，以及如何设置它们。Walker NPC 属于NPC 生成器设备与NPC 角色定义的一部分，仅在 UEFN 中可用。

要在模板中创建 Walker NPC，按以下步骤操作：

  • 在内容抽屉（Content Drawer）中找到 Fortnite > Devices > !Beta；
  • 滚动找到 NPC Spawner 设备，拖入你的岛屿；
  • 在细节（Details）面板点击 NPC Character Definition 下拉框，选择 WalkerDefinition。

WalkerDefinition 是 Epic 设计团队为该模板创建的角色定义，使用基于行尸走肉宇宙的默认行尸修正器。该 WalkerDefinition 资产位于内容抽屉 > [项目名] > AI。

要创建自己的角色定义，按以下步骤操作：

  • 在内容抽屉中点击 添加（Add）> 人工智能（Artificial Intelligence）> 角色定义（Character Definition）；
  • 命名该资产并双击打开；
  • 点击 Type 下拉框，选择 Walker 或 Walker (Prisoner Uniform)（囚服行尸）。

你也可以这样做：

  • 把角色定义直接拖入岛屿以生成行尸，该操作会自动创建一个已挂载该角色定义的 NPC 生成器设备；
  • 在 NPC 生成器的细节面板点击 NPC Character Definition 下拉框，选择 Create New Character Definition，双击图标打开角色定义。

行尸行动缓慢，但数量庞大、铺天盖地。NPC 生成器设备的细节面板中有选项，可调整开局生成多少行尸、随时间生成多少。在角色定义中，Walker 与 Walker (Prisoner Uniform) 类型包含 Walker Gameplay Modifier（行尸玩法修正器）选项，可调整攻击与撕咬伤害等属性。

NPC 生成器设备选项

角色定义 - 行尸修正器（Character Definition - Walker Modifiers）

试着调整各种设置并推送更改来测试效果。要进一步了解如何在自己的岛屿中创建 Walker NPC 并调整修正器，请参阅配置行尸（Configuring Walkers）。

继续学习（Continue Learning）

Walker NPC 模板

掌握 Walker NPC 基础后，就可以进一步探索模板了：从训练室走进恐怖与动作主题的玩法示例。通过这些示例，学习可以用第一人称或第三人称镜头打造的关卡设计场景，把这种新敌人类与武器的效果发挥到极致。

本系列指南针对行尸的特点讲解了具体技巧：

  • 行尸走肉宇宙武器：学习把 Lucille（露西尔球棒）与 Shiva Shotgun（湿婆霰弹枪）英雄武器融入玩法。
  • 行尸走肉宇宙关卡设计：了解行尸属性，学习通过关卡设计场景在岛屿中布置 NPC 的最佳实践。
  • 行尸走肉宇宙镜头：设置镜头，为你的行尸走肉宇宙岛屿营造恐怖与动作氛围。
  • TWDU 自定义 HUD：生命与选中物品：学习用 Walker NPC 模板中的即插即用配置，为 TWDU 岛屿添加显示玩家生命与选中物品的自定义 UI。
  • Heavy Linework 后期处理效果：用 Heavy Linework 后期处理效果为行尸走肉宇宙岛屿增添漫画质感。
