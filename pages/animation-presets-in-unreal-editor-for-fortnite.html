UEFN 中的动画预设

动画预设（Animation Presets）是一组可自定义的动画行为集合，可应用于 NPC 生成器的 NPC 角色。本教程将带你创建 Actor 蓝图类、了解基础移动与双足移动两种预设、创建动画预设以及 NPC 角色定义。

动画预设（Animation Presets）是一组可自定义的动画行为集合，目前只能应用于使用 NPC 生成器（NPC Spawner）的 NPC 角色。每个预设都带有一组可自定义的属性，你可以调整它们以适配角色。

动画预设控制角色的动画方式。如果你想扩展此功能，可以编写自己的 Verse 脚本，并使用 PlayAnimation API 播放一次性动画。

如果你想了解更多关于导入自定义角色的内容，参阅导入资产（Importing Assets）。

本教程将逐步讲解：

  • 从自定义骨骼网格体创建 Actor 蓝图类、
  • 两种可用预设类型的更多详细信息、
  • 使用导入的动画为该 Actor 创建动画预设，以及
  • 为该 Actor 创建 NPC 角色定义。

创建 Actor 蓝图类

要在角色上使用动画预设：

  • 将 FBX 角色和动画拖入内容浏览器完成导入。为方便访问，可为它们创建一个 Characters 文件夹。
  • 右键单击并创建蓝图类（Blueprint Class），选择 Actor 并按选择（Select）。好的做法是以 “A_” 前缀命名 Actor 类，例如 A_Doozy。
  • 双击 Actor 蓝图类以打开蓝图编辑器，然后添加骨骼网格体（Skeletal Mesh）组件，将自定义骨骼网格体指定给该组件并保存（Save）。
  • 在内容浏览器中右键单击，选择人工智能（Artificial Intelligence） > NPC 角色定义（NPC Character Definition），然后为文件命名。

动画预设类型

基础移动

基础移动（Basic Locomotion）预设适用于各种角色，设置快速简便。此预设需要五个动画：

  • 待机（Idle）
  • 向前移动（Move Forward）
  • 向后移动（Move Backward）
  • 向左移动（Move Left）
  • 向右移动（Move Right）

每个动画都有一个关联的播放速率（play rate）值，用于控制动画播放的速度。

要让预设工作，只需要待机（Idle）动画。如果你打算让 NPC 保持静止，这会很有用。

双足移动

顾名思义，双足移动（Biped Locomotion）预设非常适合双足角色。此预设比基础移动预设提供多得多的动画行为控制，可以容纳更多动画。

此预设为走和跑分别提供动画，并将动画进一步细分。例如，行走动画由起步（Walk Start）、行走循环（Walk Loop）和停止（Walk Stop）组成，让你能够调整移动的每个细节。

F、B、L 和 R 分别代表前（Forward）、后（Backward）、左（Left）和右（Right）。

创建动画预设

  • 新建一个蓝图类，选择 AnimPreset 下的基础移动（Basic Locomotion）预设。
  • 双击该资产以打开蓝图类，查看可修改的属性，为预设中要使用的每个字段选择正确的导入动画，点击编译（Compile）并保存（Save）。

当动画需要调整时，你可以使用 Control Rig 对其进行编辑。

要让动画过渡自然，需要同步。你可以添加同步标记（Sync Markers）来同步动画中的时间点。对于移动动画，标记每只脚接触地面的时刻可以改善混合效果，下面的视频演示了具体做法。

创建 NPC 角色定义

  • 在内容浏览器中右键单击，选择人工智能（Artificial Intelligence） > NPC 角色定义（NPC Character Definition）。
  • 打开该资产，将角色类型设置为自定义（Custom）。
  • 在外观修改器（Cosmetic Modifier）中，将角色外观（Character Look）更改为自定义角色（Custom Character），可用于为 NPC 选择自己的 Actor 蓝图。务必在蓝图中添加骨骼网格体组件（Skeletal Mesh Component），因为动画预设正是依靠它来工作。
  • 将角色移动（Character Movement）设置为动画预设（Animation Preset），并选择之前制作的预设资产，结果应类似下图：

动画预设通常用于自定义（Custom）角色类型。要使用动画预设为 Fortnite 角色制作动画，可使用 Animation 101 模板中提供的 FN_Mannequin 骨骼网格体，并将动画重定向（retarget）到 Fortnite 骨骼网格体。

现在可以测试 NPC 了。将 NPC 角色定义资产拖入关卡并启动 UEFN 会话。

在游戏中，你会看到带有你的 NPC 的 NPC 生成器设备。开始游戏，就能看到 NPC 以你提供的动画待机。

关于设置 NPC 行为的更多信息，参阅 UEFN 文档中的 AI 与 NPC（AI and NPCs）章节。
