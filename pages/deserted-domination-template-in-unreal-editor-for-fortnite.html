荒漠统治（Deserted Domination）模板

荒漠统治（Deserted: Domination）是一款双队伍争夺目标点的统治类玩法：玩家使用占领区域（Capture Area）设备等设备展开据点争夺战，还能用 Verse 创建自定义设备。跟随本教程，你将学会在 UEFN 中制作进阶玩法，并接触关卡序列（Level Sequencing）与后期处理（Post Processing）等 UE5 特性。

英文原标题：Deserted Domination Template In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

荒漠统治（Deserted: Domination）是一款统治类（Domination）玩法：两支队伍的玩家为争夺目标点而战。这种玩法使用了占领区域（Capture Area）设备等设备，甚至还包括用 Verse 创建的自定义设备。

跟随本教程，你将学会如何在虚幻编辑器 Fortnite 版（UEFN）中创建进阶玩法。此外，你还将接触到虚幻引擎 5（UE5）的特性，例如关卡序列（Level Sequencing）和后期处理（Post Processing）。

文中还会给出外部资源链接，帮助你学习 Verse 与 UE5 特性，以及我们涉及的其他内容。

你可以在项目浏览器（Project Browser）的示例项目（Sample Projects）分区中找到 Deserted。

以下是复刻这座岛屿所需的步骤概览：

  • 创建新项目，并修改岛屿设置（Island Settings）来搭建游戏。
  • 为玩家生成编写一段 Verse 脚本。
  • 添加并自定义核心玩法设备。
  • 添加自定义生成系统。
  • 添加玩家配装。
  • 添加音效。
  • 添加视觉效果。

创建用于玩家生成的 Verse 脚本

你可以使用 Verse 来控制玩家生成器，使玩家始终生成在己方领地内（己方已占领的占领区域附近，或盟友附近的区域）。为此，需要将标准创意设备与 Verse 结合使用。

按此页面所述添加一个新的 Verse 脚本，然后粘贴以下代码：

# Copyright Epic Games, Inc. All Rights Reserved.
using { /Fortnite.com/Devices }
using { /Fortnite.com/Teams }
using { /Verse.org/Simulation }
using { /Verse.org/Simulation/Tags }
## This device manages the player spawners
## An intial set of spawners starts enabled
## After a short time, the initial spawners are disabled

使用这份指南了解有关 Verse 的更多信息。

在本教程中，我们将使用 Verse 标签（Verse tags）来获取对其他创意设备的引用。

接下来，编译该 Verse 脚本。

在内容浏览器（Content Browser）中找到你创建的 DominationSpawnManager 设备，将其拖入世界中以自定义其设置。

这些设置和新的 Verse 设备只有在编译之后才会出现。

添加并自定义核心设备

玩家生成点（Player Spawn Pad）设备

玩家生成点（Player Spawn Pad）设备由 Verse 脚本控制，由脚本决定有效的生成位置。

你将使用多种不同设置与功能的生成点。其中一些将通过 Verse 进行通信——通过启用或禁用来决定可行的生成位置。

你总共需要 16 个初始生成器：队伍 1 八个，队伍 2 八个。把它们放置在开阔地带，它们仅用于每回合开始时的第一波生成。

要自定义此设备，请执行以下操作：

  • 从内容抽屉（Content Drawer）中选择并放置一个玩家生成点（Player Spawn Pad）设备。
  • 按下表所示自定义其设置：
选项值说明
玩家队伍（Player Team）队伍索引（Team Index）/ 队伍 1 或队伍 2设置队伍 1 或队伍 2 将生成在这个特定的生成器上。
用作岛屿起点（Use as Island Start）关（False）此设备不会用作岛屿起点传送器。
游戏中可见（Visible in Game）关（False）此设备在游戏过程中不可见。
优先级组（Priority Group）10勾选优先级组（Priority Group）复选框。这是生成用的优先级，数字越小优先级越高。
显示敌人范围（Display Enemy Range）关（Off）这是在编辑器中查看敌人范围检查（Enemy Range Check）的可视化器。默认全部设为关，即使未使用敌人范围检查也是如此。
  • 按以下说明添加Verse 标签（Verse Tags）。Verse 标签可在游戏运行时找到标有特定标签的设备。

操作步骤如下。

  • 在细节（Details）面板中选择 VerseTagMarkup。
  • 在标签（Tags）下点击编辑（Edit），打开一列 true/false 复选框。
  • 对于初始生成器，选择 initial 标签。确保每个生成器都有队伍 1 或队伍 2 的 TeamOwnership。
  • 将此设备复制粘贴 15 次（总共 16 个设备）。

将一半设备放在地图一侧，并配一个占领区域（Capture Area）设备；另一半放在地图对侧，再配一个占领区域设备。在地图中央再放第三个占领区域设备。将这三个占领区域设备命名为 Capture Area_A 至 Capture Area_C。

这些玩家生成器仅在游戏刚开始、被 Verse 禁用之前使用。

Verse 标签可以在任何位置定义。本教程的标签定义在 ProjectName.verse 中（即以你的项目名命名的文件）。

打开该文件并粘贴以下标签以完成设置。

# Copyright Epic Games, Inc. All Rights Reserved.
using { /Verse.org/Simulation/Tags }
DominationSpawnTags<public> := module:
    Tag_SpawnGroup<public>:= class(tag){}
    Tag_SpawnGroup_Initial<public>:= class(Tag_SpawnGroup){}
    Tag_SpawnGroup_GroupA<public>:= class(Tag_SpawnGroup){}
    Tag_SpawnGroup_GroupB<public>:= class(Tag_SpawnGroup){}
    Tag_SpawnGroup_GroupC<public>:= class(Tag_SpawnGroup){}

如上图所示，将生成器集群放在远离战斗的安全区域。Verse 会根据脚本判断它们是否有效，并将其关闭或开启。

红色玩家生成点是 Verse 控制的三组生成器之一。每组中有两个重叠的生成器，一个属于队伍 1，另一个属于队伍 2，地图上的其他位置也有同样的布置。

生成点集群中白色的生成器称为备用生成器（Fallback Spawner）。当 Verse 检查时若没有其他有效位置，玩家就会生成在这里。

你可以在地图上添加多组生成器，每组包含队伍 1 和队伍 2各一个。将生成组标记为 Group A、B 或 C，以表示它响应哪个占领区域。

围绕与之关联的占领区域（Capture Area）设备来布置各组。

好的占领点选址应考虑掩体、周围地形、海拔高度以及与其他占领点的距离。

在 Deserted 中，底座被替换为旋转灯具，以在视觉上加以区分。

Verse 设备

使用此设备将直接事件绑定链接到所需的设备，以便 Verse 脚本引用它们。

要自定义 Verse 设备，请执行以下操作：

  • 在大纲（Outliner）选项卡中找到并选择 DominationSpawnManager。
  • 在细节（Details）面板中选择 DominationSpawnManager（实例）。
  • 按下表所示自定义其设置：

锁（Lock）设备

许多玩家生成区域都配有锁（Lock）设备。每个锁（Lock）设备都应有唯一名称。

你可以用带锁和门的生成小隔间，确保玩家无法重新进入。

建议将相互关联的组件用统一编号，以便跟踪每个位置。在本教程中，总共有四个封闭的安全生成区域。

按以下步骤自定义 1 至 4 号锁：

  • 在紧闭的门外放置一个锁（Lock）设备。
  • 在房间内放置两个触发器（Trigger）设备以覆盖门口。
    1. 以便于引用的方式命名触发器（Trigger）设备。本教程中的触发器命名为 TriggerDoorOpen1 - 4 和 TriggerDoorClose1 - 4。
  • 按下表所示自定义锁（Lock）设备的设置。
选项值说明

锁定时隐藏交互（Hide Interaction When Locked）开（True）锁定时玩家在游戏中看不到该交互。
  • 设置直接事件绑定，将锁（Lock）设备与触发器（Trigger）设备配对。
设备 A功能设备 B事件说明

覆盖门口的触发器（Trigger）设备需要玩家接触，随后向锁（Lock）设备发送信号开门，如左侧覆盖门口的触发器（Trigger）设备所示。

添加玩家配装

你可以为玩家创建一套配装，用于争夺占领点时的战斗。将职业选择器 UI（Class Selector UI）设备与职业设计器（Class Designer）设备配对，即可在比赛开始时创建职业并展示给玩家选择。

每个职业都需要各自的职业设计器（Class Designer）设备。职业选择器 UI（Class Selector UI）设备只能放置一个。

添加音效

点击此处了解有关导入音频的更多信息。

导入音效后，将其从内容浏览器（Content Browser）拖到声音发出的区域。

你还可以在自选区域添加一组全局音效。

为此，将声波（Sound Wave）从内容浏览器（Content Browser）拖放到竞技场中。位置不重要，集中放在方便的位置即可。

打开声波（Sound Wave）资产，在细节面板中将循环（Looping）设为开（True）。与上文创建的提示音（Cue）不同，此声音将在整张地图播放，因此无需其他操作。

如果你想更精细地控制音频，提示音（Cue）会很有用。

右键点击自定义 .wav 文件的声波资产，选择创建提示音（Create Cue），即可创建一个循环波形播放器并连接输出。上述蓝图会在创建提示音时自动生成。

操作如下：

点击波形播放器（Wave Player），将循环（Looping）改为 True。

然后点击循环波形播放器（Looping Wave Player），将覆盖衰减（Override Attenuation）改为 True，以设置内半径（Inner Radius）和衰减距离（Falloff Distance）。

添加视觉效果

使用后期处理特效（Post Processing Effects）可以改变项目的外观和氛围，例如调色或应用镜头特效。按以下步骤让后期处理体积（Post Process Volume）影响整个关卡。

  • 向关卡添加后期处理体积（Post Process Volume）。放置步骤请参阅使用后期处理体积（Using Post Process Volumes）。
  • 在后期处理体积（Post Process Volume）的细节（Details）面板中，在后期处理体积设置（Post Process Volume Settings）下启用无限范围（未绑定）（Infinite Extent (Unbound)），这意味着后期处理体积将影响整个关卡。

本项目使用了以下后期处理特效：

  • 泛光（Bloom）：控制场景较亮区域的雾化/辉光
  • 色散（Chromatic Aberration）：在屏幕边缘增加一些颜色通道分离/畸变
  • 镜头光斑（Lens Flares）：控制明亮光源在镜头上投射光斑的方式
  • 暗角（Vignette）：在屏幕边缘增加深色渐变
  • 胶片颗粒（Film Grain）：增加胶片颗粒
  • 调色（Color Grading）：在饱和度/对比度/伽马中，我们只调整了饱和度（场景去饱和，意味着颜色更少、更偏灰）

本项目还使用了以下后期处理材质：

  • 场景热浪扭曲特效（Heat Shimmer Effect to Scene）
  • 基于材质的调色（Material Based Color Grading）
  • 基于镜头朝向的场景着色（Scene Coloration Based off Camera Look Direction）

你还可以添加贴花（decals）。贴花在材质编辑器中制作，然后拖入场景。

在内容浏览器（Content Browser）中找到贴花并拖到希望其出现的位置。

使用缩放（Scale）选项和邻近（Proximity）在静态网格体上显示贴花参与者（decal actor）。这可以在泥土上创建额外纹理，创建自定义纹理来表现泼洒的油漆等效果，或用于广播，在静态网格体上制作标志和战斗损伤。

你甚至可以在玩法中添加警报灯（Klaxon lights）。

警报灯是一个静态网格体，带有旋转的材质组件，并结合了使用灯光材质函数的点光源。

警报灯最初创建为 FBX 文件并导入 UEFN。

UEFN 可以导入各种内容，如 3D 对象、音频文件、纹理等，支持多种不同格式。右键点击要导入到的文件夹，即可看到导入选项。

对象导入后，需要从场景文件为其添加材质。只需双击该对象，将材质应用到所导入对象的材质槽即可。

关于如何在 UEFN 中导入和使用 3D 对象，其他教程中有更多信息，本文档不再赘述。

Niagara 可用于创建动态视觉特效（visual effects）。

在内容浏览器中找到已完成的资产，然后拖放。资产的缩放可以微调。

使用关卡序列器（Level Sequencer），你还可以设计玩法，让氛围海鸥围绕某个区域盘旋。

这是所有创作者都可用的全局资产，来自核心 UEFN 内容浏览器。要添加它，请在内容浏览器中搜索 Fortnite 文件夹并拖放 Atmospheric Seagulls Orbit。
