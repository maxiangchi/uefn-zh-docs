在 UEFN 中使用建模模式创建柱子

本教程将带你入门建模模式中的数学建模工具，使用创建、变换、建模、烘焙与 UV 工具，从零开始制作并编辑一根柱子网格体。

英文原标题：Creating a Column with Modeling Mode in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

建模模式（Modeling Mode）工具是基于数学的工具，也就是说它们用数学来创建、编辑形状及其 UV。本教程专门为入门介绍这些工具而设计。

你将使用建模模式中的基本形状，创建并编辑一个网格体。

你将用到以下工具：

  • 创建（Create）
  • 变换（XForm / Transform）
  • 模型（Model）
  • 网格体（Mesh）
  • 烘焙（Bake）
  • UV
  • 属性（Attribs / Attributes）

学完本教程，你应该能基本理解如何配合使用这些工具来构建、编辑网格体与 UV。

准备工作（Getting Started）

先在内容浏览器中为项目创建文件夹，做好准备。

  • 打开内容浏览器（Content Browser），右键点击并选择新建文件夹（New Folder）。
  • 将该文件夹命名为 Meshes。你搭建的网格体将保存在这个文件夹中。
  • 再为柱子材质创建一个文件夹。

你甚至可以按颜色整理文件夹，让资产各归其位、井井有条。

  • 文件夹建好后，从模式（Mode）下拉菜单中选择建模模式（Modeling Mode）。模式工具栏（Mode toolbar）会打开在视口左侧，同时打开建模（Modeling）选项卡。创建和塑造柱子所需的工具都在这里。
  • 在建模（Modeling）选项卡的新资产路径（New Asset Path）字段中，点击文件夹图标，从弹出窗口选择你为网格体创建的文件夹，点击确定（OK）保存选择。

本项目创建的所有网格体都会自动保存到该文件夹。现在可以开始搭建柱子了。

创建基本形状（Creating the Basic Shapes）

柱子由两种基本形状构成：圆柱体和方体。你将用两个圆柱体制作柱子的柱身部分，用一个方体制作柱子的底座和顶部。

先创建圆柱体。

  • 从创建（Create）工具中选择圆柱体（Cylinder）。
  • 将半径（Radius）设为 50，高度（Height）设为 225。
  • 点击接受（Accept）。

其余设置保持默认。

第一个圆柱体将成为柱子的柱身。重复上述步骤创建第二个圆柱体，但按以下调整半径和高度：

  • 从创建（Create）工具中选择圆柱体（Cylinder）。
  • 将半径（Radius）设为 15，高度（Height）设为 175。
  • 点击接受（Accept）。

点击图片可放大。

你将用第二个圆柱体在更大的柱身中刻出凹槽图案。

生成图案（Generating a Pattern）

图案（Pattern）工具可以控制图案的造型与呈现方式，它以所选网格体作为图案的模型。

图案（Pattern）工具沿直线、网格或圆形重复所选网格体。你可以将图案保存为整体网格体，也可以保存为多个独立网格体。在本例中，图案保存为一个整体网格体，用于在另一个网格体上压印出造型。

在视口中选中较小的圆柱体（高亮显示），然后：

  • 从变换（XForm）工具中选择图案（Pattern）。
  • 将形状（Shape）设为圆形（Circle）。
  • 将圆形图案的半径（Radius）设为 58。
  • 启用转为动态（Convert to Dynamic）。这会把图案中的所有小柱子视为一个网格体。

点击可放大图片。

  • 平移图案，使其居于大圆柱体中心，让图案中的每个小圆柱体环绕在大圆柱体周围。
  • 点击接受（Accept）。

大圆柱体此时应被一圈小圆柱体环绕，如上图所示。

如果图案显示不正确，点击重置箭头，检查该工具其余设置是否均为默认。

居中图案（Centering the Pattern）

为确保图案稳稳居于圆柱体中心，且与地面和顶部的距离相等，请使用变换（Transform）工具中的对齐（Align）。该工具按你启用的轴，把一个网格体移动到与另一个所选网格体对齐的位置。

同时选中大圆柱体网格体与图案网格体，然后：

  • 从变换（Transform）中点击对齐（Align）工具。
  • 从对齐类型（Align Type）下拉菜单选择包围盒（Bounding Boxes）。这会在两个网格体周围创建包围盒。
  • 启用以下对齐轴：
    • 对齐 X（Align X）
    • 对齐 Y（Align Y）
    • 对齐 Z（Align Z）

这样图案就与柱身圆柱体完美居中对齐了。

  • 点击接受（Accept）。

两个网格体现已在所有选定轴向上均匀分布，可以开始在柱身中成形凹槽了。

制作柱身凹槽（Forming the Column Flutes）

要在柱子中做出凹槽，需要用到 PolyEdit 工具布尔（Boolean）。该工具执行布尔运算，也就是通过判断点 x 是否位于每个网格体内部，来组合两个或多个实心形状。

点 x 就是一个网格体与另一个网格体重叠的位置，这个点用于从所选网格体中雕刻出网格体形状。在本例中，你用小圆柱体组成的图案执行布尔运算，在大圆柱体上雕刻出凹槽。

创建凹槽的步骤：

  • 确保两个网格体仍处于选中状态。
  • 从模型（Model）中点击布尔（Boolean）工具。
  • 点击接受（Accept）。

在视口中，大圆柱体上必须出现图案环绕的阴影，如上图所示。

如果圆柱体看起来与上图不符，轮流尝试运算（Operation）选项，直到圆柱体被阴影图案环绕。先选哪个网格体会影响该用哪个选项：

  • 差集 A - B（Difference A - B）：A 是第一个选中的网格体，B 是第二个选中的网格体。布尔运算用 B 网格体从 A 网格体中减去。
  • 差集 B - A（Difference B - A）：A 是第一个选中的网格体，B 是第二个选中的网格体。布尔运算用 A 网格体从 B 网格体中减去。
  • 交集（Intersection）：只保留两个网格体相交的部分。
  • 并集（Union）：将两个网格体合并在一起。

本教程只需要其中一个选项：差集 A - B 或差集 B - A。

凹槽做好后，就可以搭建柱子的底座了。

构建底座（Constructing the Base）

柱子的底座和顶部用方体制作。本教程将先做一个方体作为底座网格体，再编辑其表面，做出柱子底座和顶部。先执行以下操作：

  • 从创建（Create）工具中选择方体（Box）。
  • 将宽度（Width）和深度（Depth）设为 120。
  • 将高度（Height）设为 20。

平移方体到柱身下方，查看方体高度与柱身高度组合的效果。

  • 点击接受（Accept）。
  • 点击柱身网格体，然后按住 Ctrl 左键点击方体网格体，同时选中两个网格体。
  • 从变换（Transform）工具中选择对齐（Align），自动把底座网格体纳入柱身网格体的包围盒。
  • 取消勾选对齐 Z（Align Z），把方体移到柱身底部中央。
  • 点击接受（Accept）。

方体成形并居中后，就可以为网格体底座添加精致的细节了。

添加细节（Adding Detail）

要编辑网格体的多边形，请使用 PolyEdit 工具。要制作柱子底座，你一次只处理方体的一个面。

使用PolyGroup 编辑（PolyGroup Edit）工具，通过面、边或顶点调整网格体。你可以用选择过滤器（Selection Filter）调整这些选项。

要给柱子底座加细节，只会用到三种 PolyGroup 编辑面编辑：倒角（Bevel）、内嵌（Inset）与拉伸（Extrude）。

倒角（Bevel）

给方体顶部加一条倒角边。

  • 选中该方体。
  • 从模型（Model）工具中点击 PolyGroup 编辑（PolyGroup Edit）。
  • 选中方体的顶面，高亮该面。
  • 在建模（Modeling）选项卡中点击倒角（Bevel）。方体顶部就有了倒角边。
  • 点击接受（Accept）。

内嵌（Inset）

给刚做好的倒角边加一个内嵌角度。内嵌（Inset）会在倒角边上做出有角度的凹陷。

  • 选中该方体。
  • 从 PolyEdit 工具中点击 PolyGroup 编辑（PolyGroup Edit）。
  • 选中一个倒角面。
  • 从建模（Modeling）中点击内嵌（Inset）。光标处出现十字线。
  • 把十字线放在倒角中心，大约是方体中间数进去五个格子的位置。

随着给方体添加越来越多细节，方体线框上会出现越来越多浅蓝色线条。线框可以帮你判断所加细节上的 UV 岛位置。

  • 点击倒角面，放置内嵌角度。倒角面上就有了内嵌角度。
  • 点击接受（Accept）。
  • 对方体的每条倒角边重复上述步骤。

拉伸（Extrude）

把方体顶部抬高，使其与柱身底部凹槽齐平。拉伸（Extrude）会沿某个轴向拉动网格体的面。本例中，你将沿 Z 轴拉伸方体的顶面。

  • 选中该方体。
  • 从 PolyEdit 工具中点击 PolyGroup 编辑（PolyGroup Edit）。
  • 选中方体顶部，高亮方体的顶面。
  • 从建模（Modeling）中点击拉伸（Extrude）。方体顶部会跟随光标沿不同轴向移动。
  • 沿 Z 轴缓慢移动光标，直到方体顶部与柱身底部凹槽相接。
  • 当方体顶部到达想要的高度时，在视口中点击，确定方体高度。
  • 点击接受（Accept）。

柱子底座可以做得任意高、任意华丽。你可以用建议的编辑，也可以发挥自己的设计想法。

拉伸工具还可以缩放以做出角度。

制作柱顶（Making the Column Top）

底座设计满意后，复制底座并翻转 180 度，做出柱子的顶部。

  • 选中该方体。
  • 从变换（XForm）工具中点击复制（Duplicate）。
  • 将复制体重新命名为柱顶（Column Top）。
  • 从处理输入（Handle Inputs）下拉菜单选择保留输入（Keep Inputs）。
  • 点击接受（Accept）。
  • 沿 Z 轴平移复制的方体到柱子顶部。
  • 选中该方体并旋转 180 度。
  • 点击柱身网格体，然后按住 Ctrl 左键点击顶部方体网格体，同时选中两个网格体。
  • 从变换（Transform）工具中选择对齐（Align），自动把底座网格体纳入柱身网格体的包围盒。
  • 确保取消勾选对齐 Z（Align Z），使方体移到柱身顶部中央。
  • 点击接受（Accept）。

烘焙柱顶变换（Baking the Column Top）

接下来烘焙网格体，把物体旋转与缩放的 3D 网格体信息存下来（归零），并直接应用到该物体的几何体上。旋转值将变为 0，缩放值变为 1。

  • 选中顶部的方体。
  • 从变换（Transform）工具中点击烘焙变换（Bake Transform）。
  • 启用重定轴心（Recenter Pivot）。这会按方体的新朝向，重新对齐顶部方体的轴点。
  • 点击接受（Accept）。

顶部方体的缩放与旋转信息现已烘焙进其纹理文件。

编辑 UV（Editing the UVs）

此时，内嵌角度的 UV 与方体顶部、侧面的 UV 还没有对齐。这些需要编辑，尽量对齐，否则材质在某些地方会被拉伸或挤压得不自然，还会重复图案。

仔细看方体，可以看到内嵌部分的 UV 岛与应有位置略有偏差。

修复内嵌部分的 UV 岛并正确对齐：

  • 选中底部方体。
  • 从 UV 工具中点击 UV 展开（UV Unwrap）。方体上覆盖了棋盘格图案。
  • 点击接受（Accept）。
  • 对顶部方体重复上述步骤。

这些方格可以帮你判断 UV 是否对齐。

创建柱子材质（Creating the Column Material）

快速为柱子创建大理石纹理：

  • 在浏览器中搜索大理石纹理。
  • 把大理石纹理图片保存为 PNG 或 JPEG 文件。
  • 将图片文件导入（Import）到材质文件夹。
  • 在材质文件夹的内容浏览器中右键点击，从菜单选择材质（Material）。出现一个材质缩略图。
  • 给材质缩略图起个名字。
  • 双击材质缩略图，打开材质编辑器（Material Editor）。
  • 创建一个纹理采样（Texture Sample）材质节点，在细节（Details）面板的纹理（Texture）中添加大理石图片。
  • 从 RGB 引脚拖出连线，接到主材质节点（Main Material Node）上的基础颜色（Base Color）输入。大理石材质随即覆盖材质编辑器预览窗口中的球体。
  • 点击应用（Apply）>保存（Save）。

现在可以把材质加到柱子上，看看它在网格体上的效果。

  • 在视口中选中网格体。
  • 把材质拖到细节（Details）面板的材质（Materials）字段。材质随即覆盖所选网格体。

如果材质被拉伸、看起来不对（像上图这样），可以用属性（Attribute）与 UV 工具组合进一步编辑 UV。它们能帮你创建 PolyGroup 并对齐网格体上的 UV。

绘制 PolyGroup（Painting PolyGroups）

要修复上图中的拉伸，可以用属性（Attributes）工具编辑多边形组。这些工具适合用可视化分组信息整理网格体。

使用绘制 PolyGroup（Paint PolyGroups）绘制网格体侧面。这样可以在部分 UV 工具中快速创建 UV 岛。

创建 UV 岛可以防止 UV 拉伸，但可能仍需用 UV 展开（UV Unwrap）或自动 UV（AutoUV）编辑 UV。

  • 在视口中选中网格体。
  • 从属性（Attributes）工具中点击绘制 PolyGroup（Paint PolyGroups）。
  • 开始点击网格体一侧的所有面。完成后，这一面的所有部分应为同一颜色。
  • 点击接受（Accept）。
  • 对网格体的每一侧重复上述步骤，再对顶部方体重复这些步骤。

按以下步骤清理柱身上的 UV 接缝：

  • 选中柱身网格体。
  • 从 UV 工具中点击投影 UV（Project UVs）。
  • 从投影类型（Projection type）下拉菜单选择圆柱体（Cylinder）。
  • 从材质模式（Material mode）下拉菜单选择棋盘格（Checkerboard）。
  • 点击接受（Accept）

创建好 UV 岛后，就可以用 UV 工具中的自动 UV（AutoUV）为每一侧自动创建 UV。

  • 在视口中选中底部方体网格体。
  • 从 UV 工具中点击自动 UV（AutoUV）。
  • 从材质模式（Material Mode）下拉菜单选择棋盘格（Checkerboard）。棋盘格图案覆盖网格体。
  • 启用约束到 PolyGroup（Constrain to PolyGroups），使用用绘制 PolyGroup 创建的 UV 岛。
  • 点击接受（Accept）。

纹理贴图不应有任何扭曲，每个表面纹理应均匀。注意下图中棋盘格图案对齐均匀、没有扭曲。要让材质外观一致，就应尽量减少扭曲与可见接缝。

合并与转换网格体（Combining and Converting Meshes）

现在你有三个独立的网格体，柱子的每一节都可单独选中。要把独立网格体做成一个静态网格体：

  • 选中柱子的每一部分。
  • 从网格体（Mesh）工具中点击合并（Union）。
  • 在模型（Model）选项卡中启用修剪襟翼（Trim Flaps）与尝试修复孔洞（Try Fix Holes）。这些工具可防止网格体出现缝隙或质量问题，避免材质看起来奇怪。
  • 从输出类型（Output Type）下拉菜单选择静态网格体（Static Mesh）。这会把三个网格体转为一个完整的静态网格体，可用作岛上的道具。
  • 将名称（Name）改为柱子（Column）。这会为网格体命名。

点击图片可放大。

  • 点击接受（Accept）。

柱子现在是一个完整的静态网格体，但轴点位置不对。

按以下步骤移动轴点：

  • 在视口中选中柱子。
  • 从变换（XForm）工具中点击轴点（Pivot）。
  • 沿 Z 轴平移轴点到柱子底部。
  • 点击接受（Accept）。

现在柱子可以像 Fortnite 文件夹中的其他道具或建筑道具一样使用了。

你搭建的柱子应能与 UEFN 中的其他道具和建筑资产搭配使用。下图是柱子与银行建筑资产搭配的效果。

你创建的网格体可以随心所欲、独一无二。自定义道具让你的岛屿别具一格，而且你创建的网格体可以像 Fortnite 创意模式道具一样，在 UEFN 中使用和编辑。
