代码基础第 8 课练习：输入、参数与实参

把 CalculateDamage() 函数体中的常量与变量改成参数，并用 GetHealth() 获取角色血量作为实参传入，修复调用处的报错。

英文原标题：Basics of Writing Code 8 Practice Time in Verse · 查看英文原文 · 社区翻译镜像，仅供学习

前置知识（Prerequisite topics）

要理解和使用本页内容，请确认你已熟悉以下主题：

  • 第 8 课：输入、参数与实参的工作原理（Lesson 8: How Input, Parameters, and Arguments Work）

在上一个练习中，你为 CalculateDamage() 打下了一个不错的起点，但函数体里有一些常量和变量更适合改成参数。提醒一下，该函数目前长这样：

CalculateDamage() : float =
    MinHealth : float = 1.0
    PotionDamageAmount : float = 80.0
    var PlayerHealth : float = 100.0
    # 如果这次伤害不会淘汰玩家，就造成该数值的伤害
    if (PlayerHealth > PotionDamageAmount):
        return PotionDamageAmount
    else if (PlayerHealth > MinHealth):
        # 如果玩家血量较低，再给一次机会
        ...

更新后的函数将接收三个参数：

  • PlayerHealth：玩家当前生命值；
  • DesiredDamageAmount：可能造成的最大伤害；
  • MinHealth：如果 DesiredDamageAmount 会把玩家血量打到 0.0 或更低，玩家应保留的血量。

把函数更新成下面这样：

CalculateDamage(PlayerHealth : float, DesiredDamageAmount : float, MinHealth : float) : float =
    # 如果这次伤害不会淘汰玩家，就造成该数值的伤害
    if (PlayerHealth > DesiredDamageAmount):
        return DesiredDamageAmount
    else if (PlayerHealth > MinHealth):
        # 如果玩家血量较低，再给一次机会
        return PlayerHealth - MinHealth
    else:
        # 淘汰玩家
        return PlayerHealth

很好！你的函数现在接收三个参数来计算玩家应受的伤害，而不再使用函数内部声明的变量和常量了。

此时，你可能会看到 HurtPlayer() 中调用 CalculateDamage() 的 () 下方出现了红色波浪线。这是因为你已把 CalculateDamage() 的声明改成需要 3 个参数，但调用时还没有传入任何实参。接下来的几步我们就来修复它。

  • 在给 CalculateDamage() 传入 PlayerHealth 实参之前，必须先知道角色的血量。这就要用到 GetHealth() 方法。它的调用方式与 Damage() 和 Heal() 相同，但它会返回一个值，你需要在 HurtPlayer() 函数中把这个值存下来。 
    HurtPlayer() : void =
    Playspace : fort_playspace = GetPlayspace()
    AllPlayers : []player = Playspace.GetPlayers()
    if (FirstPlayer : player = AllPlayers[0]):
        if (FortniteCharacter : fort_character = FirstPlayer.GetFortCharacter[]):
            MyCharacterHealth : float = FortniteCharacter.GetHealth()
            DamageToDo : float = CalculateDamage()
            Print("DamageToDo: {DamageToDo}")
            FortniteCharacter.Damage(DamageToDo)
  • CalculateDamage() 的第二个参数需要用到 HurtPlayer() 的一个参数，现在就来创建它。给 HurtPlayer() 添加一个名为 DamageAmount 的 float 参数。HurtPlayer() 现在应长这样： 
    HurtPlayer(DamageAmount : float) : void =
    Playspace : fort_playspace = GetPlayspace()
    AllPlayers : []player = Playspace.GetPlayers()
    if (FirstPlayer : player = AllPlayers[0]):
        if (FortniteCharacter : fort_character = FirstPlayer.GetFortCharacter[]):
            MyCharacterHealth : float = FortniteCharacter.GetHealth()
            DamageToDo : float = CalculateDamage()
            Print("DamageToDo: {DamageToDo}")
            FortniteCharacter.Damage(DamageToDo)
  • 现在，传给 CalculateDamage() 的三个实参都准备好了：
    • MyCharacterHealth 对应参数 PlayerHealth；
    • DamageAmount 对应参数 DesiredDamageAmount；
    • 1.0 对应参数 MinHealth。

HurtPlayer() 应如下所示，并且不应再有报错：

HurtPlayer(DamageAmount : float) : void =
    Playspace : fort_playspace = GetPlayspace()
    AllPlayers : []player = Playspace.GetPlayers()
    if (FirstPlayer : player = AllPlayers[0]):
        if (FortniteCharacter : fort_character = FirstPlayer.GetFortCharacter[]):
            MyCharacterHealth : float = FortniteCharacter.GetHealth()
            DamageToDo : float = CalculateDamage(MyCharacterHealth, DamageAmount, 1.0)
            Print("Damage To Do: {DamageToDo}")
            FortniteCharacter.Damage(DamageToDo)

多调用几次 HurtPlayer()，看看在不同血量下会产生什么不同效果。

那 HealPlayer() 函数呢？现在你已经会用参数了，能想到哪些改造它的方法吗？

还有一个可能有用的方法，叫 SetMaxHealth()，调用方式与 Damage()、Heal()、GetHealth() 相同。试试用 SetMaxHealth() 加上你学到的参数与函数知识来改造 HealPlayer() 函数，想想怎样对玩家来说更有趣。
