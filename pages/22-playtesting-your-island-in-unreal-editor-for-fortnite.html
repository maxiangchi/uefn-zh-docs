试玩测试你的岛屿

在 UEFN 中随时启动试玩会话：在 Fortnite 客户端里验证道具、材质与设备，用 Live Edit 实时调优。

英文原标题：Playtesting Your Island in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

在 UEFN 中创建游戏或体验时，建议经常在 Fortnite 创意模式中试玩（playtest）你的项目，确认道具（props）、材质（materials）和设备（devices）的表现与你在编辑器中设置时预期的一致。

这也是发布项目之前的必要步骤。

Unreal Editor for Fortnite（UEFN）中的试玩，相当于虚幻引擎的 Play In Editor 功能，但关卡不是在编辑器中打开，而是上传到内容服务（content service），并在 Fortnite 游戏客户端（client）的一个实例（instance）中运行。

UEFN 还支持试玩 Verse 设备，以及在主机上测试项目。

准备好测试时，按下 Launch Session（启动会话）按钮。

图标会提示关卡（level）正在上传中。注意关卡加载可能需要几分钟。

Fortnite 创意模式从 UEFN 导入关卡期间，你会看到载入界面：

载入界面展示的是当前 Fortnite 大逃杀赛季的美术图，你实际看到的载入界面会与上图不同。

服务器加载完岛屿后，角色（character）会在测试关卡中生成。

试玩 Verse 设备

代码编译完成后，UEFN 工具栏中会出现 Push Changes（推送更改）和 Push Verse Changes（推送 Verse 更改）选项。

Push Changes 会把编辑器中的所有更改更新到客户端，例如增删道具、修改对象属性，以及对 Verse 代码的任何修改。

Push Verse Changes 只更新 Verse 代码，比 Push Changes 更快。当你只想对代码做小幅增量修改、不想刷新整个会话时很有用。点击 Push Verse Changes 即可更新客户端。

修改关卡中的 Verse 设备后，点击 Push Changes，设备会更新，新改动即可试玩。点击 Push Verse Changes 则只会拾取并推送 .verse 文件的更改。

在主机上试玩

在主机上试玩岛屿，可以在不同平台上检验游戏机制与视觉设计，确保玩家获得你设想的游戏体验。

点击 Launch Session 旁的三个点，打开会话选项下拉菜单。选择 Connect To Platform（连接到平台），再点击 Launch Session，Live Edit 会话就会在主机而不是 PC 上启动。

性能检查清单

  • 确认所有道具都可见，且渲染（rendering）正常。
  • 确认碰撞（collision）表现符合预期。
  • 确认道具可以被破坏，并能掉落预期的资源掉落物（resource drop）。注意没有碰撞的道具不会掉落资源（resources）。
  • 确认创意模式中的设备属性与在 UEFN 中设置的一致。
  • 确保游戏从开局到结束全程运行符合预期。

Live Edit（实时编辑）

试玩中如果发现需要回编辑器修改的地方，在 UEFN 中点击 End Game（结束游戏），即可停止客户端中的游戏并回到编辑模式。

试玩期间，UEFN 与游戏客户端之间保持实时连接。你在编辑器视口（viewport）中所做的任何更改都会立即呈现在客户端中。

左：UEFN 窗口。右：Fortnite 游戏客户端窗口。

按 Alt + Tab 可把鼠标控制权从游戏客户端切回编辑器。

从内容浏览器把新元素拖入场景，它会立即出现在游戏中（in-game）。

点击工具栏中的 Push Changes 按钮，可把关卡重新上传到内容服务。

开始游戏

在 Fortnite 创意模式中有三种开始游戏的方式：

  • 在客户端中按 Esc，从主菜单（Main Menu）开始游戏。
  • 从主菜单选择我的岛屿（My Island），在复查关卡设置后从这里开始游戏。
  • 在 UEFN 中按 Start Game（开始游戏）。

在我的岛屿菜单中，再次检查游戏（Game）、设置（Settings）和 UI 选项卡，确认在编辑器中修改的岛屿设置都被准确带过来了。
