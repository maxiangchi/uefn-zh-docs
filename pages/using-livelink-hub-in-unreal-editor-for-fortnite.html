在 UEFN 中使用 LiveLink Hub

LiveLink Hub（LiveLink Hub）是独立可执行程序，以单独进程在工作站上运行，可将动捕录制系统的数据流式传输到 UEFN。本教程介绍其面板与工具，并演示为 FN 骨架创建 IK 装配、流式传输、同步时间码与录制动画的完整步骤。

英文原标题：Using LiveLink Hub in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

LiveLink Hub 是独立可执行程序，以单独进程在你的工作站上启动。通过 LiveLink Hub，你可以将动捕录制系统的数据流式传输到 UEFN。

使用 LiveLink Hub 从动捕录制系统采集数据，用作 FN 骨架角色的动画，再用这些动画创造符合 NPC 个性与主题的动作。

然后你可以使用镜头录制器（Take Recorder）录制在 LiveLink Hub 中捕捉到的实时动画。

要启动 LiveLink Hub，前往工具（Tools）> LiveLink Hub。

按照 LiveLink Hub 教程逐步学习该工具的用法。

使用 LiveLink Hub

下面介绍 LiveLink Hub 的功能与工具。LiveLink Hub 顶部有录制动画的任务栏，以及三个面板，下文按对应编号拆解说明。

  • 录制按钮（Record Button）
  • 时间码栏（Timecode Bar）
  • 源面板（Sources Panel）
  • 主体面板（Subjects Panel）
  • 客户端面板（Clients Panel）

录制按钮

使用该按钮录制并保存实时动画。点击录制（Record）开始录制动画，再次点击保存。

时间码栏

该栏显示从动捕录制系统采集数据的时间码。

选择下拉框可将系统时间切换为 24、30 或 60 fps。

源面板

该面板显示电脑或网络上将向 UEFN 流式传输动画的设备，你可以查看动捕系统的源类型、源机器与状态。

在源（Sources）面板中点击添加源（Add Source），可选择以下 LiveLink 源：

  • Apple ARKit Source
  • LiveLinkInputDevice Source
  • Message Bus Source
  • Mocopi LiveLink
  • Pose AI App
  • Rokoko Studio Source
  • 1Vicon Data Stream Source

主体面板

该面板保存动画主体，即正在流式传输的单个角色或物体。

客户端面板

该面板显示电脑上已打开或网络上可访问的 UE/UEFN 会话。默认情况下，LiveLink Hub 会自动连接你的 UEFN 会话并开始流式传输动画数据。

本教程将带你搭建项目，在 FN 骨架角色上捕捉并录制动画，这些动画可用于角色（Character）设备的 Fortnite 角色。

你将首先为导入的 FN 骨架骨骼网格体资产创建反向动力学（IK，Inverse Kinematics）装配。IK 装配用于操作骨骼网格体上的区域以创建动画。

然后将动捕数据流式传输到 LiveLink Hub并录制，用于 gameplay 与过场动画。LiveLink Hub是向 UEFN 流式传输动画数据的统一接口工具。

开始本教程前，请从项目浏览器的功能示例部分基于动画（Animation）模板创建项目。

创建 IK 装配

按以下步骤从导入的骨骼网格体资产创建 IK 装配。

  • 在项目内容浏览器中前往你的项目文件夹。
  • 右键点击项目文件夹，选择新建文件夹（New Folder），将 mocopi 导入命名为“Mocopi”。
  • 访问 Epic Games Box 站点下载 mocopi 骨骼网格体资产。
  • 下载完成后，从内容浏览器工具栏选择导入（Import），选择下载的 mocopi 资产。
  • 导入 .fbx 文件时确保骨骼（Skeleton）字段为空，然后选择全部导入（Import All）。
  • 记下创建的资产。
  • 在内容浏览器中找到 Mocopi 资产，右键点击“MocopiMannequin”骨骼网格体，前往创建（Create）> IK 装配（IK Rig）。
  • 双击新的 IK 装配资产“IK_Mocopi Mannequin”打开资产窗口。
  • 在新窗口中点击自动创建重定向链（Auto Create Retarget Chains），再点击自动创建 IK（Auto Create IK），保存资产。

Mocopi 骨骼将是 UEFN 识别的唯一资产。

这两个操作将创建全身解算所需的 FK 链与 IK 效应器。

  • 接下来在内容浏览器中右键点击新的 IK 装配资产“IK_Mocopi Mannequin”，选择创建 IK 重定向器（Create IK Retargeter）。
  • 双击刚创建的 IK 重定向器资产。
  • 在新窗口的细节面板中打开目标 IK 装配资产（Target IKRig Asset）下拉菜单，选择“IK_FN_Mannequin”。
  • 在视口工具栏点击运行重定向（Running Retarget），将重定向资产切换为编辑重定向姿势（Edit Retarget Pose）。
  • 前往自动对齐（Auto Align）下拉菜单，选择对齐所有骨骼（Align All Bones）。
  • 保存你的资产。

现在你应该看到两套骨骼相互对齐。你还可以进一步重定向（retargeting）源与目标骨骼的基础旋转。

接下来通过 LiveLink Hub 将实时动画数据引入 UEFN。

流式传输到 LiveLink Hub

按以下步骤将你的资产作为动画导入。本例使用 Sony mocopi 动捕系统。

  • 前往工具（Tools）> LiveLink Hub 打开 LiveLink Hub。
  • 选择添加源（Add Source） < Mocopi LiveLink < 创建 Mocopi 源（Create Mocopi Source），将 mocopi 源加入 LiveLink Hub。
  • 添加 mocopi 源后，你会在主体（Subjects）面板看到新增的主体。主体旁绿色图标表示健康，黄色图标表示数据过期、当前未激活。
  • 在 UEFN 会话中将 MocopiMannequin 骨骼网格体拖入关卡。
  • 注意 UEFN 底部工具栏的 LiveLink Hub 已连接提示。
  • 接下来将 FN_Mannequin 加入关卡。
  • 在大纲或视口中选中 MocopiMannequin。
  • 在细节面板点击添加（Add），输入“Performer Component”。
  • 选中新的表演者组件，在主体名称（Subject Name）字段选择你的 MocopiSkeleton 主体。

此时在视口中可以看到动捕已应用到 MocopiMannequin。

  • 接下来在视口或大纲中选中 FN_Mannequin。
  • 在细节面板点击添加（Add），输入“Retarget Component”。
  • 选中新的重定向组件，打开重定向资产下拉菜单，选择之前创建的 RTG_MocopiMannequin。
  • 在细节面板打开源骨骼网格体组件，从下拉菜单选择 MocopiMannequin 下的骨骼网格体（SkeletalMesh）。
  • 此时在视口中可以看到 MocopiMannequin 与 FN_Mannequin 网格体都有动画。

同步时间码

按以下步骤从 LiveLink Hub 设置 UEFN 时间码速率，确保动画以正确的帧率录制。

  • 在 LiveLink Hub 中点击时间码下拉菜单。
  • 勾选启用时间码源（Enable Timecode Source），将时间码提供程序设为 SystemTime 到 30fps。

LiveLink 将显示时间码为 30fps、时间以及绿色图标，表示时间码正在发送到 UEFN。

录制动画

按以下步骤在 FN 骨架角色上捕捉动画序列，以应用于角色（Character）设备的 Fortnite 角色。

  • 在 UEFN 工具栏前往窗口（Window）> 过场动画（Cinematics）> 镜头录制器（Take Recorder）。
  • 从大纲将 FN 骨架拖入镜头录制器（Take Recorder）。
  • 按下录制图标开始录制动画。
  • 接下来按下胶片图标查看上次录制。
  • 再次按下录制图标结束录制。
  • 选择图标查看上次录制以观看你的动画。

你录制的关卡序列现在将加载供你查看。

你的角色会像未被录制一样继续播放动画。最终成果是 Fortnite 骨架角色上的动画序列，可将其应用于角色设备。
