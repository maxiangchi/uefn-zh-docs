Fortnite 中的星球大战远景与生物群系环境

通过地形与环境设计增强 Fortnite 体验的沉浸感。本指南介绍星球大战™功能集中的四套特色环境设计：三套生物群系主题与一套太空主题，以及远景、材质与氛围特效的工作流。

英文原标题：Star Wars Vistas and Biome Environments in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

你可以通过地形与环境设计，为你的 Fortnite 体验注入沉浸感。星球大战™（Star Wars™）功能集的美术模板包含四套风格鲜明的环境设计：三套基于生物群系、一套太空主题。这些模板采用了相似的设计工作流：使用远景（Vista）与画廊（Gallery）资产，配合地形（Landscape）Actor，构建出宏大而沉浸的世界。

本指南将重点介绍为你的银河世界构建打基础的工作流与资产：

  • 创建远景（Vista）
  • 使用地形材质（Materials）与环境生物群系资产
  • 利用氛围视觉特效（VFX）添加细节

虽然本页重点介绍品牌专属新手岛屿，但其中的信息可用于为任何体验构建环境。

环境模板

这些虚幻编辑器 Fortnite 版（UEFN，Unreal Editor for Fortnite）新手岛屿模板，展现了星球大战中所描绘的广袤、充满生活气息的银河。

它们旨在捕捉星球大战银河的规模感、奇观感与文化厚重感。星球大战中的不同场景强化了一个观念：银河是无数文明的家园，每种文明都适应着各自独特的世界。这些新手岛屿使用星球大战功能集资产与通用 Fortnite 资产构建而成。

你可以将这些模板作为体验设计的起点，在其上继续构建；也可以学习后面章节的技术，替换其中的环境资产。

要了解如何访问这些模板，请参阅访问品牌内容（Accessing Brand Content）。

远景（Vista）工作流

远景是指玩家在远处看到的大型环境特征，例如山脉。它们通常是大型资产，用于填充岛屿空间、增强沉浸感。对于星球大战，设计团队考虑了各场景的规模，以及宇宙可以显得多么浩瀚。

另一个重要元素是使用飞行载具穿越行星。基于这一考虑，设计团队不希望玩家到达某个位置时，因视野尽头穿帮而打破“身处巨大行星”的错觉。

使用远景资产打造辽阔的开放世界，呈现玩家对星球大战主题体验所期待的广阔环境。它们让环境更像一颗行星，而不是一座岛屿，还能避免地平线上出现海水。

远景资产与地形结合，共同构成世界。你可以用类似的工作流搭建环境布局，再将其打磨至符合你的岛屿风格。

远景资产

为实现这一目标，设计团队创建了远景静态网格体，并使用分层技术进行组合，呈现出行星主题新手岛屿中的效果。几何体位于全部 > Fortnite > 网格体 > 背景资产（All > Fortnite > Meshes > Background Assets）。

每种生物群系都有专用材质，确保远景资产适用于多种场景。这些材质专为匹配各网格体的 UV 而设计，也可以自定义以适配更多生物群系。

材质位于全部 > Fortnite > 材质 > 远景 > 材质实例（All > Fortnite > Materials > Vistas > Material Instances）。将材质拖到关联网格体上，或创建实例来自定义外观。更多信息请参阅下文使用材质调整外观。

地形与远景分层

远景充当玩法的背景，即背景层。体验的主要区域应包含环境细节，为玩法定下基调。

新手岛屿按以下方式分层：

  • 前景：地形资产承载核心玩法与主要移动区域，即可玩空间。
  • 中景：填充画廊与几何体资产，也包含部分远景资产。
  • 背景：填充远景资产，通常以更大的缩放值填满背景。

地形资产使用地形模式（Landscape Mode）创建。你可以用该工具构建地形，添加道路、洞穴用洞口等细节，甚至可以绘制多层地表材质以确立外观，并与远景背景融合。更多内容请参阅下文使用材质调整外观一节。

要了解地形创建的更多信息，请参阅创建自定义地形（Create a Custom Landscape）。

生物群系套件

生物群系是指具有独特气候、植被与动物群落的特定地理区域。远景静态网格体是通用 Fortnite 资产中生物群系套件的一部分，帮你快速上手主题环境创作。

附加资产包括一系列生物群系悬崖与岩石道具、砾石与远景材质、多种生物群系相关 VFX 以及少量纹理。你可以搜索关键词 biome 查看所有可用资产，或按以下表格中的名称搜索。

使用材质调整外观

为了进一步设计地形、打造独特外观，我们提供了材质实例。你可以用这些材质调整远景设计，并融合地形与环境道具。由于远景资产是静态网格体，你可以为其应用预设材质或自定义材质。

远景材质实例参数

远景材质实例包含可调整外观的设置。这些设置是父材质材质图表（Material Graph）中的参数，在材质编辑器（Material Editor）中作为公开变量暴露。更多信息请参阅 Unreal Engine 页面材质编辑器指南（Material Editor Guide）。

要调整材质属性，必须先为你的项目复制一份材质：

  • 右键点击材质并选择创建材质实例（Create Material Instance）。
  • 保存该材质。
  • 双击以在材质编辑器中打开。

UEFN 中的远景材质参数如下。你可以在材质编辑器的细节（Details）面板中访问这些值。

基础着色（Base Coloration）参数组用于调整材质的基础颜色。这些颜色由 Splatmap 纹理值驱动。Splatmap 的红色通道是一张通用噪点纹理，用于驱动资产的大部分着色。

基础着色参数说明
基础颜色 A 与 B（Base Color A and B）更改材质颜色的基础。这些是基础颜色，随后会被叠加的其他图层修改。
流动颜色 A 与 B（Flow Color A and B）使用流向贴图（Splatmap 的蓝色通道）更改漫反射着色。
高区颜色 A（High Range Color A）专门更改 Splatmap 噪点纹理高区（白色值区域，红色通道）中的漫反射着色。主要用于更改远景资产特定区域的颜色（例如山顶的深色或浅色区域）。
高区容差（High Range Tolerance）调整红色通道（土壤纹理）的值，控制高区着色出现在远景资产上的位置（Splatmap 中）。
低区颜色 A（Low Range Color A）专门更改 Splatmap 噪点纹理低区（黑色值区域，红色通道）中的漫反射着色。
低区容差（Low Range Tolerance）调整红色通道（土壤纹理）的值，控制低区着色出现在远景资产上的位置（Splatmap 中）。
中区颜色 A（Mid Range Color A）专门更改 Splatmap 噪点纹理中区（灰色值区域，红色通道）中的漫反射着色。
中区容差（Mid Range Tolerance）调整红色通道（土壤纹理）的值，控制中区着色出现在远景资产上的位置（Splatmap 中）。
坡度颜色 A 与 B（Slope Color A and B）更改材质的坡度颜色（Splatmap 的绿色通道）。

悬崖（Cliff）参数组用于调整悬崖图层的外观与纹理，该图层由坡度遮罩决定。这些值基于 Splatmap 纹理中的打包通道，特别是用作悬崖出现位置遮罩的绿色通道。

悬崖参数说明
悬崖材质混合量（Cliff Material Blend Amount）设置悬崖图层的混合量。
悬崖法线强度（Cliff Normal Intensity）设置法线材质通道的值。法线通道控制每个像素的光照反射，以产生凹凸、凹陷等表面细节。纹理中的像素表示切线空间中的归一化方向。
悬崖粗糙度（Cliff Roughness）设置悬崖效果的粗糙或光滑程度。值越低外观越亮。
悬崖缩放（Cliff Scale）设置悬崖纹理的平铺量。
悬崖染色（Cliff Tint）设置悬崖效果的染色颜色。
启用悬崖（Enable Cliff）切换悬崖纹理的可见性。禁用该参数会移除网格体上的纹理细节，使外观更扁平。该值目前位于全局静态开关参数值（Global Static Switch Parameter Value）参数组中。
坡度混合量（Slope Blend Amount）调整坡度着色的混合，该混合独立于悬崖图层。
坡度遮罩调整（Slope Mask Adjust）调整驱动坡度着色外观的坡度遮罩，增大或减小其强度（Splatmap 的蓝色通道）。

细节颜色（Detail Color）参数组会添加一层基于世界的额外噪点，以应对资产缩放可能带来的问题。

细节颜色参数说明
细节颜色 A 与 B（Detail Color A and B）设置资产的细节颜色。在参数 A 与 B 之间混合取值。
细节噪点缩放（Detail Noise Scale）设置细节颜色噪点图案的尺寸。
微观颜色细节噪点混合（Micro Color Detail Noise Blend）设置颜色值与噪点图案的混合方式。
微观颜色细节噪点对比度（Micro Color Detail Noise Contrast）设置噪点图案相对远景资产的对比度缩放。

纹理输入（Texture Inputs）参数组包含驱动材质与远景资产整体外观的纹理贴图，以及悬崖专用纹理。

纹理输入参数说明
悬崖漫反射（Cliff Diffuse）设置悬崖效果漫反射通道的纹理。
悬崖法线（Cliff Normal）设置悬崖效果法线通道的纹理。
细节法线（Detail Normal）设置细节法线效果的纹理，为表面添加额外的缩放细节。
宏观法线（Macro Normal）设置远景法线贴图的纹理。应在创建远景资产时生成或烘焙。
Splat 贴图（Splat Map）设置 Splat 贴图的纹理，用于驱动远景资产的着色与遮罩。

法线（Normal）参数组用于调整远景资产的法线贴图与法线细节外观。

法线参数说明
基础法线强度（Base Normal Intensity）设置基础远景网格体的法线值。
细节法线强度（Detail Normal Intensity）设置远景网格体细节范围的法线值。
细节法线缩放（Detail Normal Scale）设置远景网格体上细节区域的尺寸。

粗糙度（Roughness）参数组用于调整粗糙度，取值源自基础着色所用的相同信息。

粗糙度参数说明
基础粗糙度 A 与 B（Base Roughness A and B）设置主远景网格体的粗糙度。
流动粗糙度（Flow Roughness）设置流向贴图的粗糙度值。

高光（Specular）参数组用于调整资产上的光线反射强度。

高光参数说明
坡度高光（Slope Specular）设置坡度的高光值（Splatmap 的蓝色通道）。
高光值（Specular Value）设置远景资产的整体基础高光值。

顶层（Top Layer）参数组会添加一层基于垂直方向的颜色层，用于在资产旋转与调整时模拟积雪、沙地、草地等效果。

顶层参数说明
顶层颜色 A 与 B（Top Layer Color A and B）设置顶层效果的主颜色。参数 A 与 B 相互混合。
顶层对比度（Top Layer Contrast）控制顶层遮罩的对比度，可以锐化或模糊顶层的出现位置。
顶层过渡阶段（Top Layer Transition Phase）控制顶层出现在远景资产上位置的遮罩。

用于地形绘制与混合的材质层

在创建与雕刻地形时，你可以使用套件中的地形材质确立生物群系设计，再放置生物群系画廊资产以增添视觉吸引力。你可以直接将地形材质应用于几何体，但可能会注意到生物群系几何体与地形材质之间存在生硬过渡。

使用地形模式（Landscape Mode）中雕刻（Sculpt）与绘制（Paint）选项卡下的工具，统一生物群系画廊资产与地形。

通过绘制工具（Paint tools），你可以使用材质层为地形添加细节并混合资产。这是一种设计实践，可以减少资产之间的清晰边界，为环境设计增添视觉多样性。

该方法要求图层中至少有一种材质有助于混合几何体与地形材质的主基底，通常包括噪点感材质（如砾石外观），以营造更自然的过渡。

每个生物群系地形材质实例包含 6 层不同的表面材质，可绘制在基础层之上。各图层按顺序叠加。你可以使用不同的绘制工具（如噪点（Noise））进一步调整外观。

要了解该工作流的更多信息，请参阅编辑地形材质（Editing Landscape Material）与绘制地形（Painting the Terrain）。

添加更多环境细节

环境设计并不止于雕刻地形与添加背景远景资产。使用预制件与建筑画廊资产构建结构、打造兴趣点。太空新手岛屿模板没有地形，而是使用死星预制件确立起始位置。

漫游 NPC 可以让环境生机勃勃。星球大战功能集包含多种角色，契合浩瀚银河的氛围。添加NPC 生成器（NPC Spawners）与AI 巡逻路径节点设备（AI Patrol Path Node Devices），展现有人居住的环境。

你可以使用画廊资产围绕地形构建，也可以使用地形模式中的样条线工具（Spline tool）创建道路与小径，进一步确立环境氛围并引导玩家移动。

在塔图因灵感新手岛屿模板中，额外细节是将沙漠爬行者（Sandcrawler）车辙静态网格体与样条线工具结合，模拟沙漠爬行者穿越地形的痕迹。

新手岛屿模板不含屏障，供你自由探索并按玩法需求构建。你可以使用阻挡体（Blocking Volume）与屏障设备（Barrier device）等功能，设定玩家可到达的边界。

使用植被工具快速放置资产

使用植被模式（Foliage Mode）优化在岛屿上放置环境静态网格体的工作流。例如，如果你在地形上雕刻了道路，可以用该工具沿路缘添加砾石、植物等细节，让道路看起来更自然。

对植被进行抖动（Dithering，即柔化边缘）处理，也有助于植被与地形更好地融合。该方法需要调整剔除距离（Cull Distance）绘制设置，让植被随镜头拉远逐渐淡出。

你可以在全部 > Fortnite > 环境 > 植被（All > Fortnite > Environment > Foliage）下找到植物、树木、鹅卵石等植被资产。要将资产加入工具，必须先将其保存到项目文件。具体做法是将资产从内容浏览器拖入植被列表（Foliage list）。

使用植被绘制工具放置岩石。

背景资产

除远景资产外，还有其他填充环境的方式。Fortnite 内容包含专为远距离放置设计的附加资产，用于确立主题、设定环境规模，通常设计为玩家无法近距离观看，这就是背景资产。

星球大战功能集包含多种背景资产：

  • 行星
  • 离子炮（Ion Cannon）
  • 死星（Death Star）
  • 歼星舰（Star Destroyer）

可见性与优化技巧

放置背景资产后，试玩时可能看不到它。默认情况下，远距离 Actor 在游戏中通常会被剔除（culled）以优化渲染。请务必对该 Actor 禁用距离剔除，使其始终可见。

要调整可见性：

  • 点击该网格体，前往细节面板。
  • 搜索从不距离剔除（Never Distance Cull）并勾选启用。

你也可以使用白昼序列（Day Sequence）设备的设置（如天空参数）调整其在天空中的外观。

为进一步优化项目，请确保资产没有不必要地计算世界位置偏移（WPO，World Position Offset）。WPO 使用材质逻辑创建程序化动画，例如迎风飘扬的旗帜。计算 WPO 会包含成本更高的阴影渲染通道。任何没有 WPO 效果的静态网格体 Actor 都不应计算它。

你可以在 Actor 的细节面板中渲染 > 高级 > 计算世界位置偏移（Rendering > Advanced > Evaluate World Position Offset）下禁用该计算。

要搜索启用了该功能的 Actor：

  • 从视图模式下拉菜单点击 Nanite 可视化 > 计算 WPO（Nanite Visualization > Evaluate WPO）。
  • 选中不应计算 WPO 的绿色 Actor（如歼星舰），在细节面板中禁用该功能，Actor 应变为红色。
  • 切换回光照模式（Alt+4）。

如果 Actor 没有暴露计算 WPO 的开关，请在细节面板中选中所有静态网格体组件，开关即会出现。

行星材质

行星资产包含 4 种设计：D'Qar、霍斯、内瓦罗与塔图因。你也可以使用星球大战™内容 > 材质（Star Wars™ Content > Materials）文件夹中的行星材质设计自己的行星（记得创建实例）。该文件夹包含行星设计基础材质与大气层材质。

你可以使用建模模式（Modeling Mode）中的工具创建行星网格体并定义 UV，以均匀应用材质。材质包含调整大气颜色、纹理、熔岩强度等属性的参数。

氛围视觉效果

你可以用氛围视觉特效进一步确立环境氛围。下表重点介绍了新手岛屿中使用的部分特效。

云雾漂移

生物群系套件包含可直接拖入环境的漂移视觉特效。

该资产包含可在细节面板调整的参数，如生成速率与粒子缩放。如霍斯与塔图因灵感模板所示。

热浪扭曲

塔图因还带有热浪扭曲特效，以表现沙漠的酷热。

该特效使用 FNEC_MI_PPV_HeatRipple_Day 材质的实例，并将其应用于后期处理体（Post Process Volume）。你可以在全部 > Fortnite > 材质 > 后期处理（All > Fortnite > Materials > PostProcess）文件夹中找到该材质。

要将材质应用于你的环境：

  • 右键点击 FNEC_MI_PPV_HeatRipple_Day，然后点击创建材质实例（Create Material Instance）。在项目文件夹中命名并保存该材质实例。
  • 在主工具栏点击放置 Actor（Place Actors）图标，打开 Actor 下拉菜单。
  • 在菜单中前往并点击体 > 后期处理体（Volumes > Post Process Volume）。该体将出现在视口与大纲中。
  • 缩放该体以覆盖你期望的效果区域。
  • 在该体的细节面板中前往后期处理材质（Post Process Materials）。
  • 点击加号图标，搜索并添加你的材质实例。

你可以在该体的细节面板中调整材质的可见强度。材质实例包含涟漪强度、速度等可调参数，还包含调试功能以查看效果应用位置。要编辑参数，请双击材质实例以打开材质编辑器。

天空盒

星球大战品牌岛屿在世界昼夜管理器（World Time of Day Manager）中有两个白昼序列 Actor 新增项：双子太阳（Binary Suns）与太空（Space）。

该天空效果在世界设置（World Settings）面板的昼夜 > 世界昼夜管理器（Time of Day > World Time of Day Manager）设置中指定。如果编辑器中未激活该面板，可以从菜单栏 > 窗口 > 世界设置（Menu Bar > Window > World Settings）打开。

你可以用白昼序列（Day Sequence）设备进一步微调外观。为契合预设主题，部分设置无效，例如更改太阳尺寸与添加云层。

已知问题：对于双子太阳（Binary Suns）白昼序列 Actor，请添加一个白昼序列设备并将不透明度设为 0，以避免电影级质量下的错误。

超空间

太空新手岛屿模板展示了超空间特效，营造出玩家瞬间传送进激烈战斗场景的错觉。

星球大战功能集包含进入与退出两套 Niagara 系统资产，位于星球大战™内容 > VFX > 超空间（Star Wars™ Content > VFX > Hyperspace）。

超空间 VFX 镜头使用 Verse 设备 hyperspace_sequence_device 触发关卡序列，并将一块曲面平面置于玩家前方（随玩家移动重新定位）。关卡序列驱动材质与 Niagara 参数，营造进出超空间的错觉。这些关卡序列通过过场动画序列（Cinematic Sequencer）设备访问。

设计团队使用数据层在超空间 VFX 激活时卸载死星预制件，以降低内存占用。你可以使用数据层动态加载与卸载资产。要正常查看数据层，必须通过窗口 > 世界分区 > 数据层大纲（Window > World Partition > Data Layer Outliner）启用数据层大纲。更多信息请参阅 Unreal Engine 页面世界分区 - 数据层（World Partition - Data Layers）。

模板中用于创建该效果的附加资产（含音频）位于全部 > [你的项目名] > 超空间（All > [Your Project Name] > Hyperspace），以及顶层项目文件夹中的 hyperspace_sequence_device Verse 设备。

using { /Fortnite.com/Devices } using { /Verse.org/Simulation } using { /UnrealEngine.com/Temporary/Diagnostics } using { /Fortnite.com/Characters } # using { /Verse.org/SpatialMath } using { /UnrealEngine.com/Temporary/SpatialMath } # A Verse-authored creative device that can be placed in a level hyperspace_sequence_device := class(creative_device):

你可以通过迁移资产，在自己的项目中重现该镜头：

  • 右键点击 Hyperspace 文件夹并点击迁移（Migrate）。这会激活迁移工具，选中该文件夹中的内容及其所有依赖。
  • 取消勾选 NPC 与 UI 文件夹以及项目关卡文件，点击确定（Ok）。
  • 在资源管理器中选择要移入的项目位置，必须将资产放入项目的 Content 文件夹。
  • 打开你的另一个项目查看这些文件。
  • 将 BP_Hyperspace 资产放入关卡，作为效果的起点。该蓝图类代表静态网格体平面、材质实例与 Niagara 系统资产的组合。

如果迁移的资产未出现在文件夹中，请尝试以下任一方法：

  • 右键点击文件夹中已出现的资产，选择资产操作 > 修复验证问题（Asset Actions > Fix Validation Issues）。
  • 如果使用版本控制（Revision Control），请确保已同步最新版本并尝试刷新文件。
  • 重启 UEFN。

要添加 Verse 设备：

  • 创建名为 hyperspace_sequence_device 的新 Verse 设备。要了解如何在 Verse 中创建新设备，请参阅使用 Verse 创建自己的设备（Create Your Own Device Using Verse）。
  • 打开 Verse 资源管理器（Verse Explorer），双击 hyperspace_sequence_device.verse 以在 Visual Studio Code 中打开脚本。
  • 粘贴上述代码，编译，并将设备拖到你的岛屿上。
  • 在内容抽屉（Content Drawer）中搜索并添加三个过场动画序列（Cinematic Sequence）设备到岛屿。为设备命名并为每个设备连接一个关卡序列。
  • 搜索并添加一个体（Volume）设备，该设备触发超空间效果的开始。
  • 在大纲中选中你的 Verse 设备。
  • 在设备的细节面板中指定对象引用。你可以使用取色器在视口中选择设备，或使用下拉菜单搜索。
  • 保存你的项目。

在关卡序列中重新连接曲面平面与超空间 Niagara 系统资产。关卡序列还控制机库房间、歼星舰等资产的可见性。可按需替换为你的环境资产或删除。要了解 Sequencer 的更多用法，请参阅Sequencer 中的玩法事件（Gameplay Events in Sequencer）。

Sequencer 中的红色资产表示连接丢失，多因场景中没有该 Actor 或名称不匹配。你可以：

  • 重命名 Actor 以匹配 Sequencer 中的名称。在 Sequencer 工具栏点击扳手图标 > 高级 > 修复 Actor 引用（Wrench icon > Advanced > Fix Actor Reference），或尝试重新绑定可绑定引用（Rebind Possessable References）。
  • 移除现有轨道并重新添加该资产。

你可以使用迁移工具将其他非 Verse 模板专属资产添加到你的其他星球大战品牌岛屿项目。要复制 Verse 文件而不是新建，可打开资源管理器窗口手动将文件复制到另一个 Content 文件夹。

要了解可用的星球大战资产与玩法模板，请参阅使用星球大战™岛屿（Working With STAR WARS™ Islands）。
