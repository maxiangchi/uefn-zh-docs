在 Unreal Editor for Fortnite 中使用 UI 材质

Unreal Motion Graphics (UMG) 将材质用作小组件的一种“颜料”，材质可以用来创建轻量、动态的 UI 小组件外观。本节教程教你如何通过特定材质节点使用数学运算实现所需效果。

英文原标题：UI Materials in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

Unreal Motion Graphics (UMG) 将材质用作小组件（Widget）的一种“颜料”。材质可用于创建轻量、动态的 UI 小组件外观。本节教程将教你如何通过特定材质节点使用数学运算，在材质中创建所需效果。你可以创建会移动、发光乃至更多效果的材质。

有关使用偏重数学运算的材质节点创建材质的更多信息，请参阅以下 Unreal Engine 文档：

  • 矢量材质表达式（Vector Material Expressions）
  • 材质表达式参考（Material Expressions Reference）
  • 材质函数（Material Functions）
  • 仪表材质
