在 UEFN 中导入并播放网格体动画

你可以使用 Unreal Editor for Fortnite (UEFN) 为骨架网格体制作动画。本教程将展示如何导入骨架网格体及其关联动画，以及网格体上的动画在 UEFN 中的工作方式。

英文原标题：Import and Play Mesh Animations in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

你可以使用 Unreal Editor for Fortnite (UEFN) 为skeletal meshes (骨架网格体)制作动画。

本教程将展示如何导入骨架网格体、网格体附带的动画，以及网格体上的动画在 UEFN 中的工作方式。

导入骨架网格体及关联资源

UEFN 并未预置骨架网格体或动画，因此你必须自行创建或导入它们。

要深入了解如何在 Unreal Engine (虚幻引擎)中处理自定义资源，请查看Working with Content (使用内容)部分，重点阅读 FBX Content Pipeline (FBX 内容管线)页面。

  • 打开你的 UEFN 项目。
  • 在 Content Browser (内容浏览器)中，打开项目的内容文件夹，为你的骨架网格体创建一个 Characters 文件夹。
  • 为每种要导入的角色创建一个子文件夹。双击该文件夹将其打开。
  • 点击 Import (导入)，或在新文件夹内右键单击，从上下文下拉菜单中选择 Import to Current Folder (导入到当前文件夹)。

    从底部工具栏选择 Preview… (预览…)可打开预览窗口，在其中查看你要导入的所有资源。

    点击图片可放大。

  • 选择包含要导入网格体的 FBX file (FBX 文件),然后点击 Open (打开)。
  • Import Content (导入内容)窗口随即打开，点击 Import (导入)即可导入该资源及其所有关联文件。

在 Import Content (导入内容)窗口中，你可以通过自定义以下内容的导入选项，来管理随骨架网格体一起导入的资源：

  • Static Meshes (静态网格体)
  • Skeletal Meshes (骨架网格体)
  • Animations (动画)
  • Materials (材质)
  • Textures (纹理)

你的角色及其所有关联文件会上传到该子文件夹。

当你导入 FBX 以外的文件时，Import Content (导入内容)窗口会切换导入管线以适配你要导入的文件类型。

检查导入的资源

在各自的关联编辑器中打开不同资源，以检查导入的资源。

  • Skeletal Mesh (骨架网格体)
  • Animation Sequence (动画序列)
  • Skeleton (骨架)

你可以在 UEFN 的其他动画工作流中使用这些资源：

  • Creating animation presets (创建动画预设)。
  • Transferring character animations to a different character (将角色动画迁移到其他角色)。
  • Convert a static mesh into a skeletal mesh (将静态网格体转换为骨架网格体)。

Skeletal Mesh (骨架网格体)编辑器

双击骨架网格体文件会打开一个新窗口，你可以在其中更详细地查看网格体。点击右侧的 Skeleton Tree (骨架树)选项卡，导航到任意可动关节，测试骨架的哪些部位可以articulate (活动)。

Skeleton (骨架)编辑器

双击骨架文件会打开一个新窗口，你可以在其中更详细地查看骨架网格体资源的骨架。该编辑器提供了一种创建和编辑骨架网格体资源骨骼层级的方法。

Animation (动画)编辑器

双击动画缩略图可打开 Animation Editor (动画编辑器)。Animation Editor (动画编辑器)在新窗口中打开，你可以在编辑器中确认动画已应用到正确的角色并按预期播放。

在岛屿上播放动画

有多种方法可以让动画在你的岛屿上播放。每种方法各有优点，具体取决于你的需求。

从 Content Browser (内容浏览器)拖放

选择要使用的 Animation Sequence (动画序列)文件，将其从 Content Browser (内容浏览器)拖入视口。

除非在该资源的 Details (详情)选项卡下 Animation (动画)部分另有指定，否则动画将 perpetual loop (永久循环)播放。

动画不会在编辑器中播放。要查看动画播放效果，请在 Fortnite 客户端中playtest (试玩测试)你的岛屿。

使用 Animated Mesh (动画网格体)设备

当这个device (设备)与你的动画配对后，你可以控制各种动画触发器。

  • 在 Content Browser (内容浏览器)中导航到 Fortnite > Devices (设备)。
  • 将 Animated Mesh (动画网格体)设备拖入视口。
  • 按如下方式配置设备的 User Options (用户选项)：
  • 要将设备绑定到骨架网格体，请将网格体拖放到 Skeletal Mesh (骨架网格体)字段，或从该字段的下拉菜单中选择网格体。
  • 将你想用于网格体的动画拖入 Animation (动画)字段，或从下拉菜单中选择。
  • 将两个 Trigger (触发器)设备拖入视口。
  • 要将触发器bind (绑定)到动画：
  • 选中 Animated Mesh (动画网格体)设备，向下滚动到 User Options - Functions (用户选项 - 函数)。
  • 对于 Play Animation Event (播放动画事件)，点击 + 添加一个数组元素，然后在两个字段中分别选择 Trigger 和 On Triggered (触发时)。
  • 对于 Pause Animation Event (暂停动画事件)，点击 + 添加一个数组元素，然后在两个字段中分别选择 Trigger2 和 On Triggered (触发时)。
  • 按下 Play (播放)打开客户端查看设备的实际效果。踩上第一个触发器开始播放动画，第二个触发器暂停动画。
