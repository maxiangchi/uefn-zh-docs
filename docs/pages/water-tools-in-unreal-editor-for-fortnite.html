UEFN 中的水体工具

Unreal Editor for Fortnite（UEFN）提供了创建可自定义水体的工具：海洋、河流、湖泊、岛屿和游泳池。本页介绍如何放置这些水体，并使用样条线（Spline）点雕刻出所需的形状。

英文原标题：water-tools-in-unreal-editor-for-fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

Unreal Editor for Fortnite（UEFN）提供了创建可自定义水体的工具。你可以从内容浏览器（Content Browser）的 Environment 文件夹中放置海洋、河流、湖泊、岛屿和游泳池。除了游泳池之外，这些水体都会自动抬升或降低地形，无需手动雕刻地形。

水体工具不应与 Fortnite 创意模式中的水体设备（Water device）混淆。水体工具使用样条线（splines）为水体创建可编辑的轮廓，以表现曲线和弯曲。

添加河流

要使用河流（River）工具，在内容浏览器（Content Browser）的 Environment 文件夹中找到 River 缩略图，然后将其拖入视口。

将河流工具放入视口后，就可以开始雕刻河流了。

使用样条线点雕刻河流

样条线点就像脊柱上的椎骨，线条会根据你对样条线的编辑和移动，在点与点之间弯曲伸展。

在样条线上的任意位置右键单击，可打开样条线编辑（spline edit）菜单。

样条线点（Spline Point）下的菜单项包括：

菜单项值
删除样条线点（Delete Spline Point）删除选中的样条线点。
复制样条线点（Duplicate Spline Point）创建选中样条线点的副本。
选择样条线点（Select Spline Points）打开子菜单，包含以下选项：
  • 选择所有样条线点（Select All Spline Points）：选择样条线中的所有点。
  • 选择上一个样条线点（Select Prev Spline Point）：选择样条线中的上一个点。
  • 选择下一个样条线点（Select Next Spline Point）：选择样条线中的下一个点。
  • 添加上一个样条线点（Add Prev Spline Point）：将上一个样条线点加入选择。
  • 添加下一个样条线点（Add Next Spline Point）：将下一个样条线点加入选择。
样条线点类型（Spline Point Type）将样条线点设置为提供曲线控制或直线控制。
重置为自动切线（Reset to Automatic Tangent）决定如何重置曲线样条线点的切线，可在以下两者中选择：
  • 不钳制切线（Unclamped Tangent）：将切线值重置为默认的不钳制值。
  • 钳制切线（Clamped Tangent）：将此样条线点的切线重置为默认值。
样条线生成面板（Spline Generation Panel）打开一个面板，在所选样条线内创建基本形状。
聚焦所选（Focus Selected）将相机移动到所选样条线前方。
对齐吸附（Snap Align）打开侧边菜单，提供不同的吸附或对齐所选样条线点的选项：
  • 吸附到地面（Snap to Floor）：将所选样条线吸附到地面。
  • 与地面齐（Align to Floor）：将所选样条线与地面齐。
  • 吸附到最近的样条线点（Snap to Nearest Spline Point）：将所选样条线吸附到最近的样条线点。
  • 与最近的样条线点齐（Align to Nearest Spline Point）：将所选样条线与最近的样条线点齐。
  • 垂直于最近的样条线点齐（Align Perpendicular to the Nearest Spline Point）：将所选样条线与最近的样条线点垂直齐。
  • 吸附到 Actor（Snap to Actor）：将所选样条线点吸附到选定的 Actor。
  • 与 Actor 齐（Align to Actor）：将所选样条线与选定的 Actor 齐。
  • 垂直于 Actor 齐（Align Perpendicular to Actor）：将所选样条线与选定的 Actor 垂直齐。
  • 全部吸附到所选 X（Snap All to Select X）：将所有样条线吸附到所选样条线点世界 X 轴位置。
  • 全部吸附到所选 Y（Snap All to Select Y）：将所有样条线吸附到所选样条线点世界 Y 轴位置。
  • 全部吸附到所选 Z（Snap All to Select Z）：将所有样条线吸附到所选样条线点世界 Z 轴位置。
  • 吸附到上次所选 X（Snap to Last Selected X）：将所选样条线点吸附到上次所选样条线点世界 X 轴位置。
  • 吸附到上次所选 Y（Snap to Last Selected Y）：将所选样条线点吸附到上次所选样条线点世界 Y 轴位置。
  • 吸附到上次所选 Z（Snap to Last Selected Z）：将所选样条线点吸附到上次所选样条线点世界 Z 轴位置。
重置为默认值（Reset to Default）将所选样条线重置为其原型默认值。
可视化翻滚和缩放（Visualize Roll and Scale）切换可视化是否随所选样条线点翻滚和缩放。
允许不连续样条线（Allow Discontinuous Splines）切换可视化是否允许分别为离开（Leave）切线和到达（Arrive）切线单独设置。
可视化水流速度（Visualize Water Velocity）切换是否可视化水的流速。
可视化河流宽度（Visualize River Width）切换是否可视化河流的宽度。
可视化深度（Visualize Depth）切换是否可视化河流的深度。

点击默认河流工具两端的样条线点来延长河流，然后通过样条线点的轴心对其进行平移。

通过复制已有样条线点，再移动和编辑新的样条线点，或者在样条线处右键单击并选择在此处添加样条线点（Add Spline Point Here），可以在现有样条线点之间创建新的样条线点。

点击某个样条线点，再点击其两个切线控制点中的一个，即可调整曲线。

创建好河流后，切换可视化水流速度（Visualize Water Velocity）、可视化河流宽度（Visualize River Width）和可视化河流深度（Visualize River Depth），查看不同特性。通过这些切换视图查看河流，有助于明确河流的哪些部分需要编辑以贴合地形。你也可以在详细信息面板中逐个更改每个样条线点的这些属性。

添加湖泊

要使用湖泊（Lake）工具，在内容浏览器（Content Browser）中找到 Lake 缩略图并拖入视口，会出现一个默认的湖泊形状。

通过在视口中添加、复制和平移样条线点，塑造出独特的湖泊形状。

样条线菜单提供所有基本的样条线编辑功能，但河流的切换项不可用。湖泊水体还有更多属性可在详细信息面板中使用，例如深度、波浪外观，以及与地形的交互方式。

添加海洋

要使用海洋（Ocean）工具，在内容浏览器（Content Browser）中找到 Ocean 缩略图并拖入视口，会出现一个默认的海洋形状。请注意，关卡中通常只放置一个海洋 Actor 才合理。

海洋水体提供的控制与湖泊水体非常相似，区别在于：海洋的水显示在样条线之外，而湖泊的水显示在样条线之内。

海洋出现在视口边缘，洋流会推动水体流动，洋流是海洋环境的默认组成部分。

编辑样条线点可创建自定义海岸线。

添加岛屿

要使用岛屿（Island）工具，在内容浏览器中找到 Island 缩略图并拖入视口。要发挥作用，岛屿需要放置在另一个水体内部。岛屿工具提供通用的样条线编辑功能，但不提供其他属性，它的主要作用是防止其他水体在所定义的区域内雕刻地形。

添加游泳池

要使用游泳池（SwimmingPool）工具，在内容浏览器中找到 SwimmingPool 缩略图并拖入视口。这会创建一块自由漂浮的矩形水面，不会影响地形，主要用途是人工游泳池或喷泉。游泳池工具的样条线控制基本不起作用，形状限定为矩形，你可以使用常规的平移、旋转和缩放控制来调整它。
