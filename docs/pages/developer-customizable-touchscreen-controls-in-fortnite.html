开发者可自定义触屏控制

默认触屏控制按钮可摆放到平视显示（HUD）任意位置，还支持多套布局切换与单个按钮隐藏，本文介绍如何用 HUD 控制器（HUD Controller）设备与 Verse 实现开发者侧的触屏布局自定义。

英文原标题：Developer Customizable Touchscreen Controls in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

默认触屏控制组合——跳跃（Jump）、射击（Shoot）、换弹（Reload）、瞄准（Aim）、蹲伏（Crouch）、疾跑（Sprint）等动作——都可以摆放到平视显示（HUD）上的任意位置。你还可以配置多套布局随时切换，并明确隐藏体验中用不到的单个控制按钮。

这是由开发者控制的触屏布局自定义版本。由玩家控制的布局自定义是一套独立的、早已存在的功能，本功能不会改变它。

你可以使用 HUD 控制器（HUD Controller）设备自定义触屏控制的位置。整个工作流程在虚幻编辑器 Fortnite 版（UEFN）中完成。

使用 HUD 控制器（HUD Controller）设备

若要自定义游戏的触屏控制，首先把一套布局构建为 Unreal Motion Graphics（UMG）用户控件（User Widget），然后把该控件指派给岛屿上的 HUD 控制器（HUD Controller）设备。运行时，HUD 控制器设备会使用你控件中的布局，覆盖触屏控制的默认位置。

触屏控制（Touchscreen Controls）

以下控制均可重新摆放：

  • 跳跃（Jump）
  • 射击（Shoot）
  • 蹲伏（Crouch）
  • 换弹（Reload）
  • 次要技能（Secondary Ability）
  • 疾跑（Sprint）
  • 载具加速（Vehicle Boost）
  • 载具喇叭（Vehicle Horn）
  • 载具刹车（Vehicle Brake）
  • 载具瞄准（Vehicle Aim (ADS)）
  • 载具刹车 / 滑行（Vehicle Brake / Coast）
  • 载具切换座位（Vehicle Switch Seat）
  • 载具油门（Vehicle Throttle）
  • 背包（Backpack）
  • 地图标记（Map Ping）
  • 自动开火开关（Toggle Autofire）
  • 地图开关（Toggle Map）

每个控制都会映射到 HUD 控制器设备中的一个动作（Action）选项，该选项决定触屏功能实际执行的操作。

UMG 分配与设备调整（UMG Assignment and Device Adjustments）

自定义默认触屏控制的步骤如下：

  • 在虚幻编辑器 Fortnite 版（UEFN）中创建一个标准用户控件（User Widget），用来承载触屏布局。
  • 添加一个画布（Canvas）布局面板作为根控件。
  • 为每个想要重新摆放的默认控制添加一个触控布局覆盖（Touch Control Layout Override）控件。

未添加到标准布局中的触屏控制将保持默认外观。

  • 逐个设置以下属性：
    • 动作（Action）——该按钮代表的触屏动作，取值为枚举：跳跃（Jump）、瞄准（Aim）、射击（Shoot）、蹲伏（Crouch）、疾跑（Sprint）等。
  • 从布局中隐藏（Hide from Layout）——选择玩家是否可以使用该按钮。
注意：如果隐藏了某个动作，请确保你的游戏并不需要该动作，因为触屏设备上的玩家将无法再使用被隐藏的动作。
  • 图标覆盖（Icon Override，可选）——用于替代默认图标的纹理。
  • 颜色覆盖（Color Override，可选）——应用于按钮的染色。
  • 在控件画布上摆放每个按钮的位置与大小。HUD 控制器设备会使用控件画布槽位的锚点来放置实际的触屏控制。
  • 在岛屿上放置一个HUD 控制器（HUD Controller）设备，并把新布局指派给该设备的覆盖触控布局（Override Touch Layout）属性。
  • 启用 HUD 控制器设备。设备启用后，就会用你布局中的位置替换默认触屏位置。

若要在运行时切换布局（例如玩家进入不同游戏模式时），可以启用另一个指向不同用户控件的 HUD 控制器设备。

如果没有任何带覆盖触控布局（Override Touch Layout）的 HUD 控制器设备处于启用状态，体验将回退到 Fortnite 默认触屏控制。

已禁用输入的触屏控制默认隐藏

如果你在 Verse 中取消订阅了某个默认动作，引擎会自动隐藏对应的触屏按钮。

当你的体验使用精简或自定义控制组合时（例如只需要跳跃的单按钮游戏），请使用该特性。引擎会识别出该动作不适用于你的游戏，并阻止显示触屏按钮，而不需要使用变通手段，例如隐藏角色，或让默认动作在后台静默运行。

输入映射上下文（Input Mapping Context (IMC)）

在 Verse 中添加或移除输入映射上下文（Input Mapping Context，IMC），会显示或隐藏该上下文关联的所有默认触屏按钮。预置的 IMC 包括遍历映射（TraversalMapping）（移动与跳跃类动作）和远程武器映射（RangedWeaponMapping）（武器类动作），两者都位于 /Fortnite.com/Input/Character。

重新添加 IMC 或重新订阅动作，即可恢复其按钮，且不会出现重复。

若要隐藏某个映射上下文中的所有按钮，可使用 player_input.RemoveInputMapping 移除该上下文；若要恢复，则使用 player_input.AddInputMapping 加回：

if (PlayerInput := GetPlayerInput[Player]):
    # Hide every default touchscreen button in the ranged-weapon context
    PlayerInput.RemoveInputMapping(RangedWeaponMapping)
    # Later, restore them
    PlayerInput.AddInputMapping(RangedWeaponMapping)

若要隐藏单个动作的按钮，不要在 input_events 上订阅它的事件；若要让按钮出现并响应点按，可订阅触发激活事件（TriggerActivationEvent）（或 input_events 上的其他事件），不再需要该按钮时取消订阅即可：

if (PlayerInput := GetPlayerInput[Player]):
    InputEvents := PlayerInput.GetInputEvents(Reload)
    # Subscribe — the Reload touchscreen button appears
    Subscription := InputEvents.TriggerActivationEvent.Subscribe(OnReloadTriggered)
    # Cancel — the Reload touchscreen button is hidden again
    Subscription.Cancel()

input_events 对象还提供开始检测事件（BeginDetectEvent）、持续检测事件（DetectionOngoingEvent）、结束检测事件（EndDetectEvent）和取消激活事件（CancelActivationEvent），用于更丰富的输入处理。订阅其中任意一个，在可见性判定上都视为已订阅该动作。
