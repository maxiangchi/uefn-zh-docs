在 UEFN 中创建你的第一个能力

本教程将教你创建一个不可叠加的周期性治疗能力，玩家跳跃时会取消该能力，涵盖 Verse 脚本、支撑类与玩法系统。

英文原标题：Create Your First Ability in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

本教程将教你创建一个不可叠加的周期性治疗能力，当玩家跳跃时该能力会被取消。

你将创建定义治疗能力的 Verse 脚本、全部支撑类，以及授予该能力的玩法系统。

前提条件

由于该功能目前为实验性功能，你必须在 Project Settings（项目设置）中启用 Scene Graph Experimental Features（场景图（Scene Graph）实验性功能）才能使用它。

创建 Verse 脚本

在本节中，你将创建 Verse 脚本，用于存放本教程的全部代码。

  1. 在菜单栏上选择 Verse > Verse Explorer（Verse 资源管理器）。
  2. 在 Verse Explorer 中右键点击你的项目，选择 Create Verse File（创建 Verse 文件）。
  3. 在 Create Verse Script（创建 Verse 脚本）窗口中，将脚本命名为 ability_example，然后选择 Create Empty（创建空文件）。
  4. 在菜单栏上选择 Verse > Open Project in VS Code（在 VS Code 中打开项目）。
  5. 输入以下代码以添加所需的模块：
# Verse Ability Example
# A channeled heal-over-time ability that cancels if the player jumps.
using { /Fortnite.com/Characters }
using { /Fortnite.com/Input }
using { /Fortnite.com/Playspaces }
using { /UnrealEngine.com/Abilities }
using { /Verse.org/Input }
using { /Verse.org/SceneGraph }
using { /Verse.org/Simulation }

添加工具函数，用于返回目标实体的 fort_character。稍后把效果指派给目标时会用到它。

#########################################################
# UTILITY
#########################################################
# Get an entity's fort_character, if available.
(TargetEntity:entity).GetFortChar()<decides><transacts> : fort_character = first (Component : TargetEntity.GetComponents(), FortChar := fort_character[Component]) {FortChar}

治疗上下文与跳跃取消

定义两个支撑类：跳跃取消原因，以及保存目标信息和额外治疗量重写的技能上下文（ability context）。

  • 添加 jump_cancel 类。这是一个简单的类型化标记，用于标识特定的取消原因。 
    #########################################################
# CANCEL REASON - Why did the effect end?
#########################################################
# A typed cancel reason so listeners can distinguish why the heal stopped.
jump_cancel := class(cancel_reason){}
  • 添加 heal_context 类。基类自带目标信息，而新增的成员变量提供可选的数值重写，让你可以基于上下文创建效果变体。 
    #########################################################
# ABILITY CONTEXT - Data passed between layers
#########################################################
# Custom context carrying heal-specific data.
# NOTE: The base ability_context already provides Instigator, Participants, and Targets.
heal_context := class(ability_context):
    # Optional heal effect value overrides.
    HealPerTickOverride : ?float = false
    TickIntervalOverride : ?float = false

创建效果组件，其中包含周期性治疗的玩法逻辑。

  • 添加 heal_effect_component 及变量。成员变量的值可在 Prefab Editor（预制件编辑器）中编辑。

# EFFECT COMPONENT - Lifetime & logic
#########################################################

# This class handles the effect's gameplay logic and lifetime.

    # The amount of healing to apply per TickInterval.
    @editable
  • 添加 OnJumpStateChanged() 回调函数。当玩家跳跃时，它会尝试取消该效果。 
    # If the player starts jumping, cancel the channel.
OnJumpStateChanged(FortCharacter : fort_character) : void = if (Cancel[jump_cancel{}]): return
  • 添加 OnBeginUse() 回调函数重写。它会应用技能上下文中指定的数值重写。 
    # Called immediately after the effect is added to the scene graph.
# Use this for setup, caching references, etc.
OnBeginUse<override>()<transacts> : void =
    # Grab the context data and store what we need.
    if (HealContext := heal_context[Context?]):
        if (HealPerTickOverride := float[HealContext.HealPerTickOverride?]):
            set HealPerTick = HealPerTickOverride
        if (TickIntervalOverride := float[HealContext.TickIntervalOverride?]):
  • 添加 OnSimulate() 回调函数重写。它会绑定跳跃事件，并包含运行到效果结束的主更新循环。 
    # Main async logic update function. Runs after OnBeginUse completes.
OnSimulate<override>()<suspends> : void =
    var ElapsedTime : float = 0.0
    # Bind the JumpedEvent that cancels the heal.
    if:
        InstigatorAgent := Context?.Instigator
        FortChar := InstigatorAgent?.GetFortCharacter[]
    then:
        FortChar.JumpedEvent().Subscribe(OnJumpStateChanged)
  • 保存 Verse 文件。
  • 在编辑器中，点击工具栏上的 Compile Verse（编译 Verse）。

创建预制件

构建包含你制作的 heal_effect_component 的预制件。

  1. 在 Content Browser（内容浏览器）中，点击 Add (+)（添加）按钮，然后选择 Entity Prefab（实体预制件）。
  2. 在 Create Entity Prefab Definition（创建实体预制件定义）窗口中，选择 ability_effect。
  3. 将预制件命名为 PF_HealEffect。
  4. 双击该预制件以打开 Prefab Editor（预制件编辑器）。
  5. 在 Details（详情）面板中：右键点击 ability_effect_component 并选择 Delete（删除）；点击 Add Component (+)（添加组件）按钮，搜索 heal_effect_component 并添加。
  6. 保存预制件。

治疗能力

定义 heal_ability 类，用于校验能力使用，并把上下文与效果绑定在一起。

  • 添加 heal_ability 类和 ActiveEffects 列表成员变量。 
    #########################################################
# ABILITY - Declaration & activation logic
#########################################################
# Define the healing ability, its requirements, and factory overrides.
heal_ability := class(ability(heal_context, ability_effect)):
    # Tracks live effect instances.
    var ActiveEffects<override> : []ability_effect = array{}
  • 添加 CanUse() 函数重写。它在 Use() 被调用后运行，用于检查本次使用是否被允许。本实现确保同一时间只有一个治疗效果。 
    # Gate ability activation. Current implementation restricts stacking and only allows one active heal at a time.
CanUse<override>(AbilityEffectParent : entity, AbilityContext : ability_context)<reads><decides> : void = (ActiveEffects.Length = 0)
  • 添加 MakeContext() 工厂函数重写。能力校验通过后，它会创建用于绑定到效果的上下文。 
    # Context factory override. Called internally by Use().
MakeContext<override>()<transacts> : heal_context = heal_context{}
  • 添加 MakeAbility() 工厂函数重写。它会创建效果实体，具体来说，就是创建前面章节中制作的治疗效果预制件。 
    # Effect prefab factory override. Called internally by Use().
MakeAbility<override>()<transacts> : ability_effect =
    HealEffectPrefab := PF_HealEffect{}
    if (ValidAbility := ability_effect[HealEffectPrefab]):
        return ValidAbility
    return ability_effect{}

玩家能力管理组件

创建授予玩家治疗能力、绑定输入并处理效果清理的组件。

  • 添加 player_ability_manager_component 类和成员变量。 
    #########################################################
# PLAYER COMPONENT - Granting Abilities and Wiring Input
#########################################################
# Grants the owning player the heal ability and processes the related input.
# This component is attached to the manager entity constructed by the ability_system_watcher.
player_ability_manager_component := class<final_super>(component):
    # The base heal ability.
    HealAbility : heal_ability = heal_ability{}
  • 添加 OnEffectEnded() 回调函数。当效果结束时（自然结束或被取消），它会把效果从玩家和场景中移除。 
    # Called by EndUseEvent subscription when the ability is finished (naturally or cancelled).
OnEffectEnded(EffectEntity : entity) : void =
    # Remove the effect from the parent and the scene.
    EffectEntity.RemoveFromParent()
  • 添加 OnSecondaryFire() 回调函数。一旦绑定到次要开火键，玩家输入就会触发该效果。 
    # Triggered when the player inputs secondary fire.
OnSecondaryFire(Args : tuple(player, logic)) : void =
    Player := Args(0)
    IsSecondaryFirePressed := Args(1)
    # Test if secondary fire was pressed (instead of released) and get the player agent and entity.
    if:
        IsSecondaryFirePressed?
        PlayerAgent := agent[Player]
        PlayerEntity := PlayerAgent.GetFortCharacter[].GetEntity[]

    # Called when the component begins simulating within the scene.
OnSimulate<override>()<suspends> : void =
    # Get the owning player's input system.
    if:
        PlayerInput := GetPlayerInput[OwningPlayer]
    then:
        # Enable the ranged weapon input mapping (contains WeaponSecondary).
        PlayerInput.AddInputMapping(Character.RangedWeaponMapping)

  • 在编辑器中，点击工具栏上的 Compile Verse（编译 Verse）。

创建预制件

创建能力系统观察者预制件并将其放入关卡，这样会话开始时它就会运行。

  1. 在 Content Browser（内容浏览器）中，点击 Add (+)（添加）按钮，然后选择 Entity Prefab（实体预制件）。
  2. 在 Create Entity Prefab Definition（创建实体预制件定义）窗口中，点击 New Prefab (+)（新建预制件）按钮。
  3. 将预制件命名为 PF_AbilitySystemWatcher。
  4. 双击该预制件以打开 Prefab Editor（预制件编辑器）。
  5. 在 Details（详情）面板中，点击 Add Component (+)（添加组件）按钮，搜索 ability_system_watcher_component 并添加。
  6. 保存预制件。
  7. 把 PF_AbilitySystemWatcher 预制件从 Content Browser 拖入 Level（关卡），然后保存关卡。

伤害区域

在关卡中添加伤害区域，以便测试你的治疗能力。

  1. 在 Content Browser（内容浏览器）中选择 All（全部）文件夹。
  2. 搜索 Damage Volume（伤害体积）。
  3. 把 Damage Volume 拖入你的 Level（关卡）。
  4. 在 Details（详情）面板中启用 Zone Visible During Game（游戏中显示区域）。

试玩测试

启动会话并进行试玩测试，验证一切正常工作。

  • 受伤后，点击右键激活能力，观察生命值周期性提升。
  • 治疗过程中跳跃，取消治疗。
  • 验证能力会在设定时长结束后自行结束。
  • 快速连续点击右键，验证能力不会叠加。

自主拓展

想进一步探索？以下是几个可以自己尝试的方向：

  • 为你的效果预制件添加视觉和音频元素。
  • 试验技能上下文中的重写值。
  • 让治疗可以指向其他玩家。
