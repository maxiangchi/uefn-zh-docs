第一座岛屿 05：用 Verse 为玩法增添趣味

Verse 是一种可与 UEFN 配合使用的编程语言。本页介绍快速将 Verse 加入项目的入门基础，教你用 Verse 让靶子一击倒下，并实现加减分玩法。

英文原标题：First Island 05 Spice Up The Gameplay With Verse In Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

Verse 是一种可与 UEFN 配合使用的编程语言。本页介绍快速将 Verse 加入项目的入门基础，为新手和有经验的程序员打下基础，让大家感受这门语言能做些什么。

你在本教程前面创建的目标设备一击还打不倒，所以你将学习如何使用 Verse 让它们一击即倒！

创建新的 Verse 设备

你将创建一个 Verse 设备并将它放置在岛屿上。

可以把它理解为一个设备，它会根据你的指令告诉其他设备做什么。换句话说，你将编写一个 Verse 程序，用它重新编程 UEFN 中的现有设备！

  • 在菜单栏（menu bar）上选择 Verse > Verse Explorer。
  • 在 Verse Explorer 中右键点击你的项目，选择向项目添加新的 Verse 文件（Add new Verse file to project）。

这会打开创建 Verse 脚本（Create Verse Script）窗口。

  • 在创建 Verse 脚本（Create Verse Script）窗口中选择 Verse 设备（Verse Device）模板。
  • 在窗口底部将设备重命名为 shooting_range_manager_device，然后点击创建（Create）。

你可以在内容浏览器（Content Browser）中项目名称下方找到 shooting_range_manager_device，也可以使用搜索框查找该设备。

  • 在菜单栏（menu bar）上选择 Verse > 构建 Verse 代码（Build Verse Code）。

使用 Verse 设备代码时，必须先构建（build）（也叫编译（compiling））设备才能使用。这意味着让 Verse 把它转换成可以作为游戏或游戏一部分运行的格式。在构建完成之前，Verse 设备不会出现在内容浏览器或 Outliner（大纲视图）中。

  • 你可以在内容浏览器中项目名称下方找到 shooting_range_manager_device，也可以使用搜索框查找该设备。
  • 将该设备拖入视口。
  • 在细节（Details）面板的用户选项（User Options）下，取消勾选游戏中可见（Visible in Game），让游戏运行时隐藏该设备。

设置好靶子

还记得3. 建造射击场（3. Build a Shooting Gallery）中的好靶子（good targets）吗？

你将使用 Verse 设备设置好靶子，让它们被击中一次就倒下。

  • 在 Verse Explorer 中双击 shooting_range_manager_device.verse 打开 Verse 文件。
  • 删除文件中的所有代码，然后复制下面的代码，粘贴到原来代码的位置。
using { /Fortnite.com/Devices }
using { /Verse.org/Simulation }

# A device that manages shooting range gameplay.
shooting_range_manager_device := class(creative_device):
    @editable GoodTarget1:shooting_range_target_track_device = shooting_range_target_track_device{}
    @editable

在 Verse 中，变量（variable）是程序中可以在程序运行时改变的信息。

当变量是可编辑（editable）的，意味着代码在 UEFN 中是暴露（exposed）的，也就是说可以直接在 UEFN 中修改，而无需每次都重新构建 Verse 代码。

你刚刚添加到 Verse 设备的代码创建了三个变量（GoodTarget1、GoodTarget2 和 GoodTarget3），它们的类型为 shooting_range_track_device。它们将代表玩家击中得分的目标。通过将它们设为 @editable，你现在可以在细节（Details）面板中随意设置它们的值，而不必反复修改 Verse 代码。由于是第一次添加这段代码，仍然需要编译一次。

  • 打开 shooting_range_manager_device 的 Details 面板，在视口中选中 shooting_range_manager_device。
  • 编译你的代码。
  • 在细节（Details）面板中，将每个好靶子分别设置为不同的 Target Dummy Track（靶子假人轨道）设备。
  • 从下面代码块中的 <# --- New Code Start --- #> 开始，复制并粘贴以下代码到 Verse 文件中。这段代码让好靶子被击中时倒下。

事件订阅将目标的 HitEvent 与为该目标定义的回调关联起来。

<# --- New Code Start --- #>
# Runs when the device is started in a running game.
OnBegin<override>()<suspends>:void=
    # Subscribing to the GoodTarget HitEvents.
    GoodTarget1.HitEvent.Subscribe(OnGoodTarget1Hit)
    GoodTarget2.HitEvent.Subscribe(OnGoodTarget2Hit)
    GoodTarget3.HitEvent.Subscribe(OnGoodTarget3Hit)
    # A hit callback that pops down the first GoodTarget.
  • 粘贴后编译你的代码。

当你在代码块中看到以 # 或 <# 开头、以 #> 结尾的行，这些被称为代码注释（code comments）。

代码注释不是程序的一部分，而是程序员写给其他程序员的信息，或用来提醒自己当时为什么这样做。

有关代码注释的更多信息，请参阅 Verse 语言快速参考中代码注释（Code Comments）一节。

设置坏靶子

你的坏靶子是定制为泰迪熊（Teddy Bears）的靶子假人（Target Dummy）设备。这一次，你将把它们加入 Verse 设备，让它们同样一击即倒，但玩家每次击中会扣分而不是加分。

  • 添加以下代码，创建三个 shooting_range_target_device 变量来存储坏靶子的引用。
using { /Fortnite.com/Devices }
using { /Verse.org/Simulation }

# A device that manages shooting range gameplay.
shooting_range_manager_device := class(creative_device):
    @editable GoodTarget1:shooting_range_target_track_device = shooting_range_target_track_device{}
    @editable
  • 编译你的代码。
  • 在视口中选中 shooting_range_manager_device。
  • 在细节（Details）面板中，将每个坏靶子分别设置为不同的 Target Dummy（靶子假人）设备。
  • 添加以下代码，让坏靶子被击中时倒下。
using { /Fortnite.com/Devices }
using { /Verse.org/Simulation }

# A device that manages shooting range gameplay.
shooting_range_manager_device := class(creative_device):
    @editable GoodTarget1:shooting_range_target_track_device = shooting_range_target_track_device{}
    @editable

设置计分

在使用 Verse 自定义设备之前，必须先添加你要自定义的设备。

只用 Fortnite 设备也能设置计分，但在 Verse 中做这件事更容易，而且所需的设备更少。

添加计分设备（Add a Scoring Device）

尽管你要设置两种计分（加分和扣分），但使用 Verse 后，只需要一个计分设备就能全部搞定。

  • 在内容浏览器（Content Browser）的搜索栏中输入 Score Manager 找到 Score Manager 设备。
  • 将 Score Manager 设备拖入视口。Score Manager 的用户选项应在细节（Details）面板中打开。
  • 在细节（Details）面板中修改以下选项：
选项值
Enable During Phase（启用阶段）Gameplay Only（仅 gameplay）
Display Score Update on HUD（在 HUD 上显示分数更新）勾选（Check）

用 Verse 自定义计分设备（Customize the Scoring Device with Verse）

现在你可以把 Score Manager 加入 Verse 设备，根据击中的目标调整玩家分数。

  • 添加以下代码，创建变量来存储计分器的引用和分数值。你可以通过修改赋值来更改默认分数，也可以在细节（Details）面板中修改值来覆盖默认值。
using { /Fortnite.com/Devices }
using { /Verse.org/Simulation }

# A device that manages shooting range gameplay.
shooting_range_manager_device := class(creative_device):
    <# --- New Code Start --- #>
    @editable ScoreManager:score_manager_device = score_manager_device{}
  • 编译你的代码。
  • 在视口中选中 shooting_range_manager_device。
  • 在 shooting_range_manager_device 的细节（Details）面板中，将 ScoreManager 设置为 Score Manager 设备。
  • 添加以下代码，在击中好靶子和坏靶子时更新玩家分数。
using { /Fortnite.com/Devices }
using { /Verse.org/Simulation }

# A device that manages shooting range gameplay.
shooting_range_manager_device := class(creative_device):
    @editable ScoreManager:score_manager_device = score_manager_device{}
    @editable
  • 编译你的代码。
  • 从菜单栏（Menu Bar）选择 Verse > 构建 Verse 代码（Build Verse Code）。

如果你一直开着 Fortnite 会话，点击 Push Changes（推送更改）到 live edit（实时编辑），让它接收你用 Verse 所做的更新。你可能还需要结束并重新开始一局游戏才能正常看到更改。

  • 在 Fortnite 会话中试玩你的更改，确认：
    • 击中好靶子时分数增加。（游戏中按 M 键打开记分板。）
    • 击中坏靶子时分数减少。
    • 可以一击打倒靶子。
