在 UEFN 中使用 Lumen 曝光管理器

使用 Lumen 曝光管理器调整后期处理设置，让精心打磨的 UEFN 岛屿在高中低端平台上保持一致的外观与质感。

英文原标题：Using The Lumen Exposure Manager In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

如果你想知道为什么你的岛屿在 PC 上与在 Nintendo Switch 上看起来差别巨大，图形质量可能并非唯一的罪魁祸首。低端平台的光照能力不同，渲染时不使用 Lumen。

光照对岛屿的视觉冲击力起着巨大作用。

使用 Lumen 曝光管理器（Lumen Exposure Manager），你可以调整后期处理设置，让精心打磨的 UEFN 岛屿在全部支持平台上保持一致的外观与质感。

Lumen 曝光管理器允许你分别修改中低端平台（NonLumenPostProcess）与高端平台（LumenPostProcess）的后期处理，在 Fortnite 支持的设备间保持一致。

默认的昼夜循环（Day Night Cycle）包含自动曝光管理。

当所有时间管理（Time of Day Managers）都被禁用、由你手动控制全部光照时，才应使用 Lumen 曝光管理器。

你会注意到，即使使用默认设置，Lumen 与非 Lumen 设置在局部曝光（Local Exposure）上也会有所不同。

通过学习库（Learning Library）中的 UEFN 高级光照（UEFN Advanced Lighting）视频教程，学习使用 UEFN 光照工具为你的岛屿打造自定义环境：

  • UEFN 高级光照：时间管理器（Time of Day Manager）
  • UEFN 高级光照：环境灯光装置（Environment Light Rig）
  • UEFN 高级光照：Lumen 曝光管理器（Lumen Exposure Manager）

要启用完全手动控制，前往世界设置（World Settings）选项卡，勾选 Disable All Time of Day Managers。

要在项目中放置自己的光照组件：

  • 打开 Place Actors 面板
  • 从 Lights 或 Visual Effects 选项卡中选择所需的 Actor，拖入视口。

查找与放置 Lumen 曝光管理器

  • 打开内容浏览器（Content Browser）。
  • 打开 Fortnite 文件夹。
  • 打开 Lighting 文件夹并选择 Tools 文件夹。
  • 选择 LumenExposureManager 并把该设备拖入视口（Viewport）。
  • 为低端平台自定义 NonLumenPostProcess 组件的选项。
  • 为高端平台自定义 LumenPostProcess 组件的选项。

如果你的全局光照（Global Illumination）设置为 High、Epic 或 Cinematic，视口默认显示 LumenPostProcess 组件的设置。

你可以在此处检查设置：

要查看岛屿在不使用 Lumen 时的样子，把全局光照设置为 Medium 或 Low，然后编辑 NonLumenPostProcess 组件。

启用 Lumen 的岛屿的曝光设置已配置为匹配最新 Fortnite 大逃杀的外观与质感。

用户选项

你可以使用 Lumen 曝光管理器设置以下属性：

镜头（Lens）

镜头（Lens）类别包含模拟真实相机镜头常见效果的属性与设置。

泛光（Bloom）

泛光（Bloom）是真实的光学现象，能以适中的渲染性能开销显著提升渲染图像的真实感。当用肉眼观察处于深色背景上的明亮物体时可以看到泛光；更亮的物体还会引起其他效果（条纹、镜头光斑），但经典泛光不涵盖那些。更多信息请参阅 Bloom。

属性说明
泛光强度（Bloom Intensity）缩放整个泛光效果的颜色（线性）。用途包括随时间淡入淡出，或压暗场景。
泛光阈值（Bloom Threshold）定义颜色需要具有多少亮度单位才会影响泛光。除阈值外还有一个线性过渡带（一个单位宽），其中颜色仅部分影响泛光。要让全部场景颜色都贡献泛光，请使用 -1。用途包括某些梦境序列的微调。

曝光（Exposure）

曝光（Exposure）（更常称为眼睛自适应，eye adaptation）会自动调整场景看起来有多亮或多暗。该效果重现了人眼适应不同光照条件的体验，例如从昏暗室内走到明亮室外，反之亦然。更多信息请参阅自动曝光（Auto Exposure）页面。

属性说明
计量模式（Metering Mode）自动曝光直方图（Auto Exposure Histogram）模式通过由 64-bin 直方图构建的高级设置，提供对自动曝光的精细控制，这是虚幻引擎默认的曝光计量模式。
自动曝光基础（Auto Exposure Basic）模式设置较少，但速度更快，通过下采样曝光计算单一数值。
手动（Manual）模式使用后期处理与相机设置中的相机（Camera）设置控制曝光，而非仅使用曝光（Exposure）类别中的设置。
曝光补偿（Exposure Compensation）对曝光的对数调整，仅在指定了色调映射器时使用。设为 0 表示不调整，-1 表示暗两倍，-2 表示暗四倍，1 表示亮两倍，2 表示亮四倍。
应用物理相机曝光（Apply Physical Camera Exposure）该开关仅影响手动计量模式。启用后，场景亮度受相机设置（ISO、快门速度与光圈）影响；禁用后，相机使用 ISO 100、光圈 1.0、快门速度 1.0 的默认值。启用该标志后大多数场景会明显变暗。
曝光补偿曲线（Exposure Compensation Curve）该槽位接受曲线（Curve）资产，用于精细控制场景的曝光补偿。曲线图中的 X、Y 轴数值分别对应平均场景 EV100与曝光补偿（曲线）值。
曝光计量遮罩（Exposure Metering Mask）使用自定义纹理遮罩计量曝光。遮罩上的亮部对自动曝光计量影响大，暗部影响小。
最小亮度（Min Brightness）自动曝光的最小亮度，限制相机可适应的亮度下限。该值必须大于 0，且应小于等于最大亮度。合适的值应为接近 0 的正数，并在昏暗光照下调整。若该值过小，视口图像会过亮；若过大，图像会过暗。实际取值取决于内容的 HDR 范围。若最小亮度等于最大亮度，自动曝光将被禁用。
最大亮度（Max Brightness）自动曝光的最大亮度，限制相机可适应的亮度上限。该值必须大于 0，且应大于等于最小亮度。合适的值应为正数（2 是不错的起点），并在明亮光照下调整。若该值过小，视口图像会过亮；若过大，图像会过暗。实际取值取决于内容的 HDR 范围。若最大亮度等于最小亮度，自动曝光将被禁用。
变亮速度（Speed Up）从暗环境到亮环境的自适应速度。
变暗速度（Speed Down）从亮环境到暗环境的自适应速度。
低百分位（Low Percent）自动曝光根据场景颜色亮度直方图提取的值进行自适应，该值定义为有 X% 的像素暗于该亮度。数值越高，屏幕上的亮部权重越大，但结果可能不稳定；数值越低，中暗部权重越大，但亮部可能过曝。取值应大于 0 且小于 100，70 到 80 是不错的起点。
高百分位（High Percent）自动曝光根据场景颜色亮度直方图提取的值进行自适应，该值定义为有 X% 的像素暗于该亮度。数值越高，屏幕上的亮部权重越大，但结果可能不稳定；数值越低，中暗部权重越大，但亮部可能过曝。取值应大于 0 且小于 100，80 到 95 是不错的起点。
直方图对数下限（Histogram Log Min）在使用 HDR（眼睛自适应）可视化模式时，定义生成直方图亮度范围的下界。
直方图对数上限（Histogram Log Max）在使用 HDR（眼睛自适应）可视化模式时，定义生成直方图亮度范围的上界。

色差（Chromatic Aberration）

色差（Chromatic Aberration）是模拟真实相机镜头色彩偏移的效果：光线从不同位置进入镜头导致 RGB 颜色分离。更多信息请参阅后期处理效果（Post Process Effects）页面。

属性说明
强度（Intensity）模拟真实相机镜头中像差/边缘色散（即相机瑕疵）伪影的量。
起始偏移（Start Offset）效果生效位置到帧缓冲中心的归一化距离。

灰尘遮罩（Dirt Mask）

灰尘遮罩（Dirt Mask）是应用于相机的滤镜，会在相机上形成一层灰尘般的薄膜。

属性说明
灰尘遮罩纹理（Dirt Mask Texture）从下拉菜单中选择纹理。
灰尘遮罩强度（Dirt Mask Intensity）选择强度值，决定效果在相机上的可见程度。
灰尘遮罩色彩（Dirt Mask Tint）从色轮中为灰尘遮罩选择颜色。

相机（Camera）

一组控制相机快门与电影景深的属性。

属性说明
快门速度（Shutter Speed，1/s）相机快门速度，单位为秒。
ISO相机传感器对光的灵敏度。
光圈（Aperture，F-stop）定义相机镜头的开口。光圈 = 1/f-stop。典型镜头最小可到 f/1.2（大开口）。数值越小，开口越大，前景与背景虚化越多；数值越大，开口越小，前景与背景虚化越少。
最大光圈（Maximum Aperture，最小 F-stop）定义相机镜头的最大开口，用于控制光圈叶片的曲率。设为 0 得到直叶片。
光圈叶片数（Number of diaphragm blades）定义镜头内光圈的叶片数（4 到 16），决定焦外（bokeh）的形状。

局部曝光（Local Exposure）

局部曝光（Local Exposure）是在现有全局曝光系统之上，在美术可控参数内自动对曝光做局部调整的技术，用于同时保留高光与阴影细节。对于使用动态光照的高动态范围疑难场景特别有用——仅靠一次全局曝光调整不足以避免高光过曝与阴影死黑。

属性说明
高光对比度（Highlight Contrast）控制高光的对比度。局部曝光把帧亮度分解为基础层与细节层，按该值降低基础层的对比度。合适的值通常在 0.6 到 1 之间。
阴影对比度（Shadow Contrast）控制阴影的对比度。局部曝光把帧亮度分解为基础层与细节层，按该值降低基础层的对比度。合适的值通常在 0.6 到 1 之间。
细节强度（Detail Strength）控制应用于场景的细节强度。局部曝光把帧亮度分解为基础层与细节层；不等于 1 的值会启用局部曝光。大多数情况下该值应设为 1。
模糊亮度混合（Blurred Luminance Blend）在双边滤波与模糊亮度之间混合作为基础层。模糊亮度有助于保持图像观感与镜面高光，减少振铃。合适的值通常在 0.4 到 0.6 之间。
模糊亮度核尺寸百分比（Blurred Luminance Kernel Size Percent）用于模糊帧亮度的屏幕百分比（核尺寸）。

镜头光斑（Lens Flares）

镜头光斑（Lens Flare）效果是基于图像的技术，模拟观察明亮物体时因相机镜头瑕疵导致的光散射。

属性说明
强度（Intensity）图像式镜头光斑的亮度缩放。
色彩（Tint）为镜头光斑的光粒子着色。
BokehSize决定用 Bokeh 纹理产生的镜头模糊尺寸。
阈值（Threshold）镜头光斑开始生效的最小亮度。该设置应尽量设高，以避免对暗到看不见的内容做模糊带来性能开销。
BokehShape从下拉菜单中选择纹理形状。

图像效果：暗角（Vignette）

暗角（Vignette）是基于图像的效果，创建无边框窗口，使图像向边缘渐隐。

属性说明
暗角强度（Vignette Intensity）控制屏幕四角压暗的程度，从渲染图像到窗口边缘形成无边框窗口。数值越大暗角越重，0 表示无暗角。

景深（Depth of Field）

景深（Depth of Field）是模拟相机镜头对特定距离对焦、虚化近处或远处物体的视觉效果。

属性说明
使用头发深度（Use Hair Depth）景深是否使用头发深度计算弥散圆尺寸；否则按头发在头发深度与场景深度之间插值得到的距离计算。

颜色分级（Color Grading）

颜色分级（Color Grading）类别包含控制对比度、色彩、饱和度等的属性，可对场景观感做完整的艺术控制。

色温（Temperature）

本节属性用于调整场景色彩，使白色真正呈现白色，从而让场景中的其他颜色在给定光照下被正确照亮。

属性说明
色温类型（Temperature Type）选择使用的色温计算类型。
白平衡（White Balance）：用 Temperature 值控制虚拟相机的白平衡，默认设置。
色温（Color Temperature）：用 Temperature 值调整场景的色温，是白平衡操作的逆操作。
色温（Temp）根据场景中光线的温度调整白平衡。当光线温度与该值匹配时光线呈现白色；若取值高于场景光线会偏“暖”（黄），反之取值偏低会偏“冷”（蓝）。
色调（Tint）通过调整青色与品红色范围，调整场景的白平衡温度色调。理想做法是先调好白平衡 Temp 属性再用它校准色彩。在某些光温下颜色可能偏黄或偏蓝，可用它平衡到更自然的效果。

全局（Global）

本节属性是可用于场景的一组全局色彩校正。

属性说明
饱和度（Saturation）调整颜色（色相）的强度（纯度）。饱和度越高，颜色越接近其最纯形态（红、绿、蓝）；饱和度越低，颜色越灰、越发白。
对比度（Contrast）调整场景中亮暗色值的色调范围。降低强度会去掉高光、提亮图像，呈现发白的外观；提高强度会收紧高光、压暗整体图像。
伽马（Gamma）调整图像中间调的亮度强度以准确还原色彩。调低或调高会分别导致图像过暗或发白。

阴影（Shadows）

这些工具用于为阴影自定义色彩深度与形状定义。

属性说明
饱和度（Saturation）控制图像阴影区域颜色（色相）的强度。数值越高色彩越鲜艳。
对比度（Contrast）控制场景的亮暗值范围。数值越低，亮部与暗部差异越小；数值越高，亮部与暗部差异越大。
伽马（Gamma）控制阴影区域的亮度曲线。调高或调低会分别提亮或压暗阴影区域的中间调。
增益（Gain）该值与阴影区域的颜色相乘。调高或调低会分别提亮或压暗受影响区域。
偏移（Offset）这些值给阴影区域叠加颜色。调高或调低颜色值会分别使阴影更发白或更不发白。
ShadowMax该值设置何为图像阴影区域的阈值。

中间调（Midtones）

中间调（Midtones）是关卡中介于高光（最亮区）与阴影（最暗区）之间的中间亮度范围。

属性说明
饱和度（Saturation）控制图像中间调区域颜色（色相）的强度。数值越高色彩越鲜艳。
对比度（Contrast）控制中间调区域的亮暗值范围。数值越低，亮部与暗部差异越小；数值越高差异越大。
伽马（Gamma）控制中间调区域的亮度曲线。调高或调低会分别提亮或压暗阴影区域的中间调。
增益（Gain）该值与中间调区域的颜色相乘。调高或调低会分别提亮或压暗受影响区域。
偏移（Offset）这些值给中间调区域叠加颜色。调高或调低颜色值会分别使阴影更发白或更不发白。

高光（Highlights）

高光是关卡中较高的亮度值范围，主要关注最亮的区域。

属性说明
饱和度（Saturation）控制图像高光区域颜色（色相）的强度。数值越高色彩越鲜艳。
对比度（Contrast）控制高光区域的亮暗值范围。数值越低，亮部与暗部差异越小；数值越高差异越大。
伽马（Gamma）控制高光区域的亮度曲线。调高或调低会分别提亮或压暗高光区域的中间调。
增益（Gain）该值与高光区域的颜色相乘。调高或调低会分别提亮或压暗受影响区域。
偏移（Offset）这些值给高光区域叠加颜色。调高或调低颜色值会分别使阴影更发白或更不发白。
HighlightsMin该值设置何为图像高光区域的下阈值。
HighlightsMax该值设置何为图像高光区域的上阈值，应大于 HighlightsMin。默认值为 1.0（向后兼容）。

杂项（Misc）

场景色彩（Scene color tint）是应用于 HDR 场景的滤镜颜色的乘数。

Lumen 全局光照（Lumen Global Illumination）

Lumen 全局光照求解漫反射间接光照。例如，从表面漫反射反弹的光会带上该表面的颜色，再把带色光反射到附近其他表面——即颜色溢出（color bleed）效果。场景中的网格体也会阻挡间接光照，从而产生间接阴影。更多信息请参阅Lumen 全局光照。

属性说明
漫反射颜色增强（Diffuse Color Boost）按 pow(DiffuseColor, 1/DiffuseColorBoost) 计算材质漫反射颜色以提亮间接光照。大于 1（原始漫反射颜色）的值不符合物理正确，但可作为美术指导手段增加场景中的反弹光。建议保持在 2 以下，否则反射会比场景还亮。
天光泄漏（Skylight Leaking）控制允许泄漏的天空光强度占比。作为美术指导手段（非物理），可避免室内区域全黑。
全天光泄漏距离（Full Skylight Leaking Distance）控制从接收表面起多远处天光泄漏达到全强度。数值越小泄漏越平坦，数值越大越会形成环境光遮蔽效果。

渲染功能（Rendering Features）

后期处理材质（Post Process Materials）

后期处理材质（Post Process Materials）为域（Domain）设为 Post Process 的材质提供创建屏幕视觉效果的手段，材质能做到的、影响玩法或场景视觉观感的几乎都可以做。例如，可用于施加受伤效果，或在屏幕上创建风格化、视频特效。更多信息请参阅后期处理材质（Post Process Material）页面。

只需把一个或多个后期处理材质指定给后期处理体积：先点击 + 添加新槽位，在内容浏览器中选择材质，再点击左箭头指定。顺序不重要，未使用的槽位会被忽略。

动态模糊（Motion Blur）

动态模糊（Motion Blur）是基于物体运动的模糊。在摄影与电影（一连串帧）中，动态模糊是物体在成像完成前发生移动而产生的模糊效果。物体运动越快，动态模糊越明显。

属性说明
强度（Amount）动态模糊效果的强度。0 表示无动态模糊。
最大值（Max）动态模糊导致的最大畸变（占屏幕宽度的百分比）。0 表示无畸变。
目标 FPS（Target FPS）定义动态模糊的目标每秒帧数（fps）。使动态模糊与实际帧率无关，而相对于指定目标 FPS：帧越短，快门时间越短，动态模糊越少。FPS 越低动态模糊越多。0 表示动态模糊取决于实际测得的帧率。
按对象尺寸（Per Object Size）图元在速度通道中绘制以纳入动态模糊考量的最小投影屏幕半径。半径为屏幕宽度的百分比。半径越小，绘制调用越多。默认为 4%。

胶片颗粒（Film Grain）

胶片颗粒（Film Grain）是模拟冲洗后摄影胶片观感的光学效果，呈现为微小的随机粒子，给渲染帧增添胶片质感。

属性说明
胶片颗粒强度（Film Grain Intensity）应用于场景的颗粒量。0 表示无胶片颗粒，1 表示全颗粒。
胶片颗粒纹素尺寸（Film Grain Texel Size）屏幕上胶片颗粒纹素的尺寸。

其他后期处理体积设置

后期处理体积设置（Post Process Volume Settings）是 Lumen 曝光管理器的专属设置，控制它如何与场景以及可能重叠的其他后期处理体积交互。

属性说明
优先级（Priority）指定该体积的优先级。体积重叠时，优先级高的覆盖优先级低的；若两个或多个重叠体积优先级相同，顺序未定义。
混合半径（Blend Radius）设置体积周围用于混合的半径（世界单位）。例如，走进体积时内部观感可能与外部不同，混合半径会在体积周围创建过渡区。
混合权重（Blend Weight）体积属性的影响量。1 为完全生效，0 为不生效。
启用（Enabled）决定该体积是否影响后期处理。启用后，体积设置参与混合。
无界（Unbound）决定是否考虑体积边界。启用后，无论体积边界如何，该体积影响整个场景；不启用时，仅在其边界内生效。

渲染（Rendering）

渲染（Rendering）决定你用 Lumen 曝光管理器所做的更改是否可见。
