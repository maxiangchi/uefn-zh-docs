鱿鱼游戏品牌规则

使用鱿鱼游戏模板与资产创建岛屿时，必须遵守品牌规则、开发者规则与变现约定，否则可能失去分成与模板权限。

英文原标题：Squid Game Brand Rules In Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

跳进 Fortnite 创意模式(Fortnite Creative)和 UEFN虚幻编辑器(Unreal Editor for Fortnite)，用专属模板和资产构建鱿鱼游戏岛屿吧！使用鱿鱼游戏资产和岛屿意味着肩负一定的责任与期望。下面是创建鱿鱼游戏岛屿的一系列准则。

使用鱿鱼游戏模板的规则

要使用鱿鱼游戏模板进行构建，除遵守 Fortnite 开发者规则(Fortnite Developer Rules)和其他现有协议（如变现协议）外，还需要遵守以下规则。

鱿鱼游戏品牌规则

使用鱿鱼游戏模板构建、宣传使用鱿鱼游戏模板的岛屿时，必须遵守 Fortnite 开发者规则、所有其他相关协议以及以下规则，否则可能面临下文所述的后果。

对于你的鱿鱼游戏岛屿，适用以下规则：

  • 鱿鱼游戏角色与资产的使用限制。不得将任何可能侵犯鱿鱼游戏知识产权的鱿鱼游戏相关角色或资产导入 UEFN虚幻编辑器(Unreal Editor for Fortnite)，也不得在你的岛屿中使用。你只能使用 UEFN 中正式提供给你的鱿鱼游戏角色或资产。
  • 不得出售、许可或再分发鱿鱼游戏角色或资产。不得单独出售、许可或再分发任何鱿鱼游戏角色或资产，也不得将其作为数据库或市场的一部分，或以任何可能让第三方以独立文件形式访问、下载、提取或利用鱿鱼游戏角色或资产的方式进行处理。
  • 不得修改。不得在 UEFN 之外编辑、修改或更改任何鱿鱼游戏角色或资产。只能使用我们为鱿鱼游戏角色和资产提供的 UEFN 内自定义功能。
  • 不得用于广告、宣传或竞选。不得将鱿鱼游戏角色或资产用于任何产品或服务的广告或推广，也不得用于支持、呼应敏感话题（如政治或宗教组织）或就其发表言论。
  • Netflix 拥有并保留所有鱿鱼游戏角色和资产的全部权利和所有权。包括其中的所有知识产权。你对任何鱿鱼游戏角色和资产的使用均不授予你对任何鱿鱼游戏角色、资产、内容或其衍生作品的任何所有权。

鱿鱼游戏品牌规则由 Epic Games 和 Netflix 共同执行。Netflix 可以就违反鱿鱼游戏品牌规则的岛屿向 Epic Games 举报。如果发现你的岛屿违反鱿鱼游戏品牌规则，相关内容将被移除，且该岛屿将无法获得互动分成奖励。如果屡次违反鱿鱼游戏品牌规则，你将失去鱿鱼游戏模板的使用权限。持续违反这些规则可能导致更严厉的限制或账号封禁。

将你的岛屿转换为鱿鱼游戏岛屿

Epic Games 可能会提供一个选项，允许开发者在工具上线到可发布的窗口期内，将现有岛屿转换为鱿鱼游戏岛屿。要将你的岛屿转换为鱿鱼游戏岛屿，岛屿中必须包含至少一件(1)来自可用鱿鱼游戏工具包的工具、设备或资产。你可以使用与鱿鱼游戏岛屿无关的常规 Fortnite 资产。

绝不将鱿鱼游戏资产与第三方 IP 混用

鱿鱼游戏岛屿已按协议配好你可以使用、符合品牌要求的鱿鱼游戏资产，以及 Epic Games 拥有或许可的特定资产。IP 合作伙伴许可协议明确规定：即使已获得该 IP 所有者的许可，也不能将鱿鱼游戏资产与其他第三方知识产权(IP)混用。如果资产的全部权利归你所有，且符合 Fortnite 开发者规则、上述鱿鱼游戏品牌规则以及所有其他相关协议，你可以导入并使用。你也可以使用 Epic Games 直接提供给你的其他资产，但不包括来自其他 IP 合作计划伙伴的资产（例如乐高®(LEGO)岛屿相关资产）。

如果违反此规则，你的岛屿可能无法获得互动分成奖励，并可能被移出生态系统或停用。持续违反此规则可能导致更严厉的限制或账号封禁。

鱿鱼游戏变现

Netflix 对其内容提供有限许可，供你使用其批准的鱿鱼游戏资产。这让你能把官方授权的鱿鱼游戏体验带入 Fortnite 生态，为 Fortnite 社区创造新型岛屿。作为回报，你必须遵守 IP 合作伙伴许可协议（包括鱿鱼游戏品牌规则）、Fortnite 开发者规则、社区准则以及所有其他相关协议。唯一批准的鱿鱼游戏资产和功能，是通过指定模板访问到的那些。

作为 Netflix 许可你使用鱿鱼游戏资产创建鱿鱼游戏岛屿的对价，你同意将岛屿总分成中的 15% 分享给 Netflix。Epic Games 将从你的互动分成中自动扣除该金额并分发给 Netflix，你将获得剩余部分。当你同意 IP 合作伙伴许可协议时，即表示同意此流程。

岛内交易(In-island transactions)目前在此 IP 下不受支持。

使用鱿鱼游戏资产进行创作

鱿鱼游戏带来了一系列新工具，帮你构建童年主题游戏、增强社交体验、设计引人入胜的玩法场景。它通过组队合作、欺诈博弈或意外反转，解锁了新的叙事潜力。用提供的鱿鱼游戏资产和画廊，打造属于你自己的原创环境，围绕这些不同侧重点打造迷你游戏吧！你可以在使用鱿鱼游戏岛屿(Working with Squid Game Islands)查看画廊、物品等内容。也别忘了试试迷你游戏大师(Minigame Mastery)和社交推理(Social Deduction)这两个玩法模板。

宣传你的鱿鱼游戏岛屿

为岛屿制作宣传物料时，请参考宣传你的 Fortnite 岛屿(Promoting Your Fortnite Island)中的指南。确保图片和视频准确反映你创建的岛屿或玩法机制，不要抄袭其他游戏或开发者。你对鱿鱼游戏岛屿的宣传必须遵守鱿鱼游戏品牌规则、Fortnite 开发者规则(Fortnite Developer Rules)、社区准则和其他相关协议（例如 Fortnite 开发者规则第 3 节）。宣传中的内容和表述必须与这些规则和协议中的内容规则、指南一致，并适合岛屿目标受众的年龄。

缩略图、大厅背景图和视频

你可能已经注意到，一些鱿鱼游戏品牌规则同样适用于你的宣传素材。以下是针对宣传物料的鱿鱼游戏品牌规则具体指南。

你可以：

  • 在缩略图、大厅背景图和视频中使用 UEFN 中提供给你的鱿鱼游戏角色和资产，前提是遵守现有指南。
  • 在岛屿名称中使用“Squid Game（鱿鱼游戏）”。

你不可以：

  • 使用 Netflix 剧集中任何一集的具体标题。
  • 在岛屿缩略图、背景图或视频中使用第三方 IP。
  • 声称或暗示你的岛屿与 Netflix 或鱿鱼游戏品牌有关联或获得其背书。
  • 在岛屿标题或描述中使用任何鱿鱼游戏或 Netflix 标志。
  • 在岛屿标题或描述的名称中使用任何鱿鱼游戏或 Netflix 标志或商标。为明确起见，你不得在岛屿标题或描述名称中使用的商标包括但不限于：
    • 鱿鱼游戏剧集(Squid Game series)
    • 鱿鱼游戏：爆发(Squid Game Unleashed)
    • 鱿鱼游戏：Unleashed(Squid Game: Unleashed)
    • 网飞(Netflix)
    • 网飞公司(Netflix, Inc)
    • 鱿鱼游戏：挑战(Squid Game The Challenge)
    • 鱿鱼游戏：体验(Squid Game The Experience)
  • 使用任何鱿鱼游戏演员姓名（包括角色名）、肖像或形象，以及任何为唤起其联想而设计的其他图片。

你的岛屿在 Discover 中的展示

在创作者门户(Creator Portal)中，鱿鱼游戏岛屿会在发布流程中自动打上“Squid Game”标签，该标签将显示在产品详情页。

开发者制作的鱿鱼游戏岛屿会像其他 Fortnite 岛屿一样出现在 Discover 中，并且可以被搜索到。
