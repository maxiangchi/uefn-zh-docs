物理系统入门

在 UEFN（Beta）中模拟碰撞、爆炸与物体运动的物理受力，本文介绍启用方法、可用设备、物理参数与 Verse API。

英文原标题：Getting Started With Physics · 查看英文原文 · 社区翻译镜像，仅供学习

物理系统（Physics）在虚幻编辑器 Fortnite 版（Unreal Editor for Fortnite，UEFN）中，可以模拟碰撞、爆炸、物体运动等情形下的物理受力效果。模拟会计算物体下落时的加速度，以及两个物体发生碰撞时彼此之间的相互作用。

UEFN 中的物理系统目前处于 Beta 阶段。你现在已经可以发布带有物理效果的项目，但请注意，相关工具仍在频繁更新中，这些更新可能会影响你的 UEFN 岛屿。

你能做什么

玩家可以通过以下方式与物理对象交互：

  • 撞向它们——使用基于物理的玩家角色移动并撞击它们。
  • 打击它们——使用十字镐敲击，或使用武器射击它们，包括投掷手雷。
  • 使用道具移动器（Prop Mover）来移动或旋转它们。
  • 使用设备。

支持物理的设备

以下设备已经过与物理道具联动的测试，可以可靠工作：

  • 通气口（Air Vent）
  • 屏障（Barrier）
  • 弹跳板（Bouncer）
  • 弹跳陷阱（Bouncer Trap）
  • 体积（Volume）
  • 发射台（D-Launcher）
  • 伤害体积（Damage Volume）
  • 悬浮平台（Hover Platform）
  • 弹珠保险杠（Pinball Bumper）
  • 弹珠挡板（Pinball Flipper）
  • 道具移动器（Prop Mover）
  • 跳伞体积（Skydive Volume）
  • 传送器（Teleporter）
  • 触发器（Trigger）
  • 水体（Water）
  • 缓冲垫（Crash Pad）
  • 爆炸物（Explosives）
  • 可携带物生成器（Carryable Spawner）

启用物理

要开启这一 Beta 功能，你需要在岛屿设置中启用物理：

  1. 打开 UEFN，选择一个新建项目或已有项目。
  2. 查看大纲视图（Outliner）。如果你的项目中已有岛屿设置（Island Settings）设备，请直接跳到第 4 步；否则请继续第 3 步。
  1. 打开内容抽屉（Content Drawer），搜索 island settings，将该设备拖入你的项目。
  1. 在大纲视图中选中岛屿设置设备，展开 World（世界）> Physics（物理） 设置，勾选 Enable Physics (Beta)（启用物理 Beta 版）旁边的复选框，然后保存项目。
注：目前任何品牌模板均不支持物理功能。

物理运动

在游戏环境中，物理对象会受到与牛顿第二运动定律所描述的相同的自然力作用：F=ma，其中力（Force，F）等于质量（Mass，m）乘以加速度（Acceleration，a）。

力（Force）

力可以维持、改变或扭曲物体的运动状态。在电子游戏中，这种力可以由武器、其他运动物体、设备、爆炸等施加到角色和物体上。

质量（Mass）

质量是所有物质的核心属性，表示当有外力作用时，物体抵抗自身速度发生变化的程度。质量越大，外力能带来的变化就越小。在游戏中，具有物理属性的物体会带有一个设定的质量。质量大的物体更难被推动，与其他物体相互作用后移动的距离也更短。

加速度（Acceleration）

加速度是物体运动时速度发生变化的快慢，以速度和方向来衡量。在游戏中，例如弹珠保险杠给予与其相互作用的物体的加速，就是一种加速度。

为道具添加物理

在启用了物理的项目中，所有 Fortnite 道具都可以设置为模拟物理。可以通过以下两种方式为道具添加物理：

使用 Fortnite 工具（Fortnite Tools）

  1. 在工具栏中点击选择模式（Selection Mode）下拉菜单，选择 Fortnite 工具（Fortnite Tools）。
  1. 点击添加物理（Add Physics）。
  2. 在视口或大纲视图中，按住 Ctrl 并点击，选中要添加物理的道具，然后点击操作（Actions）下方的 Add Physics（添加物理）按钮。按钮上方会出现一条红色确认消息。

使用这种方法，你还可以移除物理（Remove Physics），以及选中项目中所有的物理道具或非物理道具。更多信息请查看Fortnite 工具模式（Fortnite Tools Mode）。

添加物理组件（Physics Component）

  1. 在该道具的细节（Details）面板中，点击 + 添加（+ Add）并选择 Fort Physics。
  1. 勾选模拟物理（Simulate Physics），并根据需要修改其他设置。

关于导入自定义道具并添加碰撞的更多内容，请参阅制作足球游戏（Make a Soccer Game）教程。

约束（Constraints）

你可以为道具添加旋转与位移约束（Rotation and Translation constraints），阻止它们沿特定轴移动。更多内容请查看虚幻引擎文档中的物理约束参考（Physical Constraint Reference）。

常见问题（FAQ）

以下是在试用该新功能时可能遇到的部分问题。如果你的问题未出现在本节中，可以查看最新的 Fortnite 生态系统更新与发行说明获取更新。

可以在现有项目中启用物理吗？

可以。现有项目也可以启用物理，但建议在开启物理之前先复制备份你的项目。使用了实验性功能的项目无法发布。你可以随时禁用物理实验性功能并发布你的岛屿。

用 Sequencer（过场动画编辑器）制作动画的物体能与物理对象交互吗？

不能。Sequencer 驱动的物体运行在服务器的游戏线程上，其属性与物理线程不同，无法产生物理交互所需的变更。本质上，Sequencer 并不适合与物理一起使用。我们建议使用道具移动器（Prop Mover）设备。使用道具移动器移动的道具可以与物理对象交互。

所有玩家移动模式都支持物理吗？

基本的玩家移动，如行走、跑步、疾跑、疾跑跳跃、跳跃、下落、游泳、下蹲、下蹲行走、下蹲跳跃、滑翔和跳伞，都可以正常工作。但攀爬、滑铲、滑索、滑轨和倒地未出局（DBNO）目前尚不支持。

所有武器都受支持吗？

大多数武器都支持物理 Beta 版。随着工具集日趋完善，会有更多武器支持物理。

载具能在启用物理的岛屿上工作吗？

载具不受支持，会导致岛屿不稳定。建议不要使用载具，以免破坏游戏的某些部分。

项目中可以有多少个物理对象？

你需要注意项目中物理对象的数量。超过 50 个进行物理模拟的简单形状（方块或球体）就可能影响岛屿性能。复杂物理形状比简单形状对性能的影响更大。实际结果会因环境和模拟对象的复杂度而异。

物理功能支持 Fortnite 创意模式（Fortnite Creative）吗？

目前物理功能仅支持在 UEFN 中使用。

体积设备 API（Volume Device API）

为了检测物理对象的出现，设备新增了两个事件：OnPhysicsEnter 和 OnPhysicsExit。

这些事件的有效负载为 Creative_Prop。

Verse API

新增了 PropEntersEvent 和 PropExitsEvent。可以使用下面的代码片段跟踪特工进入和离开体积的时机：

volume_device<public> := class<concrete><final>(creative_device_base): PropEntersEvent<public>:listenable(creative_prop) = external {} PropExitsEvent<public>:listenable(creative_prop) = external {}

fort_character 类可以获取和设置线速度、获取角色质量、施加线性冲量或力。creative_prop 类除了上述能力外，还可以获取和设置角速度、施加角冲量和扭矩。更多信息请参阅 fort_character 和 creative_prop API 页面。
