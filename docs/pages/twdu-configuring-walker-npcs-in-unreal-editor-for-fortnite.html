配置 Walker NPC（行尸走肉宇宙）

用 NPC 生成器设备与角色定义创建 Walker NPC：了解尸潮、挥击与撕咬攻击，用 Walker Gameplay Modifier 微调属性与外观。

英文原标题：TWDU Configuring Walker NPCs in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

概述（Overview）

在使用行尸走肉宇宙（The Walking Dead Universe）岛屿创建项目时，你可以创建并添加 NPC 生成器（NPC Spawner Devices）到项目中，生成 Walker NPC（行尸 NPC），让岛屿挤满行尸敌人类。

行尸是独特的 NPC 敌人类，会在岛屿区域巡逻，为玩家制造需要穿越与击败的挑战与障碍。这些 NPC 行动缓慢，一旦察觉玩家位置就会追上去。

你还可以添加阻挡行尸去路的障碍物。不过，如果行尸察觉玩家就在障碍物后面，会打碎障碍物穿过去。

完整的 Walker NPC 设置演示，以及在不同场景中使用行尸的观察，请参阅 Walker NPC 模板文档。

尸潮（Horde）

用 Walker NPC 做项目时，一个 NPC 生成器可以生成大量敌人供玩家挑战。

当玩家惊动多个 NPC，它们会一起追击玩家，形成尸潮！这些敌潮能让高难度玩法更刺激。

Walker Hordes（行尸尸潮）

为保证使用 Walker NPC 时岛屿性能良好，行尸 NPC 数量建议上限为 50。

攻击（Attacks）

设置行尸攻击有以下几种方式：

攻击攻击动画说明
挥击（Swipe）Swipe Attack（挥击攻击）基础攻击，会对玩家造成伤害。伤害数值用角色定义（Character Definition）资产设定。
撕咬（Bite）Bite Attack（撕咬攻击）初始伤害较小，但会以固定速率持续加重，最终淘汰玩家。被咬后玩家屏幕会出现黑色暗角，逐渐吞噬视野。

你可以调整持续伤害速率，决定玩家被咬后能存活多久，也可以用角色定义资产彻底关闭该机制。

关于调整 Walker NPC 玩法机制的更多信息，请参阅下方的 Walker Gameplay Modifier 设置一节。

行尸外观（Walker Appearance）

Walker NPC 通过 NPC 生成器设备生成，并在角色定义（Character Definition）资产中使用新的 Walker Character（行尸角色）Type（类型）选项。使用 Walker 角色类型时，NPC 生成器设备会从不同的网格体部件与颜色选项中随机组合，生成多种多样的行尸敌人类，增加尸潮的多样性。

如果想搭配监狱环境，还可以在角色定义资产 Type 下拉框中选择 Walker (Prison Uniform)（囚服行尸）。囚服类型只是外观变化，行为与其他行尸相同。更多信息请参阅 Walker 外观自定义一节。

自定义 Walker NPC（Customizing Walker NPCs）

你可以用 NPC 角色定义（NPC Character Definitions）资产的修正器（Modifiers）定义属性与行为，进一步自定义 Walker NPC 与玩家、岛屿环境的交互方式。Walker Gameplay Modifier（行尸玩法修正器）是一组专用选项，可编辑 Walker NPC 攻击的独特属性，微调你的项目。

设备获取（Device Access）

你可以在虚幻编辑器 Fortnite 版（UEFN）中创建 Walker NPC，用于你的岛屿。Walker NPC 仅在 UEFN 中使用行尸走肉宇宙项目模板时可用。要进一步了解在 UEFN 中使用行尸走肉宇宙内容，请参阅使用 TWDU 岛屿（Working With TWDU Islands）文档。

虚幻编辑器 Fortnite 版设置（Unreal Editor for Fortnite Setup）

要把 Walker NPC 加入岛屿：

  • 在内容浏览器中找到 全部（All）> Fortnite > Devices > !Beta，把 NPC 生成器设备拖入岛屿。
  • 选中 NPC 生成器设备，在细节面板中找到 NPC Character Definition 选项。
  • 用选项的资产选择下拉框新建一个 NPC Character Definition 资产，命名并选择项目中的保存位置。
  • 双击新建的 NPC 角色定义资产打开选项，在 Type 选项下拉菜单中选择 Walker。

你也可以把 NPC 角色定义资产直接拖入岛屿，自动创建一个会生成 Walker NPC 的 NPC 生成器设备。

然后在视口中选中该设备，打开设备的细节面板调整设备属性。

Walker NPC 在岛屿中经过楼梯等大型环境资产时可能出现寻路问题。

修正该寻路问题：

  • 在视口中点击该环境资产；
  • 在细节面板选择 StaticMeshComponent；
  • 滚动到 Can Ever Affect Navigation 选项，取消勾选以关闭。

Walker NPC 进阶自定义（Additional Walker NPC Customization）

创建 NPC 生成器设备后，可以在细节面板定义所有 NPC 生成器设备通用的属性，如 Spawn Count（生成数量）、Enabled at Start（开局启用）等。关于 NPC 生成器设备及其自定义属性的更多信息，请参阅 NPC 生成器设备（NPC Spawner Devices）文档。

Walker Gameplay Modifier（行尸玩法修正器）

修正器是可应用于 NPC 生成器生成的 NPC 角色的附加设置与覆盖，可产生移速调整、NPC 巡逻路线等效果。

多数修正器对所有 NPC 生成器设备通用，包括可生成 Walker NPC 的设备。通用修正器请参阅修正器（Modifiers）文档。

要制作友善的行尸，可用角色定义资产中的 Team Modifier（队伍修正器）让 Walker NPC 不主动敌对玩家，或与玩家同队，让 NPC 协助玩家对抗其他 NPC 敌人或其他玩家。

用 NPC 生成器设备生成 Walker NPC 时，还可以用 Walker Gameplay Modifier 定义控制行尸特殊属性的专属属性。

如果 NPC 生成器使用 Walker Character Type，Walker Gameplay Modifier 应已自动加入生成器的 NPC Character Modifiers 选项。在视口中选中设备，展开 NPC Character Modifiers 选项即可看到行尸玩法修正器设置。

Walker Gameplay Modifier 可应用于项目中所有 Walker NPC 生成器，也可在单个 NPC 生成器设备层面控制。对照下表选择应用方式：

对所有 NPC 生成器设备应用修正器对单个 NPC 生成器设备应用修正器
按以下步骤操作：
  • 打开角色定义资产；
  • 在 Modifiers 选项点击（+）添加（Add）数组元素；
  • 选择修正器类型；
  • 展开该修正器设置并调整数值。
 按以下步骤操作：
  • 选中要编辑的 NPC 生成器设备；
  • 在 Additional NPC Character Modifiers 选项点击（+）添加（Add）数组元素；
  • 选择修正器类型；
  • 展开该修正器设置并调整数值。

通过应用修正器，可以改变项目中 Walker NPC 的行为，例如关闭撕咬攻击的持续掉血做出更弱的敌人，或加血量做出更强的敌人。要让 Walker NPC 更多样，可以复制角色定义资产，给不同 NPC 生成器指派不同修正器。

Walker Gameplay Modifier 设置（Walker Gameplay Modifier Settings）

以下是 Walker Gameplay Modifier 各项设置及其功能说明：

选项选项说明
Headshot Damage Model（爆头伤害模型）启用后，玩家打中行尸身体伤害有限，爆头则造成暴击伤害；禁用后，Walker NPC 与其他 NPC、玩家一样正常承伤。
Attack Damage（攻击伤害）设定攻击命中后对玩家造成的伤害，默认值为 12。调大则伤害更高，调小则伤害更低。
Bitten Damage Over Time（撕咬持续伤害）设定行尸撕咬命中后每秒对玩家造成的持续伤害，默认值为 2，即被咬后每秒掉 2 点血。调大则被咬后淘汰更快，调小则更慢。设为 0 可关闭撕咬持续掉血机制。
Remove Infection On DBNO（倒地时清除感染）启用后，玩家被击倒后撕咬状态会被清除：即玩家可能被行尸咬倒，但被队友扶起后不会被淘汰；禁用后，扶起倒地玩家不会清除撕咬状态，玩家仍会被撕咬持续伤害淘汰。要让玩家倒地后清除撕咬状态，请启用此选项。
Skip Spawning Animation（跳过生成动画）启用后，行尸 NPC 生成时不播放起身生成动画；禁用后，生成时会播放该动画。
Wait Time Between Wandering Minimum（游荡等待最短时间）设定 Walker NPC 两次游荡之间站立待机的最短时间。行尸会在该值与最长时间之间随机取值，决定待机多久再移动，默认 3.0 秒。
Wait Time Between Wandering Maximum（游荡等待最长时间）设定 Walker NPC 两次游荡之间站立待机的最长时间。行尸会在最短时间与该值之间随机取值，决定待机多久再移动，默认 15.0 秒。

Walker 外观自定义（Walker Appearance Customization）

默认情况下，Walker NPC 设备会从默认行尸网格体集合中随机选择骨骼网格体部件生成行尸。你也可以把行尸外观换成行尸走肉宇宙玩法模板项目中的囚服（Prisoner Uniforms）款。要把行尸换成囚服网格体：

  • 在内容浏览器或 NPC 生成器细节面板的 NPC Character Definition 选项中双击打开角色定义资产；
  • 在资产编辑器中打开 Type 选项下拉框，选择 Walker (Prison Uniform) 选项。
