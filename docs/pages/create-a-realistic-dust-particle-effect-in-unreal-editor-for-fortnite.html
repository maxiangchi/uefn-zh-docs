创建逼真的尘埃粒子特效

跟随本教程在 Niagara 中创建尘埃粒子：学习确定尘埃颗粒大小与散布范围，并用发射器（Emitter）形状约束尘埃散布。

英文原标题：Create a Realistic Dust Particle Effect in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

本教程将教你如何在 Niagara 中创建尘埃粒子。在此过程中，你将学习如何确定尘埃颗粒的大小与尘埃散布范围，以及如何用发射器（emitter）形状约束尘埃散布。

以下各节将带你逐步完成生成新特效所需的步骤：先创建自定义材质，再使用 Hanging Particulates（悬浮微粒）发射器创建尘埃粒子特效。

请按既定顺序逐节学习。如果跳过本教程中的某一节，最终特效将无法按预期工作。

概述（Overview）

以下是复刻该尘埃特效所需的步骤及其理想顺序：

  • 创建尘埃粒子材质与 Niagara 发射器；
  • 编辑发射器 sprite（粒子精灵）；
  • 编辑发射器形状。

分节教程（Sections）

以下各节将带你创建尘埃粒子特效：

  • 1. 创建尘埃粒子材质与 Niagara 发射器：学习为尘埃粒子创建逼真材质，并将其引入 Niagara。
  • 2. 修改发射器：修改尘埃 sprite，使其使用你为 Niagara 创建的尘埃材质。
  • 3. 编辑生成特效形状：创建一束阳光中的尘埃粒子柱。
