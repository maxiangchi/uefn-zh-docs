在 Fortnite 创意模式中使用空间温度计

空间温度计（Spatial Thermometer）把岛屿划分为单元格并用热力图展示每格内存占用；本文介绍单元格内存用量条与热力图的查看方法，以及降低高占用单元格内存的技巧。

英文原标题：Using The Spatial Thermometer In Fortnite Creative · 查看英文原文 · 社区翻译镜像，仅供学习

空间温度计（Spatial Thermometer）是一种在岛屿上显示并管理内存的方法。岛屿被划分为若干单元格（Cell，相当于一个网格地块），并可显示热力图（Heatmap），展示每个单元格占用了多少内存。你不再只有一个笼统的整岛内存上限，而是可以逐格调整内存用量。在搭建占用大量内存的复杂岛屿时，这给了你更大的灵活性。

空间温度计

空间温度计（Spatial Thermometer）内存管理系统逐格测量内存，把每个单元格的内存占用与其相邻单元格进行比较。岛屿不再把所有内容一次性加载并存储，而是只用内存保存玩家能看到和用到的东西，会把视野之外的装饰物（Prop）与地形从内存中卸载。随着玩家在岛屿上移动，系统只加载玩家能看到、可交互的内容。

装饰物与设备内存

空间温度计（Spatial Thermometer）把岛屿切分为单元格网格。你放置的每个装饰物都有内存开销，会影响其周围一定半径范围内的区域。放置装饰物时，它的内存开销会被计入周围所有能看到它的单元格。

当你向岛屿添加设备（Device）时，它的内存开销会被计入岛屿上的所有单元格。设备必须始终载入内存才能运转，不能像装饰物那样换入换出。因为设备无论玩家在岛屿何处都会影响玩家，你肯定不希望玩家走远一点设备就停止工作。

放置装饰物或设备时，在正式放下之前的预览状态下，物品周围会显示一个彩色圆圈，表明放下该装饰物或设备会对该区域内存产生怎样的影响。

空间温度计系统提供两种查看内存用量的方法：

  • 单元格内存用量（Cell Memory Used）条
  • 热力图（Heatmap）

单元格内存用量条

放置装饰物时，单元格内存用量（Cell Memory Used）条会显示放置点影响范围内、内存占用最高的那个单元格的内存用量，也就是放下该装饰物对附近单元格内存影响的最大值。如果你手上没有拿着装饰物，该条会显示全岛内存开销最高的单元格的数值。

点击图片查看完整尺寸。

热力图

热力图（Heatmap）用颜色编码展示岛屿上各单元格的情况。在 PC 上按 M 打开地图界面，默认就会显示热力图。在地图界面中按 T 可以在三种模式之间切换：

  • 不显示热力图
  • 仅显示热力图
  • 显示热力图及单元格内存数值

点击图片查看完整尺寸。

如果在地图界面上显示了热力图，关闭地图界面后，小地图上也会继续显示热力图。

点击图片查看完整尺寸。

注：必须处于飞行（Fly）模式才能切换热力图模式。未来版本中这一点可能会变化。

热力图上的颜色表示每个单元格当前的内存占用情况：

  • 深蓝色：内存占用 0%
  • 浅蓝色：内存占用 50%
  • 黄色：内存占用 75%
  • 红色：内存占用 99%–100%，该单元格已接近超预算。

降低单元格内存的技巧：

  • 移除该单元格自身内的装饰物，降低其内存占用。
  • 删除附近人员密集单元格中的装饰物，降低超预算单元格的内存开销。
  • 删除一些设备，因为设备会给岛屿上每个单元格都带来内存占用。
