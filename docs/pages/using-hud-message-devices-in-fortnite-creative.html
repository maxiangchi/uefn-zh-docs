在 Fortnite 创意模式中使用 HUD 消息设备

HUD 消息设备可通过其他设备触发或回合开始计时器，向所有玩家或特定玩家显示消息，支持样式、位置、图层与动画的完整配置。

英文原标题：Using HUD Message Devices in Fortnite Creative · 查看英文原文 · 社区翻译镜像，仅供学习

HUD 消息（HUD Message）设备可以向所有玩家或特定玩家显示消息，触发方式可以是其他设备的触发，也可以是回合（round）开始后的计时器，回合相关术语见术语表（round）。

如果岛屿上放了同一设备的多个副本，给它们重命名（rename）会很有帮助。起一个和设备用途相关的名字，既方便记住每个设备是干嘛的，在用事件浏览器（Event Browser）找特定设备时也更容易。

上下文过滤

有些设备受一项名为“上下文过滤（Contextual Filtering）”的功能影响。该功能会根据某些相关选项的取值，隐藏或显示另一些选项，减少自定义面板的杂乱，让选项更易于管理和浏览。

但哪些选项或取值会触发上下文过滤并不总是显而易见。为了帮你识别，在设备文档中我们会用斜体标出会触发上下文过滤的取值。所有选项都会列出，包括受上下文过滤影响的选项；如果某个选项会根据另一个选项的取值隐藏或显示，其说明栏里会有备注。

设备选项

可以用以下选项配置该设备。

默认值用加粗表示，会触发上下文过滤的取值用斜体表示。

选项取值说明
消息（Message）输入文本并设置文本格式点击格式样式（Format Styles）页签，为文本选择样式，右侧是可用样式列表。每个单词必须逐个点击选中，再次点击则取消选中。想应用样式时，把要应用该样式的每个单词都点一遍；如果一部分单词用一种样式、另一部分用另一种样式，记得先取消之前选中的单词，再选中新的单词应用下一种样式。
选项取值说明
回合开始时显示（Show on Round Start）关闭（Off）、开启（On）决定消息是否在回合开始时自动出现。设为开启（On）后，该选项下方会显示另一个选项。
距回合开始时间（Time From Round Start）关闭（Off）、10 秒（10 seconds）、选择时长该选项仅在回合开始时显示（Show on Round Start）设为开启（On）时显示。按回合开始后的经过时长显示消息。
背景不透明度（Background Opacity）0%、选择或输入百分比决定消息背景的不透明度，默认背景透明。
背景颜色（Background Color）2600CEFF、选择颜色色板在背景不透明度（Background Opacity）中设置了不透明度后，该选项决定背景颜色。点击色板打开取色器，每个色板旁都标有十六进制色值，也可以在搜索栏输入十六进制色值查找特定颜色。选好颜色后点击对勾。
选项取值说明
消息接收者（Message Recipient）全部（All）、友方（Friendlies）、敌方（Enemies）、触发玩家（Triggering Player）、选择或输入队伍编号决定哪些玩家会收到 HUD 消息。
显示时长类型（Show for Duration）定时（Timed）、永久（Permanent）决定消息显示固定时长还是常驻。选择定时后，该选项下方会显示显示时长选项。
显示时长（Display Time）5 秒（5 seconds）、永久（Permanent）、选择时长该选项仅在显示时长类型设为定时时显示，决定消息显示多久。
播放音效（Play Sound）消息 - 重要（Message - Important）、选择音效决定显示消息时搭配播放哪段音效。
位置（Placement）底部居中（Bottom Center）、顶部居中（Top Center）、右侧居中（Center Right）、自定义（Custom）选择消息在 HUD 中的显示位置。选择自定义后，该选项下方会显示几个附加选项。
屏幕锚点（Screen Anchor）左上（Top Left）、顶部居中（Top Center）、右上（Top Right）、左侧居中（Center Left）、居中（Center）、右侧居中（Center Right）、左下（Bottom Left）、底部居中（Bottom Center）、右下（Bottom Right）该选项仅在位置（Placement）设为自定义时显示，决定消息在屏幕上的锚点位置，以及消息本身的对齐方式。
水平偏移（Placement Horizontal）0、选择正数或负数该选项仅在位置（Placement）设为自定义时显示，决定消息距离屏幕锚点选项所设锚点的水平像素距离。正数向右移，负数向左移。
垂直偏移（Placement Vertical）0、选择正数或负数该选项仅在位置（Placement）设为自定义时显示，决定消息距离屏幕锚点选项所设锚点的垂直像素距离。正数向上移，负数向下移。
HUD 控件（HUD Widget）基础（Basic）、关键（Critical）决定 HUD 消息的视觉样式。
图层（Layer）0、选择图层编号决定消息显示在哪个图层。一个图层一次只显示一条消息，同一图层的其他消息会排队；把消息放到不同图层可以同时显示多条消息。
优先级（Priority）5、立即显示（Display Immediately）、选择或输入优先级数字决定本消息的优先级。数字越小（如 1）优先级越高，会把同一图层正在显示的消息挤到队列里；选择立即显示则无视其他消息、立即显示。
队列允许多条（Allow Multiple in Queue）关闭（Off）、开启（On）默认情况下，只有当该设备没有排队消息、也没有正在显示的消息时，新消息才会排队；选择开启后，该设备可以排多条消息。
显示中再次触发（Show Behavior If Showing）重置显示时长（Reset Display Time）、重播（Replay）、忽略（Ignore）决定消息正在显示时又收到一次显示指令会发生什么。
队列超时（Queue Timeout）不排队（Don't Queue）、选择时长当高优先级消息正在显示、导致本消息排队时，该选项决定消息在队列里保留多久。
为中途加入玩家排队（Queue Message for Join In Progress Players）开启（On）、关闭（Off）决定是否把消息排队并显示给对局中途加入的玩家，同时会考虑队列超时选项的取值。
显示前重新评估（Re-Evaluate Messages On Show）关闭（Off）、开启（On）决定消息即将显示时是否重新检查它是否仍然有效。如果玩家在游戏中可能更换职业或队伍，或因其他原因不再符合查看条件，这个选项很有用。
入场动画（Intro Animation）无（None）、缩放（Zoom）、淡入缩放（Fade and Zoom）、淡入（Fade）、反向缩放（Reverse Zoom）、弹跳（Bounce）、慢速缩放（Slow Zoom）、慢速淡入缩放（Slow Fade and Zoom）、慢速淡入（Slow Fade）、慢速反向缩放（Slow Reverse Zoom）、从顶部滑入（Slide From Top）、从底部滑入（Slide From Bottom）、从左侧滑入（Slide From Left）、从右侧滑入（Slide From Right）决定 HUD 消息出现时的动画。
退场动画（Outro Animation）无（None）、缩放（Zoom）、淡入缩放（Fade and Zoom）、淡入（Fade）、反向缩放（Reverse Zoom）、弹跳（Bounce）、慢速缩放（Slow Zoom）、慢速淡入缩放（Slow Fade and Zoom）、慢速淡入（Slow Fade）、慢速反向缩放（Slow Reverse Zoom）、从顶部滑入（Slide From Top）、从底部滑入（Slide From Bottom）、从左侧滑入（Slide From Left）、从右侧滑入（Slide From Right）决定 HUD 消息移除时的动画。
文本样式集（Text Style Set）关闭（Off）、开启（On）决定文本的样式集，从下拉菜单选择文本样式。
覆盖默认文本样式（Override Default Text Style）开启（On）、关闭（Off）提供手动覆盖文本样式的选项（未添加样式时生效）。保存更改后，对预览的修改才会应用。
文本颜色（Text Color）白色（White）、选择颜色色板该选项仅在覆盖默认文本样式设为开启时显示，决定 HUD 消息中文本的颜色。点击色板打开取色器，用法与背景颜色的取色器类似，只是这里用的是颜色名而非十六进制色值。选好颜色后点击对勾关闭取色器。
文本对齐（Text Justification）左对齐（Left）、居中（Center）、右对齐（Right）、固定左对齐（Invariant Left）、固定右对齐（Invariant Right）决定文本靠哪边对齐。选择固定左对齐（Invariant Left）或固定右对齐（Invariant Right）后，无论文本以哪种语言显示，都固定按该侧对齐。
Verse 文本样式（Verse Text Style）关闭（Off）、开启（On）来自 Verse 脚本的消息会自动对整条消息应用所选样式。
阴影偏移（Shadow Offset）1、选择或输入数字该选项仅在覆盖默认文本样式设为开启时显示，决定投影偏移量。
描边强度（Outline Strength）1、选择或输入数字该选项仅在覆盖默认文本样式设为开启时显示，决定文本描边强度。
字号（Size）18、选择或输入字号该选项仅在覆盖默认文本样式设为开启时显示，决定文本字号。

直接事件绑定

直接事件绑定（Direct event binding）让设备之间可以直接通信，工作流更直观，也让你能更专注于设计创意。

下面是该设备的函数与事件。

函数

函数会监听设备上的事件，然后执行动作。

  • 对于任意函数，点击选项（option），再点击选择设备（Select Device），从设备下拉菜单（Device dropdown menu）访问并选择。
  • 选好设备后，点击选择事件（Select Event），把设备绑定到会触发该设备函数的事件上。
  • 如果有多个设备或事件要触发同一个函数，点击添加（Add）按钮新增一行并重复上述步骤。
选项说明
接收时显示（Show When Receiving From）事件发生时显示 HUD 消息。如果有多个设备或事件可以显示消息，可以点击该选项的添加（Add）按钮新增一行。
接收时隐藏（Hide When Receiving From）隐藏消息。如果有多个设备或事件可以隐藏消息，可以点击该选项的添加（Add）按钮新增一行。
接收时清空图层（Clear Layer When Receiving From）事件发生时清空所有文本图层。如果有多个设备或事件可以清空所有图层，点击添加（Add）按钮新增一行。

事件

该设备没有事件。
