使用 Niagara 创建烟花

本教程教你构建基础烟花，在此过程中介绍 Niagara 工作流、模块与 Niagara 编辑器（Niagara Editor）。

英文原标题：Creating Fireworks Using Niagara In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

本教程教你构建基础烟花。通过这个过程，你将接触 Niagara 工作流、模块以及Niagara 编辑器（Niagara Editor）。

以下章节将带你完成生成新特效所需的步骤。你将创建自定义材质，然后使用空发射器添加并编辑多个发射器节点（Emitter Nodes）。你将在每个章节中调整这些发射器，打造出外观完美的烟花。

要完成本教程，不能跳过任何章节，因为每个步骤对最终成品都必不可少！跳过某一章节意味着你的烟花将无法按预期工作。

概述

以下是复刻此烟花特效所需的步骤概述及其理想顺序：

  • 创建烟花材质与 Niagara 发射器。
  • 构建烟花头部。
  • 构建烟花尾迹。
  • 创建烟花爆炸。
  • 在爆炸效果上继续加工。

章节

以下章节将带你创建烟花特效：

  • 1. 创建烟花材质与 Niagara 发射器（Create the Firework Material and Niagara Emitter）
    创建烟花材质并添加 Niagara 发射器，打造你自己的烟花。
  • 2. 构建烟花头部（Building the Firework Head）
    构建驱动整个烟花各部分的烟花头部。
  • 3. 构建烟花尾迹（Building the Firework Trail）
    学习为你的烟花创建尾迹效果。
  • 4. 制作第一次烟花爆炸（Making the First Firework Explosion）
    制作烟花爆炸的第一部分，生成小型 Sprite 粒子并为其着色。
  • 5. 制作第二次烟花爆炸（Making the Second Firework Explosion）
    制作烟花爆炸的第二部分，创建跟随第一次爆炸粒子的 Ribbon 粒子。
