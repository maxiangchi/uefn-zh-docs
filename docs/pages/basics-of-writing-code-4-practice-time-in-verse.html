Verse 代码写作基础第 4 课：练习时间

回到魔法药水代码，用 if 表达式控制治疗与伤害逻辑，并动手找出隐藏的 bug。

英文原标题：Basics of Writing Code 4 Practice Time in Verse · 查看英文原文 · 社区翻译镜像，仅供学习

前置主题：要理解和使用本页内容，请先熟悉以下主题：第 4 课：编写简单代码（Lesson 4: Writing Simple Code）。

回到上一个练习中的魔法药水代码。当玩家喝下治疗药水时，你希望运行治疗代码；当他们喝下伤害药水时，运行伤害代码。

首先你写了一些代码……

  • 听起来你得先问问药水的类型，所以新建一个变量来记录它：一个叫 PotionType 的字符串（string）。
var PotionType : string = "heal"
  • 现在你可以问变量 PotionType 是否等于另一个字符串。当你问 PotionType 是否等于 "heal" 时，答案是肯定的，治疗代码随即运行。
if (PotionType = "heal"):
    set PlayerHealth = PlayerHealth + PotionHealAmount
  • 现在为伤害代码写一个类似的 if 表达式。
if (PotionType = "damage"):
    set PlayerHealth = PlayerHealth - PotionDamageAmount

但等等！治疗代码有个问题！

这里没有任何东西阻止玩家靠药水不停回血。限制一下是个好主意，而现在你可以用 if 做到了。

  • 首先，声明一个 float 类型的新常量，起名 MaxHealth，设为 100.0。
MaxHealth : float = 100.0

如果玩家喝下治疗药水后 PlayerHealth 会超过 MaxHealth，你需要把 PlayerHealth 设为 MaxHealth。

# 玩家喝下治疗药水时运行的代码
# 如果治疗后玩家生命不会超过 MaxHealth，
# 就按完整药量治疗
if (PotionType = "heal" and (PlayerHealth + PotionHealAmount) < MaxHealth):
    set PlayerHealth = PlayerHealth + PotionHealAmount
else:
    set PlayerHealth = MaxHealth

注意上面的代码有个 and，同时问了 PotionType 是否等于 "heal"，以及 PlayerHealth + PotionAmount 是否小于 MaxHealth。两个条件都成立，PlayerHealth 才会增加 PotionHealAmount。

读这段代码的人可能看不出它的意图是防止 PlayerHealth 超过 MaxHealth。这就是代码注释的用武之地。注意实际代码上方那三行注释。

  • 伤害代码能用，但可以用 if…else if…else 改进。如果玩家喝下伤害药水后 PlayerHealth 会变成 0.0 或更低，我们改为把 PlayerHealth 设为 1.0；如果 PlayerHealth 已经是 1.0，则设为 0.0。这样既让玩家明白药水有害，又不至于太严厉。
# 玩家喝下伤害药水时运行的代码
# 如果玩家生命高于 MinHealth 但不足以承受药水伤害，不要直接淘汰玩家
# 如果已等于或低于 MinHealth，则淘汰他们
if (PotionType = "damage" and PlayerHealth > PotionDamageAmount):
    set PlayerHealth = PlayerHealth - PotionDamageAmount
else if (PlayerHealth > MinHealth):
    # 玩家生命较低时再给一次机会
    set PlayerHealth = 1.0
else:
    set PlayerHealth = 0.0

……然后你发现了 bug

下面是本练习的全部代码，还加了一些 Print() 函数调用用于测试。试着运行这段代码，也可以把 Print() 改成你喜欢的内容。PotionType 变量初始为“heal”时，你预期只有治疗代码会运行。

但等等，这里有个 bug！

运行下面的代码，看看你能不能找到它。

MaxHealth : float = 100.0
MinHealth : float = 1.0
var PotionType : string = "heal"

# 玩家喝下治疗药水时运行的代码
# 如果治疗后玩家生命不会超过 MaxHealth，
# 就按完整药量治疗
if (PotionType = "heal" and (PlayerHealth + PotionHealAmount) < MaxHealth):
    set PlayerHealth = PlayerHealth + PotionHealAmount
    Print("Full heal")

如果 PotionType 设为治疗，按理说只有治疗代码会运行。但伤害代码中的 if…else if…if 表达式仍在执行。这意味着只要 PlayerHealth 大于 MinHealth，PlayerHealth 就会被设为 1.0。这不是我们想要的，不过可以把其他检查嵌套在只检查 PotionType 的 if 表达式里来修复。

# 玩家喝下治疗药水时运行的代码
# 如果治疗后玩家生命不会超过 MaxHealth，
# 就按完整药量治疗
if (PotionType = "heal"):
    if ((PlayerHealth + PotionHealAmount) < MaxHealth):
        set PlayerHealth = PlayerHealth + PotionHealAmount
        Print("Full heal")
    else:
        # 把 PlayerHealth 设为 MaxHealth
        set PlayerHealth = MaxHealth

现在，只有缩进在某个检查 PotionType 的 if 表达式之下的代码块会运行。把 PotionType 设为 "damage" 再试试这段代码吧。

呼！改了这么多代码，但你做到了！
