Verse 代码基础 8：输入参数与实参

输入（Input）是添加到程序中、供代码使用并产生变化的信息。本课学习形参（Parameter）与实参（Argument）：如何在函数签名中声明输入，以及调用函数时如何传值。

英文原标题：Basics of Writing Code 8: How Input Parameters and Arguments Work in Verse · 查看英文原文 · 社区翻译镜像，仅供学习

注：前置知识——要理解和使用本页内容，请先熟悉以下主题：第 7 课：指定函数的结果（Specifying the Result of a Function）。

输入（Input）是添加到程序中、供代码使用并产生变化的信息。

上一课中的函数示例不需要任何输入：

GetNumberOfMousetrapsYouCanAfford() : int

你之所以知道它不需要输入，是因为上面函数签名中的圆括号 () 是空的。

形参（Parameters）

你可以通过向函数签名添加形参（Parameter），来定义函数需要的输入（Input）。

形参是在函数签名中、圆括号之间声明的常量。设置形参后，你就可以在函数的函数体（Body）中使用它。

带形参的函数语法如下所示：

name(parameter : type) : type = codeblock

在下面的示例中，CoinsPerMousetrap 现在成了函数 BuyMousetrap() 的一个形参：

var Coins : int = 500
BuyMousetrap(CoinsPerMousetrap : int) : void =
    set Coins = Coins - CoinsPerMousetrap
    Print("Mousetrap bought! You have {Coins} coins left.")

这段代码的意思是：

  • 你有一个名为 Coins 的变量，初始整数值为 500：var Coins : int = 500。
  • 名为 BuyMousetrap() 的函数接受一个形参 CoinsPerMousetrap。你不希望这个函数返回值，所以返回类型为 void。

实参（Arguments）

当你调用一个带有形参的函数时，必须为形参赋值，就像为常量赋值一样。

这些赋给函数的取值称为函数的实参（Arguments）。

要调用 BuyMousetrap() 函数，需要在圆括号内填入实参。有几种不同的写法。

例如：

  • 你可以写 BuyMousetrap(CoinsPerMousetrap := 10)，这种写法模仿了定义函数形参的方式。其中的 10 就是传给函数的实参，它会改变运算结果的取值。
  • 还记得第 2 课和第 3 课中的字面量（Literal）吗？你也可以直接使用与形参类型相同的字面量取值。
  • 第三种方式是使用之前声明过的变量或常量作为实参。你可以用不同的实参取值调用同一个函数，得到不同的结果。
var Coins : int = 500
# 这次调用之后，Coins 变为 490
BuyMousetrap(CoinsPerMousetrap := 10)
# 这次调用之后，Coins 变为 485
BuyMousetrap(5)
CoinsPerMouseTrap : int = 20
# 这次调用之后，Coins 变为 465
BuyMousetrap(CoinsPerMousetrap)

多个形参（Multiple Parameters）

只要用逗号分隔形参，你想为函数定义多少个形参都可以。

带两个形参的函数语法如下所示：

name(parameter : type, parameter : type) : type = codeblock

调用该函数时，同样需要用逗号分隔实参，这种写法模仿了你定义函数形参的方式。

小结（Summary）

  • 形参（Parameter）是在函数签名中声明的常量，写在圆括号内。
  • 实参（Argument）是赋给函数形参所用常量的取值。
  • 同一个函数中的多个形参之间必须用逗号分隔。
