在 Fortnite 中使用星球大战载具设备

星球大战（Star Wars）生成器是可以生成（spawn）载具的设备，会在生成器所在的位置与朝向上为你的岛屿生成载具。它们位于项目根目录的星球大战（Star Wars）™ Content/Devices/Vehicle 下。

前置主题

要理解和使用本页内容，请确保你熟悉以下主题：

  • Getting Started with Devices（设备使用入门）

Star Wars™（星球大战）生成器是可以生成（spawn）载具的设备，会在生成器所在的位置与朝向上为你的岛屿生成载具。

关于如何找到星球大战（Star Wars）生成器设备，请参阅使用设备。

如果在岛屿上放置了同一设备的多个副本，为它们重命名会很有帮助。选择与设备用途相关的名称，可以更容易记住每个设备的作用，在使用事件浏览器（Event Browser）时也更容易找到特定设备。

STAR WARS 载具生成器设备类型

以下是可以在项目中使用的星球大战（Star Wars）载具生成器设备类型列表。这些生成器位于项目根目录的 Star Wars™ Content/Devices/Vehicle 下。

虽然 Fortnite 中的许多载具支持多名乘客，但所有星球大战（Star Wars）载具均为单座。

载具类型载具生成器设备名称描述
X-wing（X 翼战机）X 翼战机生成器生成可驾驶的 X 翼战机。配有油门控制，可加速、减速、极速冲刺，以及在足够接近可着陆表面时着陆。X 翼战机有两种武器——四门翼载速射激光炮和一座质子鱼雷发射器。在机翼收拢的打击翼（S-foils）飞行模式下，你将以无法使用武器作战为代价换取速度提升。
Imperial TIE Fighter（帝国 TIE 战机）TIE 战机生成器生成可驾驶的 TIE 战机。配有油门控制，可加速、减速、极速冲刺，以及在足够接近可着陆表面时着陆。TIE 战机有两种武器——两门速射激光炮和一座质子鱼雷发射器。
Naboo N-1 Starfighter（纳布 N-1 星际战机）N-1 星际战机生成器生成可驾驶的 N-1 星际战机。配有油门控制，可加速、减速、极速冲刺，以及在足够接近可着陆表面时着陆。N-1 星际战机有两种武器——两门速射激光炮和一座质子鱼雷发射器。
Armored Assault Tank (AAT)（装甲突击坦克）AAT 生成器生成可驾驶的装甲突击坦克（AAT）。AAT 有两种武器——两门侧载速射激光炮和一门发射重型激光的主炮。
DF.9 Turret（DF.9 炮塔）DF.9 炮塔生成器生成可操控的 DF.9 炮塔。DF.9 炮塔配备单根炮管，可发射反步兵激光炮。炮管俯仰与整周 360 度旋转均由玩家控制。
Turbolaser Turret（涡轮激光炮塔）涡轮激光炮塔生成器生成可操控的涡轮激光（Turbolaser）炮塔。涡轮激光炮塔配备两根炮管，可并排发射重型激光炮。炮管俯仰与整周 360 度旋转均由玩家控制。

通用载具设备选项

以下属性见于所有星球大战（Star Wars）载具生成器设备。各载具生成器设备特有的设置请参阅相应设备。各载具的默认值差异请参阅载具专属选项一节。

在 Creative 中，默认值以粗体显示。会触发上下文过滤以提供更多选项的值以斜体显示。

选项值描述
Visible During Game（游戏期间可见）On（开）、Off（关）决定设备在游戏期间是否可见。这会影响其碰撞属性。Advanced（高级）
Enabled During Phase（启用阶段）None（无）、Always（始终）、Pre-Game（赛前）、Gameplay Only（仅玩法阶段）、Create Only（仅创建）决定设备启用的游戏阶段（phases）。Pre-Game（赛前）包括游戏开始前的所有阶段。如果设为 Create Only（仅创建），该设备仅在编辑岛屿时启用。Pre-Game（赛前）包括游戏开始前的所有阶段，含精选岛屿上等待玩家的玩家大厅与游戏开始倒计时。
Vehicle Indestructible（载具无敌）On（开）、Off（关）决定生成的载具是否可被摧毁。
Vehicle Health（载具生命值）800、输入数字决定该设备载具被彻底摧毁前可承受多少伤害。
Enable Respawn（启用重生）On（开）、Off（关）决定载具被摧毁后是否重生。设为 On（开）时，会出现额外选项，用于指定重生所需时间。
Respawn Time（重生时间）0.0 秒、输入数字决定载具被摧毁后，该设备经过多长时间重生另一辆载具。此选项要求启用 Enable Respawn（启用重生）。首次生成的载具不使用此延迟。
Respawn Vehicle when Enabled（启用时重生载具）No（否）、Only If Needed（仅在需要时）、Yes（是）如果设为 Yes（是），该设备将生成载具。如果设为 Only If Needed（仅在需要时），该设备不会重置已有载具。
Destroy Vehicle when Disabled（禁用时摧毁载具）On（开）、Off（关）在设备被禁用时摧毁载具。
Destroy When Stuck Underwater（在水下被困时摧毁）On（开）、Off（关）决定载具在水下被困时是否自行摧毁。
Water Destruction Timer（水下摧毁计时器）5.0 秒、输入数字决定载具在水下被困多长时间后自行摧毁。
Activating Team（激活队伍）Team Index（队伍序号）、Any（任意）决定该设备属于哪支队伍。
Allowed Class（允许的职业）Class Slot（职业槽位）、No Class（无职业）、All（全部）、Any（任意）决定什么职业可以使用该载具，各值的含义为：All（全部）：所有玩家（含未分配职业的玩家）都可使用该载具；Any（任意）：任何已分配职业的玩家都可使用该载具；No Class（无职业）：仅未分配职业的玩家可使用该载具；Class Slot（职业槽位）：选择职业标识符（class identifier），仅分配了该职业的玩家可使用该载具。
Use Atmospheric Effects（使用大气效果）On（开）、Off（关）决定玩家是否看到模拟低空大气穿行的云雾与粒子效果。这些效果可在穿越广阔环境时提供速度的视觉指示。在创建没有大气层的太空主题环境时应将其关闭。
Flight Ceiling（飞行高度上限）0、输入数字决定该载具在失速坠落前能飞多高。0 使用项目默认值，大于 0 的值设置高度上限，-1 移除高度上限。

函数与事件

关于事件与函数工作原理的更多信息，请参阅Getting Started with Devices（设备使用入门）。

函数

函数（Function）监听设备上的事件，然后执行动作。

选项描述
Enable When Receiving From（收到时启用）该函数在事件发生时启用设备。
Disable When Receiving From（收到时禁用）该函数在事件发生时禁用设备。
Respawn Vehicle When Receiving From（收到时重生载具）该函数在事件发生时生成载具。
Destroy Vehicle When Receiving From（收到时摧毁载具）该函数在事件发生时摧毁载具。
Assigns Driver When Receiving From（收到时分配驾驶员）该函数在事件发生时让触发玩家就座。
Repair Vehicle When Receiving From（收到时维修载具）该函数在事件发生时维修载具。

事件

UEFN 中的事件为只读。当你在另一个设备上设置绑定到该设备事件的函数时，事件会被自动设置，但无法编辑。

选项描述
On Player Enters the Vehicle Send Event To（玩家进入载具时发送事件到）当玩家进入生成的载具时，向所选设备发送事件，触发所选函数。
On Player Exits the Vehicle Send Event To（玩家离开载具时发送事件到）当玩家离开生成的载具时，向所选设备发送事件，触发所选函数。
On Vehicle Spawns Send Event To（载具生成时发送事件到）当载具生成或重生时，向所选设备发送事件，触发所选函数。
On Vehicle Is Destroyed Send Event To（载具被摧毁时发送事件到）当生成的载具被摧毁时，向所选设备发送事件，触发所选函数。

STAR WARS 设备载具专属选项

X 翼战机是可驾驶的快速单座太空载具，配备主武器与副武器。

选项值描述
