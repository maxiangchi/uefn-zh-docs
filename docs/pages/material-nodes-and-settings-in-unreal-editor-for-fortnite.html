UEFN 中的材质节点与设置

在进入教程之前，请先熟悉材质编辑器的基础概念与主材质节点（Main Material Node），了解基础颜色（Base Color）、金属度（Metallic）等输入如何塑造材质外观。

英文原标题：Material Nodes And Settings In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

在开始学习本系列教程之前，请先熟悉材质核心概念（Essential Materials Concepts）、材质编辑器用户指南（Material Editor User Guide）和材质编辑器界面（Material Editor UI）。这些页面介绍了创建材质实例和材质编辑器的背景知识。

基础颜色（Base Color）、金属度（Metallic）、高光（Specular）和粗糙度（Roughness）是 UEFN 中材质的工作基础。要更好地理解材质的外观与行为，请参阅基于物理的材质（Physically Based Materials）。该页面解释了主材质节点（Main Material Node）（即材质根节点）的不同输入如何工作并相互影响。

要了解如何使用主材质节点（Main Material Node）上的输入引脚（input pin），请参阅材质输入（Material Inputs）。该页面介绍了不同的引脚如何帮助创建特定类型的表面。

材质属性

材质定义表面的属性，着色模型定义表面与光照的交互方式。

在为网格体制作材质时，大多数情况下不需要更改材质编辑器细节（Details）面板中的材质属性。只有在创建通过用户界面（UI）、后期处理（post processing）或灯光与玩家交互的材质时，才需要更改材质域（Material Domain）设置。以下是入门时建议使用的默认设置。

属性设置说明
材质域（Material Domain）表面（Surface）定义材质的用途。表面（Surface）定义网格体表面上的材质表现。
混合模式（Blend Mode）遮罩（Masked）定义材质输出与背后像素的混合方式。遮罩（Masked）会在网格体上创建遮罩。
着色模型（Shading Model）默认光照（Default Lit）通过设置材质与光照的交互方式，定义表面材质如何生成最终颜色。默认光照着色适合任何实心网格体。

当你对材质创建更加得心应手之后，可以尝试调整这些属性，改变材质在网格体上的交互方式与贴合效果。

如果你要为镂空网格体或双面网格体创建材质，请勾选双面（Two Sided）选项，为网格体背面生成次级颜色，这非常适合为植物叶片这类薄片物体创建材质。

节点

UEFN 使用材质节点来创建材质和纹理，也可以将其转换为材质实例（Material Instance），这样在材质中设置的参数就可以在设备、后期处理、灯光、UI 等地方被引用。材质编辑器打开时会显示一个主材质节点（Main Material Node），其他材质节点可以接入它的输入引脚。通过为材质节点赋值，你可以定义资产的颜色、颜色在资产上的呈现方式，以及纹理在资产上的作用方式。

根据所选材质节点的不同，你可以在材质中使用纹理和 UV 来创建有趣的效果，例如闪烁的灯光，或吹拂植被的风。

使用主材质节点（Main Material Node）的基础颜色（Base Color）输入可以查看不同节点的作用。主材质节点（Main Material Node）甚至可以接受来自默认颜色（Default Color）节点的 浮点（Float）、三维向量（3Vector）或四维向量（4Vector）值。

将材质实例拖放到视口中的网格体上。缩小材质编辑器窗口后，你就可以实时编辑网格体材质节点，而无需编译。

下表列出了最常用的节点。编辑节点值并将其接入主材质节点（Main Material Node），查看它们的效果。

常量三维向量表达式（Constant 3Vector expression）

为主材质节点（Main Material Node）添加颜色。你可以使用值（Value）节点为 R、G、B 和 A 输入分别赋值。

RGB 输入对应以下方向：

  • R = X
  • G = Y
  • B = Z

参阅材质数据类型（Material Data Types），了解有关常量值的更多信息。

按住 3 键并左键单击默认颜色（Default Color）节点。

在材质编辑器中右键单击默认颜色（Default Color）节点，可以将其转换为颜色参数（Color Parameter）节点。

常量节点（Constant node）

为材质节点或材质属性添加一个起决定作用的值。

将此节点接入另一个节点以定义其值，或直接接入主材质节点（Main Material Node）以定义某个属性的值。

按住 1 键并左键单击，即可在材质编辑器中添加值（Value）节点。

标量参数节点（Scalar Parameter node）

为所接入属性的材质节点添加参数值。

在调色板面板（Palette panel）中搜索 Scalar Parameter 节点。

插值节点（Interpolate node）

为 A、B 和 Alpha 输入分别添加值，并在信息源之间进行插值。

将颜色节点接入 Lerp 节点的 A、B 和 Alpha 输入，再将 Lerp 节点接入主材质节点（Main Material Node），即可在 RGB 值与属性之间创建颜色混合。

Lerp 节点甚至可以接入另一种节点类型，从而对某个材质属性产生效果。

在调色板面板（Palette panel）中搜索 Lerp 节点。

坐标节点（Coordinate node）

为坐标添加颜色值。

将颜色坐标添加到一个属性，或添加到两个不同的属性。

按住 2 键并左键单击，即可在材质编辑器中添加坐标（Coordinate）节点。

材质表达式常量四维向量节点（Material Expression Constant 4Vector node）

在四个颜色输入上添加恒定颜色，可以接入一个属性，也可以使用 RGB 和 Alpha 输入将颜色分散到多个属性。

将 Constant 节点添加到一个属性，或横跨多个属性使用。

按住 4 键并左键单击，即可在材质编辑器中添加 Constant 节点。

凹凸偏移节点（BumpOffset node）

为高度图上的坐标添加值，通过扭曲 UV 在材质上创建深度纹理。

BumpOffset 节点利用每个像素的高度信息为纹理增加深度。将此节点与纹理采样（Texture Sample）节点配合使用，调整纹理值与外观。

在调色板面板（Palette panel）中搜索 BumpOffset 节点和 Texture Sample 节点。

时间节点（Time node）

向编辑器询问时间、对游戏内时间计时，并为所接入的属性提供一个值。

将 Time 节点接入其他材质节点，可以为该材质节点对属性的效果定义时间限制。

在调色板面板（Palette panel）中搜索 Time 节点。

色相偏移节点（Hue Shift node）

接入属性后，在颜色值之间偏移。

将 Hue Shift 节点与 Value 节点配合使用，用 Value 节点定义色相偏移百分比（Hue Shift Percentage）的值，并接入纹理节点来添加纹理。

在调色板面板（Palette panel）中搜索 Hue Shift 节点。

平移节点（Panner node）

更改 UV 在材质实例中移动（平移）的速度和方向。

为坐标（Coordinate）和速度（Speed）选择一个值。

还可以将额外的 Value 节点接入 Panner，进一步定义单个属性。

在调色板面板（Palette panel）中搜索 Panner 节点。

顶点法线世界位置偏移节点（VertexNormal World Position Offset node）

将顶点沿随机方向移动。

将值节点接入 VertexNormalWS 节点，为顶点移动的幅度赋值。

在调色板面板（Palette panel）中搜索顶点法线世界位置偏移（Vertex Normal World Position Offset）节点。

噪点节点（Noise node）

为所接入的材质属性添加纹理（噪点）。

可以与特定纹理配合使用，为噪点添加“图案”，或生成所需的纹理。

将其他材质节点接入 Noise 节点，可以扭曲材质的某些方面。

在调色板面板（Palette panel）中搜索 Noise 节点。

乘法节点（Multiply node）

提供一种方式，将某个节点对特定属性的影响相乘。

将其他材质节点接入 Multiply 节点，可以对某个材质属性创建所需的效果。

例如，将默认颜色（Default Color）节点接入 Multiply 节点，再为 Multiply 节点添加一个值，然后将 Multiply 节点接入自发光（Emissive）输入，即可用该材质创建发光效果。

遮罩节点（Mask node）

为属性的 R（X）或 G（Y）输入添加遮罩效果。

追加向量（AppendVector）

将数据通道组合在一起，创建比原来通道更多的向量。AppendVector 按输入顺序工作，A 输入始终追加在 B 输入之前。

阶梯节点（Step node）

阶梯节点是一种着色器函数，用于比较两个值，以其中一个值的边缘为基准指定另一个值的边缘，通过定义值的边缘实现从一个值到下一个值的阶梯过渡。可用于定义渐变：决定显示一个颜色值相对另一个颜色值的多少。

纹理坐标节点（TextureCoordinate node）

该节点将 UV 纹理坐标输出为双通道向量值，使材质可以使用不同的 UV 通道、指定平铺，并对网格体的 UV 进行操作。

钳制节点（Clamp node）

Clamp 节点接受输入值，并将其约束在由最小值和最大值定义的特定范围内。

线性渐变节点（LinearGradient node）

使用 UV 通道 0 生成线性渐变，具体沿 U 还是 V 方向取决于使用了哪个输出。

常量偏移缩放节点（ConstantBiasScale node）

接受一个输入值，加上偏移（bias）值，再乘以缩放系数并输出结果。

向上取整节点（Ceil node）

Ceil 是一种表达式，接受输入值，将值向上舍入到下一个整数并输出结果。例如，向 Ceil 输入 0.2，它会将该值向上舍入为 1.0。

命名重路由节点（Named ReRoute node）

提供一种为节点命名并重路由材质节点的方式。

重路由材质节点可以将多个材质节点串联起来创建复杂的纹理和 UV，然后将串联结果的最终值接入用于创建基础颜色（Base Color）的材质节点。

要学习如何组织材质图表，请参阅虚幻引擎文档中的组织材质图表（Organizing a Material Graph）。

使用以下快捷键打开对应的材质节点。

  • 常量（Constant）：按住键盘上的 1 键并单击。
  • 常量三维向量（Constant 3 Vector）：按住键盘上的 3 键并单击。
  • 乘法（Multiply）：按住 M 键并单击。
  • 线性插值（Linear Interpolate）：按住 L 键并单击。

你越是多动手尝试这些节点、它们的取值，以及想要影响的属性，就越擅长创建自定义材质和纹理。理解如何使用值是创建材质的关键。将你创建的材质用于导入的网格体，或用于使用建模模式（Modeling Mode）制作的网格体。

材质和纹理甚至可以与过场动画序列设备（Cinematic Sequence device）配合使用，在网格体上创建自定义效果。

创建新材质时，请关注材质的统计信息。单个材质的指令数不应超过 500 条。否则材质会过于消耗数据，很可能无法正常渲染。

参阅创建闪亮材质（Creating Shiny Material）、使用自发光材质输入（Using the Emissive Material Input）和在材质中使用透明度（Using Transparency in Materials），学习材质创建的基础知识。这些教程涵盖了闪亮、金属、发光材质以及低不透明度材质等基础材质。
