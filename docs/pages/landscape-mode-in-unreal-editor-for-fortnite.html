Landscape 地形模式

地形模式（Landscape Mode）提供管理、雕刻与绘制三组工具，用于从零创建地形或修改现有岛屿地貌。本页完整介绍各工具面板与选项。

英文原标题：Landscape Mode In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

地形模式（Landscape Mode）是 UEFN（Unreal Editor for Fortnite）中的一组编辑工具，可帮助你使用地形工具构建岛屿的全部或部分地形。

该模式（mode）让你在创建环境时拥有更强的控制力。使用地形模式创建自己的地形，意味着你的岛屿无需花费大量制作时间，就能给玩家带来独特的外观与感受。

有关地形模式的更多信息，请参阅 虚幻引擎 5 地形户外地形文档（Unreal Engine 5 Landscape Outdoor Terrain）。

工作原理

使用地形模式中的工具，你可以通过修改现有岛屿的地形来构建自定义环境，也可以从零创建自己的地形。

使用地形分为三个阶段：

  • 管理（Manage）：创建新地形、放大或缩小地形并管理其属性。
  • 雕刻（Sculpt）：编辑高度图以塑造地形。
  • 绘制（Paint）：编辑权重图以混合不同的材质图层。

要了解有关创建自定义地形的更多信息，请参阅创建地形（Creating Landscapes）。

注意：可见性笔刷（Visibility Brush）会在游戏中给进入笔刷创建洞穴的玩家与载具带来问题，玩家可能消失，载具可能传送到地形上方。

管理工具

管理（Manage）包含针对地形整体的工具（新建、导入），以及针对地块与组件的工具（选择、添加、删除），还提供管理与地形关联的额外样条线（splines）的控件（样条线）。

  • 新建（New）：创建新地形（按下方说明创建新地形）。
  • 导入（Import）：从 Houdini、Gaea 等第三方程序创建的文件导入地形，也可使用真实卫星数据。你甚至可以导出当前地形，在其他软件中修改后重新导入。
  • 选择（Select）：选择组件以更改其属性。
  • 添加（Add）：向地形添加组件。
  • 删除（Delete）：从地形删除组件。
  • 样条线（Splines）：使用 Ctrl + 点击为道路、小径或其他需贴合地形的网格体创建样条线。选中线段后，可在细节（Details）面板中找到样条线网格体设置（Spline mesh settings）。

在新建（New）工具面板的新建（Create New）分区中从零创建新地形。

在 UEFN 中，地形分辨率上限为 2048 x 2048 顶点或等效尺寸，例如 4096 x 1024 或 8192 x 512。

编号选项说明
1新建（Create New）在关卡中创建新地形。
2从文件导入（Import From File）导入在外部程序中制作的地形高度图。
3世界分区网格尺寸（World Partition Grid Size）每轴每个地形流送代理的地形组件数。
4材质（Material）为地形指定材质。
5位置（Location）新地形的位置。
6旋转（Rotation）新地形的旋转。
7缩放（Scale）新地形的缩放，即地形中每个四边面的尺寸，默认为 100 单位。
8区块尺寸（Section Size）单个组件区块中的四边面数量。每个区块独立渲染，便于更精细地控制组件内的细节层次过渡。
9每组件区块数（Sections Per Component）单个组件中的区块数，与区块尺寸共同决定每个组件的大小。组件是组织地形数据的基本单位。
10组件数量（Number of Components）X 与 Y 方向的组件数，决定地形的整体尺寸。
11整体分辨率（Overall Resolution）新地形以顶点计的整体分辨率，不计相邻组件间的重叠顶点。
12组件总数（Total Components）将为该地形创建的组件总数。
13填满世界（Fill World）让地形尽可能大。
14创建（Create）按指定设置在世界中创建地形。

你可以在 Photoshop 中绘制地形，或编写程序生成图像再导入。

要了解有关地形组件的更多信息，请参阅地形技术指南（Landscape Technical Guide）。

雕刻工具

使用雕刻（Sculpt）工具可以改变地形高度，创建山谷、丘陵、山脉等地貌。你可以利用不同图层隔离区域，或将大范围雕刻修改与精细细节分开。要新建图层或配置现有图层，可在编辑图层分区右键点击。

多种雕刻与绘制工具基于笔刷，共享通用选项。

图像笔刷效果
见下图圆形笔刷（Circular Brush Type）创建圆形圆润地形。

Alpha 笔刷（Alpha Brush Type）：用笔触定位遮罩图像。

图案笔刷（Pattern Brush Type）：在地形上平铺图案遮罩。

组件笔刷（Component Brush Type）：将修改应用于整个地形组件。

平滑笔刷衰减（Smooth Brush Falloff）：笔刷边缘衰减平滑。

锐利笔刷衰减（Sharp Brush Falloff）：笔刷边缘衰减锐利。

球形笔刷衰减（Spherical Brush Falloff）：中心到边缘平滑衰减。

笔尖笔刷衰减（Tip Brush Falloff）：笔刷边缘反向平滑衰减。

笔刷衰减仅可用于圆形笔刷类型。

测试雕刻笔刷设置，找到合适的衰减、强度与笔刷尺寸，以创建山脉、丘陵、小径等。尝试用小幅半圆形运笔，为地形引入变化。

编号选项说明
1笔刷类型（Brush Type）可用的不同笔刷类型。
2笔刷衰减（Brush Falloff）可应用于笔刷的不同衰减。
3工具强度（Tool Strength）笔刷强度。
4笔刷尺寸（Brush Size）笔刷半径。
5笔刷衰减（Brush Falloff）笔刷边缘的衰减量，为笔刷尺寸的分数：0 = 无衰减，1 = 全衰减。
6使用黏土笔刷（Use Clay Brush）黏土笔刷查看鼠标下所有面的平均方向，然后沿平均方向移动顶点，因此非常适合填补缝隙与在地形上打洞。切换到黏土笔刷后，可减少小径边缘地形的“尖锐”外观，像糊上一层黏土一样按坡向雕刻坡面。

选择雕刻工具

选中 选择（Select） 后可用的附加工具。

选项说明
清除区域选择（Clear Region Selection）从工具中清除所选区域。

复制雕刻工具

选中 复制（Copy） 后可用的附加工具。

选项说明
复制数据到 Gizmo（Copy Data to Gizmo）复制 gizmo 范围内的地形数据，并考虑所选区域的遮罩。
适配 Gizmo 到所选区域（Fit Gizmo to Selected Regions）定位并调整 gizmo 尺寸，使其完全包围所有区域选择。
适配高度值到 Gizmo 尺寸（Fit Height Values to Gizmo Size）缩放 gizmo 中的数据以适配 gizmo 的 Z 尺寸。
清除 Gizmo 数据（Clear Gizmo Data）清除 gizmo 中复制的数据。
粘贴模式（Paste Mode）粘贴地形数据时按抬高、降低或两者粘贴。
Gizmo 复制/粘贴所有图层（Gizmo copy/paste all layers）若设置，则复制/粘贴所有图层，否则仅复制/粘贴目标面板中所选图层。
吸附 Gizmo 到地形网格（Snap Gizmo to Landscape Grid）决定按组件还是按纹素吸附 gizmo。
使用平滑 Gizmo 笔刷（Use Smooth Gizmo Brush）将 gizmo 数据边缘平滑融入地形，否则数据边缘锐利。
高级 > Gizmo 导入/导出（Advanced > Gizmo Import / Export）选中复制时显示的一组高级工具，包括：高度图（Heightmap）、高度图尺寸（Heightmap Size）、图层（Layers）、导入（Import）、导出（Export）。
高度图（Heightmap）输入 Gizmo 高度图文件名字符串，可选择磁盘文件夹保存高度图数据。
高度图尺寸（Heightmap Size）决定 gizmo 导入尺寸的高度图尺寸。
图层（Layers）按 gizmo 导入图层选择要导入的图层。
导入（Import）导入新的高度图。
导出（Export）导出视口中当前地形的高度图。

绘制工具

绘制（Paint）权重数据，以混合指定地形材质的不同图层。与雕刻工具类似，权重数据可在不同编辑图层中创建。此外，权重数据针对所选材质图层绘制，例如选中沙地（Sand）图层绘制权重，就会在地形上绘制沙地。材质图层的顺序决定可见性，上层材质图层被绘制后可能遮住下层。

  • 绘制（Paint）：在所选图层内绘制权重，按住 Shift 绘制可移除权重。
  • 平滑（Smooth）：平滑所选图层内的权重。
  • 压平（Flatten）：按初始左键点击位置的权重压平所选图层内的权重。
  • 噪波（Noise）：在所选图层内的权重上添加噪波，随机增大或减小权重，使其看起来更自然。

选中绘制（Paint） 后，使用地形面板中的不同笔刷与工具设置可进一步自定义绘制笔刷。地形面板中的可用设置取决于选中的绘制工具，工具设置见下文：

  • 平滑（Smooth）
  • 压平（Flatten）
  • 噪波（Noise）
编号选项说明
1笔刷类型（Brush Type）可用的不同笔刷类型。
2笔刷衰减（Brush Falloff）可应用于笔刷的不同衰减样式。
3工具强度（Tool Strength）笔刷强度。
4使用目标值（Use Target Value）启用后使工具向目标值趋近。
5笔刷尺寸（Brush Size）笔刷半径。
6笔刷衰减（Brush Falloff）笔刷边缘的衰减量，为笔刷尺寸的分数：0 = 无衰减，1 = 全衰减。
7编辑图层（Edit Layers）编辑图层的名称与其 Alpha 混合值，决定它们对整体结果的影响强度。
8绘制限制（Painting Restriction）仅限在所选材质图层已有数据的组件上绘制。
9目标图层（Target Layers）可用的材质图层。
