在 UEFN 中修改并运行你的第一个 Verse 程序

按照本页步骤，学习在 UEFN 中创建、运行、编辑和排查输出“Hello, world!”的 Verse 程序与场景图组件。

英文原标题：Modify And Run Your First Verse Program In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

按照本页面的步骤，你可以学习如何在虚幻编辑器 Fortnite 版（Unreal Editor for Fortnite，UEFN）中创建、运行、编辑和排查一个输出 “Hello, world!” 的 Verse 程序与 场景图（Scene Graph）组件（component）。

关于如何打开 UEFN，请参阅启动虚幻编辑器 Fortnite 版。

你的第一个 Verse 程序

VKT - Verse Device Starter Games 模板是对使用 Verse 创建的设备的入门介绍，其中包含多个可供参考的设备示例。在下面的步骤中，你将在该模板中创建并修改一个新的 Verse 设备。

  1. 在项目浏览器（Project Browser）窗口中，选择 Feature Examples 以查看全部 UEFN 功能示例。
  1. 在功能示例列表中，点击 Verse Device 将其高亮选中。
  1. 在屏幕底部 Project Name 下，将你的项目（project）命名为 MyVerseProject，然后点击 Create。
  2. 在菜单栏（Menu Bar）中，前往 Verse > Verse Explorer。
  3. 在Verse Explorer 中，右键点击你的项目名称，选择 Add new Verse file to project，打开 Create Verse Script 窗口。
  1. 在 Create Verse Script 窗口中，点击 Verse Device 将其选为模板，然后点击 Create。
  1. 在菜单栏中，前往 Verse > Build Verse Code，确保你新建的 Verse 设备出现在项目文件夹中。
  2. 在内容浏览器（Content Browser）中，导航到你的项目文件夹。

如果内容浏览器尚未打开，点击菜单栏上的 Window，然后选择 Content Browser，或选择 UEFN 窗口左下角的 Content Drawer。

路径应为 All > MyVerseProject > hello_world_device。

  1. 点击并拖动 hello_world_device 到关卡（level）中。
  2. 在工具栏（toolbar）中，点击 Launch Session 以试玩测试你的岛屿。

点击图片放大。

  1. 在 Save Content 窗口中，点击 Save Selected，保存你对项目的更改。
  1. 待服务器（server）完成项目加载后，打开主菜单并点击 Start Game。
  1. 在客户端（client）中，按 Escape 打开主菜单界面并点击 Island Settings，然后点击顶部导航栏中的 Log 查看日志。
  2. 在日志中找到写着 “Hello, world!” 的一行，下一行是 “2 + 2 = 4”。这两行来自 hello_world_device.verse 文件。因为你把这个用 Verse 创建的设备添加到了关卡中，所以开始游戏时它的代码随之运行。

现在你已经运行了第一个 Verse 程序，接下来看看 hello_world_device.verse 中的代码并修改它。下一节请保持客户端运行。

修改程序

按以下步骤查看上一节创建该设备的 hello_world_device.verse 文件，然后添加一行新代码。

  1. 在菜单栏中，点击 Verse > Verse Explorer，查看项目中的全部 Verse 文件。
  2. 在你的项目名称下，双击 hello_world_device.verse 打开该文件。

Verse 文件会在Visual Studio Code（VS Code）（用于编写程序的编辑器）中打开。如果你的电脑上没有安装 Visual Studio Code，会弹出提示请你安装。

点击图片放大。

Verse 代码扩展是 VS Code 的扩展，提供 Verse 错误（error）检查与语法（syntax）高亮，还允许你直接在 VS Code 中编译 Verse 脚本并推送更改。

与 UEFN 捆绑的 Verse 扩展是唯一官方支持的 Verse 语言扩展。该扩展会在你启动 UEFN 时自动启用；如果你卸载了它，下次启动 UEFN 时会重新安装。

你可以通过 VS Code 窗口顶部的 Editor Focus、Build Verse Changes 与 Push Verse Change 按钮确认 Verse 代码扩展已安装。

点击图片放大。

这段代码其余部分的作用稍后会讲；现在只需知道，在 OnBegin<override>()<suspends>:void= 这一行之下输入的任何代码都会在游戏开始时运行，因此请在文件末尾添加以下代码：

Print("This is my first line of Verse code!")

你的 Verse 文件现在看起来应该是这样：

using { /Fortnite.com/Devices }
using { /Verse.org/Simulation }
using { /UnrealEngine.com/Temporary/Diagnostics }
# See https://dev.epicgames.com/documentation/en-us/uefn/create-your-own-device-in-verse for how to create a verse device.
# A Verse-authored creative device that can be placed in a level
hello_world_device := class(creative_device):
    # Runs when the device is started in a running game

符号 # 之后的任何文本都被视为代码注释，程序运行时会被计算机忽略。代码注释对你和阅读代码的其他人很有用，因为注释可以解释代码的作用。在本例中，# Runs when the device is started in a running game 和 #TODO: Replace this with your code 都是代码注释。

保存更改

  1. 在 Visual Studio Code 中保存 hello_world_device.verse 文件。
  2. 在 UEFN 工具栏中点击 Verse，然后点击 Build Verse Code 编译代码。

点击图片放大。

  1. 编译成功后，Verse 按钮上会出现绿色对勾。如果编译过程中出现问题，会出现红色停止图标，在解决所有错误之前你都无法编译代码。如果发生这种情况，请参阅排查代码故障了解修复代码的技巧。

点击图片放大。

  1. 代码编译完成后，UEFN 工具栏中会出现 Push Changes 与 Push Verse Changes 选项。Push Changes 会把编辑器中的全部更改更新到客户端，例如增删道具、修改对象属性以及对 Verse 代码的任何更改；Push Verse Changes 只更新 Verse 代码，比 Push Changes 更快。当你只想对代码做小幅增量修改而不想刷新整个会话时，这很有用。点击 Push Verse Changes 更新客户端。

点击图片放大。

  1. 待服务器完成项目更新后，打开主菜单并点击 Start Game。
  2. 在日志中找到写着 “This is my first line of Verse code!” 的一行，那就是你刚添加到脚本中的代码的输出！

顺序执行

当你添加那行打印文本到日志的代码后，“This is my first line of Verse code!” 打印在 “2 + 2 = 4” 之后。这是因为这些代码行按它们写在 OnBegin<override>()<suspends>:void= 之下的顺序执行。

如果你调换打印行的顺序，文本就会按新顺序打印到日志，“This is my first line of Verse code!” 会出现在 “2 + 2 = 4” 之前：

OnBegin<override>()<suspends>:void=
    #TODO: Replace this with your code
    Print("Hello, world!")
    Print("This is my first line of Verse code!")
    Print("2 + 2 = {2 + 2}")

代码通常按表达式出现的顺序逐行执行，这称为顺序执行（sequential execution）。随着你进一步学习 Verse 编程，你将学会塑造执行流程以改变程序行为。

排查代码故障

既然你已经编写并运行了第一行 Verse 代码，下面介绍写代码时可能遇到的问题的排查方法。

你可能遇到两类错误：编译器错误（compiler errors）与程序缺陷（bugs）。

编译器错误

和任何写作一样，你的代码中也可能有拼写错误。这些拼写错误会让编译器无法理解你想让程序做什么，因此称为编译器错误——它们会阻止程序编译，通常是语法错误，会使你无法在试玩中运行代码。

VS Code 能发现部分编译器错误，并通过把文件选项卡与资源管理器面板中的文件名变为红色来提醒你。

VS Code 还会在检测到问题的行下方添加红色波浪线；把鼠标悬停在波浪线上，会出现错误信息，如果 VS Code 能提供快速修复，还会一并显示。

VS Code 可能无法捕获全部编译器错误，因此在尝试运行代码之前先构建代码是很好的习惯，可以及早发现错误。具体做法是：在 UEFN 工具栏（Toolbar）中点击 Verse，再点击 Build Verse Code。该选项会编译项目中的全部 Verse 文件，把你编写的代码翻译成计算机可执行的指令。

点击图片放大。

输出日志会显示成功消息（success message）（代码构建成功）或错误（errors）（需修复后才能在试玩中使用代码）。

选择 Build Verse Code 时，若存在编译错误，还会弹出提示消息。

在弹窗消息中选择 See Errors，将打开消息日志（Message Log）窗口，显示 VS Code 检测到的全部代码错误。

点击图片放大。

修复全部错误后，可以再次点击 UEFN 工具栏中的 Build Verse Scripts 重新编译代码，或点击弹窗消息中的 Rebuild，确认代码构建成功。

程序缺陷（Bug）

当代码构建成功，但程序行为不符合预期时，这类问题称为程序缺陷（bugs）。缺陷是代码中的逻辑问题，定位方法之一就是向日志打印。

hello_world_device 中的代码就是很好的例子：通过向日志打印来验证开始游戏时代码是否运行。

OnBegin<override>()<suspends>:void=
    #TODO: Replace this with your code
    Print("Hello, world!")
    Print("This is my first line of Verse code!")
    Print("2 + 2 = {2 + 2}")

你也可以打印数值来验证代码是否符合预期。运行以下代码时，日志中会出现 “2 + 2 = 4”：

Print("2 + 2 = {2 + 2}")

表达式 {2 + 2} 会在文本打印到日志之前先求值为 4。最后一行双引号 " " 之间的大括号 {} 表示其中的表达式应先求值再转换为文本。像这样把值注入字符串的做法就是字符串插值的例子。

如果你修改大括号之间的表达式，打印的值也会变化。在下例中，表达式改为 {2 + 3}，日志中就会出现 “2 + 2 = 5”：

nBegin<override>()<suspends>:void=
    #TODO: Replace this with your code
    Print("Hello, world!")
    Print("This is my first line of Verse code!")
    Print("2 + 2 = {2 + 3}")
