代码基础 6：用 Verse 定义函数

函数是可复用的代码：给出执行动作的指令，或按输入产出输出。本课学习定义函数的三要素——唯一标识符、结果类型与函数体，以及签名、代码块、作用域、实例化与生命期。

英文原标题：Basics of Writing Code 6: Defining a Function in Verse · 查看英文原文 · 社区翻译镜像，仅供学习

注：前置知识——阅读本页前，请确认你已熟悉：第 5 课：调用函数（Lesson 5: Calling Functions）。

你在第 5 课（Lesson 5）学到：函数（function）是可复用代码，给出执行某个动作的指令，或按输入产出输出。

定义函数需要三个关键部分：唯一标识符、作为结果的类型信息，以及函数被调用时要做什么。

如何定义函数

函数签名

在第 3 课（Lesson 3）中，你见过如何声明变量或常量：起个名字，再给出它所用值的类型。

函数签名（function signature）与之类似：给函数起唯一的标识符，用参数描述它需要的输入，最后给出结果（输出）的返回类型。

函数具体做什么，在代码块里定义。

代码块

代码块（code block）是跟在函数签名后面的一组表达式。函数及其代码块的语法如下：

name() : type = codeblock

代码块有多种写法，一种是把标识符之后的代码行缩进，就像上面的函数语法那样（后面会细讲代码块的写法，现在先用这种）。

代码块中的表达式定义了函数被调用时真正要做的事。

这些表达式只在函数被调用时运行。程序跑到这段代码末尾，这些表达式就执行完了——至少到下次调用该函数之前如此——然后程序继续执行这次函数调用之后的代码。

函数体

定义函数做什么的代码块，也叫函数体（body）。

作用域

到目前为止，你学到了：

  • 函数有唯一标识符，用它在程序中激活函数做事。
  • 函数做什么，取决于函数体中的表达式。
  • 函数体最后一行跑完，这次函数调用结束，程序继续执行这次函数调用之后的代码。

函数里的指令，以及函数产出的值，共同决定函数作用域（scope）。

现在回到可用于定义函数的表达式。你可以创建常量和变量（还记得第 3 课（Lesson 3）吗？），把它们加进函数体。

把变量放进函数体，它就是该函数作用域内的局部（local）变量。这里的局部指：这段代码只活在那个函数体里，只在函数被调用时干活。

那作用域（scope）到底是什么？它是函数名与其产出值的关联。那个值只能在创建它的代码块里用——也就是那个作用域里。

实例化

实例（instance）指函数被调用执行时的一次具体应用，这次实例的创建就是实例化（instantiation）。注意，instance 和 instantiation 都和 instant（极短的一瞬）同源。

这就引出了生命期（lifetime）的概念。

生命期

实例有生命期——有开始，有过程，有结束。

也就是说，函数体里东西的生命期止于函数体的作用域，出了作用域就访问不到局部变量（止于当前作用域的那些变量）。

条件语句

常量 MousetrapsYouCanBuy 创建在 if 块里，作用域止于这个 if 块。

当在 if 代码块之外使用常量 MaxMousetrapsYouCanBuy，就会报错，因为 MaxMousetrapsYouCanBuy 这个名字在作用域之外不存在。你会看到报错信息：Unknown Identifier（未知标识符）。也就是说，MaxMousetrapsYouCanBuy 只在那个作用域里有效。

表达式执行完，函数体里创建的局部常量和局部变量就不存在了——它们走到了生命期的尽头。

把作用域想象成一小段代码：里面的东西干完活就下班。

函数语法

再看一遍函数语法，这次挖深一点。

name() : type = codeblock

name() : type =

这是函数签名：name() 和 type 中间加个冒号。看起来很像常量，只不过 name() 里多了这个：()。() 里放参数，标明函数需要的输入（第 8 课细讲参数）。

函数签名包含所用输入的类型。

函数返回的值（= 后面的东西）必须与类型匹配。

codeblock

函数代码块（function code block），即函数体，在这里加常量、变量或其他表达式，说明函数被调用时要做什么。

例如，买捕鼠夹的函数长这样：

var Coins : int = 500 CoinsPerMousetrap : int = 100 BuyMousetrap() : void = set Coins = Coins - CoinsPerMousetrap Print("Mousetrap bought! You have {Coins} coins left.")

函数名的命名规范与规则（naming conventions and rules）和变量、常量一样。函数执行一串动作，按动作起名是好习惯，比如 BuyMousetrap()。

Void

你可能注意到了 BuyMousetrap() 签名里的 void。函数的 void 类型表示这次函数调用不返回任何东西。下节课细讲 void 是什么、怎么用。

别重复自己

编程有一条重要原则：别重复自己（Don't Repeat Yourself）。

意思是：同一行代码写到第三遍，就该换个写法了。没错，这是有理由的！

代码行数越多越难维护；改了一处漏了另一处，bug 就找上门了。

函数和常量一样，都是少写重复代码的办法：函数不仅省掉复制粘贴，还降低维护成本，减少出错概率。

写代码时注意大小写：表达式和函数的命名，关键字和内置函数的使用，都要留神。Verse 区分大小写，大小写不一致会引发 bug 和编译错误。

小结

  • 函数是可复用代码，给出执行动作的指令，或按输入产出输出。
  • 函数需要三部分：标识符、类型，以及包含函数被调用时产出什么的代码块。
  • 函数靠函数签名调用。
  • 定义函数做什么的代码块也叫函数体。
  • 作用域指与函数关联的值，由代码块内容定义。
  • 代码块里的代码是该作用域的局部代码。
  • 生命期是作用域的跨度。
  • 别重复自己。
