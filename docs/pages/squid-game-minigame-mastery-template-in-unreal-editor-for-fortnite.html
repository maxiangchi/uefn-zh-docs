鱿鱼游戏小游戏大师模板

探索用设备与示例构建精彩新小游戏（mini-games）的方法，打造属于你自己的鱿鱼游戏（Squid Game）岛屿。小游戏大师（Minigame Mastery）模板聚焦新设备及其设置，帮你创建新的小游戏。

英文原标题：Squid Game Minigame Mastery Template In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

探索用设备与示例构建精彩新小游戏（mini-games）的方法，示例将帮你创建属于你自己的鱿鱼游戏（Squid Game）岛屿。Unreal Editor for Fortnite（UEFN）中的小游戏大师（Minigame Mastery）模板聚焦新设备及其设置，以创建新的小游戏。

鱿鱼游戏中的游戏往往伴随着残酷的后果。鱿鱼游戏功能集与 Fortnite 的结合，为你提供了重现自己童年游戏并加入转折的机会。设计团队聚焦于游乐场游戏中常见的机制与玩家可执行的常见动作，而这些也正是剧中出现的玩法。

该模板包含多个房间，你可以在其中体验每个小游戏。熟悉得分机制、尽可能久地生存，以及多人设置。小游戏是让你的体验持续下去的绝佳方式，能为多名玩家提供获胜机会。

使用该模板可以更好地理解小游戏如何契合品牌，并打造能引起剧迷玩家共鸣的玩法。你可以将本指南作为模板的配套资料，深入了解以下内容：

  • 小游戏概念
  • 设备设置
  • 融入鱿鱼游戏素材

入门

该学习模板仅在 UEFN 中提供。

要访问该模板：

  1. 打开 UEFN。
  2. 在项目浏览器（Project Browser）中，点击品牌模板（Brand Templates） > 鱿鱼游戏（Squid Game） > 小游戏大师（Minigame Mastery）。
  3. 创建新项目。

要了解有关创建项目以及为鱿鱼游戏岛屿使用模板的更多信息，请参阅游戏合集（Game Collections）。

要从该模板获得最佳体验，请将编辑器与一个 Fortnite 游戏客户端实例（会话）配合使用。在 Fortnite 会话中，你可以游玩小游戏并阅读编辑器内指南。

使用大纲视图（Outliner）导航到各个房间，并查看设计房间所用的全部资产。

加载房间

进入主题加载房间，即刻沉浸到鱿鱼游戏世界中。穿过每扇标有标签的门，了解每种机制。每个房间都以教学走廊开始，随后是一个游戏示例。

你还记得小时候玩过什么游戏吗？捉迷藏？跳房子？抓人游戏？

你会如何颠覆这些怀旧游戏的天真无邪，把它们变成符合鱿鱼游戏风格的玩法？要易于上手，但赌注极高。

房间玩法
基于进度的网格体设备（Progress Based Mesh Device）学习交换网格体，用基于进度的网格体设备创建进度的视觉呈现。小心有惊喜。
推挤物品（Shove Item）要快，第一个按下按钮的人获胜，但平台会缩小，其他人会迫不及待地用推挤物品把你推下去。
画片与飞石物品（Ddakji and Flying Stone Items）用鱿鱼游戏投掷物品瞄准目标，看着你的骆驼银行被填满。
可携带物生成器设备（Carryable Spawner Device）搬运物品穿过障碍，但要小心，VIP 成员决心淘汰你。
技巧互动设备（多人）（Skilled Interaction Device (Multiplayer)）别掉进岩浆。组队通过多人技巧检定，避免被岩浆淘汰。Verse 关卡资产中包含 Verse 示例。

加载房间设置了多个生成器，最适合多人体验。你可以使用多人预览（multiplayer previewing）来帮助测试部分房间。

每个房间都使用主题画廊中的资产，以呈现鱿鱼游戏的美学风格。在为你的鱿鱼游戏岛屿构思创意时，请记住这些设计元素。要了解有关这些画廊的更多信息，请参阅使用鱿鱼游戏岛屿（Working With Squid Game Islands）。

继续学习

将功能集与定制设备结合，学习更多内容，创建抓住鱿鱼游戏精髓的小游戏。

  • 追踪游戏进度（Tracking Game Progression）——学习使用基于进度的网格体设备，在鱿鱼游戏岛屿中创建进度的视觉呈现。
  • 用于推挤玩家的推挤物品（Shove Item for Pushing Players）——学习在鱿鱼游戏岛屿中使用推挤物品。
  • 画片与飞石打靶练习（Ddakji and Flying Stone Target Practice）——学习使用鱿鱼游戏投掷物品打造多样的玩法。
  • 搬运物品穿过障碍（Carry Items Through Obstacles）——学习使用可携带物生成器设备创建鱿鱼游戏小游戏。
  • 多人技巧检定（Multiplayer Skill Checks）——学习为鱿鱼游戏岛屿添加多人技巧检定。
