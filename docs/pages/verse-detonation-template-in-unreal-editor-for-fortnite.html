Verse 引爆模板：在 UEFN 中制作拆弹玩法

Verse 引爆模板（Verse Detonation Template）教你制作一款双队伍对战、安放与拆除炸弹点的游戏，演示枚举（Enum）、并发（Concurrency）、竞速（Race）与等待（Await）等 Verse 概念。

英文原标题：Verse Detonation Template In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

Verse 引爆模板（Verse Detonation Template）将向你展示如何制作一款双队伍对战、安放并拆除炸弹点的游戏。

本教程使用 Verse 设备（Verse device）以及地图指示器（Map Indicator）设备等基础设备，来实现各种玩法机制，例如根据条件显示或隐藏信标。

该模板演示了以下 Verse 概念：

  • 枚举（Enum）
  • 并发（Concurrency）
  • 竞速（Race）
  • 等待（Await）

概览

以下是按理想顺序重建该岛屿所需步骤的概览：

  • 创建新项目（Create a new project）并修改岛屿设置（Island Settings）以搭建游戏。
  • 设置设备。
  • 添加 Verse 脚本。
  • 设置 Verse 设备（Set up the Verse device）。

创建新项目并设置游戏

  • 打开 UEFN 并创建一个新的空项目。
  • 在大纲视图（Outliner）中选择 IslandSettings 设备，找到用户选项 - 游戏规则（User Options - Game Rules）。
  • 按下表所示修改用户选项（User Options）。
选项值说明
队伍（Teams）Team Index 2玩家将被分为两支队伍。
总回合数（Total Rounds）5游戏结束前将进行五个回合。
允许观战其他队伍（Allow Spectating Other Teams）Disallowed玩家将无法观战其他队伍。
无限建筑资源（Infinite Building Resources）False游戏期间玩家将没有无限的建筑材料。
建筑可破坏环境（Building Can Destroy Environment）False玩家放置的建筑与其重叠的环境部分不会被破坏。
环境伤害（Environment Damage）Off游戏期间玩家无法破坏环境。
鹤嘴锄破坏（Pickaxe Destruction）None鹤嘴锄不会对环境或建筑造成任何伤害。
允许手动重生（Allow Manual Respawning）False游戏期间玩家无法使用重生（Respawn）菜单选项。
使用队伍分数（Use Team Score）True游戏中每支队伍通过其玩家得分总和进行统计。

设置设备

本教程使用以下设备：

  • 8 x 爆炸物（Explosive）
  • 2 x 计时目标（Timed Objective）
  • 4 x 地图指示器（Map Indicator）
  • 1 x 终局（End Game）
  • 若干 x 玩家出生点（Player Spawn Pad）
  • 1 x Verse

爆炸物设备（Explosive Device）

使用爆炸物（Explosive）设备为被引爆的计时器制造爆炸效果。在地图相对的两侧，各复制并放置一组共四个爆炸物设备。

按以下方式配置该设备的用户选项（User Options）：

选项值说明
可被破坏（Can Be Damaged）False该设备不会受到玩家的伤害。

计时目标（Timed Objective）

计时目标（Timed Objective）设备充当每个炸弹点的引爆器。在两组爆炸物设备上各放置一个计时目标设备。

按以下方式配置该设备的用户选项（User Options）：

选项值说明
时间（Time）30决定目标计时器的时长。
开始得分（Start Score）2设置成功启动未开始的计时器时奖励的分数。
停止得分（Stop Score）5决定成功停止进行中的计时器后奖励的分数。
完成得分（Completed Score）3设置计时器走完时奖励的分数。
计时器标签文本样式（Timer Label Text Style）Bold Orange设置倒计时显示与自定义文本的样式。
开始队伍过滤（Start Team Filter）Team Index 1决定哪支队伍可以启动未开始的计时器。
开始交互文本（Start Interact Text）Arm Bomb设置向可以启动未开始计时器的玩家显示的自定义提示文本。
开始交互时间（Start Interact Time）5决定启动未开始的计时器所需的交互时长。
停止队伍过滤（Stop Team Filter）Team Index 2决定哪支队伍可以停止进行中的计时器。
停止交互文本（Stop Interact Text）Disarm Bomb设置向可以停止进行中计时器的玩家显示的自定义提示文本。
停止交互时间（Stop Interact Time）5.0决定停止进行中的计时器所需的交互时长。
计时器声音距离（Timer Sound Distance）Whole Map决定计时器声音是局部可闻还是全图可闻。

地图指示器设备（Map Indicator Device）

使用地图指示器（Map Indicator）设备在小地图上创建自定义标记。为每个爆炸点在其上方放置两个地图指示器设备，每支队伍各一个。

按以下方式配置该设备的用户选项（User Options）：

选项值说明
图标颜色（Icon Color）pick a color设置所显示图标的颜色。为每支队伍选择一个代表色。
文本（Text）Explosive A - Explosive B将一对地图指示器设备命名为 Bomb A，另一对命名为 Bomb B。

终局设备（End Game Device）

使用终局（End Game）设备，在炸弹被成功拆除时结束回合；若 30 秒倒计时走完，则通过 Verse 脚本引爆炸弹并结束回合。

按以下方式配置该设备的用户选项（User Options）：

选项值说明
获胜队伍（Winning Team）Activating Team激活该设备的队伍将赢得游戏。
结束内容（What to End）End Round该设备将结束游戏回合。

玩家出生点设备（Player Spawn Pad Device）

将每支队伍的玩家出生点（Player Spawn Pad）设备分别集中放置在地图相对的两侧。每支队伍拥有各自的出生器，队伍 1 负责安放炸弹，队伍 2 负责拆除炸弹。每回合双方交换职责。

按以下方式配置该设备的用户选项（User Options）：

选项值说明
玩家队伍（Player Team）Team Index 1 - 2一组出生点设置为 Team Index 1，另一组设置为 Team Index 2。

添加 Verse 脚本（Adding the Verse Scripts）

添加以下 Verse 脚本（Add the following Verse scripts），首先使用 @editable 函数引用设备。

你可以按书写顺序复制代码。脚本中添加了注释以便理解。

# enum to determine the state of the bombs
bomb_state<public>:= enum {AllUnarmed, BombAArmed, BombBArmed}

上面的代码定义了一个枚举，用于跟踪炸弹的状态。

search_and_destroy := class(creative_device):
    Logger:log = log{Channel:=log_search_and_destroy}
    @editable TimedObjectiveA: timed_objective_device = timed_objective_device{}
    @editable

你可以使用 @editable 来引用设备。

# Runs when the device is started in a running game
OnBegin<override>()<suspends>:void=
    # The race expression is used to run a block of two or more async expressions concurrently (simultaneously). When the fastest expression completes, it "wins the race".
    # https://www.fortnite.com/en-US/creative/docs/uefn/race-in-verse
    race:

第一部分代码展示了使用竞速（race）实现并发，以判断炸弹 A 还是炸弹 B 先被安放。

block:
    # Wait for Bomb B to be armed
    ArmingPlayer:= TimedObjectiveB.StartedEvent.Await()
    Print("Bomb B Armed",?Duration:=5.0)

上面的代码展示了并发：脚本等待计时目标（Timed Objective）完成或被停止。

# Disable the unarmed Beacons and enable the Beacon over the armed bomb
UpdateBeacons():void=
    BombABeaconArm.Disable()
    BombBBeaconArm.Disable()

上面的代码根据哪颗炸弹被安放来更新信标的状态。

BombDetonated(Agent:agent):void=
    Print("Bomb Detonated", ?Duration:=5.0)
    # Determine which set barrels should explode
    if:
        BombState = bomb_state.BombAArmed

上面的方法在计时目标（Timed Objective）设备走完时调用，用于决定哪一组炸药桶爆炸并结束游戏。

ExplodeBarrels(Barrels:[]explosive_device, Agent:agent):void=
    for (Barrel : Barrels):
        Barrel.Explode(Agent)

上面的 for 循环用于引爆正确炸弹点的每一只炸药桶。

Verse 设备（Verse Device）

编译你的 Verse 脚本，然后在内容抽屉（Content Drawer）中找到你的设备。将 Verse 设备拖到地图上一个不起眼的区域来自定义设置。

使用该设备将直接事件绑定（direct event binding）链接到所需的设备，以便 Verse 脚本引用它们。

在该设备的细节（Details）面板中，参照上图配置每个引用设备的设置。
