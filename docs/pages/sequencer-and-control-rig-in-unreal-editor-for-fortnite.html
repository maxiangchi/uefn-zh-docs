在 UEFN 中使用 Sequencer 与 Control Rig

在 Sequencer 中为骨架网格体、动画与相机制作过场，并用 FK Control Rig 微调动作，最后挂接到过场动画序列设备触发播放。

英文原标题：Sequencer And Control Rig In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

在 Sequencer（Sequencer） 中，你几乎可以为任何东西制作动画，甚至可以做出带相机动画的完整过场动画（cinematic）！更多信息请参阅 虚幻引擎中的 Sequencer 基础。

不要把 Sequencer 和 Cinematic Sequence（过场动画序列）设备搞混！录制好关卡序列（level sequence）后，还需要把它挂接到过场动画序列设备（Cinematic Sequence Device）上。更多信息请参阅设置过场动画序列设备。

创建关卡序列

要创建关卡序列并向其中添加骨架网格体，请执行以下操作：

  • 在项目文件夹中新建一个名为 "Cinematics" 的文件夹。
  • 在 Cinematics 文件夹中右键，选择 Cinematics > Level Sequence（关卡序列）。
  • 将该关卡序列命名为 "LS_Cine"。
  • 双击该关卡序列以打开 Sequencer。
  • 打开 MeleeMinions 文件夹，把骨架网格体拖入视口。
  • 从大纲视图（Outliner）把骨架网格体 Actor 拖入 Sequencer，或点击 + Track 并选择 Actor To Sequencer 来找到该网格体。

下一节将介绍使用 Sequencer 创建动画场景的基础操作。

使用 Sequencer

本节教程将带你了解 Sequencer 的一些基本操作。

开始之前，建议打开Sequencer 编辑器参考并放在本页旁边。该参考介绍了 Sequencer 的界面元素，并演示如何高效地浏览编辑器。

关于动画序列的更详细介绍，请参阅虚幻引擎中的动画序列。

使用位移和旋转制作动画

最简单的动画就是通过位移或旋转来改变资产的状态。来试一下：

  • 双击你的关卡序列 "LS_Cine" 打开 Sequencer。该序列应该已经关联了关卡中的一个骨架网格体。
  • 在时间轴上确认播放头（playhead）位于 0000，然后按 Enter，或点击 Transform 行中的小 +（如下图所示），设置第一个关键帧（keyframe）。
  • 在视口中，把骨架网格体放到你希望动画开始的位置。
  • 启用 Auto Key（自动关键帧），这样每当属性或变换发生变化时都会自动创建关键帧。
  • 把播放头向前移动几帧。
  • 回到视口，把骨架网格体移到下一个位置。
  • 现在播放动画，或在两个关键帧之间拖动播放头，就能看到网格体从 A 点移动到 B 点。
  • 用同样的方法，试着给网格体加上旋转。
  • 如前一节所示，添加并关联 Cinematic Sequence（过场动画序列）设备和 Trigger（触发器）设备，即可在游戏中激活该动画。

添加导入的动画

要使用你之前导入的动画：

  • 在 Sequencer 中点击 + Animation，从导入的动画列表中选择。
  • 要播放多个动画，依次添加其余动画即可。
  • 为了过渡更自然，可以让第二个动画的开头与第一个动画的结尾重叠。Sequencer 会自动把两个动画混合在一起。

添加相机

你可以用相机制作过场动画，然后在关卡内触发。深入内容请参阅虚幻引擎 Cine Camera Actor 页面。

添加相机的方法：

  • 点击 Create Camera（创建相机）按钮添加相机轨道。这会同时添加 Camera Cuts 轨道和 CineCameraActor，后者也会出现在大纲视图中。
  • 创建相机会把视图切换到 Pilot Active，你可以定位相机并构图。
  • 像给骨架网格体打关键帧一样：选中 Transform 行，移动相机的同时添加关键帧。
  • 再添加第二个相机，给角色拍一个特写。
  • 当有同一 Actor 的多个实例时，建议在大纲视图中逐个重命名。
  • 构图完成后，把播放头拖到要切换机位的位置，右键 > Edit > Split。
  • 右键新切分出的段落，在菜单底部选择要使用的相机。
  • 点击 Sequencer 中 Camera Cuts 行的摄像机图标，即可在相机 Actor 和常规视口之间切换。

你也可以通过 Perspective 下拉菜单切换 CineCameraActor 来选中相机 Actor：

按弹出键（eject key）即可返回常规视口。

使用 FK Control Rig 为骨架网格体制作动画

Sequencer 允许你使用程序化生成的控制绑定——FK Control Rig 来为骨架网格体制作动画。完整工作流请参阅虚幻引擎中的 FK Control Rig。

骨骼数量较少的骨架网格体很适合用 FK Control Rig 制作动画。选中要动画的骨骼，然后按 S（焦点在视口时）或 Enter（焦点在 Sequencer 中时）打关键帧。

给小兵的慢跑动画做一点小修改：

  • 在小兵轨道上点击 + Track，选择 Control Rig > FK Control Rig。
  • 因为你是在现有动画上修改，右键新创建的 FKControlRig 轨道并勾选 Additive。
  • 展开 FK Control Rig 轨道以显示骨骼列表，选中脊柱。
  • 按 S 或 Enter 打一个关键帧，把播放头往后移，再把脊柱旋转几度。对任何身体部位都可以这样做！

设置过场动画序列设备

有了序列之后，就可以把它添加到过场动画序列设备（Cinematic Sequence Device），并用触发器播放过场动画。关于该设备的更多信息，请参阅过场动画序列设备。

把关卡序列添加到设备的方法：

  • 添加一个 Trigger（触发器）设备。按住 Alt 并移动现有触发器即可复制一个。
  • 找到 Cinematic Sequence（过场动画序列）设备并拖入视口。
  • 在 Sequence 字段选择 "LS_Cine"，或从内容浏览器拖入。
  • 对于 Play Function，点击 + 添加一个数组元素，然后在两个字段中分别选择 Trigger3 和 On Triggered。
  • 当你触发 Cinematic Sequence 设备时，就会播放录制在 "LS_Cine" 中的序列。
  • 你可以通过链接多个关卡序列设备、让它们一个接一个地触发，来制作更精致的过场。
