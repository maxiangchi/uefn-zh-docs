在 UEFN 中制作派对游戏

派对游戏是从中央枢纽进入的多个小游戏的合集，本教程教你制作投票枢纽、定向镜头、Sequencer 玩法事件与可复用的 Verse 游戏管理器。

英文原标题：Party Game in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

派对游戏（Party Game）是指可以从中央枢纽进入的多个小游戏的合集。本教程将通过以下关键玩法元素的制作步骤，教你打造自己的派对游戏：

  • 在赛前大厅中添加设备，制作投票枢纽（voting HUB）并创建简单的投票结构。
  • 使用定点镜头（Fixed Point Camera）改变常规的镜头视角，打造独特的玩法视角。
  • 使用 Sequencer（过场动画编辑器）的玩法事件（Gameplay Events）功能驱动小游戏中的游戏机制。
  • 用 Verse 编写可复用的游戏管理器（Reusable Game Manager），供你全部的小游戏使用。

一场派对游戏会话最多支持 8 名玩家加入。本教程中的小游戏最多支持 4 名玩家，每个游戏的游玩时长约为 1 分半钟。

观看下面的视频可总览本教程涵盖的全部内容。每个视频时长 10 分钟，并附带帮助你创建自己派对游戏的技巧！输入 Tilt'n Boom 岛屿代码 4214-3766-1548即可游玩这些小游戏，实际体验派对游戏的玩法机制。

你将学到什么

本教程演示了一些基础功能：

  • 设置关键设备，创建投票结构。
  • 使用定点镜头（Fixed Point Camera），从关卡区域定向视角而非第三人称视角捕捉玩法画面。
  • 使用 Sequencer（过场动画编辑器）创建在游戏过程中触发事件的玩法事件（Gameplay Events）。
  • 用 Verse 编写游戏管理器，可复用于你创建的每个小游戏。

Verse API

  • 玩家引用（Player Reference）
  • 计分管理器（Score Manager）
  • 过场动画序列（Cinematic Sequence）
  • 计时器（Timer）
  • 玩家生成点（Player Spawn Pad）
  • 传送器（Teleporter）
  • 伤害体积（Damage Volume）
  • 物品生成器（Item Spawner）
  • 占领区域（Capture Area）

总览

  • 投票枢纽
    把赛前大厅变成派对游戏的投票枢纽！
  • 定向镜头玩法
    在木筏上添加物品生成器，让不同的武器在不同时间生成。

  • 可复用的游戏管理器
