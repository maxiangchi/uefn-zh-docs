UEFN 中的用户界面功能模板

用户界面功能模板展示了使用 Unreal Motion Graphics（UMG）创建自定义用户界面（UI）的各种可能；本配套教程将带你熟悉相关创意模式设备、UI 微件的制作流程，以及模板中材质与纹理的用法。

英文原标题：User Interfaces Feature Template in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

用户界面功能模板（User Interface Feature Template）展示了使用Unreal Motion Graphics（UMG）创建自定义用户界面（user interfaces，UI）时的各种可能。你可以在 Project Browser（项目浏览器）的 Feature Examples（功能示例）中 Project Templates（项目模板）部分找到该模板。

本配套教程将带你熟悉：在抬头显示器（heads up display，HUD）上添加自定义 UI 的 Fortnite 创意模式设备；如何从设计到设备功能构建 UI 微件；以及该功能模板中的材质、纹理和材质函数是如何打造 UI 示例的自定义外观的。

用户界面功能模板的生成点。

UI 示例内容打包在内容浏览器（Content Browser）的 UI 文件夹中，再按设备分放在 Devices 文件夹里。每个设备文件夹包含以下资源文件夹：

  • Material Instances（材质实例）——用于创建扁平 UI 设计或动态设计的材质与材质函数。
  • Textures（纹理）——用于创建仅靠材质无法实现的更复杂 UI 设计的纹理。
  • Widgets（微件）——替换默认玩家 UI 的 User Widget（用户微件）设计与构造。

打开项目文件夹，再打开 UI > Devices 文件夹，即可查看所有设备资源。

该模板分为三个大厅，每个大厅都有一系列房间，展示不同的设备与 UI 示例。书签已设置好，可带你逐个房间参观，你将在其中了解不同的创意模式设备、它们如何用于展示自定义 UI，并查看为这些设备创建的 UI 示例。

按以下按键在模板中选择新房间：

  • 1 —— Room 1
  • 2 —— Room 2
  • 3 —— Room 3、Room 5、Room 6
  • 4 —— Room 4

首先按 1 键前往第一条走廊并进入 Room 1，从这里开始学习 HUD Message（抬头显示信息）与 Pop-Up Dialog（弹出对话框）设备及其微件。进入每个房间查看设备、UI 等示例。下方的文档将帮助你理解这些示例的搭建方式，以及如何制作自己的自定义 UI。

  • User Interface Devices（用户界面设备）
    详细了解支持自定义 UI 的创意模式设备。
  • UMG Widgets（UMG 微件）
    深入了解如何使用 UMG 微件创建独特的用户界面。
  • Verse Fields Examples（Verse 字段示例）
    学习如何使用 Verse 字段为下一个项目创建自定义 UI。
  • Material Assets（材质资源）
    详细了解如何在用户界面中使用材质与纹理。
  • Migrating Template Assets（迁移模板资源）
    学习如何将模板中的资源迁移到自己的项目中使用。
