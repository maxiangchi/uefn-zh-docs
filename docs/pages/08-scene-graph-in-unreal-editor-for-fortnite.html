场景图 Scene Graph

Scene Graph 是连接世界中所有对象的统一结构：用实体、组件与预制件，结合 Verse 自定义行为，搭建场景装饰、玩法系统、音频与特效。本页为总览与全部子教程入口。

英文原标题：Scene Graph in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

Scene Graph 是连接世界中所有对象的统一结构。你可以把它看作一个工具箱，里面装着搭建场景装饰、玩法系统、音频、视觉特效（VFX）等、为元宇宙（Metaverse）创建体验所需的全部工具。

Beta 功能提示：欢迎学习使用这一 Beta 功能，但在将其用于正式发布（Shipping）的项目时请谨慎。

概述

使用 Scene Graph 构建，意味着你可以对项目中相互关联的对象批量执行操作。在搭建结构与代码的过程中，你还可以复制并迭代它们。你甚至可以将自己创建的对象制成可复用的预制件（Prefab），跨不同项目使用。

Scene Graph 是 Verse 原生（Verse native）系统，充分发挥了 Verse 语言的特性。它为你提供了一种方式：用可交互的自定义对象与玩法体验，为项目添加更多定制化内容。

入门与核心工作流

如果你是第一次接触 Scene Graph，建议先从入门开始：只需几个简单步骤，即可从灰盒（Greybox）搭建过渡到完整可玩的关卡，理解实体（Entity）、组件（Component）、预制件（Prefab）与 Verse 的基础用法。

  • Scene Graph 入门：学习使用 Scene Graph 搭建游戏环境与玩法。
  • 使用实体与组件（Scene Graph）：学习向项目添加实体、组件与预制件的工作流：创建实体、嵌套组织层级、挂载组件、覆盖（Override）与清除覆盖，搭建复杂对象。

组件与自定义行为

组件（Component）为 Scene Graph 中的实体提供数据与行为，定义实体在场景中应该做什么。默认情况下，所有实体都带有变换组件（Transform Component），用于确定实体在世界中的位置。

  • 场景图组件（Components）：组件为实体添加功能与行为，是 Scene Graph 实体的能力来源。
  • 使用 Verse 创建自己的组件：通过编写自己的 Verse 组件，为实体定义自定义行为，例如生成与移除实体、增删组件，以及循环消失等效果。

预制件与编辑器

预制件（Prefab）是使用实体与组件层级保存所有预制件实例（Prefab Instance）共享基础信息的稳定对象。学会创建与复用预制件，你就能在多个项目间复用游戏对象与玩法元素，并在实例上做个性化编辑。

  • UEFN 中的预制件与预制件实例：通过创建预制件，复用并编辑游戏对象与游戏元素。
  • 预制件编辑器用户界面：总览预制件编辑器（Prefab Editor）的界面与编辑能力：菜单栏、两条工具栏、视口、大纲视图与细节面板。

玩法系统：物品、事件与变换

掌握实体与预制件之后，可以进一步用 Scene Graph 驱动玩法：自定义物品与背包、用场景事件（Scene Events）传递信号、用变换（Transform）精确控制物体的位移、旋转与缩放。

  • Scene Graph 自定义物品与背包：学习使用 Verse 与 Scene Graph 创建自定义物品、自定义 Fortnite 玩家背包等内容。
  • 场景事件（Scene Events）：学习创建场景事件，改变组件行为，为场景添加有趣的事件，实现实体与组件之间自上而下或自下而上的解耦通信。
  • Scene Graph 中的变换（Transform）：变换 Scene Graph 实体，操作其位移（Translation）、旋转（Rotation）与缩放（Scale），理解 transform 与 transform_component、局部变换与全局变换的计算，以及在编辑器与 Verse 中的用法。

教程与最佳实践

想看完整的实战例子，或想写出更健壮的 Scene Graph 代码，请阅读教程合集与最佳实践：教程带你用新颖有趣的方式使用各项功能，打造可扩展、可复用的玩法；最佳实践则通过实例讲解开发项目时应遵循的规范。

  • 场景图 Scene Graph 教程：学习用多种方式使用 Scene Graph，创造新颖有趣的玩法。
  • 场景图（Scene Graph）最佳实践：开发 Scene Graph 项目时可遵循的最佳实践合集。

已知问题、数据恢复与实验性功能

Scene Graph 仍在快速演进。在项目中使用这一 Beta 功能时，你可能会遇到已知问题与限制；当你修改已确立的 Verse 组件功能（Class Schema）时，还可能遇到数据丢失——数据恢复系统（Data Recovery System）可以帮你安全回退。同时，你也可以提前了解仍在变化中的实验性（Experimental）功能。

  • 场景图 Scene Graph 已知问题：了解 Scene Graph 中的已知问题，并学习如何把旧项目更新到 Scene Graph。
  • 数据恢复系统：学习 UEFN 如何在不丢失数据的情况下，安全回退对类架构（Class Schema）更改。
  • 场景图实验性功能：仍在变化、暂不建议用于正式发布项目的功能，例如 Scene Graph 中的骨骼动画与 LLM 对话等主题。
