编写代码基础 5：练习时间（Practice Time）

你的 Verse 代码还开着吗？太好了！在本练习中，你将调用真正能伤害 Fortnite 角色的函数，一步步逐行理解代码在做什么。

前置主题（Prerequisite topics）

要理解和使用本页内容，请确保你熟悉以下主题：

  • 第 5 课：调用函数（Lesson 5: Calling Functions）

你的 Verse 代码还开着吗？太好了！

在本练习中，你将调用真正能伤害你的 Fortnite 角色的函数，正如早在第 3 课：练习时间（Lesson 3: Practice Time）中所承诺的那样！

在开始编码之前，你需要在 UEFN 岛屿中添加一个设备（device）。它叫玩家生成器（Player Spawner），它会让你的玩家角色在设备所在位置生成，而不是默认的 Fortnite 空中生成位置。本练习中的代码要正常工作，必须放置玩家生成器。

要学习如何放置玩家生成器设备，请参阅《UEFN 创意用户控制指南（UEFN Controls for Creative Users）》中的对象放置（Object Placement）。你可以把它放在岛屿上的任何位置。

本练习中用到的部分代码对你来说是新的，但你会有机会回顾每一行在做什么。如果你现在还不能完全理解，也不用担心，本次练习只关乎调用函数。

确保 Verse 文件的最顶部包含以下所有行。它们告诉 Verse 编译器，你将在自己编写的 Verse 设备中使用 Verse 与 Fortnite 内置代码的哪些部分（using）。

using { /Fortnite.com/Devices }
using { /Fortnite.com/Characters }
using { /Fortnite.com/Playspaces }
using { /Verse.org/Simulation }
using { /Verse.org/Verse }

接下来，你要编写伤害 Fortnite 角色的代码行。我们逐行来看。

  1. 调用名为 GetPlayspace() 的函数。它返回一个 fort_playspace 类型的值，你将其保存到名为 Playspace 的常量中。你需要它来获取玩家。
  2. 在常量 Playspace 上调用名为 GetPlayers() 的方法。该方法返回一个 player 类型的数组。数组（array）是一种容器，可以容纳多个 Verse 中同类型的变量。在本例中，AllPlayers 数组容纳了关卡中的所有玩家。
  3. 你已经学过可以用 if 在代码中提问是非问题。在本例中，你用 if 询问 AllPlayers 数组的第一个位置是否存在变量。如果存在，表达式 AllPlayers[0] 将返回该位置变量的值，常量 FirstPlayer 将被初始化为该返回值。
  4. 嵌套在第一个 if 中的第二个 if 询问：通过调用 FirstPlayer 常量的方法 GetFortCharacter[]，该常量是否有 Fortnite 角色。注意调用时使用的方括号，它们用于调用可能失败的函数，这就是为什么这里用 if 来调用该函数。如果 GetFortCharacter[] 成功返回 fort_character 类型的值，常量 FortniteCharacter 将被初始化为该值。
  5. 最后，既然你已经有了 fort_character 类型的常量，就可以调用它的方法 Damage()。该方法接受一个 float 类型的参数，也就是角色将受到的伤害量。关于参数，你将在下一课学到更多。
Playspace: fort_playspace = GetPlayspace()
AllPlayers: []player = Playspace.GetPlayers()
if (FirstPlayer : player = AllPlayers[0]):
    if (FortniteCharacter : fort_character = FirstPlayer.GetFortCharacter[]):
        FortniteCharacter.Damage(50.0)

如果你运行这段代码，游戏开始时应该会看到你的 Fortnite 角色受到 50.0 点伤害！

很酷，对吧？
