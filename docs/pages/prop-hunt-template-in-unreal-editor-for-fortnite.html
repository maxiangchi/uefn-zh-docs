道具猎手（Prop Hunt）模板

在 Verse 道具猎手中，猎人必须找出并淘汰伪装成道具躲藏起来的玩家队伍。本教程将演示玩家加入/离开事件、循环、类、非对称队伍与自定义事件等基础功能。

英文原标题：Prop Hunt Template in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

在 Verse 道具猎手（Verse Prop Hunt）中，猎人必须找出并淘汰一支伪装成道具（Prop）躲藏起来的玩家队伍。

每一回合开始时，玩家都会出生在大厅中。游戏开始后随机分配队伍。在游戏开始后的前 15 秒，猎人队伍会在赛前大厅中等待，道具队伍则去躲藏。

被猎人队伍的玩家射中后，道具会受到伤害并被淘汰。被淘汰的道具将在大厅中重生为猎人。

15 秒未移动的道具会发出心跳视觉特效与音效（VFX 与 SFX），向猎人暴露自己的位置。为避免被发现，道具需要持续移动。

道具每存活一秒即可得分，猎人每次淘汰也可得分。猎人获得的分数会随着被淘汰道具数量的增加而提高。最后一个道具的分值最高，玩法也因此更加刺激。

输入岛屿代码 0259-6053-5824 即可游玩并体验 Verse 道具猎手（Verse Prop Hunt）模板的玩法机制。该模板位于 UEFN（Unreal Editor for Fortnite，Fortnite 虚幻编辑器）的 精选示例（Featured Examples）分区中。

本教程将演示以下基础功能：

  • 玩家加入/离开事件
  • 循环：for 与 loop
  • 类（Classes）
  • 非对称队伍
  • 自定义事件

与创意模式（Creative）的 道具猎手（Prop Hunt）教程不同，本教程使用 Verse（Verse）来实现某些功能。

在本教程中使用 Verse（Verse），你可以：

  • 处理玩家加入与离开游戏。
  • 按玩家总数定义猎人数量。
  • 统计道具数量，并在所有道具都被摧毁时结束回合。
  • 遍历游戏内所有玩家的信息。
  • 根据剩余道具数量，提高猎人每次淘汰获得的分数。
  • 通过脚本阅读逻辑，而不必在 UI 中追踪多个设备之间抽象的事件/频道关联。
  • 在场景中使用更少的设备。
  • 查看 @editable 属性，无需理解 Verse（Verse）即可调整脚本行为。
