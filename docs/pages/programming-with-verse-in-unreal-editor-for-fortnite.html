在 UEFN 中使用 Verse 编程

准备好用 Verse 把你的岛屿提升到新高度了吗？从创建自己的设备、NPC 行为和 Verse 文件开始吧。

英文原标题：Programming with Verse in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

准备好用 Verse（Verse）把你的岛屿提升到新高度了吗？从这里开始吧！

创建你自己的设备

使用 Verse（Verse），你可以构建自己的设备、制定自己的游戏规则。在 Verse 资源管理器（Verse Explorer）中基于 Verse 设备（Verse Device）模板新建 Verse 文件，就能为项目添加你自己的设备。

  • 使用 Verse 创建你自己的设备
    用 Verse 打造你自己的设备与规则！

创建你自己的 NPC 行为

使用 Verse（Verse），你可以定义自己的 NPC 行为（NPC Behavior），为游戏打造独一无二的非玩家角色。在 Verse 资源管理器（Verse Explorer）中基于 NPC 行为（NPC Behavior）模板新建 Verse 文件，即可得到一个会四处走动的可用示例；也可以从 NPC 行为基础（NPC Behavior Basic）模板从零开始。

  • 创建自定义 NPC 行为
    用 Verse 代码创建符合你游戏设计需求的 NPC 行为！

创建你自己的 Verse 文件

在 Verse 资源管理器（Verse Explorer）中选择 创建空文件（Create Empty）即可新建空白 Verse 文件，随心定义你自己的类、模块，anything you can think of，一切皆可定义！

定义好自己的内容后，把它们引入 Verse 设备（Verse Device）或 NPC 行为（NPC Behavior）中，就能在游戏里用起来了。
