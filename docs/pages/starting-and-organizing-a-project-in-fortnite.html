开始并组织项目

本指南将教你如何在 Unreal Editor for Fortnite（UEFN）中创建并启动项目，并分享实用的项目组织技巧，帮你高效搭建岛屿。

英文原标题：Starting and Organizing a Project in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

在本指南中，你将学习如何在 Unreal Editor for Fortnite（UEFN） 中创建并启动项目。

你还将获得一些组织方面的技巧与窍门，帮你为成功打好基础。无论你是团队协作还是独自开发，这些技巧都是行业通用标准，能帮你更高效地搭建与开发岛屿。

创建项目

要创建项目，请启动编辑器，并选择一个岛屿作为起点来创建项目。当你向项目中添加内容时，内容会保存在你的项目之内。

开始新项目的推荐做法包括：

  • 在纸上或以数字方式草绘你的想法。
  • 为打算导入的资产（Asset）创建线框图。
  • 推演游戏逻辑，即项目资产应呈现的外观，以及资产之间应如何互动。

启动 UEFN 会直接打开项目浏览器（Project Browser），除非你勾选了启动时打开上次的项目（Open last project），那样会自动打开你当前正在做的项目。

  • 启动 UEFN。（如果弹出了新闻（News）窗口，点击 Let's get started! 将其关闭。）此时会打开项目浏览器（Project Browser）。

如果你之前已在 Fortnite 中创建过岛屿，这些岛屿会显示在我的项目（My Projects）选项卡下。如果这是你第一次使用 Fortnite，该选项卡为空。

  • 点击岛屿模板（Island Templates）选项卡，然后点击空白（Blank）以打开一个空岛屿。
  • 在窗口底部，你可以为项目命名（Name）并保存（Save）项目。名称默认为 MyProject，但你可以改成任何想要的名称。

关于项目命名，有三点需要了解：

  • 你为项目所取的名称，将作为该项目今后的名称长期使用。
  • 命名时只使用字母、下划线（_）和数字。
  • 名称中不要使用空格。
  • 为你的项目命名。
  • 点击创建（Create）。

你也可以从已打开的项目中创建新项目：

  • 从文件（File）菜单中选择新建 / 打开项目（New / Open Project）。
  • 从项目（Project）菜单中选择新建 / 打开项目（New / Open Project）。

复制项目

复制已发布的项目是加速岛屿开发、管理风险的好方法，适合作为计划中的项目扩展或改进的一环。

你只能复制已同步的项目。

要从项目浏览器（Project Browser）复制项目：

  • 在浏览器中选择一个项目并右键打开上下文菜单，然后选择复制（Duplicate） > 复制项目（Duplicate the Project）。此时会打开复制项目（Duplicate Project）对话框。
  • 在“复制项目”对话框中：
  • 为新项目命名。
  • 选择目标文件夹（Destination Folder）。
  • 点击复制（Duplicate）。

复制出的项目会自动归属于与源项目相同的文件夹目标和团队，你也可以在“复制项目”对话框中修改这两项。

复制过程会对项目运行验证检查，并扫描源项目中过期的资产。

模板

模板让项目（Project）创建变得简单直接，无论你是从空岛屿关卡（Level）开始，还是从内容完整的教程开始。

模板都支持自定义。你可以编辑地形，删除不需要的对象和资产，也可以添加模板原生不包含的内容和资产。所有模板都包含以下通用元素：

  • Fortnite 玩家出生点。
  • 标记关卡边缘的关卡边界。
  • 时间（Time-of-Day）设置。
  • 岛屿设置（Island Settings）设备。

可从以下模板分组中选择：

  • 岛屿模板（Island Templates）——包含一系列模板：
    • 空白模板，一切由你从零搭建。
    • 基于 Fortnite 大逃杀地图目的地的岛屿，其中包含你可以添加、移动、删除或修改的预制件（Prefab）或资产。
    • 特定地形的岛屿，不含预制件或资产。
  • 品牌模板（Brand Templates）——包含一系列品牌模板：
    • Fortnite 空白模板岛屿。
    • 品牌专属资产，例如乐高（LEGO）® 或其他 IP，只能与特定模板搭配使用。
  • 功能示例（Feature Examples）——帮你学习使用不同 UEFN 功能与系统，以及 Verse 编程语言的模板。

项目组织

从一开始就正确设置项目，可以在日后为你节省大量时间与烦恼。

组织工作从你在编辑器中创建并打开项目的那一刻就开始了。

了解如何在 UEFN 中设置项目，能帮你更好地理解编辑器的默认功能，以及它能为你的项目带来哪些好处。

组织新项目的最佳做法包括：

  • 为关卡（Level）、道具（Prop）、设备（Device）等建立并使用一致的命名规范。
  • 确定迭代资产时如何为资产名称添加版本。
  • 使用嵌套文件夹在 UEFN 内存储与共享文件。
  • 按岛屿位置与功能对设备和 Actor 进行分组。
  • 用颜色标记文件夹，让组织工作保持一致。

要落实这些做法，请熟悉编辑器的每个区域及其用途。参阅用户界面参考文档，进一步了解 UEFN。

使用标准命名规范

从事游戏开发意味着项目中会有大量资产。遵循游戏行业命名规范是一项应尽早落实的最佳实践，它能帮你快速定位资产，对团队协作至关重要。

命名规范最重要的是保持一致。命名规范通常遵循以下结构：

  • 资产类型前缀（Asset Type Prefix）——标识资产类型，例如材质实例用 MI_。
  • 资产名称（Asset Name）——赋予资产的名称。
  • 描述符（Descriptor）——为资产提供上下文。例如，如果是一张法线贴图纹理，名称可以是 T_WoodenBox_N。
  • 可选的变体编号或字母（Optional Variant Number or Letter）——当同一资产有多个版本时使用。例如 MI_Cube_2。

命名规范通过以下方式提升开发效率：

  • 对项目中的所有资产进行分类。
  • 跟踪同一资产的不同版本。
  • 在项目及其团队内树立统一标准。

命名资产时，单词之间不要使用空格。你需要确定采用哪种命名风格。常见的文件与资产命名规范包括蛇形命名法（snake case）与驼峰命名法（camel case）。

蛇形命名法（Snake Case）

蛇形命名法中，名称或名称各部分的首字母均小写，单词之间以下划线连接，从而组成完整名称。例如：mi_userinterface_background。

蛇形命名法提升了可读性，并在为资产创建多词标识符时保持一致。

驼峰命名法（Camel Case）

驼峰命名法将多个单词组合在一起，每个单词首字母大写，并使用下划线分隔单词。

驼峰命名法同样能提升可读性，并在为资产创建多词标识符时保持一致。

在 UEFN 中，资产命名采用驼峰命名法。例如：MI_UserInterface_Background。

使用文件夹结构

文件夹结构同样有助于组织项目资产。

当你使用一致的文件夹层级、将同类资产归置在一起时，需要选择或编辑资产就能快速找到。

组织与命名文件夹结构时，最好按以下维度：

  • 内容类型（Content Type）——文件夹内资产的类别，例如材质（Materials）或用户界面（User Interfaces）。
  • 资产类型（Asset Type）——子文件夹中的资产类型，例如微件或关卡序列。（有时该文件夹就是父文件夹。）
  • 资产用途（Asset Use）——资产的用途。一般很少需要深入到第三层，但如果需要，在第三层嵌套文件夹中按用途标识资产会很有效。

例如，你可以有一个用户界面文件夹，其中包含名为 Materials 的子文件夹。在 Materials 文件夹中，还可以按用途进一步拆分不同的材质，例如 Progress_Bar 或 Icons。

内容浏览器设置

内容浏览器（Content Browser）是编辑器中非常实用的功能。你所有的项目资产都会汇总在浏览器中，无论它们是否已被添加到视口。

以下是更多内容浏览器使用技巧。

  • 创建父文件夹（Create parent folders）——父文件夹是组织所有资产的方式，即按基本结构对资产分组。例如：用户界面（User Interfaces）、材质（Materials）、Verse 设备（Verse Devices）、网格体（Meshes）等。
  • 项目设置（Project setup）——确保内容已正确配置以识别资产路径，这样内容浏览器才能定位你的资产。
  • 使用多个内容浏览器（Using multiple content browsers）——在布置岛屿布景时最有用，你最多可以同时打开五个浏览器。
  • 使用内容抽屉（Using the Content Drawer）——将最常用的文件夹放入内容抽屉（Content Drawer），它们会置顶显示在来源面板（Sources panel）顶部，免去查找文件夹的麻烦。
  • 创建资产库（Create asset libraries）——在单个项目内或跨多个项目组织与共享资产。
  • 本地与共享文件夹（Local vs shared folders）——决定是在团队工作区共享资产，还是为项目资产保留本地文件。共享工作区适合团队，本地工作区适合个人项目与修改。
  • 使用内容浏览器筛选器（Use content browser filters）——通过搜索栏快速筛选，迅速定位某个资产或某类资产。
  • 将资产文件夹添加到收藏（Add asset folders to Favorites）——在来源面板中收藏文件夹，把常用文件夹加入收藏列表，就无需在内容浏览器中反复搜索。

大纲视图设置与组织

放置到视口中的所有资产都会按文件名列在大纲视图（Outliner）中。与内容浏览器一样，你也可以在大纲视图中创建文件夹。在大纲视图中使用嵌套文件夹系统有助于清理大纲视图列表，并能快速找到想要编辑的资产。

  • 父文件夹与子文件夹（Parent and child folders）——以岛屿的某个区域命名父文件夹，再为该区域中的不同资产创建子文件夹，例如预制件、道具与设备。这是一种行业通用的组织方法，能帮开发者更高效地查找与编辑资产。
  • 收起文件夹（Close folders）——收起当前不用的文件夹，专注于正在使用的文件。
  • 重命名资产（Rename assets）——如果有多个同类型资产，可以使用大纲视图的右键菜单重命名。当你复制资产或向视口中拖入多个资产时，编辑器会自动为重复资产编号。
  • 隐藏或显示资产（Hide or reveal assets）——有助于可视化与集中注意力。不需要布置布景时隐藏资产，或在工作时隐藏视口中的设备，之后再重新显示。如果忘记重新显示，保存并退出项目后，下次登录该项目时它们会自动重新显示。
  • 将同类资产归组（Group like assets together）——无论是放入文件夹还是按类别分组，都能更高效地在细节面板中编辑。也可以从主菜单栏的选择（Select）下归组。更多信息请参阅用户界面参考文档。

有关大纲视图操作的更多信息，请参阅大纲视图技巧与窍门。
