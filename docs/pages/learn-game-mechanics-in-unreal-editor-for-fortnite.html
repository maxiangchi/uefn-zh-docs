学习游戏机制

想学习如何在 Verse 中操控平台？或者创建逻辑解谜？下面汇总了多种游戏机制与交互，可直接加入你自己的项目。

英文原标题：Learn Game Mechanics in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

想要学习如何在 Verse 中操控平台？或者创建逻辑解谜？快来看看下面这些不同的机制与交互，把它们加入你自己的项目吧。

  • 动画道具移动
    学习如何使用 Verse，为《糖豆人》障碍赛制作道具移动画。

  • 创建你自己的 NPC 医疗兵
    使用 Verse 代码创建自定义 NPC 医疗兵。

  • 自定义回合逻辑
    学习如何保存跨回合持久化信息，并在多回合游戏结束或玩家离开会话时重置持久化数据。

  • 循环消失平台
    使用 Verse 创建周期性出现与消失的平台。

  • 触碰消失平台
    使用 Verse 创建玩家触碰后消失、并在随机秒数后重现的平台。

  • 在 Verse 中制作游戏内排行榜
    创建跨对局追踪玩家数据的游戏内排行榜。

  • 移动目标标记
    使用 Verse 创建移动目标标记。

  • 使用社交协同 API 的小队玩法
    学习如何使用社交协同 API 在 Verse 中读取小队成员，构建奖励组队游玩的玩法。

  • 持久化玩家统计
    学习如何创建在游戏会话之间保存的持久化玩家统计。

  • 同步消失平台
    使用 Verse 与一台设备，创建按顺序依次出现与消失的一系列平台。

  • 标记灯光解谜
    创建一个解谜：玩家需要找出灯光开关的正确组合来生成物品，通过使用 Verse 创建的设备实现。

  • 队伍多人平衡
    使用 Verse 在运行时以及玩家加入游戏时平衡队伍。

  • 用镜头切换玩家视角
    学习如何在玩家开门时切换镜头，实现区域之间的过渡。

  • 时间跳跃平台跳跃与生存游戏
    创建一座在白天与黑夜之间跳跃的岛屿。
