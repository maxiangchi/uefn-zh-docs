鱿鱼游戏岛屿

用鱿鱼游戏设备、岛屿模板与小游戏大师、社交推理两大玩法模板，在创意模式与 UEFN 中打造高风险挑战。

英文原标题：Squid Game Islands in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

用鱿鱼游戏（Squid Game）品牌岛屿，把游戏与尔虞我诈一起带进 Fortnite。用丰富的工具与资产探索 Fortnite 中的鱿鱼游戏世界，这些资源面向所有开发者，帮你打造抓住品牌精髓的独特体验。

在创意模式与 Fortnite 虚幻编辑器（UEFN）的新手岛中都可以获取鱿鱼游戏功能组合。不过某些功能，比如小游戏大师（Minigame Mastery）与社交推理（Social Deduction）玩法模板，只有 UEFN 才有。

想进一步了解如何获取品牌内容，请查看游戏合集（Game Collections）。本地子教程：Fortnite 中的游戏合集。

让游戏开始

搭建鱿鱼游戏岛屿时，请使用以下资源：

  • 鱿鱼游戏品牌规则（Squid Game Brand Rules）——使用鱿鱼游戏资产与模板创建并发布自定义鱿鱼游戏岛屿的品牌规则。
  • 使用鱿鱼游戏岛屿（Working With Squid Game Islands）——了解如何用独占鱿鱼游戏内容创建自定义鱿鱼游戏岛屿。
  • 小游戏大师模板（Minigame Mastery Template）——探索用设备与示例构建精彩新小游戏（mini-games）的方法，打造属于你自己的鱿鱼游戏岛屿。
  • 社交推理模板（Social Deduction Template）——学习用设备与玩法示例，为鱿鱼游戏岛屿构建各种社交欺诈玩法。
