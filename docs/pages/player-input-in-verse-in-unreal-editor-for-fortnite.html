在 Verse 中处理玩家输入 Player Input

在 UEFN 中，你可以用 Verse 输入 API（Input API）控制哪些输入对玩家生效，并在输入触发时做出响应，本文介绍其核心概念与事件生命周期。

英文原标题：Player Input in Verse in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

玩家输入是指把玩家的物理操作转换为游戏内响应的方式。游戏中常见的玩家输入示例是：玩家按下空格键，角色跳跃。

在虚幻编辑器 Fortnite 版（UEFN）中，你可以用 Verse 实现玩家输入。Verse 输入 API（Input API）让你可以控制哪些输入对玩家生效，并在这些输入被触发时做出响应。

/Verse.org/Input 模块提供了 player_input 类，它是你的 Verse 代码与玩家物理输入之间的主要接口。通过这个类，你可以激活多组输入动作（input action），在这些动作触发时订阅事件，并在不再需要时清理。

你可以用输入 API（Input API）实现：

  • 监听玩家动作，如跳跃、开火、下蹲或换弹。
  • 根据游戏状态启用或禁用多组输入，例如进入载具、打开菜单或拾取武器时。
  • 跟踪玩家按住某个输入的时长，再决定触发还是释放。
  • 响应界面导航输入，实现自定义菜单交互。

输入动作与输入映射

输入映射（input mapping）与输入动作（input action）的组合让你可以精细控制玩家能做什么、何时能做。例如，玩家拾取枪械时才激活武器输入，或仅在界面面板打开时启用菜单导航输入。

  • 输入动作（input action）：单个可绑定的动作，触发时会产生一个值，值的类型取决于动作。例如按键会产生 logic 值，模拟量（如手柄扳机）会产生 float 值。
  • 输入映射（input mapping）：一组相关的输入动作及其默认按键绑定。它相当于一种情境，告诉系统玩家现在可以执行这些动作。例如 TraversalMapping 把跳跃、疾跑和下蹲编为一组。

必须先把输入映射添加到玩家身上，其中的输入动作才会产生事件。如果映射未激活，对其动作的订阅不会触发。

开箱即用的预置输入动作按类别组织在不同模块中，每个模块都提供输入映射与单个输入动作：

  • /Fortnite.com/Input/Character 中的角色动作用输入
  • /Verse.org/Input/UI 中的界面动作用输入

事件生命周期

系统通过一系列事件处理玩家输入。理解这个生命周期有助于你决定应该订阅哪个事件。事件的更多细节请参阅 Verse API 参考。
