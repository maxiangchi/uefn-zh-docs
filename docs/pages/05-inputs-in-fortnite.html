输入系统

一套输入逻辑贯穿移动端、主机与 PC：玩家输入、输入设备信息与虚拟指针入口。

英文原标题：Inputs in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

玩家输入直接决定游戏的可玩性：在 Unreal Editor for Fortnite（UEFN） 中编写一次玩家交互逻辑，即可在移动端、主机与 PC 上一致运行，无需平台专属代码。

输入系统概述

玩家输入（Player inputs）直接决定游戏的可玩性。在 Unreal Editor for Fortnite（UEFN）中，输入（inputs）为你提供了一种构建玩家交互逻辑的方式：只需构建一次，即可在移动端、主机与 PC 上一致工作，无需任何平台专属代码。

UEFN 的控制方案为你提供了基础构建块，可让你的游戏适配玩家的设备。将移动、射击与菜单交互转化为可复用的配置，使其在各平台上表现一致。

输入系统（input system）还会在运行时为你提供每位玩家输入上下文的可见性。你可以查询玩家正在使用的硬件，以及他们与游戏交互的方式，从而相应地调整 UI 与功能。有了这些工具，你就可以面向全平台进行设计，而无需为每个平台编写单独的输入逻辑。

深入了解输入系统

以下页面深入介绍了 UEFN 独特的输入系统及其实现方式。

  • 玩家输入（Player Input）：定义玩家输入如何映射为游戏内响应。
  • 玩家输入设备信息（Player Input Device Info）：学习如何通过 Verse 玩家输入设备信息 API（Player Input Device Info API）检测玩家可用的输入硬件与首选输入方式。
  • 虚拟指针（Virtual Pointer）：使用 Verse 增强输入（Verse Enhanced Input），通过自定义输入映射（input mappings）、操作（actions）与手势（gestures），为 UEFN 岛屿添加跨平台指针输入。
