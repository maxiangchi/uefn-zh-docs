Verse 代码写作基础 7：实战练习

你的 HurtPlayer() 函数已经能工作，但伤害值是写死的字面量。在本练习中，你将创建一个返回 float 的 CalculateDamage() 函数，并把它的返回值传给 Damage() 方法，让伤害逻辑更加灵活。

前置知识

要理解和使用本页内容，请确保你已熟悉以下主题：

  • 第 7 课：指定函数的结果（Lesson 7: Specifying the Result of a Function）

你的 HurtPlayer() 函数已经能工作了，但由于你向 Damage() 方法传递的是字面量值，这个值只有在你手动修改代码时才会改变。在本练习中，你将通过创建另一个函数并利用其返回值，让 HurtPlayer() 函数更加灵活。

在第 4 课：实战练习（Lesson 4: Practice Time）中，你曾使用条件语句根据玩家生命值计算药水应造成多少伤害或治疗量。你将把其中部分代码拿回来，装进一个名为 CalculateDamage() 的函数中，它将返回一个 float 类型的值。你会把这个值存入一个常量，再传递给 Damage() 方法。

  • 创建一个名为 CalculateDamage() 的函数。在函数内声明两个 float 类型的常量：MinHealth 和 PotionDamageAmount，再声明一个 float 类型的变量 PlayerHealth。
CalculateDamage() : float =
    MinHealth : float = 1.0
    PotionDamageAmount: float = 80.0
    var PlayerHealth : float = 100.0
  • 创建一个 if…else if…else 表达式，返回以下三个值之一：
    • 如果 PlayerHealth 大于 PotionDamageAmount，返回 PotionDamageAmount；
    • 如果 PlayerHealth 小于 PotionDamageAmount 但大于 MinHealth，返回 PlayerHealth - MinHealth；
    • 如果 PlayerHealth 小于或等于 MinHealth，返回 PlayerHealth。
# If the damage amount would not eliminate the player, do that amount of damage
if (PlayerHealth > PotionDamageAmount):
    return PotionDamageAmount
else if (PlayerHealth > MinHealth):
    # Give player one more chance if their health is low
    return PlayerHealth - MinHealth
else:
    # Eliminate player
    return PlayerHealth

这段代码的效果是：如果药水本会淘汰玩家，它会给玩家一次“再来一次”的机会。

  • 既然已经有了一个能返回有用结果的函数，就需要存储这个结果。声明一个名为 DamageToDo 的 float 常量，并用 CalculateDamage() 的返回值初始化它，把它加到 HurtPlayer() 函数中。
HurtPlayer() : void =
    Playspace : fort_playspace = GetPlayspace()
    AllPlayers : []player = Playspace.GetPlayers()
    if (FirstPlayer : player = AllPlayers[0]):
        if (FortniteCharacter : fort_character = FirstPlayer.GetFortCharacter[]):
            DamageToDo: float = CalculateDamage()
            FortniteCharacter.Damage(50.0)
  • 最后，用起来吧！把 DamageToDo 作为参数传给 Damage()，再加一个 Print()，这样就能清楚看到 CalculateDamage() 返回了什么。
HurtPlayer() : void =
    Playspace : fort_playspace = GetPlayspace()
    AllPlayers : []player = Playspace.GetPlayers()
    if (FirstPlayer : player = AllPlayers[0]):
        if (FortniteCharacter : fort_character = FirstPlayer.GetFortCharacter[]):
            DamageToDo: float = CalculateDamage()
            Print("DamageToDo: {DamageToDo}")
            FortniteCharacter.Damage(DamageToDo)

现在，你对 Damage() 方法的调用不再使用字面量值，而是使用 CalculateDamage() 返回的值。你在之前的练习中应该已经写好了对 HurtPlayer() 的调用，但别忘了检查。
