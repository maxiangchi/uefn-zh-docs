动画与过场动画

在 UEFN 中为骨骼网格体导入动画，用 Sequencer 制作过场动画，并通过过场动画序列设备触发播放。

英文原标题：Animation and Cinematics in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

在 UEFN 中，你可以为骨骼网格体（skeletal mesh）导入并指定动画。然后使用 Sequencer 创建关卡序列（Level Sequence）来制作过场动画，再通过 Cinematic Sequence 设备触发播放。

教程导览

以下子教程覆盖从入门模板、动画导入播放，到 Sequencer、Control Rig、镜头语言与设备触发的完整链路：

  • UEFN 中的 Animation 101 模板 — 学习多种为骨骼网格体制作动画的方法。
  • UEFN 中的动画预设 — 了解动画预设（Animation Presets），以及如何在 NPC 上进行设置。
  • UEFN 相机轨道与摇臂（Rig Rail 与 Rig Crane） — 使用相机轨道（Camera Rig Rail）与摇臂（Rig Crane）打造富有戏剧张力的过场。
  • 在 Sequencer 中使用 Gameplay 事件 — 在 Sequencer 中添加 Gameplay 事件，准时触发设备功能与玩法机制。
  • 在 UEFN 中使用 LiveLink Hub — 学习设置资产、连接 LiveLink Hub，并录制可在游戏中使用的动捕数据。
  • Verse 单口喜剧俱乐部模板 — 使用该 UEFN 模板，学习制作单口喜剧演出与其他线性内容。
  • 在 UEFN 中导入并播放网格体动画 — 导入骨骼网格体动画，并在 UEFN 中播放！
  • 在 UEFN 中使用动画网格体设备（Animated Mesh） — 使用 Animated Mesh 设备，为骨骼网格体打造独特的动画。
  • 在 UEFN 中使用 Sequencer 与 Control Rig — 用 Sequencer 记录骨骼网格体的表演。
  • 使用影视级过场（Cinematic Sequence）设备 — 为岛屿添加独特的过场序列，推动游戏剧情，从视觉上吸引玩家。
  • 迁移角色动画（IK 重定向） — 使用 IK 重定向（IK Retargeting），把动画从一个角色迁移到另一个角色。
  • UEFN 中的镜头震动效果（Camera Shake Effect） — 为关卡序列添加镜头震动，为项目营造独特的电影氛围。
  • 将静态网格体转换为骨骼网格体 — 使用网格体编辑器套件，把静态网格体做成完整可用的骨骼网格体。
  • 在 UEFN 中制作过场动画与播片 — 发现打造令人满意、深思熟虑的过场所需的一切要素。
  • 场景图中的骨骼动画 — 学习使用 Verse 与 Scene Graph，在实体上播放与停止骨骼动画。

相关工具：Take Recorder

Take Recorder 是 UEFN 中可用的虚幻引擎动画工具，与 MetaHuman 配合良好。除 Spawnables 与 PIE 外，Take Recorder 的全部功能均可在 UEFN 中使用。
