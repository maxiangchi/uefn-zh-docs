Fortnite 中的虚拟指针（Virtual Pointer）

虚拟指针（Virtual Pointer）让玩家能在所有受支持的输入设备上以一致的方式指向并与屏幕内容交互。本文介绍如何启用虚拟指针、处理捏合缩放，并提供完整的 Verse 示例代码。

英文原标题：Virtual Pointer in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

你可以发布使用 PointerSelect 和 TouchMapping 的岛屿。

PointerZoom 功能目前处于实验（Experimental）状态，供你试用、提供反馈并了解我们的规划。目前你无法发布使用了 PointerZoom 的项目。

请注意，我们不保证用实验性功能创建的资产向后兼容。这些功能的 API 可能会发生变化，我们也可能自行决定移除整个实验性功能或特定功能。

为了保证输入机制一致，进入虚拟指针模式（Virtual Pointer Mode）时，玩家与镜头移动将被禁用。

什么是虚拟指针？

虚拟指针（Virtual Pointer）让玩家能以适用于所有受支持输入设备的方式与屏幕元素交互。根据玩家使用的设备，指针的定义有所不同：

  • 在触屏上，由手指触摸驱动。
  • 在使用鼠标和键盘时，即为现有的鼠标指针。
  • 在使用手柄时，是由左摇杆驱动的虚拟屏幕指针。

你可以用虚拟指针为玩家提供清晰一致的方法来指向并与屏幕内容交互，无论是在主机、PC 还是移动端。这包括使用屏幕空间反投影（screen-space deprojection）与世界对象交互。

虚幻编辑器 Fortnite 版（UEFN）会将虚拟指针读取为普通指针。

这种方法让手势驱动的输入在各平台上可预测且一致，使滑动及未来的交互无处不在，设计师无需担心设备特定的边界情况。

Fortnite 游戏菜单打开时，虚拟指针（Virtual Pointer）不起作用。

启用虚拟指针

要在游戏中启用虚拟指针（Virtual Pointer），首先必须使用 AddInputMapping 方法启用触摸映射（touch mapping）。

你必须为玩家添加自定义输入映射，任何自定义输入才能在游戏中生效。

为玩家启用虚拟指针模式

AddTouchMapping(Player:player):void= if: PlayerInput := GetPlayerInput[Player] then: PlayerInput.AddInputMapping(TouchMapping)

这会将 TouchMapping 输入映射添加到玩家，使玩家进入虚拟指针模式。此时，使用手柄的玩家将看到虚拟指针。

处于虚拟指针模式时玩家无法移动。你可以对玩家的 FortCharacter 实体调用 ReleaseFromStasis() 来解除定身。

获取屏幕空间坐标

以下代码片段可用于捕获屏幕空间坐标：

var MaybeInputCancelableBegin : ?cancelable = false StartSubscription(Player:player):void= if: PlayerInput := GetPlayerInput[Player] then: PlayerInput.AddInputMapping(TouchMapping) InputCancelableDetectBegin := PlayerInput.GetInputEvents(PointerSelect).BeginDetectEvent.Subscribe(PlayerClicked) set MaybeInputCancelableBegin = option{InputCancelableDetectBegin} PlayerClicked(Arg:tuple(player, vector3)):void=

检测与虚拟指针相交的世界对象

可以用 Verse 检测与虚拟指针射线相交的世界对象：

PlayerClicked(Arg:tuple(player, vector3)):void= Player := Arg(0) ClickPos := Arg(1) Ray := TraceFromClick(Player, ClickPos.Left, ClickPos.Up) RayOrigin := Ray.Origin RayDir := Ray.Direction # Sweep: ray direction * max distance Displacement := RayDir * 50000.0

虚拟指针的捏合操作

捏合（Pinch）操作是一种连续输入，可用于镜头缩放和对象缩放等功能。根据玩家使用的设备，捏合的控制方式有所不同：

  • 在触屏上，玩家用两根手指做捏合动作，靠拢或分开。捏合以两指之间的中点为中心。每次更新都会产生一个反映捏合速度的值，0 表示没有变化。
  • 在使用鼠标和键盘时，滚轮根据滚动方向产生一个值（-1 到 1）。捏合以当前指针位置为中心。在没有飞轮模式的鼠标上，该值为 -1 或 1。在飞轮模式下，其行为更像右摇杆。
  • 在使用手柄时，右摇杆上推为放大，下拉为缩小。两种情况下，摇杆偏离中立位置的幅度都会产生一个 -1 到 1 的值。捏合以虚拟指针当前位置为中心。

使用捏合进行缩放

订阅 PointerZoom 输入事件即可启用缩放。如下所示为订阅 PointerZoom 输入事件的输入动作、并在订阅到动作时向控制台打印的示例：

EnableCursorZoom(Player : player):void = if: PlayerInput := GetPlayerInput[Player] then: PlayerInput.AddInputMapping(TouchMapping) BeginSub := PlayerInput.GetInputEvents(PointerZoom).BeginDetectEvent.Subscribe(OnPinchBegin) OngoingSub := PlayerInput.GetInputEvents(PointerZoom).DetectionOngoingEvent.Subscribe(OnPinchOngoing) TriggerSub := PlayerInput.GetInputEvents(PointerZoom).TriggerActivationEvent.Subscribe(OnPinchTrigger) EndSub := PlayerInput.GetInputEvents(PointerZoom).EndDetectEvent.Subscribe(OnPinchEnd)

你可以使用 PointerZoom 输入事件检测玩家在屏幕上用两指向特定方向捏合，或在手柄或鼠标上执行等效操作。

让我们用捏合操作调整场景图（Scene Graph）实体（entity）的大小。

创建一个简单实体：

  • 使用工具栏添加一个空白实体：放置 Actor（Place Actors）> 实体（Entities）> entity。
  • 在细节（Details）面板中左键单击+ 组件（Component）按钮并选择 mesh_component，为实体添加 mesh_component。
  • 在本示例中，选择立方体（Cube）作为 mesh_component 子类。

禁用虚拟指针

取消订阅 PointerSelect 输入动作后，系统将停止获取屏幕空间坐标。此外，移除 TouchMapping 映射将退出虚拟指针模式。

移除 TouchMapping 时，无需取消订阅 Pointer Select。

RemoveTouchInput(Player:player) : void = if: PlayerInput := GetPlayerInput[Player] then: # Remove touch/pointer input mapping PlayerInput.RemoveInputMapping(TouchMapping)
