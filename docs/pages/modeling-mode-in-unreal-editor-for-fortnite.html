UEFN 中的建模模式（Modeling Mode）

建模模式（Modeling Mode）是 UEFN 中用于创建与雕刻自定义网格体的编辑模式，你可以用它制作可在项目间共享的自定义装饰道具。

英文原标题：Modeling Mode in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

UEFN 包含一个用于网格体（meshes）的编辑模式，称为建模模式（Modeling Mode）。你可以用它创建并雕刻自定义网格体，再使用建模编辑工具为项目创建自定义装饰道具，还可以将这些道具分享给其他开发者。

无论是创建新的网格体（mesh），还是编辑下载的网格体，都可以使用建模模式编辑网格体的形状、属性、体积（volume）、体素（voxels）、细节级别（LODs）和 UV。编辑完网格体后，决定如何烘焙（bake）最终成品，然后在项目中使用你的网格体。

要进一步了解建模模式，请参阅 UE5 建模模式概述文档（UE5 Modeling Mode Overview）。

工作原理

打开建模模式时，视口中会打开一个面板，提供创建或编辑网格体的选项。

要创建自己的网格体，可从以下选项中选择：

选项图标 — 建模选项 — 说明

收藏夹（Favorites）

你收藏的所有工具都会显示在收藏夹下。

形状（Shapes）

提供可添加到视口并进一步编辑的不同形状。所有形状网格体都会显示在大纲（Outliner）面板中，并可在细节（Details）面板中编辑。

创建（Create）

一系列用于创建网格体的工具。用线条绘制多边形（polygons）以创建路径或对象。使用这些工具复制、合并或旋转你创建的网格体。

要编辑现有网格体，可从以下选项中选择：

选项图标 — 建模选项 — 说明

多边形编辑（PolyEdit）

编辑网格体和 PolyGroup。

三角面工具（TriTools）

通过三角面对网格体进行编辑。

变形（Deform）

使选中的网格体变形。

变换（Transform）

更改并变换网格体。

网格体操作（MeshOps）

执行复杂的网格体操作。

体素操作（VoxOps）

编辑网格体的三维立方体。

属性（Attribute）

编辑网格体或其三角面的属性。

UV

用于编辑和调整网格体 UV 的工具。

烘焙（Baking）

为网格体提供三种不同的烘焙选项。

体积（Volumes）

编辑网格体上的体积，以定义碰撞和网格体的物理空间。

细节级别（LODs）

定义并编辑网格体的细节级别（LOD）。

你可以将网格体数据保存为内容浏览器中的文件，然后与其他开发者分享该文件，或在其他项目中使用。

在导入和导出网格体时，传输过程中可能会丢失网格体数据（权重贴图、PolyGroup 和顶点色）。

形状（Shape）

首先向视口（viewport）添加形状来开始创建网格体，你可以用材质实例、LOD、碰撞等编辑和定义这些形状。你甚至可以将这些形状与其他建模工具结合，用于灰盒关卡设计。要进一步了解灰盒（greyboxing），请滚动到本文档末尾。

在弹出窗口中单击形状，然后在视口中单击，将形状添加到项目中。在单击接受（Accept）之前，可以使用 形状（Shape）工具集编辑网格体的参数。单击接受（Accept）后，可以在细节面板中编辑网格体。

在基础教程：创建柱子（Basic Tutorial: Creating a Column）中学习如何使用基本形状和模型编辑工具创建柱子。

这些工具适用于每种形状。

形状 — 图片

方块（Box）

球体（Sphere）

圆柱体（Cylinder）

圆锥体（Cone）

圆环体（Torus）

箭头（Arrow）

矩形（Rectangle）

圆盘（Disc）

楼梯（Stairs）

创建（Create）

使用可挤出你创建的形状和路径的工具创建自己的自定义网格体。必须在视口中选中网格体，编辑才会生效。每种工具都会在建模模式（Model Mode）面板中打开特定的操作工具。

工具 — 操作 — 演示

挤出多边形（Extrude Polygon）

绘制并挤出多边形以创建新对象。打开编辑多边形属性的工具集。

挤出路径（Extrude Path）

绘制并挤出多段路径以创建新对象。打开编辑路径属性的工具集。

旋转路径（Revolve Path）

绘制并旋转路径以创建新对象。打开编辑路径和网格体旋转的工具集。

边界旋转（Boundary Revolve）

旋转网格体边界循环以创建新对象。打开决定网格体边界和旋转的工具集。

合并（Merge）

合并多个网格体以创建新对象。打开决定合并属性的工具集。

复制（Duplicate）

复制单个网格体以创建新对象。打开决定复制网格体属性的工具集。

图案（Pattern）

使用选中的网格体创建图案。图案也有形状：

  • 直线（Line）
  • 网格（Grid）
  • 圆形（Circle）

变换（Transform）

使用以下工具变换网格体或其子组件，并更改轴心点。每种工具都会在建模模式面板中打开特定的操作工具。

执行多种操作，以控制网格体的移动，或在编辑和移动网格体部件或整个网格体后捕获网格体数据。

工具 — 操作 — 动图演示

变换（Transform）

打开变换选中网格体不同方面的工具集。

对齐（Align）

打开根据相互关系对齐选中网格体的工具集。

编辑轴心点（Edit Pivot）

打开在选中网格体上编辑轴心点位置的工具。

轴心点 Actor（Pivot Actor）

向选中网格体添加 Actor 对象作为子组件的轴心点，并打开编辑轴心点和 Actor 对象的工具。

烘焙变换（Bake Transform）

将实例化网格体的缩放和旋转值烘焙到父静态网格体资产中。

传递（Transfer）

将一个网格体的数据传递到目标网格体或目标网格体使用的特定 LOD。

转换（Convert）

网格体主体被转换为实体或表面主体，并显示在画布和浏览器中。打开编辑网格体主体表面的工具集。

拆分（Split）

将具有不连通几何体的网格体拆分为单独的网格体资产。

变形（Deform）

通过选择网格体的部分并对网格体应用效果，或直接雕刻选中区域，以不同方式使网格体变形。

工具 — 操作 — 动图演示

顶点雕刻（Vertex Sculpt）

通过多种不同的雕刻笔刷在目标网格体上启用雕刻。

动态雕刻（Dynamic Sculpt）

通过多种不同的雕刻笔刷在目标网格体上启用雕刻，并通过重建网格动态向网格体添加新几何体。

平滑（Smooth）

展平网格体表面，并打开决定应用于网格体的平滑程度的工具集。

偏移（Offset）

偏移选中网格体的表面。

弯曲（Warp）

对目标网格体的整体轮廓应用某种弯曲或喇叭形效果，并打开决定包裹量和弯曲方式的工具集。

晶格（Lattice）

向选中网格体的表面添加晶格效果，并打开决定晶格效果应用位置和方式的工具。

置换（Displace）

向选中网格体的表面添加波浪效果，并打开决定如何添加效果以及向网格体表面添加变形程度的工具。

多边形编辑（PolyEdit）

编辑网格体的多边形，为项目创建新资产，或变换下载的对象。多边形建模工具通过选择多边形组来工作。根据使用的 PolyModel 工具和所做的编辑，直接影响组中所有选中的多边形。

工具 — 操作 — 动图演示

PolyGroup 编辑（PolyGroup Edit）

打开通过 PolyGroup 编辑网格体的工具。

变形 PolyGroup（Deform PolyGroups）

打开通过 PolyGroup 使网格体变形的工具。

立方体网格（CubeGrid）

打开使用可重新定位的网格创建白盒网格体的工具。

布尔运算（Boolean）

打开对网格体对应用布尔运算的工具。

网格体切割（Mesh Cut）

使用第二个网格体将一个网格体切割成多个部分。打开决定如何拆分网格体的工具集。

细分（Subdivide）

按 PolyGroup 或三角面细分网格体。打开决定如何细分网格体的工具集。

三角面工具（TriTools）

编辑网格体的三角面，为项目创建新对象。三角面建模工具通过选择和编辑三角面组，或在选中网格体上创建三角面组来工作。

工具 — 操作 — 动图演示

三角面选择（Tri Select）

使用决定笔刷大小和半径以及三角面容差和多边形组层的工具选择和编辑网格体三角面。

三角面编辑（Triangle Edit）

打开通过三角面编辑网格体的工具。

填充孔洞（Fill Holes）

填充网格体中的所有孔洞。

平面切割（Plane Cut）

在平面上切割选中的网格体。打开决定切割范围的工具。

镜像（Mirror）

用挤出多边形创建镜像，并打开定义新网格体的工具集。

多边形切割（PolyCut）

用挤出多边形切割选中的网格体，并打开定义新网格体的工具。

裁剪（Trim）

用第二个网格体裁剪或切割选中的网格体。使用工具决定如何裁剪第二个网格体。

网格体操作（MeshOps）

使用 MeshOps 中的工具编辑网格体的多边形和三角面。每种工具都会在建模模式面板中打开特定的操作工具。这些工具针对三角面组，通过增减三角面来改变网格体的结构完整性。

工具 — 操作 — 动图演示

简化（Simplify）

尝试降低选中网格体的三角面密度，并打开编辑网格体多边形和三角面不同方面的工具集。

重建网格（Remesh）

打开一组工具，对选中网格体重新三角化并提高三角面密度。

焊接（Weld）

在给定容差内自动焊接选中网格体的断开边，并打开编辑焊接设置的工具集。

外壳（Jacket）

打开从选中网格体移除隐藏三角面的工具集。

合并（Union）

对选中网格体使用布尔并集解析自相交（包括自合并）。

投影（Project）

打开将一个网格体映射或重建网格到目标网格体（第二个选中的网格体）上的工具集。

体素操作（VoxOps）

添加和编辑与网格体关联的体素（voxels）。每种工具都会在模型模式（Model Mode）面板中打开特定的操作工具，根据所选设置增减或编辑网格体的三维数据。

工具 — 操作 — 动图演示

体素包裹（Vox Wrap）

打开使用体素包裹选中网格体的工具集。（基于体素）

体素混合（Vox Blend）

打开使用体素混合选中网格体的工具集。（基于体素）

体素偏移（Vox Offset）

打开可使用体素偏移或内嵌选中网格体的工具集。（基于体素）

体素布尔运算（Vox Boolean）

打开对选中网格体执行布尔运算、再用体素包裹结果的工具集。（基于体素）

体素合并（Vox Merge）

打开合并选中网格体、再将结果体素化的工具集。（基于体素）

烘焙（Baking）

使用烘焙工具按你设定的规格烘焙自定义网格体。烘焙是保存和编辑选中网格体纹理信息的过程。

工具 — 操作 — 动图演示

烘焙纹理（Bake Textures）

打开为单个网格体烘焙纹理的工具集。

烘焙全部（Bake All）

打开从多个源网格体为单个网格体烘焙纹理的工具集。

烘焙顶点色（Bake Vertex Colors）

打开为单个网格体烘焙顶点色的工具集。

UV

编辑网格体的 UV 坐标，改变纹理映射到表面的方式。UV 工具决定网格体的材质是否在网格体上均匀显示。

工具 — 操作 — 动图演示

自动 UV（AutoUV）

为选中的网格体自动展开并打包 UV。

UV 展开（UV Unwrap）

为现有 UV 岛或 PolyGroup 重新计算 UV，帮助最小化拉伸和挤压区域。

投影 UV（Project UVs）

通过将预定义形状或点投射到目标网格体上来创建 UV。

编辑 UV 接缝（Edit UV Seams）

在视口中以交互方式分离边以创建接缝。

变换 UV（Transform UVs）

在视口中以交互方式缩放、旋转和平移 UV 岛。

排布 UV（Layout UVs）

变换、堆叠或重新打包现有 UV。

UV 编辑器（UVEditor）

启动专用的编辑器（Editor）以创建和编辑 UV。

有关如何在静态网格体上添加着色的更多信息，请参阅虚幻引擎中的着色模型（Shading Models in Unreal Engine）。

属性（Attributes）

更新、编辑并向项目中的网格体添加属性。每种工具都会打开特定的操作工具，用于编辑创建 UV 和向 UV 分配数据所需的网格体拓扑数据。

工具 — 操作 — 动图演示

检查（Inspect）

向网格体添加一层高亮多边形并显示网格体数据统计。通过开关选项编辑网格体。

法线（Normals）

重新计算法线（normals），并打开通过开关选项设置法线计算、设置法线拓扑的工具。

切线（Tangents）

打开编辑网格体线条和切线的工具集。

编辑属性（Edit Attributes）

打开编辑网格体不同属性、UV 并添加新属性的工具集。

生成 PolyGroup（Generate PolyGroups）

为网格体覆盖明亮的多边形组皮肤，并打开编辑选中网格体 PolyGroup 的工具。

绘制 PolyGroup（Paint PolyGroups）

允许用户使用笔触在网格体上绘制 PolyGroup。

绘制贴图（Paint Maps）

允许用户在特定权重贴图层上绘制，这些层需要先用属性编辑器生成。

编辑材质（Edit Materials）

允许用户通过笔触为选中的三角面分配材质和新材质元素。

体积（Volumes）

使用体积工具集编辑和创建网格体的体积，设置碰撞等。体积工具集为你设置网格体碰撞、编辑网格体的物理和几何体提供了途径。

工具 — 操作 — 动图演示

体积转网格体（Volume to Mesh）

打开定义体积并将其转换为新网格体资产的工具。

网格体转体积（Mesh To Volume）

打开定义网格体到新体积对象转换的工具集。

检查碰撞（Inspect Collision）

打开检查选中网格体物理几何体的工具集。

网格体转碰撞（Mesh To Collision）

将选中的网格体转换为最后一个选中网格体的简单碰撞（Simple Collision）几何体。打开定义和编辑网格体碰撞（collision）设置的工具集。

碰撞转网格体（Collision To Mesh）

打开定义简单碰撞（Simple Collision）几何体到网格体转换的工具集。

细节级别（LODs）

为新网格体或编辑过的网格体编辑、定义和创建 LOD。这些工具根据玩家与网格体的距离以及在游戏中与网格体交互的平台，决定网格体生成的视觉信息。

工具 — 操作 — 动图演示

LOD 管理器（LOD Manager）

打开 LOD 管理器，为选中的静态网格体资产定义和创建 LOD。

自动 LOD（AutoLOD）

打开生成和定义静态网格体 LOD 资产的工具集。
