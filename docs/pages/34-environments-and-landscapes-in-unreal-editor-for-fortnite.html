环境与地形

在 UEFN 中打造岛屿地形与环境：地形模式、植被、水体、Fortnite 工具集与程序化建筑。

英文原标题：Environments and Landscapes in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

学习在 UEFN 中打造属于自己的岛屿地形与环境吧！

教程导览

从植被、工具集、程序化建筑，到地形雕刻、水体与地形材质：

  • UEFN 中的植被模式（Foliage Mode） — 使用植被模式快速打造令人惊叹的地貌。
  • Fortnite 工具模式 — 使用 Fortnite 工具集，在 UEFN 中搭建岛屿时提升效率。
  • Verse 程序化建筑模板 — 以 Verse 程序化建筑模板为起点，打磨关卡设计技巧。
  • Landscape 地形模式 — 使用 UEFN 的地形模式，为岛屿打造独特的地貌与地形。
  • UEFN 中的水体工具 — 使用这些自定义环境工具创建河流、湖泊与海洋。
  • 在 Unreal Editor for Fortnite 中创建自定义地形 — 学习使用地形模式创建自定义地形。
  • 编辑地形材质 — 学习编辑地形材质，为地形打造自定义外观。
