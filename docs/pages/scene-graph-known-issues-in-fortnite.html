场景图 Scene Graph 已知问题

在项目中使用场景图（Scene Graph）时，你可能会遇到 Beta 功能的已知问题与限制，本页汇总了这些问题，并说明如何把旧项目更新到场景图。

英文原标题：Scene Graph Known Issues in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

注：你可以学习使用这一 Beta 功能，但在用它发布正式作品时请谨慎。

本页面已随 42.00 版本更新（2026 年 8 月 20 日）。

以下是在项目中使用场景图（Scene Graph）时已知的问题。如果你有任何反馈，或发现了下方列表未收录的问题，请前往论坛反馈帖报告。

  • 由于场景图（Scene Graph）是 Beta 功能，你可能会遇到意外的崩溃与不稳定情况。
  • 网格体、声音与粒子特效组件仅会针对你导入项目或在项目中创建的资产（以及少量内置网格体形状）生成 Verse 代码。默认情况下，你无法在场景图（Scene Graph）中使用 Fortnite 或 Fab 资产。
  • 在预制件编辑器（Prefab Editor）中，实体上的光照组件（Light）不会显示光照线框。
  • 无法将被覆盖的预制件实例保存回预制件资产。
  • 负缩放可能导致子实体在旋转时出现异常交互。
  • 组件逻辑会在编辑模式与运行模式下同时执行。
  • 组件的初始化远早于创意模式设备（Creative devices），因此在 component.OnBeginSimulation 或 component.OnSimulate 中尝试获取创意模式设备会失败。你应使用 fort_round_manager 中的回合开始事件。
  • 在预制件编辑器中所做的更改，除非保存，否则不会传播到已放置的预制件实例。
  • 在材质编辑器或 Niagara 编辑器中添加或修改参数后，需要重新构建 Verse 代码，这些更改才会暴露给关卡编辑器。
  • 如果在编辑器中移动、重命名或删除网格体、声音或粒子系统资产，可能会丢失关卡编辑器中对已生成组件实例的引用，因为当前生成的类无法使用重定向器（Redirector）。
  • LUF 坐标系会影响现有内容与场景图（Scene Graph）内容。现有 Verse 代码可继续工作，但如果想在场景图中使用相同的代码，需要把旧的 /UnrealEngine.com/Temporary/SpatialMath 类型转换为 /Verse.org/SpatialMath 类型。新增的转换函数可以在新旧类型之间转换：
    • FromVector3
    • FromScalarVector3
    • FromRotation
    • FromTransform
    TeleportLocation := (/Verse.org/SpatialMath:)vector3{Left := 330.0, Up := 20.0, Forward := 50.0}
TeleportRotation := (/Verse.org/SpatialMath:)MakeRotationFromYawPitchRollDegrees(90.0, 0.0 ,0.0)
if:
    FortCharacter := Agent.GetFortCharacter[]
    FortCharacter.TeleportTo[FromVector3(TeleportLocation), FromRotation(TeleportRotation)]
then:
    Print("Character Teleported")

物品化 Itemization

  • 部分物品栏输入不会遵循重映射后的按键。
  • 使用手柄时，部分手柄按键绑定的图标缺失。
  • 物品栏与物品存在一些界面与表现层面的问题。

将旧项目更新到场景图 Scene Graph

  • 由于场景图（Scene Graph）默认启用，生成到 Assets.digest.verse 的类的代码生成规则发生了一些变化，这可能导致现有 Verse 代码无法编译。你需要先修复 Verse 代码，再继续开发项目。

    典型示例，场景图启用前：

    # Assets.digest.verse
MyMesh := class(mesh){}
MyMaterial := MakeAsset(material, "MyMaterial.uasset")
# YourVerseFile.verse
SetMesh(MyMesh)
SetMaterial(MyMaterial)

    启用场景图后：

    # Assets.digest.verse
MyMesh_asset := class(mesh){}
MyMesh := class(mesh_component){}
MyMaterial := class(material){}
# YourVerseFile.verse
SetMesh(MyMesh_asset)
SetMaterial(MyMaterial{})
  • 在 Verse 组件类中更改默认对象值的类型后，再复制粘贴实体，可能仍会引用旧类型的实例，即使该属性并未被覆盖。
  • 当预制件资产新增了实体子级并重新加载时，会触发报错 OldToNew.Value->HasAnyClassFlags(CLASS_TokenStreamAssembled)。
