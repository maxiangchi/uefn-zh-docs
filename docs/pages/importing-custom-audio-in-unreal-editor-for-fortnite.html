导入自定义音频

将电脑上的音频文件直接拖入内容浏览器即可导入 UEFN 项目，了解支持的音频格式与其他导入方法。

英文原标题：Importing Custom Audio in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

将电脑中的音频文件直接拖入内容浏览器（Content Browser），即可将其中的音频文件（Audio Files）导入 Unreal Editor for Fortnite（UEFN） 项目。

上传内容即表示你确认该内容不侵犯或违反他人的权利，包括其知识产权（例如不侵犯他人的版权或商标），并且你拥有或已获得分享该内容所需的权利。

你导入的音频还应遵守我们的《Fortnite 开发者规则（Fortnite Developer Rules）》。

更多信息请参阅《UEFN 补充条款（UEFN Supplemental Terms）》。

支持的格式

UEFN（Unreal Editor for Fortnite）支持以下音频格式：

  • .wav
  • .aif
  • .flac
  • .ogg

其他导入方法

你还可以通过以下方式将音频导入 UEFN（Unreal Editor for Fortnite）：

  • 点击内容浏览器（Content Browser）中的导入（Import），然后从硬盘中选择文件。
  • 在内容浏览器（Content Browser）中右键点击，从下拉菜单中选择导入（Import），然后从硬盘中选择文件。
