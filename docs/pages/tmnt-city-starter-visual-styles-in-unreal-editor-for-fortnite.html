TMNT 城市起始模板视觉风格（UEFN）

城市起始模板（City Starter）展示了在 Fortnite 虚幻编辑器中设计城市外观的流程与技巧：从概念设计、资产布局，到卡通与漫画两种后期风格、自定义程序化天空盒、灯光与窗户，一步步打造忍者神龟的纽约城。

英文原标题：TMNT City Starter Visual Styles in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

城市起始（City Starter）模板展示了在 Fortnite 虚幻编辑器（UEFN）中设计城市外观可用的流程与技巧。

这座岛屿还原了纽约城的一角，经过灯光与风格化处理，让忍者神龟（Teenage Mutant Ninja Turtles，TMNT）仿佛回到了家！试玩该模板，可以从低处和高处两种视角体验这座城市。

本指南回顾了团队构思并搭建该模板视觉效果的步骤，涵盖以下方面：

  • 从概念出发设计视觉效果
  • 资产布局方法
  • 后期处理技巧
  • 更多风格化技巧：自定义天空盒、灯光与窗户
  • 扩展体验的思路

欢迎查看后期处理、天空盒与自定义灯光，学习如何打造出色的风格化视觉效果。

这不是一篇玩法教程。该关卡中没有放置屏障（Barrier）。在用这些资产搭建自己的体验时，你可以自行添加，例如使用屏障设备（Barrier device）。要学习如何搭建街机游戏模式（包括横版卷轴相机与自定义用户界面 UI），请参阅TMNT 街机模板（TMNT Arcade Template）。

按以下步骤获取该模板：

  • 打开 UEFN。
  • 前往品牌模板（Brand Templates）> 城市起始（City Starter）。
  • 新建项目。

视觉风格

城市起始模板有两种突出的美学风格：卡通（cartoon）与漫画（comic）。这两种视觉风格专为 TMNT 玩法与主题设计。这两种风格在 UEFN 模板中通过后期处理体（post-process volumes）提供，在创作模式岛屿中则可通过后期处理设备（Post-Processing device）使用。这些风格并非 TMNT 开发者工具独占，欢迎把模板中的技巧用在自己的岛屿定制中，或以该模板为基础继续搭建。

卡通风格滤镜（Cartoon Style Filter）

漫画风格滤镜（Comic Style Filter）

这些风格是在研究了从卡通到三维动画等各类 TMNT 作品后精挑细选出来的。团队与派拉蒙（Paramount）合作，确立了能代表 TMNT 世界的标志性元素。从概念美术与其他参考资料中，团队提炼了赛璐璐着色（cel shading）、明月高悬的屋顶场景、配色方案等元素。

概念参考图（Concept References）

美学本身就是一种游戏设计元素，需要与体验的机制和叙事相契合。这些美学涵盖色彩、灯光、资产与场景布局，帮助玩家感受到体验的氛围。

切换风格

在编辑器中，你可以用大纲视图（Outliner）在两种风格之间切换。在大纲视图中搜索“postproccess”，即可看到 PostProcessVolume_Cartoon 与 PostProcessVolume_Comic 两个体。

下水道巢穴中的风格切换器。

默认启用的是卡通风格。要启用漫画风格，请按以下步骤操作：

  • 在大纲视图中，把 PostProcessVolume_Cartoon 的眼睛图标切换为关闭。
  • 选中 PostProcessVolume_Comic，在细节面板中搜索“blendweight”。
  • 把混合权重（Blend Weight）设为 1。

运行模板前，记得撤销上述修改。

在模板玩法中，你可以在下水道巢穴里通过墙上的开关设备选择视觉模式。切换风格，然后到街道和屋顶逛逛，看看构成这座城市的 TMNT 资产。可以把该模板作为基础，打造自己的 TMNT 体验，也可以把其中的视觉技巧抽出来用到其他项目。

要了解如何进一步调整这些风格，请参阅本页的后期处理技巧（Post-Process Techniques）一节。

关卡设计

卡通与漫画滤镜都是抢眼的视觉风格，但真正把模板串起来的，是这座城市。美术师们精心布置资产，打造出一座原汁原味的 TMNT 之城。TMNT 资产与 Fortnite 资产层层叠加，让城市更有层次。用资产排布定义空间、指引玩家行进路线的做法，就叫关卡设计（level design）。

TMNT 之城，背景中的剪影天际线增加了纵深感，将玩家环抱其中。

以城市为中心

模板的各项选择都围绕“定义这座城市”展开。虽然模板不是完整的游戏示例，但为了帮助设计布局，模板采用了平台跳跃（platformer）主题。这一游戏类型有助于界定可玩空间。在可玩空间内，美术师放置了独特而精细的资产，以 TMNT 资产为主，并希望玩家能走进去细细探索。

这些资产都服务于主题。谈风格离不开资产：它们既能成就体验的视觉效果，也能毁掉它。资产在关卡中的排布、玩家穿行场景的方式，同样举足轻重。模板还用了海报、霓虹灯、涂鸦、小道具等额外资产，为世界注入个性，进一步确立主题。完整资产列表请参阅使用 TMNT 岛屿（Working with TMNT Islands）。

漫画风格模式下的 6 频道（Channel 6）资产。

可玩空间确定后，团队就知道该如何搭建地图其余部分来填满空间了。

地图由前景、中景、背景构成。离中心越远，建筑和窗户就越简化。天际线充当地图的背景幕，把玩家围在城市之中。而下水道巢穴里放的都是高度精细的资产，因为那里就是要让玩家把每个角落都逛遍。

城市关卡资产布局（City Level Asset Layout）

下水道巢穴资产布局（Sewer Lair Asset Layout）

最后，再用月亮、窗户、灯光、视觉滤镜等点睛元素，抓住城市夜生活的感觉。

后期处理技巧

城市感之所以强烈，靠的是打造视觉风格的种种技巧，其中最突出的是后期处理体。

后期处理（Post-processing）是一种视觉叠加层，可以整体或局部影响岛屿的美学。每个滤镜都调整了标准后期设置，并叠加了驱动外观的自定义材质。要了解后期处理及其标准设置，请参阅后期处理入门（Intro to Post-Processing）。

卡通后期滤镜

深度雾

模板通过材质实现了自定义大气雾效。雾为场景增添色彩，也为城市营造纵深。你可以用材质设置，从艺术角度控制建筑剪影与场景色彩。

要了解可调控件，请参阅本页的自定义雾材质（Custom Fog Material）一节。

前景中的城市天际线（City Skyline in Foreground）

被推远的城市天际线（City Skyline Pushed Back）

赛璐璐着色器

赛璐璐着色器（cel shader）材质会压平光照，并引入轻微的色调分离（posterization）与阈值，让场景看起来更卡通。

在模板中，该效果只遮罩在前景，以免远景看起来生硬。参考的卡通和动画往往背景更柔和、像手绘的一样，加遮罩就是为了贴近这种观感。

Cel Shader Value 0（赛璐璐着色器数值为 0）

Cel Shader Value 1（赛璐璐着色器数值为 1）

描边

描边（Outlines）进一步风格化场景，强化卡通感。材质支持按深度控制线宽、颜色与不透明度。美术师借此加粗了前景线条，并为远去的建筑配上协调的描边。

Outline Value 0（描边数值为 0）

Outline Value 1（描边数值为 1）

漫画后期滤镜

漫画（黑色电影，Comic Noir）滤镜用了部分标准后期设置，以及与卡通滤镜类似的赛璐璐着色器与描边材质。描边材质经过调整，以配合灰阶影调。滤镜独有的自定义材质包括色调分离、漫画影调与画框，最终呈现出漫画 / 图像小说般强烈的平面风格。

漫画影调与画框

漫画影调（comic tone）材质会去色并应用亮度阈值，营造印刷品般的影调层次，再叠加画框（frame）材质收尾。

Comic Tone and Frame Value 0（漫画影调与画框数值为 0）

Comic Tone and Frame Value 1（漫画影调与画框数值为 1）

色调分离

为了让漫画效果更逼真，图像被色调分离：纯灰色带按深浅转成不同大小的圆点。影调越暗圆点越大，直到连成纯黑，再按所需强度合并回灰阶图像。该材质只用了 25% 的强度，以减轻游玩时的视觉疲劳。

Posterization Value 0（色调分离数值为 0）

Posterization Value 1（色调分离数值为 1）

编辑后期材质

材质驱动着两种风格模式下的后期效果。你可以查看每种材质的构成并调整，以适配自己的项目，也可以直接在后期处理体中替换材质，快速改变风格。

查看每个后期处理体的自定义材质：

  • 在大纲视图（Outliner）中点击该后期处理体。
  • 前往细节面板 > 渲染特性（Rendering Features）> 后期处理材质（Post Process Materials）> 数组（Array）。

卡通后期材质（Cartoon Post Process Materials）

漫画后期材质（Comic Post Process Materials）

你可以把每个数组值在 0 到 1 之间调节，观察每种材质的效果。要打开某种材质的位置，点击文件夹图标，再点击想查看的材质，即可打开材质编辑器。材质编辑器中，部分美术向设置在细节面板里，也有的参数在材质图表（Material Graph）中。所谓美术友好型设置，就是把材质图表中的参数暴露为公开变量。要了解材质（含编辑器、函数、表达式），请参阅材质节点与设置（Material Nodes and Settings）。

自定义雾材质

深度雾材质的参数就是材质中美术向设置的一个例子。雾的颜色值由曲线渐变（curve ramps）驱动，可以沿场景深度精确调节雾值，比编辑器内置的大气雾系统更利于打造风格化外观。

深度雾材质的控件。

该材质包含以下核心参数，方便美术师快速调整。在材质的细节面板中可以改这些值，也可以进材质图表调整默认值。

雾参数说明
Curve Far and Near Point（曲线远近点）设置曲线资产渐变映射到的近 / 远距离。渐变左侧颜色对应近点，右侧对应远点。
Curve Input（曲线输入）提供颜色曲线，用于调整雾的渐变色。双击图标打开曲线。要了解更多信息，请参阅虚幻引擎文档材质中的曲线图集（Curve Atlases in Materials）。
Global Amount（全局强度）设置雾渐变的可见百分比。
Range Cutoff（范围截止）设置场景深度的阈值。可用范围值控制雾是否作用于天空盒。

雾材质展示了如何打开每种材质做调整，其余材质同理。要练习新建后期材质、了解材质图表，请参阅使用后期材质（Using a Post Process Material）。

更多视觉技巧

本节介绍配合灯光与窗户进一步烘托氛围、强化风格的技巧。

调整程序化天空盒

另一个基于材质的技巧是天空盒，它独立于后期处理体。两种滤镜共用自定义程序化天空盒来营造风格化氛围。材质贴在一颗包住整张地图的静态网格球体上，材质的细节面板暴露了美术友好型参数，可快速调整。

可从以下位置打开天空盒工具：

  • 大纲视图（Outliner）> SkySphere > MI_ProceduralSkybox
  • 内容抽屉（Content Drawer）> 项目名称 > Materials > MI_ProceduralSkybox

双击材质打开材质编辑器。参数组（Parameter Groups）分类下是调整天空风格的设置（见下表），其中 Global Static Switch Parameter Values（全局静态开关参数值）可切换地平线与月亮的锐利度。

天空盒材质的控件。

天空盒参数说明示例
Global Scalar Parameter Values（全局标量参数值）调整月亮与大气属性。为美术师提供了把月亮打造成视觉中心的手段，正好呼应“神龟们在月下掠过楼顶剪影”的概念。
Global Vector Parameter Values（全局向量参数值）调整天空属性的颜色。自定义天空盒对天空渐变色与混合偏移有更强的控制。这种颜色控制对改善摩天楼前的天际线影调至关重要，微调即可超越真实感、贴合风格化色板。
Stars（星星）调整星星的变换、颜色、平铺与亮度。
Clouds（云）调整云的纹理贴图、云量、边缘柔和度、亮暗部颜色、轮廓光、不透明度与飘动方向。美术师借此调出更有动感、更有看点的天空。自定义天空加灯光方案确定后，记得在世界设置（World Settings）中关闭昼夜管理器（World Time of Day Manager）。

你还可以在材质图表中深入研究该材质。在材质编辑器工具栏点击层级（Hierarchy）> M_ProceduralSkybox 即可打开图表，节点按注释框分组，标明各自影响的参数，可自行调整节点、重定义参数。

程序化天空盒的材质图表（Material Graph）。

自定义灯光

模板的灯光与后期处理体联动，以保证美学统一。灯光负责定基调、给玩家指路，也参与定义后期滤镜的属性。先布通用灯照亮城市，再加重点灯突出建筑与道具。

氛围灯光

氛围灯光（Mood lighting）指为定下特定感受而精确布设的灯光。

在概念阶段，美术师会翻阅参考素材（常称情绪板 mood boards）来确立情绪与灯光方向。真人电影、动画、舞台剧也都用这一套流程。

场景中的氛围灯大多由以下光源构成：

  • 天光（Skylight）：驱动场景环境色，控制阴影中最暗的照明。
  • 方向光（Directional light）：控制月亮位置与月光照明。
  • 点光源（Point lights）：在略显平淡的区域点缀卡通色彩（已关闭高光 Specular，避免这些灯产生亮斑）。
  • 挂在 Actor 上的灯光组件。
  • 自发光材质。

氛围灯还有助于项目优化时保住视觉品质：风格化的灯光与资产在低端设备上依然好看。

窗户

离市中心越远，场景中的窗户就越简化。如关卡设计所述，简化能增加纵深、帮助优化。窗户还用材质发光，进一步支撑风格化观感。下表介绍了窗户的各种技巧。

一个昼夜序列设备（Day Sequence device）用于把背景建筑上基于材质的灯关掉。

在这个例子里，那些材质灯的颜色和样式与城市美学不搭，于是决定关掉它们，改用自定义窗户灯。

技巧说明示例
Interior Cubemap（室内立方体贴图）用材质营造 3D 空间的观感。用于填充玩家不会进入、但路过时能看到的建筑。可从内容抽屉 > 项目名称 > Materials > M_Windows_Interior 获取该材质。
Window Mask（窗户遮罩）随机化窗户位置，给背景建筑更多变化。可从内容抽屉 > 项目名称 > Materials > M_WindowMask 获取该材质。
Random Value from World Position（按世界位置取随机值）房间亮与不亮的外观由窗户在世界中的位置决定。每种窗户材质都按世界位置偏移调制材质颜色，偏移产生随机亮度因子，让城市活起来。这种做法减少了独特材质与内存占用。
Cartoon Sheen Material（卡通高光材质）在窗户上加斜线，模仿风格化的高光效果。内容抽屉 > 项目名称 > Materials > M_Windows_Channel6。

扩展体验

学完打造模板核心美学的思路与技巧，就可以着手把它升级成你自己的 TMNT 体验了！

通关模板，在两种风格间切换，想想哪种玩法元素和叙事适合这种滤镜和城市。

以下思路供你起步：

  • 以平台跳跃为底子，沿途加入敌人遭遇战。要学习如何添加遭遇战，请参阅TMNT 街机模板中的 TMNT 敌人遭遇战与障碍（TMNT Enemy Encounters and Obstacles）一节。
  • 用新闻编辑室资产搭配漫画风格做叙事过场。要了解更多信息，请参阅制作过场动画与片头（Making Cinematics and Cutscenes）。
  • 用 Sequencer 播出的漫画星爆材质做对话框，增强效果。要了解更多信息，请参阅Sequencer 中的玩法事件（Gameplay Events in Sequencer）。

打造晴天风格

无论是基于模板继续搭建，还是把资产抽到其他项目，都先从概念出发：什么样的叙事和玩法配得上这座城市和 TMNT 资产？想定什么基调、灯光该什么样？玩家会去地图的哪些部分？

晴天风格地图的概念参考：屋顶上的 NPC 遭遇战。

有了后期处理体和更多视觉技巧，就可以把晴天城市的概念变成现实。

天空盒调整

先用程序化天空盒提亮氛围。按以下步骤调出蓝天：

  • 在内容抽屉中搜索 MI_ProceduralSkybox，双击打开材质编辑器。
  • 在细节面板中调整以下值：
    • Cloud Dark and Light（云暗部与亮部）：RGB 1.0、1.0、1.0
    • Horizon Colour（地平线颜色）：RGB 0.0619、0.970、1.0
    • Colour Top（顶部颜色）：RGB 0.038、0.119、0.838
    • Star Brightness（星星亮度）：0（关闭星星）
    • Moon Brightness（月亮亮度）：9.5（模拟太阳）

不想调月亮亮度的话，也可以在材质图表中把月亮纹理换成自己的太阳贴图。

灯光调整

天蓝了，太阳的位置和光照方向也要跟上。按以下步骤调整太阳位置与光照方向：

  • 在大纲视图中搜索并选中 DirectionalLight_Index1。
  • 向左旋转灯光，抬高位置。
  • 在细节面板中，把光照强度提高到 6。

接下来关掉中景和前景的窗户灯，按以下步骤操作：

  • 点击一扇中景窗户。
  • 在菜单栏点击选择（Select）> 选择所有同材质（Select All With Same Material）。
  • 删除这组窗户。
  • 对前景窗户重复上述步骤。

不需要的窗户及时删掉，有助于优化场景。

雾效调整

晴天模式以 PostProcessVolume_Cartoon 为底。按以下步骤调整雾的深浅与颜色：

  • 在内容抽屉中搜索 PP_DepthFog_Inst，双击材质打开材质编辑器。
  • 在细节面板中双击曲线输入（Curve Input）颜色曲线。
  • 调整顶部颜色关键帧：
    • 最右颜色关键帧：RGB 0.022、0.979、0.629
    • 中间颜色关键帧：RGB 0.0、0.140、0.307
    • 最左颜色关键帧：RGB 0.208、0.059、0.117

在 PP_DepthFog_Inst 的细节面板中，用以下值调整颜色渐变的深度：

  • Curve Far Point（曲线远点）：93511
  • Curve Near Point（曲线近点）：14887

色调分离调整

最后加上色调分离，做出类似漫画黑白模式的圆点效果。

  • 在细节面板的后期材质下，点击加号新增一个材质数组元素。
  • 在新数组的下拉菜单中选择资产引用（Asset reference），搜索并选中 PP_Posterize。
  • 要调强度，找到该材质双击打开材质编辑器。
  • 在参数面板中，把 Posterize Amount（分离强度）设为 0.05。

调调材质和灯光，城市就从沉睡中醒来，迎来蓝天！现在赶紧带神龟们回巢穴吧。
