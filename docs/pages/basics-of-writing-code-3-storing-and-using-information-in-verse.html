Verse 代码基础 3：存储与使用信息

在第 2 课认识常见类型与运算的基础上，本课学习如何在 Verse 代码中使用这些类型与值：用变量（variable）与常量（constant）存储信息（information）/数据（data），并理解可变（mutable）与不可变（immutable）的区别。

英文原标题：Basics Of Writing Code 3 Storing And Using Information In Verse · 查看英文原文 · 社区翻译镜像，仅供学习

前置主题：要理解和使用本页内容，请确保你已熟悉以下主题：
  • 第 2 课：基本编程组件（Lesson 2: Basic Programming Components）

在第 2 课中，你已经见识了一些更常见的类型（type），以及与之相关的运算（operation）和值（value）。现在，是时候开始学习如何在代码中使用这些类型和值了。

表达式（expression）所使用的值（value）有时也被称为信息（information）或数据（data）。程序需要数据才能知道该做什么，而存储数据（即值）有不同的方法。

数据也有不同的种类。

可变与不可变

可变（mutable）表示能够改变。可以想一想变种人（mutant）——就是 DNA 代码发生了改变（即突变，mutated）的人。

海岸边的波浪就是可变的，时刻都在变化。

当某样东西不可变（immutable）时，它就不能被改变。如果你不考虑地震、海啸、爆炸或侵蚀，那么俯瞰海滩的悬崖就是不可变的。

但这和代码有什么关系呢？

当某个值在程序运行时不能被改变，它就是不可变的（immutable）。如果某个值在程序运行时会根据来自其他地方的输入而改变，那么这个值就是可变的（mutable）。

Verse（Verse）自带内置（built-in）类型，支持大多数程序运行所需的基本运算。这些内置类型是你在 Verse（Verse）中使用变量（variable）和常量（constant）的基础。

变量与常量

在编程中，你使用变量（variable）和常量（constant）来存储程序要使用的值。

当程序需要数据来决定接下来发生什么时，计算机的计算和决策都基于代码中变量和常量里存储的值。

虽然变量（variable）一词有时被泛指为同时包含变量和常量，但两者有一个重要区别：变量在程序运行时可以改变它的值，而常量在程序运行时不能改变它的值。换句话说，变量的值是可变的（mutable），而常量的值是不可变的（immutable）。

现在来拆解一下这段语法到底在说什么：

name

name 是程序员赋予这个变量或常量的唯一名称。

请记住，var 不是名称的一部分，它只表示这是一个变量，而不是常量。当你想在程序中引用这个变量时，用的就是这个名称（name）。

type

类型（type）说明了这个变量中的值可以执行哪些操作。

注意，名称和类型之间用冒号 : 分隔。

value

对于常量，这个值将保持不变——顾名思义就是恒定的。对于变量，这是变量的起始值，虽然在程序执行过程中它可以改变（变化）。这就是初始值（initial value）。

注意，类型和值之间用 = 分隔。

为变量设置初始值是可选的，但这是值得养成的好习惯。

而为常量设置值是必需的。

标识符

标识符（identifier）是程序员赋予某个表达式的唯一名称。

标识符（identifier）和名称（name）是同义词。

命名规则与约定

在 Verse（Verse）中命名是有规则的。创建变量和常量时，请牢记以下命名规则：

  • 尽可能给变量（以及其他表达式）起一个能表明其作用的名字。
  • 用一致的方式为变量命名是一种好习惯，这样别人读你的代码会更容易（你自己回忆起来也更容易！）。
  • 标识符的第一个字符必须是字母或下划线（_）字符。
  • 第一个字符之后的字符必须是字母、数字或下划线字符。名称中可以有多个下划线，甚至可以有两个或更多下划线连在一起。
  • 变量和常量的标识符都不能包含空格。
  • Verse（Verse）区分大小写，因此大小写保持一致非常重要。如果不一致，代码就会报错。

关于 Verse（Verse）命名约定的完整指南，请参阅 Verse 代码风格指南（Verse Code Style Guide）。

声明变量

每个变量或常量都有三个基本组成部分：标识符（identifier）（即名称）、它能存储的值的类型（type），以及值（value）本身。

var name : type = value

在 Verse（Verse）中，你通过声明（declare）来创建变量。要声明变量，变量必须具备全部三个部分：标识符、类型和值。

初始化

给常量（或任何其他表达式）设置初始值（initial value）称为初始化（initialization）。声明（declare）变量或常量时必须进行初始化。

使用 : = 运算符（operator），你可以初始化常量或变量中的值。

注意，使用这个运算符时，名称（name）写在 : 之前，类型（type）写在 : 和 = 之间，值（value）写在 = 之后。

var Coins : int = 500

有效使用常量

当某个值在代码多个地方出现、并且永远不变时，用常量来保存它是很明智的做法。

还记得第 2 课（Lesson 2）中的字面量吗？字面量（literal）就是永远不变的值。理想情况下，你应该尽量少用字面量。

例如，如果你的游戏允许玩家用一百枚金币购买一个捕鼠夹，你可以在程序中每次从 Coins 扣款时都直接写入字面量（不变的）值 100——或者（这样要好得多！）你可以声明并使用一个常量，比如 CoinsPerMousetrap，让它保存值 100。

CoinsPerMousetrap : int = 100

这样使用常量，会让你的代码对你和队友都更容易阅读，万一有人以后回来修改一段很久没动过的代码，也能更快看懂。

当你使用命名良好的常量而不是含义不明的字面量值时，其他程序员也更容易理解你的代码。

这样使用常量的另一个好处是：如果你决定修改某个值，比如捕鼠夹的价格，你只需要更新这一处常量，而不必逐个修改使用该值的每一处代码。

请尽可能给常量起清晰的名字。上例中的 CoinsPerMousetrap 就清楚地表示：这是玩家购买一个捕鼠夹要花费的金币数量常量。

当某个值不会改变时，就用常量来存储它。

为变量赋值

与常量不同，变量的值可以在程序运行时改变。

常量让你免于一遍遍输入同一个值，那么使用变量有什么好处呢？

嗯，有时候你希望某个值能根据其他输入而改变。

例如，当玩家购买捕鼠夹时，你可以用下面这行代码，从玩家拥有的金币总数中减去购买捕鼠夹花费的金币数：

set Coins = Coins - CoinsPerMousetrap

我们来逐段拆解这行代码：

第一部分 set 是 Verse（Verse）内置的关键字（keyword）。set 关键字可以用来改变变量的值，所以这行代码的意思是：把 Coins 改为 Coins 减去 CoinsPerMousetrap 之后的值。

这种用 set 改变值的操作只能用于变量，不能用于常量。

这里的 Coins 和 CoinsPerMousetrap 都是程序中已存在的表达式（expression）的标识符（identifier）。

小结

  • 变量（variable）和常量（constant）都用于存储值。
  • 两者的主要区别在于：常量的值在程序运行时不能改变，而变量的值可以改变。
  • 变量和常量都是表达式，在求值（evaluate）时会产生结果。
  • 变量和常量需要在 Verse（Verse）中声明（declare）：为该表达式指定唯一名称即标识符（identifier）、类型（type）和值（value）。
  • 给表达式设置初始值时，称为初始化（initialization）。
