发布 UEFN 项目

无法直接从 UEFN 内发布项目，需通过创作者门户完成发布流程，在 UEFN 中检查项目大小与内存后，在创作者门户中管理版本与发布。

英文原标题：Publishing Projects in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

你无法直接从 Unreal Editor for Fortnite（UEFN） 内发布项目。相反，你可以通过创作者门户（Creator Portal）发布项目——你可以在其中管理发布的各个方面。

发布流程从 UEFN（Unreal Editor for Fortnite）开始：先检查项目大小（Project Size）和内存（Memory），然后在创作者门户（Creator Portal）中完成发布工作流。在创作者门户（Creator Portal）中发布项目同样适用于 Verse 项目。通过创作者门户（Creator Portal），你可以为项目创建版本、添加媒体，并推动项目完成整个发布流程。

发布流程

发布项目必须年满 18 岁。

首先，在 UEFN（Unreal Editor for Fortnite）中打开你的项目。

  1. 在关卡编辑器工具栏（Level Editor Toolbar）中点击启动会话（Launch a Session）。游戏开始后，重新选中编辑器窗口并点击结束游戏（End Game）。这会烘焙（Cook）项目中的所有资产，并用于计算项目的总内存占用。
  2. 点击关卡编辑器工具栏（Level Editor Toolbar）中的项目（Project），在项目（Project）下拉菜单中选择启动内存计算（Launch Memory Calculation）。此时会打开内存计算（Memory Calculation）弹窗，提示你计算内存（Calculate Memory）。
  3. 在弹窗中点击计算内存（Calculate Memory）。此时会出现加载条并开始加载项目的内存数据。
  4. 项目加载完成后，此时会为你的项目创建私有版本（Private Version）代码并显示在弹窗中。要使用该代码，点击复制（Copy）并将其发送给团队成员，或保存在个人文件中。
  5. 屏幕右下角会出现 Toast 消息，通知你内存计算已完成。要查看项目的内存预算，点击 Toast 消息中的显示结果（Show Results）。项目的总内存计算结果会在新的弹窗消息中打开。
  6. 为内存计算（Memory Calculation）弹窗截屏存档。该消息会通知你的项目是否在发布预算之内，还包括岛屿版本号（Island Version）和内存用量（Memory Usage）。
  7. 要在创作者门户（Creator Portal）中显示此数据，请勾选在创作者门户中显示（Show in Creator Portal）复选框。
  8. 点击取消（Cancel）关闭弹窗消息。

在你从创作者门户（Creator Portal）发布项目之前，你的项目将一直处于未发布（Unpublished）状态。在创作者门户（Creator Portal）中，你将：

  • 添加岛屿的详细信息、描述符和备注；标题、标签等。
  • 填写 IARC 问卷，为你的岛屿获取分级。
  • 附加支持媒体：缩略图、游戏大厅背景图和视频。
  • 为你购买并使用的任何第三方内容提供署名。
  • 决定项目的可见性。
  • 提交项目进行审核。

要继续发布工作流，请参阅《从创作者门户发布（Publishing from the Creator Portal）》文档，了解所有重要信息。
