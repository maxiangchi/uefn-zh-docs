在 Unreal Editor for Fortnite 中创建自定义地形

使用地形模式（Landscape Mode）工具可以轻松创建自定义地形，你既可以从空白岛屿模板开始从零搭建，也可以雕刻已有岛屿上的现成地形。

英文原标题：Create a Custom Landscape in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

使用地形模式（Landscape Mode）工具可以轻松创建自定义地形。地形模式工具既可用于空白的岛屿模板、从零开始搭建自定义地形，也可用于雕刻已有人气岛屿上的现有地形。

本教程按章节划分，涵盖构建独特地形所需的关键要素。每一节都会介绍一组不同的工具及其工作原理。

请经常试玩测试你的岛屿，确保地形可玩，并适用于你正在创作的体验类型。

概述

跟随以下教程，你将学会构建地形、使用水体工具、创建洞穴、铺设道路与小径，并使用植被（Foliage）让你的岛屿更生动、更真实。

  • 生成新地形

    按尺寸、位置等自定义你的地形。

  • 雕刻地形

    学习如何雕刻自定义地形。

  • 绘制地形

    绘制你的自定义地形以编辑其外观。

  • 为自定义地形创建水体

    为你的地形创建河流，并更改河流的外观与行为。

  • 制作洞穴

    在你的自定义地形内部创建洞穴。

  • 创建道路与小径

    学习如何为你的自定义地形创建道路与小径。

  • 放置植被

    在岛屿上布置植被（Foliage），完成地形的收尾工作。
