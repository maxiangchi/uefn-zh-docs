在 Fortnite 创意模式中使用乐高组装 (Assembly) 设备

抽出时间，使用乐高 Assembly (组装)设备创建各种配置，玩家只需按一下按钮，即可在你的乐高岛屿上组装和拆解道具！在这台设备上设置交互半径，即可将其覆盖范围内的道具变为可供玩家组装的全息图。

英文原标题：Using LEGO Assembly Devices in Fortnite Creative · 查看英文原文 · 社区翻译镜像，仅供学习

抽出时间，使用乐高® Assembly (组装)设备创建各种配置，玩家只需按一下按钮，即可在你的乐高岛屿上组装和拆解道具！在这台设备上设置交互半径，即可将其覆盖范围内的道具变为可供玩家组装的全息图。

乐高® Assembly (组装)设备不适用于使用 LEGO Brick Editor (乐高积木编辑器)制作的物体。

通过 Verse，你甚至可以设置可供玩家拆解的道具。设计一个世界，让玩家看着搭建好的建筑整齐地归位，再也不用担心踩到乐高积木。享受积木如雨落下的乐趣吧！

使用 Assembly (组装)设备，你甚至可以隐藏道具并动态关闭其碰撞，从而创建基于进度的建造机制。

不过，这台设备只能组装乐高积木道具，所有道具都可以被暂时隐藏。

配置audio (音频)和visual effects (视觉特效)来标志建造完成，让玩家完全沉浸在你的可搭建模拟玩法中。你甚至可以在交互中使用cinematic (电影)过场动画。

使用这台设备可以创建大亨风格的玩法：玩家通过组装道具收集货币、解锁任务。你还可以自定义设置，在成功完成搭建后触发事件。在LEGO Home Builder (乐高房屋建造师)模板中试用这台设备，将乐高资源与 Fortnite 资源结合，创建全新环境。

如果在同一岛屿上使用同一设备的多个副本，为它们rename (重命名)会很有帮助。选择与设备用途相关的名称，可以更轻松地记住每台设备的作用，在使用Event Browser (事件浏览器)时也更容易找到特定设备。Event Browser (事件浏览器)相关说明请参阅对应文档。

设备获取方式

Assembly (组装)设备适用于 Fortnite 创意模式中的乐高岛屿以及 Unreal Editor for Fortnite (UEFN)。

你可以在以下位置找到该设备：

  • 创意模式：Creative Menu (创意模式菜单) > Content (内容) > LEGO® Content (乐高®内容) > Devices (设备) > Assembly Device (组装设备)
  • UEFN：Content Drawer (内容抽屉) > LEGO® Content (乐高®内容) > Devices (设备) > Assembly Device (组装设备)

要学习访问、放置设备并调整设备设置的基础知识，请参阅Using Devices (使用设备)。

上下文过滤

某些设备受到一项名为上下文过滤 (contextual filtering) 的功能影响。该功能会根据为某些相关选项选择的值来隐藏或显示选项。这减少了 Customize (自定义)面板中的杂乱内容，使选项更易于管理和浏览。为便于识别，触发上下文过滤的值为斜体。

下方列出了所有选项，包括受上下文过滤影响的选项。如果某个选项根据特定值隐藏或显示，其说明字段中会有相关注释。

设备选项

默认值已加粗。触发上下文过滤的值为斜体。

你可以通过以下选项配置该设备。

选项值说明
Selection Radius (选择半径)100.0，输入数值选择半径内的 actor 由该设备组装和拆解。
Assembly Time (组装时间)1.0s，输入数值组装和拆解一个道具所需的时间。以秒为单位。
Held Interaction (按住交互)True，False决定组装或拆解是持续动作还是单击。True 会在玩家松开输入按键时停止组装或拆解。
Held Interaction Reset (按住交互重置)True，False决定交互被打断时是否重置建造进度。此选项仅在 Held Interaction (按住交互)设为 True 时可用。
Collison (碰撞)Always On (始终开启)，Off if Disassembled (拆解后关闭)决定设备被拆解时如何处理 actor 的collision (碰撞)。
  • Always On (始终开启)：道具组装和拆解时碰撞均处于活动状态。
  • Off if Disassembled (拆解后关闭)：道具完全拆解后无碰撞；部分组装时碰撞处于活动状态。
  • On if Assembled (组装后开启)：道具完全组装后碰撞处于活动状态。
Enabled During Phase (启用阶段)None (无)，Always (始终)，Pre-Game Only (仅赛前)，Gameplay Only (仅玩法阶段)决定设备启用的游戏阶段。被禁用的设备无法直接交互，但仍会响应事件。
Selection Volume Shape (选择体积形状)Sphere (球体)，选择静态网格体设置用于检测该设备所影响对象的静态网格体。
Start Game Assembled (开局已组装)True，False决定游戏开始时设备的状态。
Show Hologram (显示全息图)True，False决定在拆解状态下是否显示已完全组装的 actor 的预览。
Preview Material (预览材质)M_VFX_PreviewHologram，选择材质设置未组装预览全息图使用的材质。

直接事件绑定

以下是该设备的direct event binding (直接事件绑定)选项。

函数

function (函数)会监听设备上的事件，然后执行一个动作。

要创建或编辑函数，请按以下步骤操作：

  • 打开设备设置，点击一个函数选项。
  • 点击 ADD (添加)，然后点击 Select Device (选择设备)，从 Device (设备)下拉菜单中访问并选择。
  • 点击 Select Event (选择事件)，将该设备绑定到触发本设备函数的事件。
  • 如果有多个设备或事件触发一个函数，点击 Add (添加)按钮新增一行并重复上述步骤。
函数说明
Enable (启用)收到所设事件时激活设备。
Disable (禁用)收到所设事件时停用设备。
Reset (重置)发生事件时将设备恢复到初始状态。
Stop (停止)收到事件时暂停设备的组装或拆解。
Assemble (组装)收到事件时开始组装道具。
Disassemble (拆解)收到事件时开始拆解道具。
Show Hologram (显示全息图)收到事件时显示全息图。
Hide Hologram (隐藏全息图)收到事件时隐藏全息图。

事件

event (事件)会告知其他设备何时执行函数。

要创建或编辑事件，请按以下步骤操作：

  • 打开设备设置，点击一个事件选项。
  • 点击 Add (添加)，然后点击 Select Device (选择设备)，从 Device (设备)下拉菜单中访问并选择。
  • 点击 Select Function (选择函数)，将此事件绑定到该设备的函数。
  • 如果一个事件触发多个函数，点击 Add (添加)新增一行并重复上述步骤。
事件说明
On Enabled (启用时)Assembly (组装)设备激活时向关联设备发送事件。
On Disabled (禁用时)Assembly (组装)设备停用时向关联设备发送事件。
On Assembled (组装完成时)选择半径内的道具完全组装后向关联设备发送事件。
On Disassembled (拆解完成时)选择半径内的道具完全拆解后向关联设备发送事件。

在 Verse 中使用乐高组装设备

你可以使用以下代码在 Verse 中控制乐高 Assembly (组装)设备。这段代码使用 Assembly (组装)设备 API 的功能来隐藏、组装和拆解道具。你可以修改它以满足体验需求。

要在你的乐高岛屿中使用这段代码，请按以下步骤操作：

  • 在 UEFN 中，将一台 Assembly (组装)设备拖到你的岛屿上。
  • 创建一个名为 assembly_example_device 的新 Verse 设备。要学习如何在 Verse 中创建新设备，请参阅Create Your Own Device Using Verse (使用 Verse 创建你自己的设备)。
  • 打开 Verse Explorer (Verse 资源管理器)，双击 assembly_example_device.verse，在 Visual Studio Code 中打开脚本。
  • 粘贴上述代码，编译，然后将该设备拖到你的岛屿上。
  • 在 Content Drawer (内容抽屉)中搜索并添加两台 Button (按钮)设备到你的岛屿上。
  • 将一个按钮命名为“Assemble (组装)”，另一个命名为“Disassemble (拆解)”。
  • 在 Outliner (大纲视图)中选中你的 Verse 设备。
  • 在该设备的 Details (详情)面板中，将岛屿上的 Assembly (组装)设备、按钮和道具的对象引用指派给 Hide Then Build。你可以使用吸管工具在视口中拾取设备，也可以使用下拉菜单搜索设备。
  • 保存项目，点击 Launch Session (启动会话)。

由于该设备仅适用于乐高岛屿，只有在乐高岛屿中，你才能在 Verse digest (摘要)文件中查看 Assembly (组装)设备的 Verse API。
