在 Fortnite 创意模式中使用乐高®收藏品设备

用乐高®收藏品金币（studs）拼出你的岛屿体验：玩家拾取后可在 HUD 上展示并计分，进而满足设备或分数要求，打造更有奖励感的玩法。

英文原标题：Using LEGO Collectible Devices in Fortnite Creative · 查看英文原文 · 社区翻译镜像，仅供学习

用乐高®收藏品金币（LEGO® Collectible studs）奖励玩家，把岛屿体验的各个部分拼接起来。

这些是可以拾取的收藏品金币，拾取后会显示在 HUD 上。玩家随后可以用这些收藏品来满足设备或分数要求。

可以查看 LEGO® 动作冒险模板（LEGO® Action Adventure template），了解如何使用该设备打造有奖励感的玩法体验。在该模板中，金币会在游戏全程中发放，用于解锁区域、组装道具和满足任务要求。

你可以在以下位置找到该设备：

  • 创意模式（Creative）：创意模式菜单（Creative Menu） > 内容（Content） > 乐高®内容（LEGO® Content） > 设备（Devices） > 乐高®收藏品（LEGO® Collectible）
  • UEFN：内容抽屉（Content Drawer） > 乐高®内容（LEGO® Content） > 设备（Devices） > 乐高®收藏品（LEGO® Collectible）

要学习访问、放置设备并调整其设置的基础知识，请参阅使用设备（Using Devices）。

如果在岛屿上放置了同一设备的多个副本，为它们重命名会很有帮助。选择与设备用途相关的名称，便于记住每个设备的作用；当使用事件浏览器（Event Browser）查找特定设备时也更容易找到，详见事件浏览器（Event Browser）。

上下文筛选

部分设备会受到上下文筛选（contextual filtering）功能的影响。该功能会根据某些相关选项所选的值，隐藏或显示部分选项，从而减少自定义（Customize）面板中的杂乱内容，让选项更易于管理与浏览。为便于识别，触发上下文筛选的值以斜体显示。

下方列出了所有选项，包括受上下文筛选影响的选项；如果某个选项会根据特定选项的值而隐藏或显示，其说明（Description）字段中会有相应注释。

设备选项

默认情况下，每个收藏品金币对所有玩家可见。当玩家触碰它时，可获得 1 分，金币随即消失。收藏品金币仅对已拾取它的玩家隐藏，其他玩家仍能看到并拾取。

你可以通过以下选项配置该设备。

默认值以粗体显示，触发上下文筛选的值以斜体显示。

选项值说明
收藏品对象（Collectible Object）金色金币（Gold Stud）、蓝色金币（Blue Stud）、紫色金币（Purple Stud）、银色金币（Silver Stud）决定收藏品对象的视觉元素。
分数（Score）1、输入数量设置拾取该对象时奖励的分数。
环境音效（Ambient Audio）开（True）、关（False）决定玩家靠近时该对象是否播放环境音效。
被谁拾取后消耗（Consume if Collected By）自己（Self）、任何人（Anyone）、队伍（Team）决定该对象何时从世界中移除。
可拾取队伍（Collecting Team）队伍编号（Team Index）、全部（All）设置哪支队伍可以拾取该对象。
允许的职业（Allowed Class）职业槽位（Class Slot）、无职业（No Class）、任意（Any）决定哪个职业可以拾取该对象。
对敌对玩家可见（Visible to Opposing Players）从不（Never）、总是（Always）、拾取前可见（Until Collected）决定无法拾取该对象的玩家是否能看到它。
游戏开始时可见（Visible on Game Start）开（True）、关（False）决定游戏开始时该对象是否可见。
显示拾取特效（Show Pickup Effects）关闭（Off）、仅音效（Only Audio）、仅视觉（Only Visuals）、开启（On）决定玩家拾取物品时播放哪些特效。
在 HUD 上显示分数更新（Display Score Update on HUD）开（True）、关（False）决定是否在 HUD 上显示玩家得分事件。
重置 HUD 消息分数（Reset HUD Message Score）开（True）、关（False）设置该设备是否在 HUD 上显示计分消息。
HUD 消息（HUD Message）输入文本（Enter text）设置随分数显示在 HUD 上的消息。
HUD 消息分数颜色（HUD Message Score Color）#BFEBFFFF、自选颜色设置 HUD 上显示的分数文本颜色。
HUD 消息颜色（HUD Message Color）#00BAFFFF、自选颜色决定 HUD 上显示的消息文本颜色。
自定义网格体（Custom Mesh）开（True）、关（False）决定是否使用自定义网格体替代收藏品对象定义的收藏品。自定义网格体不会有视觉浮动效果。
手动设置碰撞体（Manually Set Collider）开（True）、关（False）更改该设备的碰撞属性。
播放环境视觉特效（Play Ambient VFX）开（True）、关（False）决定收藏品上环境辉光特效的可见性。
拾取时自定义特效（Custom on Collected VFX）开（True）、关（False）定义要使用的自定义粒子特效。

直接事件绑定

以下是该设备的直接事件绑定（direct event binding）选项。

函数

函数（function）会监听设备上的事件，然后执行某个动作。

  1. 对于任意函数，点击相关选项，然后点击选择设备（Select Device），从设备（Device）下拉菜单中访问并选择。
  2. 选定设备后，点击选择事件（Select Event），将该设备绑定到会触发本设备函数的事件。
  3. 若有多个设备或事件触发同一函数，点击添加（Add）按钮新增一行并重复上述步骤。
选项说明
开启可见性（Turn Visibility On）当事件发生时使该对象可见。
关闭可见性（Turn Visibility Off）当事件发生时使该对象不可见。
重生（Respawn）当事件发生时，立即为触发玩家重生该对象。会受到“被谁拾取后消耗（Consume if Collected By）”的影响。
为所有人重生（Respawn for All）当事件发生时，立即为所有玩家重生该对象。

事件

事件（event）会通知其他设备何时执行函数。

  1. 对于任意函数，点击相关选项，然后点击选择设备（Select Device），从设备（Device）下拉菜单中访问并选择。
  2. 选定设备后，点击选择函数（Select Function），将本事件绑定到该设备的函数。
  3. 若同一事件触发多个函数，点击添加（Add）按钮新增一行并重复上述步骤。
选项说明
被拾取时（On Collected）当对象被玩家拾取时发送事件。
