为岛内交易构建自定义 UI

为岛内交易商店搭建自定义 UI 菜单的实用建议，以及读懂转化信号、优化商店的四点思考。

英文原标题：Building Custom UI For In Island Transactions In Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

下面是为你的岛内交易（In-Island Transactions）商店搭建自定义 UI（User Interface）菜单的一些实用建议：

先用灰盒搭建 UI

在加精修、复杂 UI 材质和花哨动画之前，先用简单的形状和文字把 UI 搭出来，这是个好习惯。这样你可以先聚焦并迭代布局和视觉层级，再花大量时间打磨细节。

利用现有 UI 资产快速起步

在 UEFN（Unreal Editor for Fortnite）的 Fortnite > UI > Materials 文件夹里有一些好用的 UI 美术材质，比如 M_UI_TextureMask 可用来给物品图标画边框，M_UI_TextureEffects 可用来做像素化视觉效果。更多信息请参阅UI 材质合集。

此外，用户界面功能示例（User Interfaces Feature Example）里有大量 UI 美术示例，可以迁移到你的项目中。你甚至能找到支持 SDF 图像作为图标的 UI 材质，比如你想让图标在多种尺寸下都清晰显示，或想加描边和阴影时就用得上。

把 Verse 商品与 UI 菜单分开

好的做法是让 UI 商店菜单保持模块化，与定义商品的 Verse（Verse）代码分开维护。在 UI 功能示例的 shop_setup_device_template.verse 和 link_volume_to_shop_device 中可以看到这样的例子。

遵循岛内交易设备 Verse 模板

商品是用 Verse 创建的。UEFN 自带了一个趁手的模板帮你起步，其中甚至包含示例商品和捆绑包，以及打开默认商店菜单的 Verse 代码。

关于岛内交易商店的四点思考

商店搭好了，商品也上架了，玩家开始光顾你的岛屿。但转化率告诉你：大多数人什么都没买就走了。下面是一些读懂信号、优化商店 UI 的思路。

1. 玩家常常只扫一眼，不细读

打开岛内交易商店的玩家，第一次浏览通常只花三秒左右。在这一扫中，他们记住的是：屏幕上最大的视觉元素、第一个带可见价格的物品，以及有没有明确告诉他下一步该做什么。如果这三样都没传达出价值，他就会关掉商店。

你精心写的商店介绍、认真起的物品名、为每个商品编的背景故事——在第一眼扫描中往往都落不到玩家眼里。既然第一印象完全是视觉的、完全关乎信任，那就先建立信任。商品要不要笼罩在神秘感和背景故事里由你决定，但一定要让玩家清楚：这次购买到底能得到什么。

2. 信任信号

对照下面六个问题检查你的商店：

问题 1.只看名字，玩家能知道物品是干嘛的吗？“Extra Life Token（额外生命代币）”就比“Lost Relic（失落遗物）”好。

问题 2.描述有没有讲清玩法功能？讲物品身世的描述文字远不如功能说明来得直接有用。

问题 3.预览图清晰易认吗？模糊或被裁掉一半的缩略图会让玩家困惑。

问题 4.有没有说清物品是永久的还是一次性的？永久物品叫“durable（耐用型）”，和用完即消失的消耗品是两回事。

问题 5.不滚动就能清楚看到价格吗？

问题 6.购买后有没有反馈？这是告诉玩家他得到了什么、该怎么用的好机会。

3. 如果处处是重点，就等于没有重点

如果用默认商店 UI，建议把第一个位置留给你最强的商品，因为所有配置好的商品会以一致的视觉权重出现。

如果你有超过六到八个商品，可以考虑拿掉转化最低的。数量少而精的商品陈列，通常胜过塞满整个目录。

如果用自定义商店 UI，可以考虑加一个主推位（hero slot）来展示你最好的商品。这个商品可以在视觉上与其他商品拉开差距（比如展示尺寸、留白）。

4. 记录你改了什么

记下当前在创作者门户（Creator Portal）中的转化率（conversion rate）、日期，以及你到底改了什么、为什么改。没有这份记录，转化率的升降都是无法行动的信息——你根本不知道是什么导致了变化。

另外，一次只改一处，并考虑给每次改动留两周数据再评估。创作者门户会给你转化率、D1 留存和 D7 留存。做改动时三个指标一起跟踪，别只看转化。
