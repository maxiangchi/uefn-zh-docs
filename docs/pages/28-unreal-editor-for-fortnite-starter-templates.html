UEFN 新手模板

UEFN 自带丰富的新手工具包：在项目浏览器的功能示例中体验动画、对话、灯光、材质等特性，或从枪战、跑酷、据点等游戏示例快速起步。

英文原标题：Unreal Editor for Fortnite Starter Templates · 查看英文原文 · 社区翻译镜像，仅供学习

Unreal Editor for Fortnite（UEFN）自带品类丰富的新手工具包。这些功能示例与游戏示例旨在让你亲身体验编辑器中的功能与机制，帮你的项目快速起步。

功能示例

启动 UEFN，在项目浏览器（Project Browser）窗口选择功能示例（Feature Examples），即可找到以下全部内容。

UEFN 介绍

非常适合首次创作的创作者，以及想快速回顾开箱即用资产类型的任何人：该模板像一座博物馆展厅，你可以在各展区之间穿行，学到起步所需的全部知识。

动画

动画功能示例让你近距离了解 UEFN 中用于角色动画的工具：与使用 animated mesh device 的各式舞蹈假人互动，或体验 Control Rig 与 Sequencer。更多内容请查看完整的Animation 101 模板页面。

对话

深入该功能示例，学习如何搭建对话（conversations），打造引人入胜的叙事或沉浸式 NPC 互动。更多对话内容请查看对话（Conversations）页面。

创意模式游乐套装

这个简单的 starter 展示了创建自制游乐套装（playset）的可能性，之后即可从 Creative 物品栏放入关卡。

白昼序列

白昼序列（Day Sequence）模板教你使用白昼序列管理器（Day Sequence Manager），在游戏中营造不同环境。深入内容请见白昼序列新手岛屿模板。

灯光

灯光模板展示如何为室内外制作自定义灯光：在现代美术馆中漫步，探索不同复杂度的环境灯光。更多信息请见灯光新手岛屿模板。

护符 MetaHuman

探索如何创建自己的 MetaHuman（高保真数字人）并导入 UEFN；还可以了解用 Marvelous Designer 制作自定义服装。深入内容请见护符 MetaHuman 模板页面。

用户界面

学习使用微件、材质与贴图创建自己的用户界面！更多信息请查看用户界面功能模板页面！

Verse 设备

在这个功能示例中游玩 Verse Commander——一款指挥角色解谜的游戏，同时学习 Verse 代码如何管理玩法。完整的 Verse Commander 文档见Verse 新手模板页面。

视觉特效

为关卡加入高品质灯光、后期处理与 VFX，让关卡更抓人！更多内容请查看熔岩洞穴 VFX页面！

建模

参观 UEFN 中的建模展厅，学习网格体、单位与网格的相关知识。更多内容请前往建模文档章节。

材质

在一系列示例中深入材质创作：基础材质搭建、材质节点、材质实例，以及函数、分层、顶点绘制等进阶特性。更多信息请查看文档的材质章节。

地形

地形（Landscape）模板教你创建自制地形的基础知识。更多内容请前往文档的环境与地形章节。

灰盒搭建 101

该展厅式模板带你了解灰盒搭建（greyboxing）如何帮你快速验证原型、做出稳固的关卡布局。更多信息请见灰盒搭建 Greyboxing页面。

角色、相机与 NPC

学习使用角色、序列与 NPC：探索控制单个或多个角色、控制 NPC、操纵相机的不同方式。

游戏示例

以下示例为众多热门游戏品类提供了扎实的起点，还有大量技巧与最佳实践，助你的游戏在 Fortnite 生态中脱颖而出，快来看看吧！

荒漠统治

这是一款统治类游戏：两队玩家争夺目标点。该模式依托占领区域（Capture Area）设备，以及用 Verse 定制的设备实现。更多信息请查看荒漠统治模板页面！

引爆

这是一款游戏类型的 starter 项目：一队安放炸药，另一队尝试拆除。更多信息请见Verse 引爆模板页面。

淘汰赛

这是一款使用 Verse 的淘汰赛模式 starter 项目。更多内容请前往Verse 淘汰赛模板页面。

枪战

该模板展示 2v2 FPS 游戏的最佳实践：在一座岛屿中制作多张小关卡，给玩家更多 variety。它包括：

  • 示例项目：一张空白地图，包含核心玩法与 Verse 设备；
  • 完整的示例地图：多张使用 Fortnite 道具的小关卡；
  • 清晰的 Outliner 结构：直观的命名规范，方便导航；
  • Verse 设备示例代码：展示玩家加入、比赛中加入、重连等玩法逻辑。

我的第一座岛屿

准备好学习在 Fortnite 中开发了吗？掌握在 UEFN 中构建游戏、在 Fortnite 中试玩，以及引入 Verse 扩展玩法的基础。跟随构建你的第一个岛屿教程，还能拿到完整 Verse 代码。

跑酷

该项目为跑酷类游戏提供了好玩的初始搭建。更多内容见Verse 跑酷模板页面。

道具猎手

该模板是道具猎手模式的绝佳起点：玩家用 Prop-O-Matic 设备藏身，静止太久心跳声会暴露位置，猎人必须找出并淘汰道具！完整教程见道具猎手模板。

Verse 持久化极速竞速

看看这款越野卡车德比竞速模板，通过赛前排行榜与发车阵容学习 Verse 持久化（Verse Persistence）。更多内容见Verse 持久化极速竞速模板页面。

单口喜剧

学习使用角色设备，以及椅子与输入触发器设备，打造 NPC 取悦观众的独特游戏。更多信息请查看单口喜剧俱乐部模板。

据点

这是一座精致的游戏示例：AI NPC 看守一处院落。更多内容请查看据点模板页面。

护符：环境

学习在 UEFN 中制作高细节环境的最佳实践。参观精美的关卡，更多信息见护符环境模板页面。

三方潜入战

这是一款独特的游戏：三支队伍争夺目标点，形成非对称多人对抗。在三方潜入战教程中可以找到亲手做出这款游戏所需的全部步骤。

村庄 starter 模板

村庄（Village）游戏任你改造，探索该模板，看看这套自定义游戏模式是如何搭建的。

Verse 程序化建筑

这是一套完全用 Verse 编写的程序化建筑系统示例！更多信息请查看程序化建筑模板页面！

在开发者论坛（Developer Forums）提问并帮助同行。在学习库（Learning Library）编写自己的教程或阅读他人的教程。

UEFN 中的 Animation 101 模板通过 Animation 101 模板快速学习骨骼网格体动画，了解 UEFN 中的动画设备、工具与工作流。对话系统 Conversations对话设备是 UEFN 中的强大工具，可构建动态交互式游戏模式，让玩家选择直接影响玩法。白昼序列新手岛屿模板讲解白昼序列设备与后期处理体积，为你的项目打造多样化、美术驱动的环境设计。荒漠统治（Deserted Domination）模板双队伍争夺目标点的统治类玩法，还能接触关卡序列与后期处理等 UE5 特性。灰盒搭建 Greyboxing为关卡制作可游玩粗稿、在打磨视觉之前先验证玩法布局的过程，又称 Blockout。灯光新手岛屿模板展示如何在关卡设计中使用室内与室外灯光，打造与经典 Fortnite 迥异的外观与氛围。Verse 程序化建筑模板用纯 Verse 实现程序化建筑系统，介绍体素编辑、形状文法等玩法的实现原理。道具猎手（Prop Hunt）模板猎人必须找出并淘汰伪装成道具躲藏的玩家队伍；演示加入/离开事件、循环与非对称队伍等功能。使用 Verse 持久化的极速竞速模板新增 Verse 持久化本地排行榜、按上一轮名次排位发车与选手数据开场介绍。据点模板（UEFN Verse 潜行战）AI 守卫按指定区域巡逻的据点：潜行还是强攻，支持单人或四人小队，附声光效果教学。Talisman 环境模板在 UEFN 中创建高度精细逼真环境的最佳实践：模块化构建、内存优化与光照材质技术。护符 MetaHuman 模板导入并使用 MetaHuman 超写实数字人，学习自定义服装，在项目浏览器功能示例中找到它。Verse 三方潜入战（Triad Infiltration）创建三方非对称对抗玩法：潜入者、攻击者与防守者，学习用 Verse 平衡队伍并争夺目标。UEFN 中的用户界面功能模板学习使用微件、材质与纹理创建自己的用户界面，含血条、小地图等 HUD 实现。Verse 引爆模板：在 UEFN 中制作拆弹玩法双队伍安放与拆除炸弹点的游戏，演示枚举、并发、竞速与等待等 Verse 概念。UEFN 中的 Verse 淘汰赛模板玩家每次淘汰对手都会获得不断变化的配装；展示映射容器、数组与淘汰事件订阅。Verse 跑酷模板在障碍与平台之间穿梭、收集 4 块电池即可通关，找到隐藏电池还能延长时间。Verse 单口喜剧俱乐部模板用椅子、输入触发器、角色与过场动画设备打造喜剧俱乐部演出，附完整 Verse 代码讲解。UEFN 中的 Verse 新手模板游玩 Verse Commander 小游戏：向角色发送指令解开谜题，由此进入 Verse 的世界。在 UEFN 中打造熔岩洞穴视觉特效综合运用多种视觉效果，将玩家带入环境深处，为关卡与玩法增添纵深感。
