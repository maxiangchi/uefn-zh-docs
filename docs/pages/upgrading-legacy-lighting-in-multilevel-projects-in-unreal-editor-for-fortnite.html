在多层级项目中升级旧版灯光

旧版昼夜管理器与 Skydome 设备已被弃用，本文介绍如何把默认关卡与多层级附加关卡转换到新的 TODM 与白昼序列设备。

英文原标题：Upgrading Legacy Lighting In Multilevel Projects In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

随着旧版昼夜管理器（Time of Day Manager，TODM）的昼夜循环和天空穹顶（Skydome）设备被弃用，建议把你希望保留的所有岛屿都转换到新的 TODM。所有使用 Skydome 设备的岛屿都会保留其玩法、体积数据和位置数据，但岛屿灯光将默认使用第五章灯光，并忽略 Skydome 设备上的所有设置。

升级后可以保证：

  • 使用 Lumen 和 Nanite 获得更真实的灯光。
  • 与 UEFN 的 TODM 以及未来的 TODM 更新保持一致。

这同样会影响使用多层级实例（即多个地图）的 UEFN 项目。为了确保能发布你的岛屿并尽可能减少出问题的可能，你需要转换附加关卡中的全部灯光。

默认关卡

你始终会有一个默认关卡，即启动会话时加载的关卡。你可以随时通过 GameFeatureData 资产更改哪个关卡是默认关卡，步骤如下：

  • 在内容浏览器（Content Browser）中双击 Game Feature Data 缩略图，Game Feature Data 会在新窗口中打开。
  • 在细节（Details）面板中展开体验数据（Experience Data）。
  • 在默认地图（Default Map）选项中，点击下拉菜单，选择一个关卡将其提升为默认地图。

默认情况下，打开 UEFN 项目时会加载“默认地图”，但你也可以加载其他附加关卡，方法是：

  • 打开文件（File）菜单，选择打开关卡（Open Level…）

手动升级灯光

要升级某个特定关卡的灯光，建议打开所有使用了旧版灯光的次级关卡，逐个升级 TODM 和 Skydome 设备。加载地图后，你可以转换该地图并调整视觉效果，确认转换符合你的预期。

昼夜管理器（Time of Day Manager，TODM）

判断地图是否使用旧版灯光，最简单的方法是查看世界设置。要检查地图使用的是哪种 TODM：

  • 打开窗口（Window）菜单，选择世界设置（World Settings），世界设置面板会在细节面板旁边打开。
  • 向下滚动到昼夜（Time of Day） > 世界昼夜管理器（World Time of Day Manager），打开下拉菜单。

如果地图设置为昼夜循环（旧版）（Day Night Cycle (Legacy)），说明该地图使用的是第十四章旧版世界灯光，这种 TODM 即将被停用，必须替换。

  • 在世界昼夜管理器（World Time of Day Manager）下拉菜单中选择昼夜循环 - 第五章（Day Night Cycle - Chapter 5）。
  • 点击保存（Save），该地图就升级到了新的 TODM。

天空穹顶与白昼序列设备

如果地图中使用了旧版 TODM，地图中可能还有旧的 Skydome 设备。这种情况下，把 Skydome 设备升级为新的白昼序列（Day Sequence）设备也很重要，因为 Skydome 设备与最新的第五章 TODM 不兼容。

要检查地图是否使用了 Skydome 设备，请执行以下操作：

  • 在大纲视图（Outliner）的搜索栏中输入 Skydome，找到该设备。

对于正在使用的 Skydome 设备，请将其替换为白昼序列设备。你可以在内容浏览器的内容层级中找到白昼序列设备：Fortnite > 设备（Devices） > 环境（Environment）文件夹。

可以添加任意数量的白昼序列设备，并按你的喜好调整视觉效果。

Skydome 设备与白昼序列设备的参数不同，因此熟悉新功能非常重要。关于创建世界灯光的更多细节，请参阅白昼序列设备（Day Sequence device）文档。
