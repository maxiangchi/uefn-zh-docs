UEFN MCP

UEFN MCP 在 Unreal Editor for Fortnite 进程内嵌了一个 MCP 服务器，让 Claude Code、Cursor 等兼容 MCP 的 AI 智能体通过本地 HTTP 连接驱动编辑器。本页介绍其概念、前置条件、配置与连接方法。

英文原标题：Uefn Mcp · 查看英文原文 · 社区翻译镜像，仅供学习

UEFN MCP 在 Unreal Editor for Fortnite（UEFN）（Fortnite 虚幻编辑器）进程内嵌了一个 MCP 服务器，Claude Code、Cursor、MCP Inspector 等任何兼容 MCP 的 AI 智能体都可以通过本地 HTTP 连接驱动编辑器。

它对外提供以下 UEFN 专属功能：

  • 创建、修改 Verse 场景图（Scene Graph）实体
  • 读写 Verse 文件
  • 放置创意设备并编辑其属性
  • 启动、停止、检查游玩会话

什么是 MCP？

UEFN MCP 在 UEFN 编辑器进程内嵌了一个模型上下文协议（Model Context Protocol，MCP）服务器。任何兼容 MCP 的 AI 智能体都通过本地 HTTP 连接它，经由分组为工具集（toolset）的类型化工具驱动编辑器。它把编辑器变成智能体可以检查、操作的对象：读取 Verse、编辑场景图（Scene Graph）、放置并配置创意设备、运行游玩会话。

开发者把智能体（如 Claude Code）指向运行中的编辑器完成设置后，就可以开始用自然语言提问或下指令，例如：

  • 我可以放置哪些设备？
  • 回合开始时加一条日志，然后编译。
  • 启动会话，我要测试。

面对这类问题与指令，智能体会发现可用工具集、调用工具并汇报结果。

UEFN MCP 前置条件

继续之前，项目中需要先设置好以下内容：

  • 为项目启用Python 编辑器脚本（Python Editor Scripting）。
  • 为 MCP 配置自启动。
  • 生成客户端配置文件。
  • 从 Fortnite UEFN 安装目录启动 AI 智能体。

启用 Python 与 UEFN MCP

在项目设置（Project Settings）中，勾选 Python 编辑器脚本（Python Editor Scripting）与 UEFN MCP 工具集（UEFN MCP Toolsets）。

两者都必须启用，UEFN MCP 才能工作。

创建客户端配置

每个 AI 智能体都要求服务器列表采用特定的文件格式，并放在项目树的特定位置。它需要知道你的 UEFN 项目安装在哪里。

创建 mcp.json 文件：

  • 在 UEFN 项目根文件夹右键，新建文本文档，命名为 .mcp.txt。
  • 打开该文本文档。
  • 把以下文本复制粘贴进文件。这是模型专用的 JSON，需要按你使用的 AI 智能体格式化。下面示例是 Claude 的 JSON： 
    mcp.json { "mcpServers": { "unreal-mcp": { "type": "http", "url": "http://127.0.0.1:8000/mcp" } } }
  • 以所有文件（All Files）类型保存，把扩展名改为 .json（替换掉 .txt）。

修改扩展名的过程中，如果系统复制出一个文件、保留一个原 .txt（文本文档）扩展名的文件，可以把那个文件删掉，它用不上。

为 AI 智能体创建好配置后，使用 Codex CLI 时还有一项收尾工作要注意。它用的 TOML 配置只写一次，也就是说该命令不会覆盖已存在的文件。因此，过期的配置必须手动删除。而 Claude Code、Cursor、VS Code、Gemini 用的 JSON 格式配置会与已有条目合并，多次运行命令是安全的。

连接 AI 智能体

要把 AI 智能体连到 UEFN，请从项目（或工作区）根目录——也就是生成 .mcp.json 配置文件的位置——启动你偏好的 AI 智能体 CLI 或应用。生成配置文件时的输出日志可查到该文件位置。

具体连接步骤与高级设置请查阅你的 AI 客户端文档。

  • 如果 AI 智能体 CLI 或应用找不到 Unreal MCP，请确认它是从放置配置文件的项目（或工作区）根目录启动的。
  • 如果默认端口（8000）被其他服务占用，换个端口试试。可以在编辑器偏好设置（Editor Preferences）中用服务器端口号（Server Port Number）设置。
  • 确认项目设置（Project Settings）中同时启用了Python 编辑器脚本（Python Editor Scripting）与 UEFN MCP 工具集（UEFN MCP Toolsets）。
  • 启停服务器必须关闭再重新打开编辑器。拿不准时，重启编辑器试试。

Unreal MCP 还与哪些功能交互？

功能名说明
工具集注册表（Toolset Registry）工具集如何被发现并作为 MCP 工具对外提供。
VerseVerse 工具集读取、编辑、编译项目 Verse 源码。
Verse 场景图（实体与组件）实体（Entity）工具集的操作对象。
创意设备设备（Device）工具集浏览目录、放置设备、编辑任何 @editable 属性。
会话会话（Session）工具集的游玩循环。注意 UEFN 游玩使用客户端内运行（Play-in-Client，PIC），而非虚幻引擎的编辑器内运行（Play-in-Editor，PIE）。
Verse 文件沙盒把 Verse 文件操作限制在创作者自己的项目内。

工具集提示建议

下表列出可用于逐步体验各功能能力的提示语，也可用来逐一确认每个工具集工作正常。

结果因 AI 智能体而异。

工具集建议提示语
Verse
  • 列出我项目中的 Verse 文件。
  • 读取我的主 Verse 文件并解释它是做什么的。
  • 在我的 Verse 文件中搜索所有引用玩家生成器的地方。
  • 回合开始时加一条日志消息，然后编译 Verse 并告诉我是否构建成功。
Verse 场景图实体
  • 我可以创建哪些实体类，可以给它们添加哪些组件？
  • 在原点创建一个实体并给它一个网格体组件。
  • 你创建的实体的变换是什么？把它上移 500 单位。
  • 列出该关卡中的每个实体及其组件。
创意设备
  • 该项目可以放置哪些设备？
  • 在关卡中放置一个玩家生成器和一个计时器设备。
游玩会话
  • 为我的项目启动游玩会话。
  • 会话连上了吗？
  • 开始游戏。
  • 我改了一些 Verse，把 Verse 改动推送到运行中的会话。
  • 检查客户端日志有没有报错，然后停止会话。

获得最佳结果的技巧

  • 命名要具体。
    • 提示时，描述操作对象越具体越好。例如，让智能体改“计时器设备（Timer device）”比改“刚才加的那个东西”效果更好。
  • 让智能体列出可用工具。
    • 发现工具就是为此存在的，能减少错误猜测。
  • 多步骤请求先要计划。
    • 执行前先审阅智能体给出的计划，避免智能体误解你的意图。
  • 保持改动可审查。
    • 小步修改比一大批改动更容易验证。大改动越往后越难验证，容易漏掉问题。

已知问题

以下已知问题正在调查中，可能在未来版本解决：

  • 从 LUF 到 XYZ 格式的坐标系与变换转换。
    • 目前 Python 工具集使用 XYZ 格式，而非左-上-前（Left-Up-Forward，LUF）坐标系。请求 AI 智能体在 UEFN 用的 XYZ 与 LUF 之间换算时，有时能成功，但由于两套系统在空间数学上工作方式不同，出错的可能性会被放大。
  • 编辑器卡顿
    • MCP 工具调用可能导致编辑器卡顿、无响应。正在调查，并评估让编辑器内工具调用更高效的方案。
