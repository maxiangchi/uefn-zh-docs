Verse 跑酷模板

通过 Verse 跑酷模板学习创建一种游戏模式：玩家在障碍与平台之间灵活穿梭，收集 4 块电池即可通关，找到隐藏电池还能延长时间。本教程将按理想顺序带你完整复刻这座岛屿。

英文原标题：Verse Parkour Template in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

Verse 跑酷模板（Verse Parkour Template）将向你展示如何创建一种游戏模式：玩家可以在障碍物与平台之间巧妙穿梭、移动，收集电池（Battery）。

在这种游戏模式中，玩家需要收集 4 块电池来完成关卡。如果找到隐藏电池，时间将会延长。当时间耗尽时，玩家将回到起点。

该模板演示了一些基础语言特性，例如：

  • For 循环（For Loops）
  • 订阅（Subscriptions）
  • 数组（Arrays）
  • 设备 API（Device API）

本模板不会使用并发（Concurrency）等复杂概念。

概述

以下是按理想顺序复刻这座岛屿所需的步骤概览：

  • 创建新项目，并修改岛屿设置（Island Settings）以完成游戏设置。
  • 构建竞技场。
  • 设置设备。
  • 添加 Verse 脚本。
  • 设置 Verse 设备。

创建新项目并设置游戏

  • 打开 UEFN（Unreal Editor for Fortnite），创建一个新的空项目。
  • 在大纲视图（Outliner）中选择岛屿设置（Island Settings）设备，找到用户选项 - 游戏规则（User Options - Game Rules）。
  • 按下表所示修改用户选项。
选项值说明
加入进行中的游戏（Join in Progress）Spawn指定当玩家在游戏进行中加入时如何处理。设为 Spawn（生成）即允许玩家中途加入。
游戏胜利条件（Game Win Condition）Most Scores Win得分最高的玩家将赢得游戏。
回合胜利条件（Round Win Condition）Score得分最高的玩家将赢得该回合。
移动预设（Locomotion Preset）Custom快速配置移动设置以匹配官方体验并跟随未来的预设更新，或使用自定义设置锁定行为。
允许攀爬 / 冲刺 / 滑行 / 肩撞（Allow Mantling/Sprinting/Sliding/Shoulder Bashing）True玩家将可以翻越场景中的各种环境物体，做出跑酷动作。
玩家建筑墙体生成边缘（PBWs Generate Ledges）False当允许攀爬（Allow Mantling）设为 True 时，该选项决定玩家建造的墙体（Player Built Walls）是否生成可抓取边缘；若攀爬设为关闭，则墙体不会生成边缘。
滑翔伞重新部署（Glider Redeploy）False决定玩家是否可以在不使用道具的情况下自由部署滑翔伞。
移动速度调优（Movement Speed Tunings）Ch 4 Movement决定玩家移动应使用的移动速度调优方案。
允许助跑跳（Allow Boosted Jump）False助跑跳允许玩家在边缘附近冲刺时做出更高更远的跳跃。
允许翻滚落地（Allow Roll Landing）False翻滚落地允许玩家在落地时翻滚缓冲。
允许蹬墙跳（Allow Wall Kick）False决定玩家是否可以蹬墙起跳。
允许爬墙（Allows Wall Scramble）False决定玩家是否可以短距离跑墙而上。
自动拾取消耗品（Auto Pickup Consumables）Yes决定玩家是否自动收集消耗品。Auto Only 会隐藏拾取交互 UI。
无限建筑资源 / 金币 / 世界资源 / 耐久度（Infinite Building Resources/Gold/World Resources/Durability）True玩家将可以在环境中收集所有资源。
开局携带鹤嘴锄（Start With Pickaxe）False玩家开局时不会携带鹤嘴锄。
鹤嘴锄破坏（Pickaxe Destruction）None鹤嘴锄不会破坏环境。
自动拾取物品（Auto Pickup Items）Yes玩家接触到物品时会自动拾取。
计分板第一列（First Scoreboard Column）Score计分板第一列将显示得分。

设置设备

本教程使用以下设备：

  • 玩家出生点（Player Spawn Pad）~[Player Spawn Pad]
  • 5 x 物品授予器（Item Granter）5 x[Item Granter]
  • 1 x 结束游戏（End Game）1 x[End Game]
  • 1 x 伤害体积（Damage Volume）1 x[Damage Volume]
  • 1 x 计时器（Timer）1 x[Timer]
  • 1 x HUD 消息（HUD Message）1 x[HUD Message]
  • 1 x Verse 设备（Verse Device）1 x[Verse Device]

玩家出生点（Player Spawn Pad）设备

使用玩家出生点（Player Spawn Pad）设备将玩家生成到地图上。在地图起点处为每位玩家放置一个出生点，该设备可在 Fortnite > 设备 > 玩家出生点（Devices > Player Spawn Pad）下找到。

按如下配置该设备的用户选项（User Options）：

选项值说明
游戏中可见（Visible In Game）False该设备在游戏中不可见。

物品授予器（Item Granter）设备

在 UEFN 中，从内容抽屉（Content Drawer）拖出消耗品（Consumable）会自动放入物品生成器（Item Spawner）设备。将电池（Battery）物品拖到地图上，该物品可在 Fortnite > 物品 > 电池（Items > Battery）下找到。

按如下配置该设备的用户选项（User Options）：

选项值说明
生成前等待时间（Time Before Spawn）0.1决定物品生成前的等待时长。
按计时器重生物品（Respawn Item on Timer）False电池被拾取后不会重生。
游戏期间显示底座（Base Visible During Game）False该设备在游戏中不可见。
经过即拾取（Run Over Pickup）True玩家会自动拾取该物品。
物品缩放（Item Scale）2.0决定电池的大小。

复制粘贴该设备再制作 4 个，放置在地图各处。

结束游戏（End Game）设备

放置一个结束游戏（End Game）设备，在被激活时结束游戏。

按如下配置该设备的用户选项（User Options）：

选项值说明
自定义胜利播报（Custom Victory Callout）enter text输入要展示给获胜玩家的文本。

伤害体积（Damage Volume）设备

伤害体积（Damage Volume）设备是一个可对其区域内玩家造成伤害的边界。将该设备放在地图下方，调整区域宽度（Zone Width）、深度（Depth）和高度（Height）以覆盖竞技场底部，从而即时淘汰掉落的玩家。

按如下配置该设备的用户选项（User Options）：

选项值说明
伤害（Damage）500该设备造成足以即时淘汰坠落玩家的伤害。

计时器（Timer）设备

在结束游戏设备附近放置一个计时器（Timer）设备。该设备会倒计时，时间耗尽后玩家将被淘汰并必须重新开始。

按如下配置该设备的用户选项（User Options）：

选项值说明
时长（Duration）30计时器持续 30 秒。
游戏开始时启动（Start at Game Start）True计时器在游戏开始时启动。
应用于（Applies To）Player计时器启动时将应用于指定玩家。
计时结束视为成功（Success on Timer End）False计时器结束时不会被视为成功。
游戏期间可见（Visible During Game）Hidden该设备在游戏中隐藏。
计时进行文本（Timer Running Text）enter text输入要为计时器显示的文本。

HUD 消息（HUD Message）

使用 HUD 消息（HUD Message）设备向玩家展示醒目的消息。

按如下配置该设备的用户选项（User Options）：

选项值说明
显示时长（Display Time）2.0消息将显示两秒后消失。
回合开始时显示（Show on Round Start）False该消息不在回合开始时显示，而在拾取电池时显示。

添加 Verse 脚本

按此添加以下 Verse 脚本，首先使用 @editable 函数引用设备。

你可以按书写顺序复制代码。脚本中添加了注释以便理解。

using { /Fortnite.com/Devices }
using { /Fortnite.com/Characters }
using { /Verse.org/Simulation }
using { /UnrealEngine.com/Temporary/Diagnostics }

log_parkour := class(log_channel){}

# This is a Verse-authored creative device that can be placed in a level
# This script example is a take on Parkour where the objective is to gather 4 batteries before the timer expires

上面的脚本展示了如何使用 @editable（可编辑属性）将创意设备、数组和浮点数暴露给 UEFN。脚本稍后要调用它们，必须先在 Verse 中定义这些设备。

# Messages to display when a battery is collected
BatteryCollectedMessage<localizes>(Amount:int) : message = "You collected {Amount} battery"
BatteriesCollectedMessage<localizes>(Amount:int) : message = "You collected {Amount} batteries"
# Messages for collecting the secret battery and the completion message
AllBatteriesCollectedMessage<localizes> : message = "You collected all of the batteries!"
SecretBatteryCollectedMessage<localizes> : message = "You collected the secret battery, additional time added!"

上面的脚本展示了如何定义函数，根据收集的电池数量（Amount）返回参数化消息，同时还定义了集齐所有电池和拾取隐藏电池时显示的消息。

# Runs when this device_script is started in a running game
OnBegin<override>()<suspends>:void =
    # You can output to the log like this to determine what your script is up to
    Logger.Print("Parkour Race Script Started!")
    # Subscribing to the AgentSpawnedEvent.
    # When the player spawns, the function "HandleAgentSpawned" is called.
    PlayerSpawnDevice.SpawnedEvent.Subscribe(HandleAgentSpawned)
    # Same for the Timer. We subscribe to when it expires
    TimerDevice.FailureEvent.Subscribe(HandleTimerExpired)

OnBegin 函数定义了游戏开始时发生的事情，同时通过 for 循环订阅电池拾取事件。

# A function that is called when the Agent Spawns from the Player Spawn Pad
HandleAgentSpawned(Agent:agent):void =
    Logger.Print("Agent Spawned!")
    # Reset the Timer Device to ensure respawning players get the full amount of time
    TimerDevice.Reset(Agent)
    TimerDevice.Start(Agent)

以上是玩家生成时的代码：重置计时器并重新开始计时。

# Function that is called when a battery item is picked up from the Item Spawners
HandleBatteryPickedUp(Agent:agent):void =
    # Increment the number of batteries collected
    set BatteriesCollected = BatteriesCollected + 1
    # This is how you can output the number of batteries to the log. Useful for debugging
    Logger.Print("Number of batteries picked up: {BatteriesCollected}")
    # Check to see if there are enough batteries collected to the end the game
    if:
        BatteriesCollected >= BatteryItemSpawners.Length

以上是处理电池拾取的代码。如果已拾取足够数量的电池，就调用 EndGame 方法结束游戏；否则向玩家显示 HUD 消息并生成下一块电池。

HandleSecretBatteryPickedUp(Agent:agent):void =
    Logger.Print("Picked up secret battery")
    # Get the time remaining so we can add additional time to it
    var TimeRemaining:float = TimerDevice.GetActiveDuration(Agent)
    var TimeToAdd:float = (TimeRemaining + SecretBatteryTimeReward)
    # Add additional time to the Timer Device, but don't go over the initial starting time
    TimerDevice.SetActiveDuration(Min(TimeToAdd, TimerDevice.GetMaxDuration()), Agent)
    HUDMessageBattery.SetText(SecretBatteryCollectedMessage)
    HUDMessageBattery.Show(Agent)

以上代码在拾取隐藏电池时为计时器设备增加时间，且不会超过计时器 30 秒的初始时长，同时会在屏幕上显示消息。

# Function that is called when the timer expires
HandleTimerExpired(MaybeAgent:?agent):void =
    Logger.Print("Timer Ended")
    if (Agent := MaybeAgent?):
        # Eliminate the player
        if:
            FortCharacter:fort_character = Agent.GetFortCharacter[]

以上代码在时间耗尽时淘汰玩家。玩家随后会重生，计时器则在 HandleAgentSpawned 方法中重置。

# Asynchronous function that handles the end of the game
EndGame(Agent:agent)<suspends>:void =
    HUDMessageBattery.SetText(AllBatteriesCollectedMessage)
    HUDMessageBattery.Show(Agent)
    # Wait for three seconds before ending the game
    Sleep(3.0)
    EndGameVictoryDevice.Activate(Agent)
    # Runs when this device_script is stopped or the game ends

以上是结束游戏的代码。其中 Sleep(3.0) 是使用异步（async）方法的示例。

设置 Verse 设备

编译你的 Verse 脚本，然后在内容抽屉（Content Drawer）中找到你的设备。将 Verse 设备拖到地图上不起眼的区域来自定义设置。

在该设备的细节（Details）面板中，参照上图为每个引用的设备配置设置。

按如下配置该设备的用户选项（User Options）：

选项值说明
PlayerSpawnDevicePlayer Spawn Pad从下拉框中选择此项以引用设备。
EndGameVictoryDeviceEnd Game Victory Device从下拉框中选择此项以引用设备。
TimerDeviceTimer从下拉框中选择此项以引用设备。
HUDMessageBatteryHUD Message Device Battery从下拉框中选择此项以引用设备。
BatteryItemSpawners - 0Battery Spawner 1从下拉框中选择此项以引用设备。
BatteryItemSpawners - 1Battery Spawner 2从下拉框中选择此项以引用设备。
BatteryItemSpawners - 2Battery Spawner 3从下拉框中选择此项以引用设备。
BatteryItemSpawners - 3Battery Spawner 4从下拉框中选择此项以引用设备。
SecretBatteryItemSpawnerBattery Spawner - Secret从下拉框中选择此项以引用设备。
