在 UEFN 中使用移动端预览会话

移动端预览会话让你在 PC 上模拟目标 iOS 或 Android 设备启动体验，轻松测试岛屿在移动端的外观、手感与性能。

英文原标题：Mobile Preview Session in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

移动端预览（Mobile Preview）会话让你可以在 PC 上启动体验，就好像它运行在目标 iOS 或 Android 设备上一样。这样你就能轻松测试岛屿在移动端玩家眼中的样子和手感，并做出关键调整、改善用户体验。

使用移动端预览启动岛屿

用移动端预览启动会话的步骤如下：

  • 点击 启动会话（Launch Session）旁边的竖排省略号（vertical ellipsis）下拉菜单。
  • 在平台（Platform）分组下选择 移动端预览（本机）（Mobile Preview (This PC)）。
  • 把鼠标悬停在 Mobile Preview (This PC) 选项上，选择想要的屏幕尺寸。可选尺寸包括常见手机（20:9）（Common Mobile (20:9)）、老款手机（16:9）（Older Mobile (16:9)）或平板（4:3）（Tablets (4:3)）。
  • 根据你要测试的目标设备选择一个设备配置（Device Profile）。
  • 点击启动会话（Launch Session）。

显示设备叠加层

你可以从最常见的多款 iOS 和 Android 设备中挑选一款进行预览。选中后会叠加该设备的圆角、摄像头挖孔与正确的安全区。

  • 在 Mobile Preview (This PC) 中，向下找到预览 Android 设备（Preview Android Devices）或预览 iOS 设备（Preview iOS Devices）。
  • 选择要预览的设备。
  • 勾选显示设备叠加层（Display Device Overlay）。此时纵横比会更新为来自 JSON：[设备名称]（From JSON: [name of device]）。
  • 启动会话（Launch Session）后，就能看到正确应用的叠加层效果。下图展示的是 iPhone 17 Pro 的叠加层效果。

测试操作

会话运行后：

  • 在屏幕左侧按住鼠标左键拖动，可以模拟触摸移动输入。
    点击并拖动鼠标，模拟触摸方向输入。
  • 鼠标点击可以模拟触摸按键。
    点击按钮，模拟触摸操作。
  • 用 WASD 键移动，模拟双手 gameplay 操作。
    键鼠配合，模拟双手 gameplay。

如果你用的是带触摸屏的 Windows 设备，可以在操作屏幕时直接使用触摸输入。

移动端测试清单

在移动端平台上测试岛屿时，主要考虑以下几点：

外观

你的岛屿在移动端上看起来和 PC / 主机差别大吗？请确认：

  • 资源在 Android / iOS 上都能正常显示。
  • 美术资源、光照、材质与视觉特效的质量符合预期。
  • 昼夜序列（Day Sequence）设备、环境灯光装置（Environment Light Rig）设备等灯光 Actor 能正确照亮岛屿。

你可以分别截取移动端会话和 PC 会话的画面，对比后发现光照设置中的不一致。

需要留意的视觉问题：

  • 室内与室外的曝光问题。
  • 色彩问题。
  • 贴花分辨率问题。
  • 后期处理效果问题。

UI / HUD 的外观与手感

移动端预览对于确认用户界面元素位置正确、针对触摸环境优化至关重要。请检查：

  • HUD 布局在移动端上是否正确。
  • 各控件在移动端上的观感。
  • 设计是否真正适合触摸操作。
  • 按钮尺寸是否适合手指点按。
  • 图标与文字是否清晰可读。

性能分析

你可以在编辑器中启动空间性能分析器（Spatial Profiler）工具来分析游戏性能。该分析器可以给出针对移动端目标平台的数值，帮你更好地理解性能问题、找准优化方向。

空间性能分析器采集的关键性能指标：

  • 对象数量（Object counts）。
  • 渲染绘制调用（Rendering draw calls）与图元数量（primitive counts）。
  • 时间指标，包括帧时间（Frame Time）、游戏更新时间（Game update time）、GPU 时间（GPU Time）、渲染时间（Render Time）与 RHI 时间（RHI Time）。

这些指标使用的是 PC 烘焙数据，不能准确反映真机上的表现。详见下方常见问题。

常见问题

问：体验发布或设为私有后，还能用移动端预览测试吗？

答：目前还不行，无法用它在已发布或私有的岛屿中启动移动端 gameplay。这一限制是为了应对欺诈与安全方面的考虑。

问：移动端预览适用于所有测试场景吗？

答：不适用。移动端预览会话只能在实时编辑（Live Edit）会话中使用。

问：移动端预览能准确测出体验在真机上的内存占用吗？

答：由于会话使用的是 PC 烘焙数据而非移动端烘焙数据，在计算内存时并不能反映真机上的实际内存占用。要获得最准确的内存计算结果，建议从会话（Session）菜单选择连接到平台（Connect to platform），在目标设备上计算内存。

问：移动端预览还有哪些已知限制？

答：由于会话使用的是 PC 烘焙数据，且游戏性能会因 PC 配置不同而有差异，该预览不能完全代表真机上的实际性能与准确画质。
