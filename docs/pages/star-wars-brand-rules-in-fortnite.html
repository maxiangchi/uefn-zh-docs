星球大战™品牌规则（Fortnite）

使用 UEFN 中提供的星球大战™资产打造灵感源自星球大战银河的岛屿，并遵守创建与发布星球大战岛屿必须遵循的品牌规则。

英文原标题：Star Wars Brand Rules In Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

使用包含星球大战™（Star Wars™）资产的独特模板，打造你自己灵感源自星球大战银河的岛屿吧。这些资产包括角色、美术、标志、服装、预制件、图库、工具、外观、载具、武器、地图、音效及其他物品（以下称“星球大战资产（Star Wars Assets）”）。进入 Fortnite 建造模式与虚幻编辑器 Fortnite 版（UEFN），使用星球大战资产建造创意岛屿（以下称“星球大战岛屿（Star Wars Islands）”）！使用星球大战资产意味着承担一定的责任并遵守相关要求。以下是在创建与发布星球大战岛屿时必须遵守的一套规则。

你在 Fortnite 建造模式与 UEFN 中使用星球大战资产创建星球大战岛屿（包括对其的任何推广），受《星球大战™品牌规则（STAR WARS™ Brand Rules）》（如下文所述）、《Fortnite 最终用户许可协议》、IP 合作伙伴授权协议、《社区准则》、《变现协议》以及《Fortnite 岛屿开发者规则》（合称“开发者协议”）约束。在使用任何星球大战资产之前，请仔细阅读这些条款。如果你打算在星球大战岛屿中提供任何物品或优惠作为岛内交易（“岛内交易（In-Island Transactions）”），请仔细阅读《Fortnite 开发者规则》第 4.4 节中的岛内交易规则以及《岛内交易限制》。使用星球大战资产即表示你同意受开发者协议约束。相关链接：Fortnite 最终用户许可协议、社区准则、Fortnite 岛屿开发者规则、岛内交易限制。

STAR WARS 品牌规则

在使用星球大战资产构建、发布与推广星球大战岛屿时，你必须遵守所有相关协议以及以下星球大战品牌规则：

  • 星球大战资产的使用范围限制。你只能使用在虚幻编辑器 Fortnite 版（“UEFN”）中提供给你的星球大战资产，并仅以其在 Fortnite 中提供的方式使用；唯一经批准的星球大战资产，是通过 UEFN 向你开放访问的那些资产。请勿复制、录制，或试图在 UEFN 或你的星球大战岛屿之外提取、复刻星球大战资产。请勿将任何迪士尼角色或资产（例如星球大战武器、护盾、载具等）导入 UEFN 并在你的岛屿或岛内交易中使用。
  • 只能使用正版星球大战资产进行创作。你不得自行创作某个星球大战资产的仿制版本，也不得基于星球大战或星球大战资产创作新资产或翻新任何非正版星球大战资产，包括用于岛内交易。但允许你组合所提供的环境资产（例如建筑、道具、地形）来搭建独特的结构与布局（“套件拼装 kitbashing”）。此例外不适用于你为岛内交易创建的物品，也不适用于拼装零件创造新的载具、角色或武器。
  • 只能使用允许的修改方式。不得以拉伸、裁剪、重新着色等方式更改或修改任何现有星球大战资产、星球大战元素或其他星球大战内容。对岛内交易用星球大战资产的修改，仅允许使用我们提供的工具所支持的修改。请仅使用我们为星球大战资产提供的 UEFN 自定义或变现工具。例如，对于星球大战音效，除我们工具允许的范围外不得做任何编辑；音效不得单独用于创建或提供岛内交易。允许对环境资产进行均匀缩放、旋转与叠放，以满足玩法需求与关卡设计。“英雄资产（Hero Assets）”（特指角色、载具与武器）不在此许可范围内，必须严格按提供原样使用，不得扭曲变形。
  • 发布岛屿时，星球大战岛屿必须使用星球大战资产。要被认定为星球大战岛屿，你的岛屿必须包含至少一件（1）星球大战资产。
  • 不得导出、出售或再分发任何星球大战资产。你不得下载、移除、出售、许可、分发或利用任何星球大战资产，包括以独立形式，或作为在线资产数据库、市场或其他数据库的一部分，包括以允许第三方以独立文件形式使用、下载、提取或访问任何星球大战资产的方式，或允许你或他人在你自己的星球大战岛屿之外转移或利用星球大战资产的方式，无论是单独还是以“套件拼装”成资产合集的形式，包括作为你未创建的其他非星球大战岛屿中岛内交易的一部分。仅允许在你的星球大战岛屿内、以我们提供的工具所支持的方式提供或销售岛内交易。
  • 不得打广告、传教或搞竞选宣传。
    • 不得在你的岛屿中或与之相关地为任何产品、服务或财产做广告或推广。不得将星球大战或其他迪士尼角色用作产品“代言人”，也不得以可能暗示与产品、服务或财产（包括你本人及你的岛屿）存在关联的方式使用星球大战资产。
    • 不得就政党、宗教等敏感话题进行说教。不得将星球大战资产与宗教图像或偶像一同展示，不得将其置于制服中，或与复制现实世界社会、政治、军事团体或机构的旗帜、标志一同展示（Epic 在 Fortnite 或 UEFN 中更广泛提供的资产除外）。不得利用星球大战资产支持任何社会、政治或宗教组织、竞选或事业，或就此表态（例如涉及候选人、法律，或就战争、枪支使用等问题表态）。
  • 使用自有资产的限制。只要遵守开发者协议、本星球大战品牌规则及所有其他相关协议，你可以在岛屿中使用你拥有全部权利的资产，但不得在星球大战岛屿中使用（i）源自影视作品的知识产权（IP），或（ii）大型多媒体电子游戏系列中的角色，即使你拥有该 IP 或角色的权利。你在其他非星球大战岛屿中创建或提供的岛内交易，不得在星球大战岛屿中推广或使用。你可以在你的星球大战岛屿（包括你开发的多个星球大战岛屿）之间创建并提供岛内交易。

  • 诚实准确地推广你的岛屿。不要误导他人访问你的岛屿。在制作推广岛屿的媒体内容（例如文字描述、缩略图、大厅背景图与视频）时，确保其准确反映你创建的星球大战岛屿或玩法机制，不要抄袭或假冒其他游戏或开发者。参考《推广你的 Fortnite 岛屿》中列出的要求；另请注意，你推广星球大战岛屿的内容与信息必须遵守开发者协议，且适合目标受众的年龄。详见《Fortnite 开发者规则》第 3 节。相关链接：推广你的 Fortnite 岛屿、Fortnite 开发者规则。

STAR WARS 音乐

Epic 可能提供星球大战风格音乐（“星球大战音乐（Star Wars Music）”）作为星球大战资产，供你在星球大战岛屿中使用。在使用星球大战音乐构建、发布与推广星球大战岛屿时，除遵守星球大战与迪士尼品牌规则外，还必须遵守以下规则：

  • 允许的用途。你仅可将星球大战音乐用于以下目的：
    • 背景音乐；
    • 兴趣点配乐；
    • 短促音效（Stingers）；
    • 循环段落（Loops）；以及
    • 与 NPC 关联的配乐。
  • 修改限制。你仅可对星球大战音乐做以下调整：
    • 时长；
    • 音量；以及
    • 循环。
  • 使用限制。除本星球大战音乐规则允许的范围外，你不得使用星球大战音乐。例如，你不得使用星球大战音乐创作以下内容（包括但不限于）：
    • 推广素材；
    • 重录版本；
    • 复制件；
    • 混音版本；
    • 重制版本；
    • 改编版本；
    • 音高/变速调整；
    • 歌词展示；
    • 与其他歌曲或音效的混音；或
    • 任何岛内交易。
  • 期限：由于授权限制，星球大战音乐可能仅在有限期限内可用。一旦星球大战音乐不再作为星球大战资产提供（“星球大战音乐到期（Star Wars Music Expiration）”），你不得试图在任何星球大战岛屿更新中导出、保存、重新上传、录制、复制或继续使用该星球大战音乐。在星球大战音乐到期之前已发布的星球大战岛屿可保留其中的星球大战音乐，但到期之后，若你的星球大战岛屿包含星球大战音乐，你将无法发布该岛屿的任何后续更新或重新发布版本。

切勿将 STAR WARS 资产与第三方 IP 混用

不得在你的星球大战岛屿中或其推广中使用任何第三方 IP（例如源自影视、电子游戏、图书、漫画与音乐的 IP），包括用于任何岛内交易，或星球大战岛屿内的付费营销、推广，即使该 IP 的权利人已给予许可。你的资产、岛屿、优惠及其任何分发、推广或利用，也不得侵犯或违反第三方权利，包括 IP 权利（如著作权、商标权）以及隐私权、公开权。你必须拥有分享与发布星球大战岛屿中所含或其推广中所用任何内容所必需的权利，且该等权利必须使你能够向 Epic 授予符合《Fortnite 最终用户许可协议》与《UEFN 补充条款》的许可。你也可以使用 Epic 直接提供给你的其他资产，但另一 IP 合作伙伴计划合作方（如乐高®岛屿、忍者神龟岛屿、TWDU 岛屿）的资产除外，并须遵守该等资产各自的使用条款。相关链接：Fortnite 最终用户许可协议、UEFN 补充条款。

STAR WARS 岛屿变现

迪士尼向你提供其内容的有限许可，允许你使用其批准的星球大战资产。这将使你能够把获得官方授权的星球大战岛屿带入 Fortnite 生态，为 Fortnite 社区创造新型岛屿。作为回报，你必须遵守 IP 合作伙伴授权协议（含星球大战品牌规则）、Fortnite 开发者规则、社区准则及所有其他相关协议。唯一经批准的星球大战资产与功能，是通过指定模板访问的那些。唯一经批准的岛内交易是：（i）耐久型物品、（ii）消耗型物品、（iii）付费区域、（iv）付费随机物品，以及（v）上述经批准岛内交易的捆绑包，且该等捆绑包仅可在你开发的星球大战岛屿内提供。岛内交易不得包含类赌博机制，不得误导玩家无意消费，且必须按照《Fortnite 开发者规则》第 4.4 节中的岛内交易规则与《岛内交易限制》创建、提供与销售。相关链接：Fortnite 开发者规则、岛内交易限制。

作为迪士尼授权你使用星球大战资产创建星球大战岛屿的对价，你同意与迪士尼分享你岛屿互动参与分成总额的 20%，以及岛内交易分成总额的 30%。Epic 将从你的参与分成和/或岛内交易分成中自动扣除该金额并分配给迪士尼，你将获得剩余部分。当你在创作者门户签署 IP 合作伙伴授权协议时，即表示同意此流程。

推广你的 STAR WARS 岛屿

在为你的岛屿制作媒体内容时，请参考《推广你的 Fortnite 岛屿》中列出的指南。确保图像与视频准确反映你创建的岛屿或玩法机制，不要抄袭其他游戏或开发者。你对星球大战岛屿的推广必须遵守星球大战品牌规则、《Fortnite 开发者规则》（Fortnite 开发者规则）、社区准则及其他相关协议（例如 Fortnite 开发者规则第 3 节）。推广中的内容与信息必须符合该等规则与协议中的内容规则与指南，且适合你岛屿目标受众的年龄。相关链接：推广你的 Fortnite 岛屿。

缩略图、大厅背景图与视频

除现有规则外，你可能已经注意到，部分星球大战品牌规则也与你的推广素材相关。以下是对推广素材方面星球大战品牌规则的具体指南。

你可以：

  • 在缩略图与大厅背景图中使用 UEFN 提供给你的星球大战资产，只要该使用遵守本星球大战品牌规则与开发者协议。
  • 在星球大战岛屿的标题中使用“星球大战（Star Wars）”以及星球大战宇宙中的地点与角色名称。

你不可以：

  • 在星球大战岛屿的缩略图、大厅背景图、描述、视频、推广素材或任何岛内交易中使用任何星球大战或迪士尼影视、电视、电子游戏、图书、漫画中的图像、主视觉、音乐或营销素材。
  • 在星球大战岛屿的缩略图、大厅背景图、描述、视频、推广素材或任何岛内交易中使用第三方 IP。
  • 在星球大战岛屿的缩略图、大厅背景图、描述、视频、推广素材或任何岛内交易中使用任何星球大战或迪士尼标志（或风格近似的标志），或迪士尼及其关联方的实体名称。
  • 在星球大战岛屿的缩略图、大厅背景图、描述、视频、推广素材或任何岛内交易中，使用任何星球大战或迪士尼演员、员工或代表的姓名、图像或肖像（星球大战资产中包含的除外），或任何意在唤起其联想的其他图像。
  • 声称或暗示你的星球大战岛屿或任何岛内交易隶属于迪士尼或星球大战品牌，或获得其背书。

你的岛屿在 Discover 中

在创作者门户中，星球大战岛屿会在发布流程中自动打上“开发者制作的星球大战岛屿（Developer-Made Star Wars Island）”标签，该特殊标签将出现在产品详情页。必须明确表明你的星球大战岛屿由你本人创建，而非迪士尼创建；必须明确表明任何岛内交易均仅由你创建与提供，并非由迪士尼创建或背书。

开发者制作的星球大战岛屿会出现在 Discover 中并可被搜索，与其他 Fortnite 岛屿一样。
