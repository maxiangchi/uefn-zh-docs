第一座岛 3：搭建射击场

给玩家加点能打的靶子：本教程区分好靶（命中得分）与坏靶（命中扣分），带你放移动靶、复制摆成嘉年华射击场、再加不该打的固定靶，最后用屏障把玩家挡在射击区之外。

英文原标题：First Island 03: Build a Shooting Gallery in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

给玩家加点能打的靶子吧！

本教程把靶子分成好靶（good targets）和坏靶（bad targets）：好靶命中得分，坏靶命中扣分。

用到的设备

  • 3 x 移动靶（Target Dummy Track）设备
  • 3 x 固定靶（Target Dummy）设备
  • 1 x 屏障（Barrier）设备

添加移动靶

打中移动靶得分！

  • 打开内容浏览器（Content Browser），沿文件夹找到 Fortnite > Devices。
  • 搜索 target，筛出靶子设备。

在搜索栏搜索 Target。

  • 把移动靶（Target Dummy Track）拖进视口，在细节面板的绿色（U 轴（U-axis））旋转（Rotation）字段填 90，旋转设备。这个靶子会在轨道上来回滑动。
  • 在细节面板的用户选项（User Options）下，把靶子类型（Target Type）定制为 Round（圆形）。

这些圆形靶就是你的好靶，玩家打中得分。

  • 保持用户选项展开，再展开高级（Advanced），按需滚动，定制以下选项。

选项与值

Score Value（分值）=0

Show Health Bar（显示血条）=取消勾选

Move on Proximity（靠近时移动）=取消勾选

Bullseye Knockdown（命中靶心击倒）=勾选

Hinge from Center（从中间折倒）=勾选

Reset Time Type（重置时间类型）=Random（随机）

Random Reset Minimum Time（随机重置最短时间）=3.0 s

Random Reset Maximum Time（随机重置最长）=6.0 s

Pop-Up Delay Type（弹出延迟类型）=Random（随机）

Random Pop-Up Minimum Time（随机弹出最短时间）=3.0 s

Random Pop-Up Maximum Time（随机弹出最长）=6.0 s

这套设置的效果：

  • 靶子变成圆形。
  • 靶子倒下时从支架中间折倒，而不是从底部折倒。
  • 重置与弹出时间随机，在 3 到 6 秒之间重置或弹出。

添加更多靶子

只打一个靶子没劲，加几个把节奏带起来。

这个已经定制好了，直接复制，再像嘉年华射击摊那样摆成错落有致的阵型。

  • 在视口点击 Target Dummy Track 设备选中它。
  • 按住 Alt 键，拖 L 轴（L-axis）箭头，复制出一个靶子。

按住 Alt 键时，沿任意轴拖动物件都能复制。选中的轴限定拖动方向：左右、上下、前后。点两轴交界的直角，还能同时沿两轴拖。

  • 复制靶子，直到有三个。
  • 看地板网格平移（translate，移动）靶子，摆成错落阵型。

Three Targets Dummy Track devices（三个移动靶设备）。

想更随机一点，改改复制靶的随机重置与弹出延迟时间，别让它们整齐划一。

添加固定靶

滑动靶给射击场加了一层复杂度——移动靶总比固定靶难打。

这一步再加一层复杂度：放一个不该打的固定靶，打中扣分！

  • 在内容浏览器里再搜一遍 target。

在搜索栏输入 target。

  • 这次把固定靶（Target Dummy）拖进视口。和第一个靶子不同，它不在轨道上滑，而是在击倒和立起之间摆动。

这个靶子就是你的坏靶，玩家打中扣分。

  • 在细节面板的用户选项（User Options）下，把靶子类型（Target Type）设为 Teddy Bear（泰迪熊），再展开高级（Advanced）设以下值：

选项与值

Score Value（分值）=0

Show Health Bar（显示血条）=取消勾选

Pop Up Delay Type（弹出延迟类型）=Random（随机）

Random Pop Up Minimum Time（随机弹出最短时间）=2.0 s

Random Pop Up Maximum Time（随机弹出最长）=10.0 s

Time Before Hiding Type（隐藏前等待类型）=Random（随机）

Random Hide Minimum Time（随机隐藏最短时间）=2.0 s

Random Hide Maximum Time（随机隐藏最长）=10.0 s

Start Position（起始位置）=Down（倒下）

这套设置让靶子开局倒着，之后随机弹起。

添加屏障

为了管住玩家走位，不让玩家边打边摸到靶子跟前，做一道屏障把玩家挡在远处。

  • 在内容浏览器里搜索 barrier。

在搜索栏输入 barrier。

  • 把屏障（Barrier）设备拖进视口，放在靶子设备前面。

给视口添加屏障设备。

  • 在细节面板的用户选项（User Options）下，设 Barrier Depth（屏障进深）、Barrier Width（屏障宽度）、Barrier Height（屏障高度），让屏障和射击场区域一样大，用变换箭头按需摆位置。
  • 打开 Barrier Material（屏障材质）下拉菜单，选 Clear（透明），屏障就透亮了。

选择透明屏障材质，去掉屏障上的图案。

  • 往下滚到 Block Weapon Fire（阻挡武器开火），取消勾选。

玩家出生后可以在屏障后的区域闲逛，但进不了射击场区域。
