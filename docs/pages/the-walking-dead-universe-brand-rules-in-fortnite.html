行尸走肉宇宙（TWDU）品牌规则

在 Fortnite 创意模式与 UEFN 中使用专属模板和资产构建行尸走肉宇宙（TWDU）岛屿时，必须遵守以下品牌规则与创作者义务，违规将面临内容下架与收益、模板权限乃至账号方面的处罚。

跳入 Fortnite 创意模式与虚幻编辑器 Fortnite 版（UEFN），使用专属模板和资产（assets）构建行尸走肉宇宙（The Walking Dead Universe，TWDU）岛屿吧！使用 TWDU 资产与岛屿伴随着一定的责任与期望，以下是创建 TWDU 岛屿的一系列准则。

使用 TWDU 模板的规则

要使用行尸走肉宇宙（The Walking Dead Universe，TWDU）模板进行构建，除遵守Fortnite 开发者规则（Fortnite Developer Rules）以及变现协议等其他现有协议外，还需要遵守以下规则。

行尸走肉宇宙品牌规则

使用行尸走肉宇宙模板构建、并推广使用了 TWDU 模板的岛屿时，你必须遵守 Fortnite 开发者规则、所有其他相关协议以及以下规则，否则可能面临下文所述的后果。

  • 仅在你的 TWDU 岛屿中使用行尸走肉宇宙资产。这条规则仅适用于与行尸走肉系列相关的资产，你可以在 TWDU 岛屿中使用与行尸走肉无关的资产。我们向你开放的角色与资产仅来自 Skybound 出品的行尸走肉漫画，请勿使用来自任何其他第三方的行尸走肉 IP。如果你使用了 TWDU 工具集中提供的资产之外的其他行尸走肉资产，你的项目可能审核失败，并面临 DMCA 下架等其他后果。
  • 不要把行尸走肉宇宙岛屿称为“The Walking Dead”或“TWD”。如果你选择提及行尸走肉宇宙岛屿，只能使用“The Walking Dead Universe”或“TWDU”。
  • 不要使用源自 AMC 行尸走肉电视剧的内容。不要使用只存在于行尸走肉电视剧、而不存在于行尸走肉漫画中的内容、角色或其他 IP。例如，达里尔（Daryl）、玛丽（Mary）、莫尔（Merle）、萨莎（Sasha）、莉齐（Lizzie）、米卡（Mika）、鲍勃（Bob）、T-Dog、亨利（Henry）、小瑞克（Rick Grimes Jr）、贾迪斯（Jadis）、贝丝（Beth）、奥尔登（Alden）、西蒙（Simon）、杰里（Jerry）和戴安娜（Deanna）等角色只存在于电视剧中，因此禁止出现在你的行尸走肉宇宙岛屿中。此外，禁止使用与电视剧演员形象相似的图片或角色。
  • 仅使用我们提供的行尸（Walker NPC）自定义配置。你可以通过 NPC 角色定义（NPC Character Definition）配置行尸的外观与行为，不要使用其他工具修改行尸的行为、外观或感觉，那会破坏行尸走肉宇宙独特而恐怖的氛围这一核心魅力。
  • 不要出售或再分发行尸走肉宇宙资产。不得出售、许可或分发任何独立的行尸走肉宇宙资产。
  • 发布岛屿时，TWDU 岛屿必须包含 TWDU 内容。要被认定为 TWDU 岛屿，你的岛屿必须至少包含一件（1）来自 TWDU 游戏合集的工具、设备或资产。

TWDU 品牌规则由 Epic Games 与 Skybound 共同执行，Skybound 可就违反 TWDU 品牌规则的岛屿向 Epic Games 举报。

如果你的岛屿被发现违反 TWDU 品牌规则，你的内容将被移除，且该岛屿将无法获得互动收益（engagement payout）。如果你屡次违反 TWDU 品牌规则，将失去 TWDU 模板的使用权限；持续违规可能导致日益严厉的限制乃至账号封禁。

不得将 TWDU 资产与第三方 IP 混用

TWDU 岛屿已预置符合品牌要求的 TWDU 资产、按协议允许你使用的资产，以及 Epic Games 拥有或授权的特定资产。IP 合作伙伴授权协议明确规定：即使已获得该 IP 所有者的许可，你也不能将 TWDU 资产与其他第三方知识产权（IP）混合使用。只要符合 Fortnite 开发者规则、上述 TWDU 品牌规则及所有其他相关协议，你可以导入并使用你拥有全部权利的资产；你也可以使用 Epic Games 直接提供给你的其他资产，但不包括来自其他 IP 合作伙伴计划伙伴的资产（例如乐高®（LEGO®）岛屿的资产）。

如果你违反这条规则，你的岛屿可能无法获得互动收益，并可能从生态系统中被移除或禁用；持续违规可能导致日益严厉的限制乃至账号封禁。

TWDU 岛屿变现

Skybound 向你提供其内容的有限许可，允许你使用经批准的 TWDU 资产，将官方授权的 TWDU 体验带入 Fortnite 生态，为 Fortnite 社区创造新型岛屿。作为回报，你必须遵守 IP 合作伙伴授权协议（含 TWDU 品牌规则）、Fortnite 开发者规则、社区准则及所有其他相关协议的条款，唯一获批的 TWDU 资产与功能是经由指定模板访问的那些。

作为 Skybound 授权你使用 TWDU 资产创建 TWDU 岛屿的对价，你同意将岛屿总收益的 12% 分给 Skybound。Epic Games 会从你的互动收益中自动扣除该金额并分发给 Skybound，你获得剩余部分。当你同意 IP 合作伙伴授权协议时，即表示同意这一流程。

该 IP 目前不支持岛内交易（in-island transactions）。

使用 TWDU 资产

用包含 TWDU 资产的独特模板成为行尸走肉宇宙的一员吧，包括英雄武器湿婆霰弹枪（Shiva Shotgun）与露西尔（Lucille）——那支源自行尸走肉漫画的标志性球棒。生成拥有独特攻击类型与尸群行为的行尸 NPC，连最勇敢的玩家也会被吓到。你可以在使用 TWDU 岛屿（Working with TWDU Islands）中查看其他预制件、画廊、武器、物品等。

推广你的 TWDU 岛屿

为你的岛屿制作宣传物料时，请参考推广你的 Fortnite 岛屿（Promoting Your Fortnite Island）中的指南。确保图片与视频准确反映你创建的岛屿或玩法机制，不要抄袭其他游戏或开发者。你对 TWDU 岛屿的推广必须遵守 TWDU 品牌规则、Fortnite 开发者规则（Fortnite Developer Rules）、社区准则及其他相关协议（如 Fortnite 开发者规则第 3 节）。推广中的内容与表述必须与这些规则和协议中的内容规则及指南一致，并适合你岛屿目标受众的年龄。

你的岛屿在发现页（Discover）中

在创作者门户（Creator Portal）中，TWDU 岛屿会在发布过程中自动打上“The Walking Dead Universe”标签，该特殊标签将出现在产品详情页上。

开发者制作的 TWDU 岛屿会出现在发现页（Discover）中并可被搜索，与其他 Fortnite 岛屿一样。

遇到问题可在开发者论坛（Developer Forums）提问，或在学习库（Learning Library）中编写、阅读教程。
