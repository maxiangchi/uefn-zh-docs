UEFN 中的 Verse 新手模板

通过 VKT - Verse 设备新手游戏（VKT - Verse Device Starter Games）模板进入 Verse 的世界，游玩 Verse Commander 小游戏：向角色发送指令来解开谜题。

英文原标题：Verse Starter Template in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

通过 VKT - Verse 设备新手游戏（VKT - Verse Device Starter Games）模板进入 Verse 的世界，游玩 Verse Commander 小游戏——通过向角色发送指令来解开谜题。

小游戏（minigame）是短小、自包含的体验，可以作为你主游戏的配套内容。它们可以简单到一连串按钮操作，也可以复杂到完整游戏模式。你可以用小游戏更好地控制游戏节奏、探索新机制与新想法——或者，仅仅因为它们好玩！小游戏通常高度可扩展：从一份简单的机制清单出发，你就有很大空间在每款游戏中创造多样性。

本模板教程将带你一步步创建 Verse Commander 小游戏：在一系列棋盘上引导 NPC 角色抵达终点。你将使用自定义 Verse 指令控制 NPC，把界面（UI）上的选择直接转化为角色行动。

Verse Commander 展示了如何用 Verse 管理游戏，包括：

  • 在 Verse 设备与 NPC 行为（NPC Behavior）脚本之间传递数据。
  • 使用在 Verse 中创建并更新的自定义动态游戏内界面（UI）。
  • 在 Verse 中协调视觉特效（VFX）与过场动画（cinematics），对游戏状态给出视觉反馈。
  • 以及更多！

这个示例中有不少 Verse 代码，但它们分散在多个文件与类中，设计上易于自定义，可直接放入你自己的体验中。根据职责把代码拆分到不同文件，并以可扩展为目标设计代码，不仅能帮你快速迭代核心玩法，还能让你更轻松地把小游戏复用到多个体验中。

上手准备

在游玩 Verse Commander 小游戏之前，你需要完成以下操作：

  • 在 UEFN 中以 VKT - Verse 设备新手游戏（VKT - Verse Device Starter Games）模板创建新项目。
  • 在大纲（Outliner）中搜索设备 Verse Commander Minigame，选中该设备以打开其详情（Details）面板。
  • 在其详情面板中选择 VerseTagMarkup 组件，查看其在详情面板中的设置。
  • 在标签（Tags）下编辑 标签（Tags）属性，添加 Verse 标签 verse_commander_minigame_tag。
  • 启动会话（session），开始游玩 Verse Commander 小游戏！

查看玩法标签（Gameplay Tags），了解在项目中使用标签的更多信息。

总览

按以下步骤深入了解这款小游戏的创建过程：

  1. 1. 创建 NPC 行为（Creating the NPC Behavior）
    学习在 Verse 新手模板中如何用指令控制 NPC。
  2. 2. 定义游戏棋盘（Defining Boards for the Game）
    创建可在 Unreal Editor for Fortnite 中用 Verse 自定义的模块化关卡。
  3. 3. 设计关卡（Designing Levels）
    学习如何为俯视视角设计关卡，以及如何通过指令控制角色。
  4. 4. 表示指令数据（Representing Command Data）
    学习如何在 Verse 代码中表示与使用角色指令。
  5. 5. 用界面控制 NPC（Controlling the NPC with UI）
    学习如何用 Verse 创建并更新自定义动态游戏内界面（UI）。
  6. 6. 管理游戏循环（Managing the Game Loop）
    学习如何在 Verse 新手模板中定义小游戏的核心行为。
  7. 7. 最终成果（Final Result）
    查看创建 Verse 新手模板用到的全部 Verse 代码。
