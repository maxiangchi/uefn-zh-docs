UEFN 中的预制件与预制件实例

学习使用这一 Beta 功能，但在将其用于正式发布的项目时请谨慎。预制件是使用实体与组件层级来保存所有预制件实例共享的基础信息的稳定对象。

英文原标题：Prefabs and Prefab Instances in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

注意：学习使用这一 Beta 功能，但在将其用于正式发布的项目时请谨慎。

预制件 (Prefab) 是使用实体与组件层级来保存所有预制件实例共享的基础信息的稳定对象。

这让你在继续搭建和设计关卡时，可以更轻松地将预制件作为整体或按部件进行编辑。你可以实例化 Scene Graph (场景图)中创建的资源并对其进行覆盖，从而创建新的游戏对象和预制件。

预制件就像游戏对象的印章，你可以将预制件在场景中放置任意多次。你创建的所有实例都可以作为一个整体或单独进行编辑。

要进一步了解预制件的强大功能与潜力，请参阅以下文档：

  • Scene Graph Sample Tutorial (场景图示例教程)
  • Create a Platformer with Scene Graph (使用场景图创建平台跳跃游戏)

将实体另存为预制件

预制件应尽可能紧凑，你的预制件设计不应过于复杂。包含大量实体和组件的预制件会占用过多数据，可能给项目带来问题。

一个实体一次只能使用一种组件类型。这意味着一旦选择了某种组件类型，就无法在同一实体上重复使用该组件类型。要使用相同的组件，需要添加另一个实体，然后将相同的组件添加到新实体上。

要创建预制件：

  • 在 Outliner (大纲视图)中右键单击父实体，然后选择 Save As Prefab… (另存为预制件…)。此时会打开 Create New Prefab (创建新预制件)窗口。

    点击图片可放大。

  • 你可以先在 Outliner (大纲视图)中嵌套实体，也可以在之后于 Prefab Editor (预制件编辑器)中向预制件添加新实体。
  • 为预制件命名，然后选择 Create entity Class (创建实体类)。Prefab Editor (预制件编辑器)随即打开，视口中显示你创建的预制件。预制件缩略图会出现在 Content Browser (内容浏览器)中。

预制件可以在 Outliner (大纲视图)中嵌套和分组，以便更轻松地进行编辑。

  • 选中预制件缩略图，将预制件从 Content Browser (内容浏览器)拖入视口。这会创建该预制件的另一个实例。

将更改传播到所有预制件实例

预制件实例不仅仅是原件的视觉复制品。使用Prefab Editor (预制件编辑器)进行更改后，所有实例会自动采用所有已保存的更改。使用 Scene Graph (场景图)中的层级有助于确定子预制件和实体如何与父级交互。特别是当你使用的资源的轴心点可能偏离中心，或未使用 Unreal Units (虚幻单位)与世界中的对象对齐时，这一点非常有用。

这为你节省了时间，因为你不必找到每个预制件实例并一遍又一遍地重复相同的更改。

你还可以将不同的预制件组合在同一层级中，以创建更复杂的预制件。

覆盖预制件实例

你可以覆盖预制件实例中的组件，使更改仅适用于单个实例。覆盖组件后，Outliner (大纲视图)中的实体、组件卡以及 Details (详情)面板中被覆盖的组件旁边都会出现 Override (覆盖)图标。

覆盖会以上级预制件设计为基础，在受影响组件的层级上，用该组件被覆盖的属性更改来替代原设计。你可以通过两种方式覆盖组件：

  • 在 Prefab Editor (预制件编辑器)中编辑预制件。
  • 从组件卡覆盖实体或组件。

在Prefab Editor (预制件编辑器)中，添加新组件或创建 Verse 组件，为预制件添加移动或交互等功能。在 Prefab Editor (预制件编辑器)中保存这些更改，可确保场景中该预制件的每个实例都发生相应更改。

覆盖实体可通过添加新组件，或通过创建 Verse 组件来添加移动或交互等功能来实现。

从预制件实例的组件卡覆盖实体或组件，会将独特的更改仅应用于该单个实例。如下图所示，两座木屋基于同一个原始预制件设计，但第二座房屋在关键组件的组件卡上进行了覆盖，更换了不同的网格体，或将预制件的某些部分转向不同方向，从而展示出房屋的新面貌。

点击图片可放大。

要覆盖组件：

  • 在 Content Browser (内容浏览器)中，将预制件的实例拖入视口。
  • 在 Details (详情)面板中选择该预制件实例的 sphere_light_component (球形光源组件)卡。

    点击图片可放大。

  • 点击 component card menu button (组件卡菜单按钮)，然后选择 Override Component (覆盖组件)。
  • 为该组件选择新属性。该实例上此组件的覆盖即与父预制件不同，即使你之后更改父预制件，该覆盖也会保持不变。

覆盖图标

覆盖图标是蓝色圆形，中间有一支向下的蓝色箭头。该图标表示此实体中的组件已被覆盖。当实体被覆盖后，你可以在场景中多次使用它们，这些实体在预制件中仍能一致地工作。

在预制件确定后新增的实体带有绿色圆形、中间有加号，用于表示它们是后来添加的。

点击图片可放大。

预制件层级

预制件层级通过将实体和预制件嵌套在一个父预制件或实体之下创建。设置父子关系可以：

  • 缩放预制件的组件功能，以指定预制件在场景中的工作方式。
  • 确定子实体如何与父预制件交互。

点击图片可放大。

通过轴心点放置，层级可以将资源吸附到场景中的特定矢量上。这不仅有助于布景，也有助于使用坐标的玩法元素。

轴心点放置与网格吸附

Pivot points (轴心点)和grid snapping (网格吸附)与实体的transform_component (变换组件)配合使用，以在场景中对齐游戏对象和预制件。

Prefab Editor (预制件编辑器)不使用网格来缩放预制件。请使用 Outliner (大纲视图)的右键菜单来确定预制件轴心点的偏移。

网格吸附与资源的大小相关。为确保资源按预期工作，应将其缩放到 512 Unreal Units (虚幻单位)，并使用 UEFN 中设置的相同网格度量。如果不重新缩放资源，请重置资源的轴心点，并重新缩放网格吸附设置。

将轴心点放在预制件中心并不适用于所有资源类型，例如楼梯。此时可以使用 Modeling Mode (建模模式)中的 Edit Transform (编辑变换)选项来偏移轴心点，以确保资源在世界中出现在你想要的位置并正确对齐。

可通过Left-Up-Forward Coordinate System (左-上-前坐标系)文档进一步了解 3D 世界空间。

Scene Graph (场景图)中的组合

Scene Graph (场景图)中的组合提供了一种对齐资源的方法。所有子实体和预制件都围绕父对象按偏移旋转。如果你将预制件结构旋转 360 degrees (360 度)，该对象会围绕其在网格上的中心移动。

在 UEFN 中旋转 actor 时，旋转由该 actor 在世界中的位置决定。这使得对齐单个 actor 以组成完整结构更加困难。

使用 Scene Graph (场景图)中的层级有助于确定子预制件和实体如何与父级交互。特别是当你使用的资源的轴心点可能偏离中心，或未使用Unreal Units (虚幻单位)与世界中的对象对齐时，这一点非常有用。

在场景中将装饰性资源相对于其所依附的父预制件放置时，层级也很有帮助。

点击图片可放大。

要进一步了解 Transform (变换)组件，请参阅Transforms in Scene Graph (场景图中的变换)文档。

Verse 中的预制件类

你在项目中创建的预制件会作为类暴露给 Verse，位于项目的 Assets.digest.verse 文件中。你可以通过实例化 Prefab (预制件)类，并使用 Verse 将其添加到场景中的实体来生成预制件实例。

要进一步学习使用预制件，请参阅Creating Your Own Component in Verse (在 Verse 中创建你自己的组件)。
