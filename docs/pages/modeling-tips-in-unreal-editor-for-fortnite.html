UEFN 建模技巧（Modeling Tips）

在常用 3D 软件中为 UEFN 创建资产前，先了解资产朝向、道具建模、命名规范与 UV 要求，确保道具在 UEFN 中顺畅运行。

英文原标题：Modeling Tips in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

在你最顺手的 3D 软件中为 虚幻编辑器 Fortnite 版（UEFN）项目创建资产（assets）之前，请先读完下面的建模注意事项，确保你创建的道具能在 UEFN 中顺畅运行。

为确保使用正确的比例，请参阅在 UEFN 中创建 Fortnite 就绪资产，了解单位、比例与网格尺寸。

摆放资产朝向（Orienting Your Assets）

Blender

  • Z 轴朝上，Y 轴正方向朝前；
  • 用 Y 轴正方向作为模型的正面朝向。

Maya

  • 坐标系设为 Z-up，Y 轴负方向为正确的正面朝向；
  • 导入 UEFN 后会自动转换为 Y 轴正方向。

3DS Max

  • 使用右手系、Z 轴朝上的世界坐标系。视口前视图中，Y 轴正方向指向屏幕内侧。

建议在 blockout（白盒）阶段就把网格体（mesh）导入，确认其在 UEFN 中的坐标正确，及早发现其他问题，避免细化后再返工。

要让资产在 Fab Marketplace 中正确显示，请做到：

  • 制作时就匹配 Z-up 轴，或在导出时转换以匹配 UEFN，否则资产导入时朝向可能错误；
  • 轴心点（Pivot points）应便于顺畅组装，并基于网格体本身而非场景来放置。一般把轴心点放在地面高度；需要随机旋转的网格体，应把轴心点放在网格体中心。

创建道具（Creating a Prop）

用你最顺手的 3D 工具为 UEFN 创建自定义资产。

在为对象（object）设计基础网格体时，遵循以下指南，创建同时面向 Fab Marketplace 与 UEFN 就绪的资产。

创建 UEFN 资产时可能遇到的问题清单，请参阅《在 UEFN 中创建 Fortnite 就绪资产》中的资产故障排查（Asset Troubleshooting）一节。

多边形建模（Poly Modeling）

  • 从原型（blockout 资产）起步，确定资产的剪影与大体观感，观察其与角色比例的关系。合适后再深入细化；
  • 网格体应定向（oriented），使正面朝向与 UEFN 中的 X 轴（axis）正方向一致；
  • 物体应有厚度，例外情况可用双面材质处理；
  • 倒角边不能小于 0.5 厘米；
  • 尽可能做成连续网格体，注意内部多边形；
  • 网格体表面复杂度保持尽可能简单，让资产文件尽可能小；
  • 如果资产包含可独立使用的部件，应做成模块化。例如集市摊位带篮子与水果：可以是一个整体，也可以把篮子、水果做成可单独使用的独立网格体；
  • 删掉不需要的东西；
  • 为 3D 资产制作平铺材质时，使用面加权法线（normals）以获得平滑边缘。

多边形、顶点与象限（Polygons, Vertices, and Quadrants）

  • 资产保持低多边形、简洁；
  • 把部件焊接在一起，避免网格体出现破洞：元素之间不应有孔洞。如果物体可独立使用，要分别考虑（例如桌子和椅子应是不同对象、不同 TextureSet，可独立使用）；
  • 网格体保持干净，尽量用四边面，只在必要处用三角面，注意重叠面；
  • 平坦处布线稀疏、复杂处布线密集：平坦表面用更少的多边形；
  • 最终顶点（vertex）数以 UE 中的统计为准，而非建模软件中的数字：硬边、多重平滑组、多余 UV 都会增加引擎内最终顶点数。

水密结构（Watertight Construction）

能否做出水密资产取决于你的设计选择。建模软件一般有高亮边界边的选项，帮你找到未焊接的边。用清理工具查找有问题的几何体，确保资产没有背面（backfaces）与缝隙。

静态网格体命名规范（Static Mesh Naming Conventions）

命名资产时，要能看出资产是什么。例如网格体是椅子，命名就应包含 "chair"。

同一网格体有多个时，在资产名后加编号：Blue_Highback_Chair_01、Blue_Highback_Chair_02，以此类推。

UV

网格体至少需要一套 UV。建筑资产的第二套 UV 用于区分不同的 texture set（纹理集）指派；自定义材质可以用多套 UV 实现更多效果。

要正确排布 UV：若采用高模烘焙流程，所有 UV 必须在 [0 到 1] 空间内；若使用平铺材质，UV 可以超出 [0 到 1] 空间并重叠。

不要拉伸 UV 或 UV 孤岛（UV islands），UV 排布尽可能紧凑高效。

创建 UV 时：

  • 使用 纹素（texel）密度 1024 px/m（该数值可因物体而异）；
  • 按对象分组 texture set，例如桌椅应由基础 T_Table01Base_[TextureSet] 与 T_Chair01_[TextureSet] 组成；
  • 把 UV 孤岛放在 [0 到 1] 方框内；
  • 尽可能缝合 UV 孤岛以减少接缝，UV 孤岛数量越少越好；
  • 为物体的所有元素创建 UV。

为可平铺材质创建 UV 时的额外注意事项：

  • UV 孤岛可以带不同偏移重叠；
  • UV 孤岛水平放置，便于后期切换材质：这样换材质、做变体更方便；
  • 用 Relax 选项与边/环对齐工具横平竖直地对齐 UV，拉伸更小；
  • UV 孤岛拉直得越平滑越好。

把选中区域拉直以展平 UV 孤岛时，某些建模软件会引入拉伸。

材质文件命名规范（Material File-Naming Conventions）

纹理与材质的文件命名与静态网格体命名规范类似：材质名应能看出材质用途与类型。

如果材质属于一组资产，组内所有物品使用同一标识。例如制作马戏团主题的一套道具、材质与纹理，就在命名中加入主题（Circus_Stripe_Material）。命名不同会被视为新材质，需要重新创建。
