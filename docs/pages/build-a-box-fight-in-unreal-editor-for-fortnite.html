在 UEFN 中构建盒子战 Box Fight 游戏

盒子战（Box Fight）是快节奏的近距离射击玩法，本教程将一步步带你在 UEFN 中创建盒子战游戏，包括搭建关卡、添加设备与关联设备。

英文原标题：Build a Box Fight in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

盒子战（Box Fight）是一种快节奏的射击玩法，玩家在非常有限的空间内相互淘汰。开局前屏障会把玩家隔开，让每位玩家在屏障落下之前快速搭建防御。

本教程将一步步带你在虚幻编辑器 Fortnite 版（UEFN）中创建盒子战游戏。

如果你是第一次使用 UEFN，请先花几分钟熟悉 UEFN 的基本操作（Controls）与大纲视图技巧（Outliner Tips）。

UEFN 支持你在制作过程的任何阶段试玩关卡。点击视口左上方的启动会话（Launch Session）按钮：

等待 FN 客户端加载你的关卡，然后开始测试。

总览

以下是按推荐顺序复刻这座岛屿所需的步骤：

  • 1. 设置盒子战游戏：创建新项目并修改岛屿设置。
  • 2. 搭建关卡：建造盒子战区域，包括主对战区下方的地下室。
  • 3. 添加设备：添加并配置构成盒子战的各个设备。
  • 4. 关联设备：通过直接事件绑定或 Verse 脚本关联这些设备。

如果你想做出可运行的盒子战游戏，每一步都不可或缺，缺一不可！
