在 UEFN 中使用动画网格体设备（Animated Mesh）

动画网格体（Animated Mesh）设备让创作者可以在 UEFN 中为骨骼网格体播放 FBX 动画，把动画文件变成玩家可以互动的新角色。

英文原标题：Using Animated Mesh Device In Unreal Editor For Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

动画网格体（Animated Mesh）设备（Device）让创作者可以在虚幻编辑器 Fortnite 版（UEFN，Unreal Editor for Fortnite）中，为骨骼网格体（Skeletal Mesh）（FBX 文件）播放 FBX 动画文件。你可以把它理解为：为玩家创建可互动的新角色（Actor）。

例如：

  • 在关卡终点创建一个供玩家挑战的首领（Boss）。
  • 创建一个玩家可以互动的新 NPC。
  • 移动道具（Prop）或为其制作动画。
  • 创建特殊动画，配合过场动画序列设备（Cinematic Sequence Device）制作关卡（Level）之间的过场动画（Cutscene）。

该设备的内存（Memory）占用取决于引用的动画集。

请试玩测试你的动画，确保它们在 Fortnite 创意模式中正常工作。

查找并放置设备

  • 打开内容浏览器（Content Browser）。
  • 打开 Fortnite 文件夹索引列表。
  • 打开 Devices 文件夹。
  • 选中动画网格体（Animated Mesh）设备，将其拖入视口（Viewport）。
  • 在大纲视图（Outliner）面板中选中动画网格体设备。
  • 在细节（Details）面板中自定义动画网格体设备的选项。

如果在岛屿上放置了同一设备的多个副本，为它们重命名会很有帮助。选择与每个设备用途相关的名称（Name），方便记住每个设备的作用。

用户选项

该设备用于为骨骼网格体应用动画。将其拖入视口后，你可以调整设备的缩放、轴向（Axis）（X、Y、Z）与旋转。沿 Z 轴提拉设备可显示底座，并让它平稳地放置在关卡平面上。

你可以通过以下选项配置该设备。

默认值以粗体显示。

选项取值说明
循环（Loop）真（True）、假（False）循环播放动画。
播放速率（Play Rate）1.0、选择播放速率设置动画播放的速度与速率。
骨骼网格体（Skeletal Mesh）从下拉菜单中选择骨骼网格体文件将选中的骨骼网格体附加到设备。
动画（Animation）从下拉菜单中选择动画文件将动画文件附加到设备。

直接事件绑定

UEFN 中的设备使用直接事件绑定（Direct Event Binding）进行通信。要在 UEFN 中为设备设置直接事件绑定：

  • 在大纲视图（Outliner）面板中选中该设备。
  • 打开细节（Details）面板。
  • 找到用户选项-函数（User Options-Function）。
  • 选择要交互的设备（Device）。
  • 设置当动画网格体（Animated Mesh）触发该设备时，设备执行的函数（Function）。

函数

函数（Function）会告诉所选设备：当触发设备执行动作时，它需要做什么。

选项取值说明
播放动画事件（Play Animation Event）点击 Add（添加）图标选择设备，再选择事件当所选设备与事件触发动画网格体设备时播放动画。
暂停动画事件（Pause Animation Event）点击 Add（添加）图标选择设备，再选择事件当所选设备与事件触发动画网格体设备时暂停动画。
倒放动画事件（Play Reverse Animation Event）点击 Add（添加）图标选择设备，再选择事件当所选设备与事件触发动画网格体设备时倒放动画。
