版本控制

版本控制（又称源代码控制或修订控制）用于跟踪和管理软件代码的变更，是团队协作开发同一项目时的基础工具。

英文原标题：Version Control · 查看英文原文 · 社区翻译镜像，仅供学习

版本控制（Version control，又称源代码控制 Source control 或修订控制 Revision control）是一种跟踪和管理软件代码变更的方式。当程序员团队在同一个项目上协作时，这非常有用。如果有人犯了错，版本控制可以比较代码的早期版本，从而在不打断其他人工作的情况下发现并纠正问题。
