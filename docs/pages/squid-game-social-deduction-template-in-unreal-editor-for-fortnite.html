鱿鱼游戏社交推理模板（UEFN）

在社交推理（Social Deduction）模板里谨慎选择盟友、谋定而动：背叛是鱿鱼游戏的核心主题之一。本指南配合模板，带你深入伪装、投票、藏身、动态组队等玩法，复刻鱿鱼游戏的猜疑与欺骗。

英文原标题：Squid Game Social Deduction Template in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

在社交推理（Social Deduction）模板里谨慎选择盟友，一路谋定而动。背叛是鱿鱼游戏核心主题的心脏——常常披着社交推理与欺骗的外衣。

社交推理模板在玩家之间埋下这种情境，播撒欺骗与猜疑的种子。把它和你的小游戏（mini-game）内容搭配，能在玩家之间再添一层不信任与未知。

伪装设备（Disguise Device）玩法

玩转社会阶层是加深猜疑与欺骗的另一招。比如通过职业选择器（Class Selector）设备，让出生为警卫的玩家比出生为参赛者的玩家更强，自然形成非对称对抗。但反过来，一群参赛者围殴警卫的威胁，可能和单个警卫的枪一样可怕。

把本指南当模板的配套读物，深入以下内容：

  • 围绕社交关系、欺骗与背叛的体验。
  • 核心设备的设置。
  • 鱿鱼游戏特性集。

上手

该学习模板仅 Unreal Editor for Fortnite（UEFN）可用。

获取模板：

  • 打开 UEFN。
  • 在项目浏览器（Project Browser）点击品牌模板（Brand Templates）> 鱿鱼游戏（Squid Game）> 社交推理（Social Deduction）。
  • 新建项目。

创建项目与使用鱿鱼游戏岛屿模板的更多信息，请参阅游戏合集（Game Collections）。

想获得最佳模板体验，请编辑器和 Fortnite 游戏客户端（会话）双开。在 Fortnite 会话里玩游戏、读编辑器内指南。

用大纲视图（Outliner）导航到各房间，查看设计房间用到的全部资产。

大纲视图中的房间文件夹组织

加载房间

一进主题加载房间，直接空降鱿鱼游戏世界。穿过每扇标牌门，了解每种机制与主题。每个房间都以一条教学走廊开场，再接一个游戏示例。

社交推理游戏房间（Social Deduction Game Rooms）

学着在玩家之间创造新交互，解锁更多连接方式，讲出更有意思的故事。每个房间聚焦一种设备，抓住鱿鱼游戏的主题。

我们能信谁？周围的人真的是他们自称的那样吗？眼见不一定为实，尤其是有了伪装设备（Disguise）。匿名（如隐藏名牌）会助长冒险行为，匿名暴民的意志混乱、可怕又危险，背叛随时可能降临。

房间（设备）玩法
Disguise Device（伪装设备）用伪装混进 NPC 群，躲避狙击手的侦察。当狙击手，在 NPC 中找出玩家，子弹有限，开枪要慎重。
Voting Device（投票设备）用投票设备答题，答错吃后果。哪怕胸有成竹，看到别人选了不同答案，玩家也会动摇。Verse 关卡资产中有 Verse 示例。
Hiding Props（Giftbox，藏身道具）时间有限，找出藏起来的人。当藏身者，用 Giftbox 设备戏耍搜寻者。Verse 关卡资产中有 Verse 示例。
Dynamic Team Emotes（动态组队表情）用动态组队表情换队伍，拿不同资产。

加载房间摆了多个生成器，多人体验最佳。你可以用多人预览（multiplayer previewing）测试部分房间。

每个房间都用主题画廊集的资产，还原鱿鱼游戏美学。构思鱿鱼游戏岛屿时，记得留心这些设计元素。这些画廊集的更多信息，请参阅使用鱿鱼游戏岛屿（Working With Squid Game Islands）。

继续学习

把特性集和定制设备结合，给岛屿加上社交推理与背叛，抓住鱿鱼游戏的神韵，继续学习：

  • 用伪装欺敌（Deception Through Disguises）：学用伪装设备与套件，给鱿鱼游戏岛屿加欺骗。
  • 创造投票机会（Create Voting Opportunities）：学用投票设备装点鱿鱼游戏岛屿。
  • 藏身传送 Giftbox 设备（Giftbox Device for Hiding and Teleportation）：学用 Giftbox 设备在鱿鱼游戏岛上藏身与传送玩家。
  • 用表情建临时队伍（Create Temporary Teams Through Emotes）：学着给鱿鱼游戏岛加表情，让玩家自建临时队伍。
  • 鱿鱼游戏自定义 UI（Squid Game Custom UI）：学着给岛屿加上鱿鱼游戏自定义 UI。
