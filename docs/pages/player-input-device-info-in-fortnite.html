玩家输入设备信息（Player Input Device Info）

通过读取每位玩家设备的输入能力与上下文，打造自适应的玩法与界面：玩家输入设备信息 API（Player Input Device Info API）扩展了 player_input 类，新增两个属性，让你不仅知道存在哪些输入，还能了解玩家正以何种方式实际操作游戏。

通过读取每位玩家设备的输入能力与上下文，构建自适应的玩法与界面。玩家输入设备信息 API（Player Input Device Info API）扩展了 player_input 类，新增了两个属性，让你不仅能了解存在哪些输入，还能了解玩家正以何种方式实际与游戏交互。

许多设备支持同时使用多种输入类型。例如，Nintendo Switch 可同时支持手柄（gamepad）与触控（touch）。AvailableInputDevices 为你呈现完整的硬件情况，而 PreferredInputMethod 则给出一个高层级的单一分类，方便你做出诸如显示触控优先还是手柄优先界面之类的决策。

关于可用输入设备与输入方式

可用输入设备（Available input devices）描述玩家设备上当前启用的硬件能力。每种能力都是 available_input_devices 结构体上的一个逻辑（logic）字段。由于多个能力可以同时为真，该结构体为你呈现硬件支持能力的完整情况。

输入方式（input method）是一个高层级分类，表示玩家与游戏交互的主要方式。即使设备同时支持多种输入类型，PreferredInputMethod 也只会解析为单一值，便于你的代码做出直接的分支决策。

玩家输入设备信息 API 的功能

  • 通过 AvailableInputDevices 报告处于活动状态的完整输入硬件集合。
  • 通过 PreferredInputMethod 识别玩家首选的输入类别。

你可以用它做什么

你可以使用玩家输入设备信息 API（Player Input Device Info API）实现以下效果：

  • 根据玩家的实际游玩方式显示正确的按钮提示（手柄图标、触控图标或键盘快捷键）。
  • 构建随玩家设备形态自适应的界面布局，例如紧凑的移动端布局、大字体的电视端布局等。
  • 支持同时使用多种输入类型的平台：查询所有可用设备，而不是依赖对单一输入的假设。

可用输入设备

available_input_devices 结构体描述玩家可用的硬件输入能力。每个字段都是一个逻辑（logic）值，表示是否存在该能力。导入方式如下：

using { /Verse.org/Input }
字段值类型说明
Gamepadlogic是否连接了手柄（gamepad）。
Keyboardlogic是否连接了键盘（keyboard）。
Mouselogic是否连接了鼠标（mouse）。
Touchlogic是否可用触控输入（touch）。

输入方式

input_method 枚举是对玩家主要交互方式的高层级分类。导入方式如下：

using { /Verse.org/Input }
值说明
KeyboardAndMouse玩家主要使用键盘与鼠标（keyboard and mouse）。
Gamepad玩家主要使用手柄（gamepad）。
Touch玩家主要使用触控输入（touch）。

在 Verse 中使用玩家输入设备信息

以下步骤将演示如何导入模块、获取玩家的输入数据，并根据其首选输入方式或可用硬件进行逻辑分支。

导入模块

using { /Verse.org/Input }
using { /Verse.org/Simulation }
using { /Fortnite.com/Devices }

获取玩家输入并读取属性

GetPlayerInput 是一个可失败（failable）函数，必须在失败上下文（failure context）中调用。拿到 player_input 实例后，即可直接读取设备信息属性：

if (PlayerInput := GetPlayerInput[Player]):
    Devices := PlayerInput.AvailableInputDevices
    Method := PlayerInput.PreferredInputMethod

按首选输入方式分支

使用 PreferredInputMethod 决定呈现哪种界面风格：

if (PlayerInput := GetPlayerInput[Player]):
    case (PlayerInput.PreferredInputMethod):
        input_method.Gamepad => ShowGamepadUI()
        input_method.Touch => ShowTouchUI()
        input_method.KeyboardAndMouse => ShowKeyboardMouseUI()
        _ =>

检查特定硬件

当你需要在启用某功能前确认存在特定硬件时，请使用 AvailableInputDevices：

if (PlayerInput := GetPlayerInput[Player]):
    if (PlayerInput.AvailableInputDevices.Touch?):
        EnableTouchAiming()
    if (PlayerInput.AvailableInputDevices.Mouse?):
        EnableMouseTargeting()

完整示例

以下示例演示了一个设备：在玩家加入时读取每位玩家的输入设备信息，并相应地调整界面与功能。

using { /Fortnite.com/Devices }
using { /Verse.org/Input }
using { /Verse.org/Simulation }
using { /UnrealEngine.com/Temporary/Diagnostics }

input_device_info_example := class(creative_device):
    OnBegin<override>()<suspends> : void =
        for (Player : GetPlayspace().GetPlayers()):
            AdaptToPlayer(Player)

使用玩家输入设备信息的技巧

以下技巧可帮助你高效地使用玩家输入设备信息 API（Player Input Device Info API）：

  • 大多数界面决策请使用 PreferredInputMethod。即使在同时支持多种输入类型的平台上，它也只解析为单一值，分支逻辑更简洁。
  • 当某功能需要特定硬件时，请使用 AvailableInputDevices，以防在缺少该硬件的设备上出现意外行为。
  • 在玩家加入时读取设备信息属性；若玩家设备上下文可能发生变化（例如玩家从键盘鼠标切换到手柄），请再次读取。
