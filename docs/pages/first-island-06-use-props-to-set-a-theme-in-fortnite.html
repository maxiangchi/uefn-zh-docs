第一个岛屿 06：用道具定主题

用创意模式的道具与画廊资产为射击摊定下嘉年华主题，再回到 UEFN 做置景、加音频，完成你的第一个岛屿。

英文原标题：First Island 06 Use Props to Set a Theme in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

本教程的最后一步，是让你的游戏看起来像个射击游乐摊。为此，你将使用创意模式中的道具与画廊资产。

主题（theme）是游戏的基本概念，尤其指视觉风格。例如本游戏的主题是嘉年华里的射击摊，所以要选用与之相配的元素。

道具（prop）是可以摆放到岛屿上的物体，可以是家具、盖房子的墙体地板、植物等数百种东西。道具通常与一个或多个主题相配。

道具可以在预制件（prefabs，预制结构）与画廊（galleries）（同主题道具合集）中找到。为本游戏定主题，用到了以下画廊、道具与声音 cue：

  • Mega Mall（大型商场）画廊；
  • 6 x Princess Castle Toy Bunny（公主城堡玩具兔）道具；
  • 1 x Commerce Shelve Toy 02（商业货架玩具 02）道具；
  • 1 x Carnival Game Deactivation Laugh 01（嘉年华游戏停机笑声 01） Cue。

如果你在 Fortnite 创意模式中添加道具，可以以玩家角色为参照来缩放道具。

为此可以使用热键与按键绑定快捷键（Hotkeys and Keybinding Shortcuts）中介绍的热键。

在创意模式 live edit 会话中所做的更改会保存到 UEFN 中。

在创意模式中定主题（Set the Theme in Creative）

  • 在创意模式的编辑会话（Edit Session）中按 M 键打开创意模式菜单（Creative Menu），选择画廊（Galleries）；
  • 在搜索框输入 mega mall，双击第一个缩略图展开该画廊内容。
  • 找一块符合主题的地板，双击加入底部快捷栏（quick bar）。
  • 点击 Equip（装备）把想用的其他资产加入快捷栏，再点击 Exit 返回岛屿；
  • 选中条纹墙（striped wall），在网格上放置并右键确认。

    不断放置墙体，直到把靶子围起来；

  • 选中地砖地板（tile floor），左键点击放在靶房角落。

    不断放置地板，直到铺出 4 x 4 的正方形；

  • 加一堵矮墙（short wall）挡住玩家进入射击摊；
  • 在玩家身后搭出区域并加上屋顶，完成关卡设计。

接下来要做置景（set dressing），让项目更有打磨感。你将回到 UEFN 添加置景、灯光与音效，完成你的第一个岛屿。

在 UEFN 中做置景（Dress the Set in UEFN）

置景（Set dressing）指添加资产与其他细节，打造支撑游戏设计与品类的美观环境。

UEFN 有大量贴合主题的资产。

添加道具（Add Props）

准备好加道具了吗？可以找玩具、玩具货架、海报，以及一切能营造嘉年华氛围的东西。

  • 从 Windows 菜单再打开两个内容浏览器（Content Browsers）。
  • 在第二个内容浏览器窗口中打开 Fortnite > Props 文件夹，在搜索栏输入 Toys，资产视图会列出玩具道具。
  • 把 Commerce Shelve Toys 2 拖入视口，摆到你觉得好看的位置；
  • 在搜索栏输入 Princess Toy，把 Princess Castle Toy Bunny 拖到视口的墙上，营造“能赢奖品”的感觉。

添加音频（Add Audio）

在电子游戏中加入声音，会为玩家带来全新的趣味层次。声音设计应与视觉元素相得益彰。

声音 cue（sound cue）是一种音频对象，可与其他音频文件配合，实现循环（loops，重复播放）或随玩家走远而衰减（fade）等效果。

UEFN 在 Fortnite 文件夹的 Sounds 下提供了不少声音 cue。把鼠标悬停在声音 cue 上再按播放（play）图标即可试听。

声音 cue 必须配合音频设备使用。这里用音频播放器（Audio Player）设备，并把选中的声音 cue 加进去。

  • 在内容浏览器中打开 Fortnite > Devices 文件夹，在搜索栏输入 Audio。
  • 把 Audio Player 拖入视口，放在玩家出生点（Player Spawn Pad）后面。
  • 在细节面板的 Audio 下拉搜索栏输入声音 cue 名称，找到该声音 cue；
  • 从列表中选中该声音 cue，它就是这个设备播放的音频。射击摊选用的是 Fairground_Spot_11 声音 cue；
  • 取消勾选 Play on Hit 选项，玩家无需与该设备交互即可听到音效。
  • 把 Play Location 设为 Local Player，让声音跟随玩家位置播放。
  • 把 Stereo Spread 设为 2.0 m，这样在设备 2 米范围内，音频会在玩家角色左右两侧均衡播放。

绑定音频设备（Bind the Audio Device）

要让音频设备无需玩家交互就自动播放，需要把它绑定到另一个设备的事件上。

  • 在 User Options - Functions 下，点击 Play 旁的 + 图标，打开数组元素下拉菜单。
  • 在搜索栏输入 Player，找到 Player Spawn Pad。
  • 从下拉菜单选择 Player Spawn Pad，该设备的事件会出现在事件下拉框中；
  • 从事件下拉框选择 On Player Spawned。

玩家出生到岛上时，声音 cue 会立即播放。

收尾！（Wrapping It Up!）

搞定！你已经用 UEFN、创意模式和 Verse 创建了一个迷你射击摊游戏！
