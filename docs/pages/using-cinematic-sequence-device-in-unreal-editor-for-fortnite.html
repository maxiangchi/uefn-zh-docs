使用影视级过场（Cinematic Sequence）设备

影视级过场（Cinematic Sequence）设备可在关卡中播放预先制作的关卡过场（Level Sequence），在非线性时间轴上添加自定义关键帧动画，本文介绍设备的放置、用户选项与直接事件绑定。

英文原标题：Using Cinematic Sequence Device in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

影视级过场（Cinematic Sequence）设备提供了一种向关卡添加影视级过场（cinematic sequence）的方法，让你可以在非线性时间轴上添加自定义关键帧（keyframe）动画。

你可以把它理解为制作一段过场动画：展示敌人的能力、演示如何完成某项任务的重要剧情，或通过角色之间的对话推动故事发展。

有关如何在设备中配合关卡过场使用的更多信息，请参阅 Sequencer 与 Control Rig。

该设备会占用较多内存（memory），添加动画时也需要较强的算力。在岛屿上加载一个影视级过场设备需要几秒钟，因此在同一岛屿上放置多个该设备时请谨慎。

设备占用的内存量很大程度上取决于其播放资产的复杂度。请试玩测试你的过场，确保它们在 Fortnite 创意模式（Fortnite Creative）中流畅运行。

查找并放置设备

  • 打开内容浏览器（Content Browser）。
  • 打开 Fortnite 文件夹索引列表。
  • 打开 Devices 文件夹。
  • 选中影视级过场（Cinematic Sequence）设备，按住拖入视口（viewport）。
  • 在大纲（Outliner）面板中选中影视级过场（Cinematic Sequence）设备。
  • 在细节（Details）面板中配置影视级过场（Cinematic Sequence）设备的用户选项（User Options）。

如果在同一岛屿上使用了同一设备的多个副本，为它们重命名（rename）会很有帮助。你可以选用与每个设备用途相关的名称（names），这样更容易记住每个设备的作用。

用户选项（User Options）

该设备被其他设备触发时，会播放预先制作的关卡过场（Level Sequence）。把设备拖入视口（viewport）后，可以更改设备的缩放、坐标轴（axis）（X、Y、Z）与旋转。沿 Z 轴提拉设备可以让底座可见，并让它落在关卡平面上。

上图是该设备在编辑时于视口中的显示效果，并非试玩时在岛屿上的显示效果。

你可以通过以下选项配置该设备。

默认值已加粗显示。

选项取值说明
过场（Sequence）从下拉菜单中选择一个过场。你希望用该设备播放的动画。
循环播放（Loop Playback）打开开关即启用。循环播放关卡过场（Level Sequence），直到被停止。
完成状态覆盖（Finish Completion State Override）无（None）、强制保持状态（Force Keep State）、强制还原状态（Force Restore State）决定关卡过场（Level Sequence）播放完成后如何处理轨道状态。
  • 强制保持状态（Force Keep State）：强制关卡过场在轨道结束时保持其状态。
  • 强制还原状态（Force Restore State）：强制关卡过场在轨道结束时还原其状态。
自动播放（Auto Play）打开开关即启用。游戏开始时即开始播放关卡过场（Level Sequence）。打开该选项后，按阶段启用（Enabled on Phase）选项会高亮显示。
按阶段启用（Enabled on Phase）仅游玩阶段（Gameplay Only）、始终（Always）、仅游戏前（Pre-Game Only）、仅创建时（Create Only）如果勾选了自动播放，决定在小游戏的哪个阶段播放过场。
  • 仅游玩阶段（Gameplay Only）：关卡过场在游玩期间播放。
  • 始终（Always）：在任何游戏状态下都播放。
  • 仅游戏前（Pre-Game Only）：在游戏开始前播放关卡过场。
  • 仅创建时（Create Only）：在岛屿处于只读状态、游戏开始前播放。
可见性（Visibility）所有人（Everyone）、仅触发者（Instigator Only）、触发者队伍（Instigator's Team）指定谁可以看到设备播放效果。
关卡过场 Actor 始终相关（Level Sequence Actor Always Relevant）开（On）、关（Off）指定该设备在网络层面是否始终相关。关闭后，设备播放只会按距离就近复制到客户端。例如，如果播放期间在一定距离外看不到某些物体，应打开该选项。

直接事件绑定（Direct Event Binding）

UEFN 中的设备使用直接事件绑定（Direct Event Binding）相互通信。为设备设置事件绑定的步骤如下：

  • 在大纲（Outliner）面板中选中该设备。
  • 打开细节（Details）面板。
  • 找到用户选项-函数（User Options-Function）。
  • 选择一个要交互的设备（device）。
  • 设置当影视级过场触发该设备时，该设备执行的函数（function）。

函数（Functions）

函数（function）告诉被选中的设备：当触发设备执行动作时，它需要做什么。

选项取值说明
播放函数（Play Function）点击添加（Add）图标，从下拉菜单中选择函数，再选择要触发函数的设备。当所选设备与事件触发影视级过场设备时，播放过场动画。
暂停函数（Pause Function）点击添加（Add）图标，从下拉菜单中选择函数，再选择要触发函数的设备。当所选设备与事件触发影视级过场设备时，暂停过场动画。
停止函数（Stop Function）点击添加（Add）图标，从下拉菜单中选择函数，再选择要触发函数的设备。当所选设备与事件触发影视级过场设备时，停止过场动画。
暂停切换函数（Toggle Pause Function）点击添加（Add）图标，从下拉菜单中选择函数，再选择要触发函数的设备。当影视级过场被所选设备与事件触发时，在播放与暂停之间切换关卡过场（Level Sequence）。

事件（Events）

事件（event）描述被选中设备执行的一个动作，被选中的事件会触发一个函数。

选项取值说明
影视级过场设备（Cinematic Sequence device）停止时事件（On Stopped Event）当关卡过场（Level Sequence）停止时发送事件。
