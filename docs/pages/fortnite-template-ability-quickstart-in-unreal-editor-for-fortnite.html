UEFN 中的 Fortnite 模板能力快速入门

构建你的第一个 Fortnite 模板能力“Spicy Sprint（香辣疾跑）”，同时施加持续伤害与移速提升效果。

英文原标题：Fortnite Template Ability Quickstart in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

本教程将教你构建你的第一个 Fortnite 模板能力："Spicy Sprint（香辣疾跑）"能力，可同时施加持续伤害（damage-over-time）效果与移速提升。

你将创建定义模板能力的 Verse 脚本，构建赋予该能力的物品，并创建一个把物品发放给玩家的设备。

前置条件

要使用模板能力并完成本教程，必须在项目设置（Project Settings）中启用场景图实验性功能（Scene Graph Experimental Features）与自定义物品与背包（Custom Items and Inventory）。

此外，建议先阅读自定义物品与背包（Custom Items and Inventories）文档以补充背景知识，但这不是必需的。

创建 Verse 脚本

在本节中，你将创建 Verse 脚本，用于存放本教程的全部代码。

  • 在菜单栏（menu bar）上选择 Verse > Verse Explorer（Verse 资源管理器）。
  • 在 Verse Explorer（Verse 资源管理器）中右键点击你的项目，选择 Create Verse File（创建 Verse 文件）。
  • 在 Create Verse Script（创建 Verse 脚本）窗口中，把脚本命名为 template_ability_example，并选择 Create Empty（创建空文件）。
  • 在菜单栏（menu bar）上选择 Verse > Open Project in VS Code（在 VS Code 中打开项目）。
  • 输入以下代码以添加所需模块：
using { /Fortnite.com/Abilities }
using { /Fortnite.com/Devices }
using { /Fortnite.com/Itemization }
using { /UnrealEngine.com/Abilities }
using { /UnrealEngine.com/Itemization }
using { /Verse.org/SceneGraph }
using { /Verse.org/Simulation }
  • 添加一个工具函数，用于返回玩家身上的武器快捷栏组件。授予模板能力物品时将用到它。
# A utility method that gets the first fort_inventory_weapon_hotbar_component on the player.
(Player : player).GetWeaponHotbarComponent()<decides><transacts> : fort_inventory_weapon_hotbar_component =
    first (WeaponHotbarComponent : Player.FindDescendantComponents(fort_inventory_weapon_hotbar_component)) { WeaponHotbarComponent }

创建基础模板能力类

定义基础 template_ability 类及其必需的重写。编译后，创建物品预制体时可以配置该类的属性。

  • 添加 template_ability 类和 ActiveEffects 列表重写。
  • 添加 MakeContext() 与 MakeAbility() 工厂函数重写。当玩家使用能力时，这些函数负责构造能力上下文（context）与效果（effect）。
  • 保存 Verse 文件。
  • 在编辑器（Editor）中点击工具栏上的 Compile Verse（编译 Verse）。

创建 Spicy Sprint 物品预制体

接下来，构建带有 Spicy Sprint 能力的物品预制体。

  • 在内容浏览器（Content Browser）中点击 Add (+)（添加）按钮，再选择 Entity Prefab（实体预制体）。
  • 在 Create Entity Prefab Definition（创建实体预制体定义）窗口中选择 New prefab (+)（新建预制体）。
  • 把预制体命名为 PF_SpicySprintItem。
  • 双击该预制体，打开预制体编辑器（Prefab Editor）。
  • 在细节（Details）面板中：
  • 点击 Add Component (+)（添加组件）按钮，搜索 item_component 并添加。
  • 选中 item_component，在 Categories（分类）列表中添加一个条目。
  • 把新条目设为 FortniteItemCategories.WeaponMelee。
  • 点击 Add Component (+)（添加组件）按钮，搜索 fort_item_ability_component 并添加。
  • 选中 fort_item_ability_component，在 ItemAbilities（物品能力）列表中添加一个条目。

如果希望该能力仅在物品处于装备状态时可用，可以改为添加到 ItemEquippedAbilities（装备时物品能力）列表。

  • 把 Index[0] 的值设为 template_ability，然后展开 Index[0]。
  • 把 InputTrigger（输入触发器）设为 Assets_input_action，再点击新出现的下拉框并搜索 IA_Sprint。
  • 把 TargetQuery（目标查询）设为 self_ability_target_query。
  • 在 AbilityElements（能力元素）列表中添加两个条目。
  • 点击 Index[0] 下拉框并设为 fort_ability_status_effect_burn_point。该状态效果会造成周期性生命伤害。
  • 点击 Index[1] 下拉框并设为 fort_ability_status_effect_pepper_point。该状态效果会提升移动速度。
  • （可选）可以自定义每个状态效果的 StatusEffectDuration（状态效果时长）与 Time（时间）。
  • 保存预制体。
  • 把 PF_SpicySprintItem 预制体从内容浏览器（Content Browser）拖入关卡（Level），然后保存关卡。

创建物品发放设备

创建在对局开始时把 Spicy Sprint 物品发放给玩家的设备。

  • 添加 template_ability_item_granter_device 与成员变量。这声明了一个新的创意设备，并暴露模板能力物品属性，稍后可在细节（Details）面板中设置。
# A creative device that grants the assigned item to the first player.
template_ability_item_granter_device := class(creative_device):
    # The template ability item to grant.
    @editable TemplateAbilityItemEntity : entity = entity{}
  • 添加 GrantItemTo() 函数。它获取武器快捷栏与物品组件，再把物品加入快捷栏。
# Grants the TemplateAbilityItemEntity to the given player.
GrantItemTo(Player : player) : void =
    if:
        WeaponHotbarComponent := Player.GetWeaponHotbarComponent[]
        ItemComponent := TemplateAbilityItemEntity.GetComponent[item_component]
    then:
        WeaponHotbarComponent.AddItem(TemplateAbilityItemEntity)
        ItemComponent.Equip()
  • 添加 OnBegin() 回调重写，在对局开始时把物品发放给第一位玩家。
# When the session begins, grant the item entity to the first player.
OnBegin<override>()<suspends> : void =
    if (FirstPlayer := GetPlayspace().GetPlayers()[0]):
        GrantItemTo(FirstPlayer)
  • 保存 Verse 文件。
  • 在编辑器（Editor）中点击工具栏上的 Compile Verse（编译 Verse）。
  • 把 template_ability_item_granter_device 从内容浏览器（Content Browser）拖入关卡（Level）。
  • 在关卡中选中该设备。
  • 在细节（Details）面板中，把 TemplateAbilityItemEntity 设为关卡中的 PF_SpicySprintItem 预制体实例。
  • 保存关卡。

试玩测试

启动对局并试玩测试，验证按下疾跑（Sprint）时是否触发了 Spicy Sprint：受灼烧状态效果影响，你的生命会按固定频率下降，同时受辣椒状态效果影响，移动速度得到提升。

自主探索

想进一步尝试？以下是几个可以自主探索的方向：

  • 使用其他 TargetQuery（目标查询）选项，创建准星瞄准或范围效果类物品。
  • 尝试其他 AbilityElements（能力元素）类型，打造完全不同的物品。
  • 在不同的 Time（时间）值上叠加元素，创造有趣的效果序列。
