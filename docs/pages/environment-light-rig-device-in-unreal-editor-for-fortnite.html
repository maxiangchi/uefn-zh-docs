环境光照平台设备

环境光照平台（Environment Light Rig）让创作者可以为岛屿添加全局世界光照，从一天中的时间、阳光颜色入手，逐步打磨出独特的项目外观。

英文原标题：Environment Light Rig Device in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

环境光照平台（Environment Light Rig）为创作者提供了一种为岛屿添加全局世界光照的方式。

从最重要的调整入手，比如一天中的时间、阳光颜色、天光颜色和色温。在此之后，你可以添加更精细的更改，比如镜头光斑，或者渐晕（vignetting）和色差（chromatic aberration）等镜头效果。

可以把它看作创建自定义阳光、月光、地平线、反射等效果的途径。建议进行大胆的渐进式更改，为你的自然光照确定一个中间基准。先用尽可能少的调整创建项目的基础光照，再着手打磨项目的独特外观。

用最少的调整确定基础光照，意味着每次调整光照时你都不必从头开始。

环境光照平台控制整个岛屿的光照，因此该设备只能放置一次。

要使用此设备，请在世界设置（World Settings）中禁用一天时间管理器（Time of Day Manager）。

通过学习库（Learning Library）中的 UEFN 高级光照（UEFN Advanced Lighting）视频教程，学习如何在 UEFN 中使用光照工具为你的岛屿打造自定义环境。

  • UEFN 高级光照：一天时间管理器（UEFN Advanced Lighting: Time of Day Manager）
  • UEFN 高级光照：环境光照平台（UEFN Advanced Lighting: Environment Light Rig）
  • UEFN 高级光照：Lumen 曝光管理器（Fortnite UEFN Advanced Lighting Ch. 3 of 3 Lumen Exposure Manager）

查找并放置设备

  • 打开内容浏览器（Content Browser）。（术语可参考UEFN 词汇表与Fortnite 词汇表中的“内容浏览器”词条。）
  • 打开 Fortnite 文件夹索引列表。
  • 打开 Devices 文件夹。
  • 选择环境光照平台（Environment Light Rig）设备，将其点击并拖入视口（Viewport）。
  • 在大纲视图（Outliner）面板中选择环境光照平台设备。
  • 在细节（Details）面板中为环境光照平台设备配置用户选项（User Options）。

你可以通过将轴心点切换为旋转点，并在世界中旋转设备图标，将光照指向你想要的位置，以此控制光照的方向。

设备选项

该设备有许多控制光照各方面的功能，比如方向光（Directional Lighting）、天空大气（Sky Atmosphere）、天光（Sky Light）、指数高度雾（Exponential Height Fog）等。此外，还有一些高级选项，用于控制到达视口相机传感器的光量，从而生成可视化数据。

你可以从细节面板的组件字段（Component Field）中选择不同的光照组件来配置此设备。

方向光选项（Directional Lighting Options）

这些选项决定岛屿上世界光照的外观和行为。你可以控制太阳和月亮的外观、阴影的反弹方式等。

光照（Light）

强度（Intensity）

10.0，选择一个强度等级。

光源的最大照明量，以勒克斯（lux）为单位。

光照颜色（Light Color）

展开该选项后，从色轮中选择颜色，或在 RGB 字段中填写数值。

过滤光照的颜色。这可能会改变光照的有效强度。

光源角度（Source Angle）

1.5，选择一个角度。

光源角度以度为单位设置（也称为角直径）。

光源柔和角度（Source Soft Angle）

0.0，选择一个角度。

柔光光源的角度，以度为单位。

使用色温（Use Temperature）

关（Off），开（On）

设为关时，白色光将作为默认滤光颜色。将该选项切换为开，即可使用色温（Temperature）设置。

色温（Temperature）

6500.0，选择一个色温数值。

决定光源上使用的滤光片颜色。

影响世界（Affects World）

开（On），关（Off）

决定光照是否可以影响世界。禁用的光照不会以任何方式为场景贡献光照。

此设置无法在运行时更改，更改后会取消构建光照。

将此效果设为 false 与删除光照的效果相同，因此它适用于非破坏性的光照测试。

投射阴影（Cast Shadows）

开（On），关（Off）

决定光照是否应投射阴影。

间接光照强度（Indirect Lighting Intensity）

2.0，选择一个强度。

缩放该光源的光照贡献。

体积散射强度（Volumetric Scattering Intensity）

0.0，选择一个强度。

该光源的体积散射强度。它会缩放强度和光照颜色。

高级（Advanced）

展开该选项。

展开后还有控制光照通道和体积阴影的附加光照设置。

高光缩放（Specular Scale）

选择一个高光缩放设置。

高光反射的乘数。

请务必谨慎使用！除 1 以外的任何值都不符合物理规律。

此设置可用于艺术化地去除高光，模拟偏振滤镜或照片修饰效果。

阴影分辨率缩放（Shadow Resolution Scale）

选择一个阴影分辨率缩放值。

缩放用于该光源阴影的阴影贴图分辨率。默认情况下，阴影贴图分辨率根据投射者的屏幕尺寸选择。

将缩放设为零会禁用阴影贴图，但不会禁用阴影。例如，接触阴影（Contact Shadows）仍保持启用。

阴影贴图分辨率仍受“r.Shadow.MaxResolution”钳制。

阴影偏移（Shadow Bias）

选择一个偏移值。

控制该光源投射的整个场景阴影的自阴影精确程度。

为 0 时，阴影将从投射者表面开始，但会出现许多自阴影伪影。

数值越大，阴影从投射者开始的位置越远，不会出现自阴影伪影，但物体可能看起来像在飘浮。

0.5 左右似乎是个不错的折中值。这也会影响阴影的柔和过渡。

阴影斜率偏移（Shadow Slope Bias）

选择一个阴影斜率偏移值。

控制该光源投射的整个场景阴影的自阴影精确程度。

它在阴影偏移（Shadow Bias）的基础上，根据表面斜率增加偏移量。

为 0 时，阴影将从投射者表面开始，但会出现许多自阴影伪影。

数值越大，阴影从投射者开始的位置越远，不会出现自阴影伪影，但物体可能看起来像在飘浮。

0.5 左右似乎是个不错的折中值。这也会影响阴影的柔和过渡。

阴影滤波锐化（Shadow Filter Sharpen）

选择一个阴影滤波锐化量。

锐化阴影滤波的量。

接触阴影长度（Contact Shadow Length）

选择一个接触阴影长度。

用于锐利接触阴影的屏幕空间光线追踪长度。

设为零可禁用此设置。

世界空间单位的接触阴影长度（Contact Shadow Length in World Space Units）

关（Off），开（On）

锐利接触阴影的屏幕光线追踪长度使用世界空间单位还是屏幕空间单位。

接触阴影投射强度（Contact Shadow Casting Intensity）

选择一个接触阴影投射强度量。

启用了“投射接触阴影”的图元所投射阴影的强度。

  • 0 = 无阴影
  • 1（默认值）= 完全阴影

接触阴影非投射强度（Contact Shadow Non Casting Intensity）

选择一个接触阴影非投射强度量。

禁用了“投射接触阴影”的图元所投射阴影的强度。

  • 0 = 无阴影
  • 1（默认值）= 完全阴影

光照通道（Lighting Channels）

0、1、2，展开选项可直接选择通道

决定图元和光源的默认通道。

投射体积阴影（Cast Volumetric Shadow）

关（Off），开（On）

决定光照是否为体积雾投射阴影。禁用此项可以节省 GPU 时间。

渲染（Rendering）

可见（Visible）

可见（Visible）

开（On），关（Off）

是否完整绘制该图元；为 false 时，该图元不被绘制，也不投射阴影。

使用挂接父级包围盒（Use Attach Parent Bound）

关（Off），开（On）

为 true 时，该组件在挂接时使用其父级的包围盒。当多个组件挂接在一起时，这可能是一项重要的优化。

光轴（Light Shafts）

光轴遮挡（Light Shaft Occlusion）

关（Off），开（On）

决定是否使用该光源经屏幕空间模糊遮挡处理后的遮挡，来遮挡雾和大气中的散射。

设为开时，遮挡蒙版暗度（Occlusion Mask Darkness）和遮挡深度范围（Occlusion Depth Range）选项变为可用。

遮挡蒙版暗度（Occlusion Mask Darkness）

选择一个遮挡蒙版暗度量。

控制遮挡蒙版的暗度，值为 1 时不产生变暗项。

遮挡深度范围（Occlusion Depth Range）

1000000.0，选择一个遮挡深度范围量

比该距离更靠近相机的所有内容都会遮挡光轴。

光轴辉光（Light Shaft Bloom）

关（Off），开（On）

决定是否为该光源渲染光轴辉光。

对于方向光，光源方向周围的颜色将被径向模糊并加回场景。对于点光源，比光源半径（Source radius）更近的像素上的颜色将被径向模糊并加回场景。

设为开时，辉光缩放（Bloom Scale）、辉光阈值（Bloom Threshold）和辉光最大亮度（Bloom Max Brightness）选项变为可用。

辉光缩放（Bloom Scale）

0.2，选择一个辉光缩放量

缩放叠加颜色。

辉光阈值（Bloom Threshold）

0.0，选择一个辉光阈值量。

场景颜色必须大于该值，才会在光轴周围产生辉光。

辉光最大亮度（Bloom Max Brightness）

100,0，选择一个辉光最大亮度量。

应用曝光后，如果场景颜色亮度数值大于辉光最大亮度，场景颜色亮度将被重新缩放至辉光最大亮度。

辉光色调（Bloom Tint）

白色（White），选择一个颜色。

与场景颜色相乘以生成辉光颜色。

展开此选项后，你可以分别为辉光色调颜色选择 R、G、B、Y 各分量。

级联阴影贴图（Cascade Shadow Maps）

动态阴影距离（Dynamic Shadow Distance）

选择一个动态阴影距离。

可移动光源的级联阴影贴图动态阴影覆盖范围，从相机开始测量。

值为 0 时禁用动态阴影。

动态阴影级联数（Num Dynamic Shadow Cascades）

选择动态阴影级联数。

将整个场景动态阴影的视锥分割成的级联数量。

级联越多，阴影分辨率越好，但会显著增加渲染开销。

分布指数（Distribution Exponent）

选择一个分布量。

控制级联分布更靠近相机（指数大）还是更远离相机（指数小）。

指数为 1 表示级联过渡发生的距离与其分辨率成正比。

过渡比例（Transition Fraction）

选择一个过渡比例量。

级联之间渐隐区域的比例。

位于两个级联渐隐区域内的像素，其阴影会被混合，以避免质量等级之间的生硬过渡。

  • 值为零会消除渐隐区域，产生生硬过渡。
  • 值越大，渐隐区域越大，级联之间的过渡越平缓。
  • 该值表示为百分比比例（例如 0.1 = 10% 重叠）。

理想值是能隐藏过渡的最小值。增大渐隐区域可能会增加阴影渲染开销。

距离渐隐比例（Distance Fadeout Fraction）

选择一个距离渐隐比例量。

控制动态阴影影响最远端的渐隐区域大小，以动态阴影距离（DynamicShadowDistance）的比例表示。

高级（Advanced）

展开该选项。

展开后还有挂接父级包围盒的附加选项。

远阴影级联数（Far Shadow Cascade Count）

选择一个远阴影级联量。

  • 0 = 无远阴影级联

其他值表示动态阴影距离（DynamicShadowDistance）与远阴影距离（FarShadowDistance）之间由远阴影级联覆盖的级联数。

远阴影距离（Far Shadow Distance）

选择一个远阴影距离量。

远阴影级联应结束的距离。远阴影将覆盖“动态阴影距离”与该距离之间的范围。

距离场阴影（Distance Field Shadows）

距离场阴影（Distance Field Shadows）

距离场阴影（Distance Field Shadows）

开（On），关（Off）

是否使用光线追踪距离场区域阴影。

必须启用项目设置 bGenerateMeshDistanceFields，此项才会生效。

距离场阴影支持区域光，因此可以生成接触锐利的柔和阴影。

它们的锯齿伪影比标准阴影贴图少，但继承了距离场表示的所有限制（仅均匀缩放，无变形）。

这些阴影的逐对象开销较低，且不依赖三角面数，因此适合用作动态太阳的远距离阴影。

高级（Advanced）

展开该选项。

展开后还有挂接父级包围盒的附加选项。

光线起始偏移深度缩放（Ray Start Offset Depth Scale）

选择一个光线起始偏移深度量。

控制随着相机变远，光线追踪阴影与接收表面之间的偏移量。

这有助于隐藏巨大静态网格因低分辨率距离场产生的自阴影伪影。

光函数（Light Function）

光函数材质（Light Function Material）

从下拉菜单中选择一个材质。

应用于该光源的光函数材质。

只有非光照贴图光源才能拥有光函数。

体积雾内支持光函数，但仅限方向光、点光源和聚光灯，不支持矩形光。

自发光材质在低端设备上不能用作光源，因为它们无法使用动态全局光照。

应用材质后，光函数缩放（Light Fade Scale）、渐隐距离（Fade Distance）和禁用时亮度（Disabled Brightness）选项变为可用。

光函数缩放（Light Function Scale）

为 X 轴、Y 轴和 Z 轴选择光函数缩放量。

缩放光函数投影。X 和 Y 在垂直于光源方向的方向上缩放，Z 沿光源方向缩放。

渐隐距离（Fade Distance）

1000000.0，选择一个渐隐距离量。

光函数应完全渐隐至禁用时亮度（Disabled Brightness）的距离。这有助于隐藏远处光函数产生的锯齿。

禁用时亮度（Disabled Brightness）

0.5，选择一个禁用时亮度系数

指定了光函数但被禁用时应用于光源的亮度系数。例如，在使用 SceneCapView_LitNoShadows 的场景捕捉中。

应将其设为光函数材质自发光输入的平均亮度，取值应在 0 到 1 之间。

标签（Tags）

组件标签（Component Tags）

为你的光照组件创建一个数组。

你可以使用数组标签进行分组和分类，也可以从脚本访问这些标签。

性能（Performance）

最大绘制距离（Max Draw Distance）

2800.0，选择一个最大绘制距离。

网格被渲染的最大距离。

最大距离渐隐范围（Max Distance Fade Range）

2048.0，选择一个最大距离渐隐范围。

为渐隐渲染而渲染网格的最大距离。

天空大气（Sky Atmosphere）

天空大气改变远处天空的颜色。可以把它看作绘制岛屿背景幕布。

行星（Planet）

变换模式（Transform Mode）

绝对世界原点处的行星顶部（Planet Top at Absolute World Origin），组件变换处的行星顶部（Planet Top at Component Transform），组件变换处的行星中心（Planet Center at Component Transform）

阳光在大气中反弹时为大气着色的地面反照率。仅在多次散射（MultiScattering）> 0.0 时纳入计算。

地面半径（Ground Radius）

6360.0，选择一个地面半径量。

从行星中心到地面高度的半径，以千米为单位。

地面反照率（Ground Albedo）

选择一个颜色。

阳光在大气中反弹时为大气着色的地面反照率。

仅在多次散射（MultiScattering）> 0.0 时纳入计算。

展开地面反照率可手动控制 RGB 各分量的颜色。

大气（Atmosphere）

大气高度（Atmosphere Height）

60.0，选择一个大气高度量。

地面以上大气层的高度，以千米为单位。

多次散射（Multiscattering）

1.0，选择一个多次散射量。

使用双重散射方法渲染多次散射，模拟阳光在大气中的反弹。

高级（Advanced）

展开该选项。

展开后还有追踪样本数缩放（Trace Sample Count Scale）的附加选项。

当 r.SkyAtmosphere.SampleCountMax 下 r.Sky Atmosphere.FastSkyLUT 为 0 时，样本数仍根据可扩展性设置钳制。

追踪样本数缩放（Trace Sample Count Scale）

1.0，选择一个追踪样本数缩放量。

缩放大气追踪样本数。质量等级可扩展。

当 r.SkyAtmosphere.SampleCountMax 下 r.Sky Atmosphere.FastSkyLUT 为 0 时，样本数仍根据可扩展性设置钳制。

大气-瑞利（Atmosphere-Rayleigh）

你可以从环境光照平台使用 Lumen 曝光（Lumen Exposure），也可以从内容浏览器将其单独添加到项目中。更多信息请参阅Lumen 曝光管理器（Lumen Exposure Manager）文档。

基础曝光与颜色分级（Basic Exposure and Color Grading）

这些组件拥有相同的选项，但影响光照的不同方面。你可以在后期处理体（Post Process Volume）中使用曝光设置来控制最终渲染的图像，可以使用颜色分级来校正与方向光、天空大气和天光设置配合使用的颜色。

后期处理体（Post Process Volume）

镜头（Lens）

展开该选项。

展开后还有辉光（Bloom）、曝光（Exposure）、色差（Chromatic Aberration）、相机（Camera）、局部曝光（Local Exposure）、镜头光斑（Lens Flare）和图像效果（Image Effects）的附加选项。

辉光（Bloom）

展开该选项。

展开后还有强度（Intensity）和阈值（Threshold）的附加选项。

强度（Intensity）

关（Off），开（On）：0.675，选择一个强度量。

辉光强度是所有辉光贡献的乘数。

  • = 0：关
  • 1（默认值）
  • 1 更亮

阈值（Threshold）

关（Off），开（On）：-1.0，选择一个阈值量。

辉光阈值是辉光开始生效的最小亮度。

  • -1：所有像素均匀辉光（物理正确，因省略阈值通道而更快）
  • 0 = 所有像素都影响辉光，越亮越增亮
  • 1（默认值）
  • 1 更亮

曝光（Exposure）

展开该选项。

展开后还有测光模式（Metering Mode）、曝光补偿（Exposure Compensation）、应用物理相机曝光（Apply Physical Camera Exposure）、曝光测光蒙版（Exposure Metering Mask）、最小亮度（Min Brightness）、加速（Speed Up）和减速（Speed Down）的附加选项，还有附加的高级设置。

测光模式（Metering Mode）

自动曝光直方图（Auto Exposure Histogram），自动曝光基础（Auto Exposure Basic），手动（Manual）

所选曝光测光模式决定低端平台的亮度计算方法。

曝光补偿（Exposure Compensation）

0.5，选择一个曝光补偿量。

用于确定低端平台曝光补偿的曝光对数调整。

仅在指定了色调映射器时使用。调整使用 2 的幂。

  • 0：无调整
  • -1：暗 2 倍
  • -2：暗 4 倍
  • 1：亮 2 倍
  • 2：亮 4 倍

应用物理相机曝光（Apply Physical Camera Exposure）

关（Off），开（On）

打开此选项以使用它。自动曝光应用物理相机曝光：仅影响手动曝光模式。

曝光补偿曲线（Exposure Compensation Curve）

打开该选项，然后选择一个材质。

基于场景 EV100 的曝光补偿。

用于根据平均场景亮度以不同方式校准最终曝光。

  • 0 = 无调整
  • -1：2 倍暗
  • -2：4 倍暗
  • 2：4 倍亮

依此类推。

曝光测光蒙版（Exposure Metering Mask）

打开该选项，然后选择一个材质。

曝光测光蒙版。蒙版上的亮斑对自动曝光测光影响更大，暗斑影响更小。

最小亮度（Min Brightness）

0.075，选择一个最小亮度量。

自动曝光最小适配。如果最小值 = 最大值，则禁用眼睛适配。

你可以通过选择一个曝光值来实现自动曝光，使平均亮度生成的像素亮度等于恒定校准值。

最小/最大值以像素亮度（cd / m2）表示，或在使用扩展默认亮度范围（ExtendDefaultLuminanceRange，见项目设置）时以 EV100 表示。

最大亮度（Max Brightness）

1.0，选择一个最大亮度量。

自动曝光最大适配。如果最小值 = 最大值，则禁用眼睛适配。

你可以通过选择一个曝光值来实现自动曝光，使平均亮度生成的像素亮度等于恒定校准值。

最小/最大值以像素亮度（cd / m2）表示，或在使用扩展默认亮度范围（ExtendDefaultLuminanceRange，见项目设置）时以 EV100 表示。

加速（Speed Up）

3.75，选择一个加速量。

以每秒 F 档为单位，该值应 > 0。

减速（Speed Down）

5.5，选择一个减速量。

以每秒 F 档为单位，该值应 > 0。

高级（Advanced）

展开该选项。

展开后还有低百分比（Low Percent）、高百分比（High Percent）、直方图对数最小值（Histogram Log Min）和直方图对数最大值（Histogram Log Max）的附加选项。

低百分比（Low Percent）

关（Off），开（On）：10.0，选择一个百分比。

眼睛适配将适配从场景颜色亮度直方图中提取的值。

该值定义为低于此亮度的 x 百分比。较高的值使屏幕上的亮斑具有更高优先级，但可能导致结果不够稳定。

较低的值使中等和较暗值具有更高优先级，但可能导致亮斑过曝。合适的取值范围是 70–80。

  • 0
  • 100

高百分比（High Percent）

关（Off），开（On）：90.0，选择一个百分比。

眼睛适配将适配从场景颜色亮度直方图中提取的值。

该值定义为低于此亮度的 x 百分比。较高的值使屏幕上的亮斑具有更高优先级，但可能导致结果不够稳定。

较低的值使中等和较暗值具有更高优先级，但可能导致亮斑过曝。合适的取值范围是 70–80。

  • 0
  • 100

直方图对数最小值（Histogram Log Min）

关（Off），开（On）：-8.0，选择一个直方图对数最小值量。

直方图最小值。以 Log2（亮度）表示，或在使用扩展默认亮度范围（ExtendDefaultLuminanceRange，见项目设置）时以 EV100 表示。

直方图对数最大值（Histogram Log Max）

关（Off），开（On）：4.0，选择一个直方图对数最大值量。

直方图最大值。以 Log2（亮度）表示，或在使用扩展默认亮度范围（ExtendDefaultLuminanceRange，见项目设置）时以 EV100 表示。

色差（Chromatic Aberration）

展开该选项。

展开后还有强度（Intensity）和起始偏移（Start Offset）的附加选项。

强度（Intensity）

关（Off），开（On）：0.0，选择一个强度量。

场景边缘强度。以百分比表示的场景色差/色彩边缘（相机缺陷），用于模拟真实镜头中出现的伪影，在图像边角最为明显。

起始偏移（Start Offset）

关（Off），开（On）：0.0，选择一个起始偏移量。

色差起始偏移。效果生效处与帧缓冲中心的标准距离。

污垢蒙版（Dirt Mask）

展开该选项。

展开后还有污垢蒙版纹理（Dirt Mask Texture）、污垢蒙版强度（Dirt Mask Intensity）和污垢蒙版色调（Dirt Mask Tint）的附加选项。

污垢蒙版纹理（Dirt Mask Texture）

关（Off），开（On）：从下拉菜单中选择一个纹理。

下拉菜单可访问 UEFN 中的所有材质和纹理。

污垢蒙版强度（Dirt Mask Intensity）

关（Off），开（On）：为污垢蒙版选择一个强度量。

辉光污垢蒙版（BloomDirtMask）滤镜强度，用于营造相机镜头上灰尘的错觉。

污垢蒙版色调（Dirt Mask Tint）

关（Off），开（On）：选择一个颜色。

辉光污垢蒙版（BloomDirtMask）滤镜的颜色。

相机（Camera）

展开该选项。

展开后还有快门速度（Shutter Speed）、ISO、光圈（F 值）（Aperture (F-Stop)）、最大光圈（最小 F 值）（Maximum Aperture (min F-stop)）和光圈叶片数（Number of diaphragm blades）的附加选项。

快门速度（Shutter Speed）

关（Off），开（On）：60.0，选择一个快门速度。

相机快门速度。

ISO

关（Off），开（On）：100.0，选择一个感光度量。

相机传感器感光度。

光圈（F 值）（Aperture (F-stop)）

关（Off），开（On）：4.0，选择一个光圈量。

定义相机镜头的开孔：

  • 光圈为 1 / f 值，典型镜头光圈可大至 f / 1.2（大开孔）。
  • 较大的数值会减弱景深（DOF）效果。

最大光圈（最小 F 值）（Maximum Aperture (min F-stop)）

关（Off），开（On）：1.2，选择一个最大光圈量。

定义相机镜头的最大开孔，以控制光圈叶片的弯曲度。设为 0 可获得直叶片。

光圈叶片数（Number of diaphragm blades）

关（Off），开（On）：5，选择叶片数。

定义镜头内光圈的叶片数（4 到 16 之间）。

局部曝光（Local Exposure）

展开该选项。

展开后还有高光对比度缩放（Highlight Contrast Scale）、阴影对比度缩放（Shadow Contrast Scale）、细节强度（Detail Strength）、模糊亮度混合（Blurred Luminance Blend）、模糊亮度核尺寸百分比（Blurred Luminance Kernel Size Percentage）和中间灰偏移（Mid Grey bias）的附加选项。

高光对比度（Highlight Contrast）

关（Off），开（On）：1.0，选择一个高光对比度缩放量。

局部曝光将帧亮度分解为基础层和细节层。

阴影对比度（Shadow Contrast）

关（Off），开（On）：1.0，选择一个阴影对比度缩放量。

局部曝光将帧亮度分解为基础层和细节层。

基础层的对比度根据此值降低。

小于 1 的值将启用局部曝光。合适的取值范围通常为 0.6 - 1.0。

细节强度（Detail Strength）

关（Off），开（On）：1.0，选择一个细节强度量。

局部曝光将帧亮度分解为基础层和细节层。

不等于 1 的值将启用局部曝光。大多数情况下此值应设为 1。

模糊亮度混合（Blurred Luminance Blend）

关（Off），开（On）：0.6，选择一个模糊亮度混合量。

局部曝光将帧亮度分解为基础层和细节层。

在双边滤波与模糊亮度之间混合作为基础层。

模糊亮度有助于保持图像外观和高光，并减少振铃效应。

合适的取值范围通常为 0.4 - 0.6。

模糊亮度核尺寸百分比（Blurred Luminance Kernel Size Percent）

关（Off），开（On）：50.0，选择一个百分比。

用于模糊帧亮度的核尺寸（屏幕百分比）。

强度（Intensity）

色调（Tint）

焦外成像尺寸（BokehSize）

关（Off），开（On）：从下拉菜单中选择一个纹理。

下拉菜单可访问 UEFN 中的所有材质和纹理。

阈值（Threshold）

关（Off），开（On）：选择一个阈值量。

镜头光斑开始生效的最小亮度。

该值应尽可能高，以避免模糊过暗而不可见的内容所带来的性能开销。

焦外成像形状（BokehShape）

关（Off），开（On）：从下拉菜单中选择一个纹理

定义基于图像的镜头光斑模糊时焦外成像的形状，不可混合。
