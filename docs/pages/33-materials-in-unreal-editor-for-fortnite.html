材质

在 UEFN 中创建自定义材质与纹理：材质节点、材质库、双面材质与材质特效。

英文原标题：Materials in Unreal Editor for Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

在 Unreal Editor for Fortnite（UEFN） 中创建自己的材质（material）与纹理（texture），让你岛屿上使用的网格体（mesh）拥有独特的外观与质感。

在材质属性相关页面中，查看创建或自定义材质与纹理的教程、常用材质节点等更多内容。

教程导览

从材质节点基础，到 UI 材质、材质库、双面材质与材质特效：

  • UEFN 中的材质节点与设置 — 学习材质节点的工作原理，以及如何在材质实例中设置它们。
  • 在 Unreal Editor for Fortnite 中使用 UI 材质 — 学习创建多种可与 UMG 搭配使用的动态材质。
  • 材质库 — 使用材质库，为从草地到建筑的一切打造自定义外观。
  • 在 UEFN 中创建双面材质 — 学习创建双面材质，为网格体做出镂空效果。
  • UEFN 中的材质特效 — 了解 UEFN 中材质的各类特效。
