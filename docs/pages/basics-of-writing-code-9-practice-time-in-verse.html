Verse 代码写作基础 9：实战练习

在本练习中，你的目标是：如果玩家在规定时间内没有从出生点移动足够远的距离，就对其造成伤害。你将使用失败表达式和失败上下文获取玩家位置，并在出生 10 秒后计算他们移动了多远。

前置知识

要理解和使用本页内容，请确保你已熟悉以下主题：

  • 第 9 课：失败与控制流（Lesson 9: Failure and Control Flow）

在本练习中，你的目标是：如果玩家在规定时间内没有从出生点移动足够远的距离，就对其造成伤害。你将使用失败表达式和失败上下文来获取玩家的位置信息，并在出生 10 秒后计算他们移动了多远。

首先，确保 Verse 文件中仍保留 HurtPlayer() 和 CalculateDamage() 函数。如果玩家移动得不够远，你将调用 HurtPlayer()。提醒一下，这两个函数的代码如下。

HurtPlayer(DamageAmount:float):void=
    Playspace:fort_playspace = GetPlayspace()
    AllPlayers:[]player = Playspace.GetPlayers()
    if (Player:player = AllPlayers[0]):
        if (FortniteCharacter:fort_character = Player.GetFortCharacter[]):
            MyCharacterHealth:float = FortniteCharacter.GetHealth()
            DamageToDo:float = CalculateDamage(MyCharacterHealth, DamageAmount, 1.0)
            Print("Damage To Do: {DamageToDo}")
            FortniteCharacter.Damage(DamageToDo)

现在，你需要获取关卡中所有 player 对象（这里只有一个，就是你自己！），还要创建两个变量来存储玩家在不同时刻的 transform。变换（transform）保存着对象的位置、旋转和缩放数据。在本练习中，你只需要位置，但它存储在 transform 对象中。

Playspace:fort_playspace = GetPlayspace()
AllPlayers:[]player = Playspace.GetPlayers()
var FirstPosition:transform = transform{}
var SecondPosition:transform = transform{}

是时候用 if 创建几个失败上下文了。下面前两行从 player 对象获取 fort_character 对象。如果这段代码看起来眼熟，那是因为它与 HurtPlayer() 函数中的部分代码几乎相同。你必须在这里再写一次，因为你还需要它来获取 fort_character 的 transform。它可能失败，如 [] 所示，因此必须放在失败上下文中。

将之前创建的 FirstPosition 变量设置为 FortniteCharacter.GetTransform() 返回的值。这个表达式本身不会失败，但如果前两个表达式中有任何一个失败，你就不希望运行它，因此它属于同一个失败上下文。

if:
    Player:player = AllPlayers[0]
    FortniteCharacter:fort_character = Player.GetFortCharacter[]
    set FirstPosition = FortniteCharacter.GetTransform()

由于所有可失败表达式都在 if 代码块中，如果它们成功，你需要一个新的代码块来运行后续代码，这就是 then 的作用。当你书写不带 () 的 if 形式时，用 then 编写所有 if 代码块中的代码成功后应运行的代码。

你的第一个 then 块应如下所示。

then:
    Print("Move or prepare to take damage!")
    Sleep(10.0)

这两个函数你之前都见过。Print() 在这里用于警告玩家需要移动，Sleep() 给玩家 10 秒时间远离出生点，然后再运行下一块代码。

等待 10 秒后，就该运行检查玩家是否已远离出生点特定距离的代码了，如果没有，就对其造成伤害。

if:
    Player:player = AllPlayers[0]
    FortniteCharacter:fort_character = Player.GetFortCharacter[]
    set SecondPosition = FortniteCharacter.GetTransform()
    DistanceBetweenPositions:float = DistanceXY(FirstPosition.Translation, SecondPosition.Translation)
    DistanceBetweenPositions < 10000.0

前三行与第一个 if 代码块几乎相同，只是现在设置的是 SecondPosition 而不是 FirstPosition，这样你就有了两个位置可以比较。

接下来，声明并初始化 DistanceBetweenPositions。为此，你将使用 Verse 内置函数 DistanceXY()，它接受两个参数，都是三维空间中的坐标（称为向量），只使用 X 和 Y 坐标测量距离，并将该距离作为 float 返回。记住只使用两个 transform 变量的 Translation 属性。

最后，将 DistanceBetweenPositions 与字面量 float 值比较。建议一开始用一个大数，以确保代码正常工作，在摸索出给定时间内合理的移动距离后，再逐步调小。

如果玩家在时限内没有移动规定的距离，你的下一个 then 块就会运行，所以你希望这里是伤害玩家的代码。

then:
    Print("Distance Moved: {DistanceBetweenPositions}")
    Print("Applying Damage")
    HurtPlayer(50.0)

这将打印玩家实际移动的距离、一条即将施加伤害的通知，并调用你之前编写的 HurtPlayer() 函数。通过调用 HurtPlayer() 函数，你无需考虑它是如何实现的，你知道它会遵循你之前为伤害玩家设定的规则。
