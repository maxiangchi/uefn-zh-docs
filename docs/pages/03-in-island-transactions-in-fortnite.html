岛内交易

用 Verse 以 V-Bucks 在岛内出售物品与玩法权益，自建游戏内经济：配置、设备模板与变现指南入口。

英文原标题：In-Island Transactions in Fortnite · 查看英文原文 · 社区翻译镜像，仅供学习

岛内交易（In-Island Transactions）为你提供了一种打造自有游戏内经济的方式：以 V-Bucks 为代价，向玩家提供物品。使用 Verse 定义物品名称、描述和价格（以 V-Bucks 计价）。在创作者门户（Creator Portal）中查看你的报价目录、监控销售表现，系统会确保每笔交易都有集中且不可更改的记录。

设置岛内交易

通过岛内交易功能示例（In-Island Transactions Feature Example），在 UEFN 中进一步了解相关代码。你还可以学习岛内交易设备（In-Island Transactions device），以及如何构建自己的自定义商店 UI——请参阅用户界面示例（User Interface example），为玩家打造独特体验。

点击图片可放大查看。

如果你已经加入了Fortnite 开发者计划（Fortnite Developer Program），需要同意更新后的协议。互动参与度分成计划条款（Engagement Payout Program Terms）已更新为Fortnite 开发者条款（Fortnite Developer Terms），其中包含与岛内交易相关的条款。IPPP 计划条款也已更新以涵盖岛内交易，需要重新签署。

深入学习岛内交易

通过以下页面进一步学习岛内交易（In-Island Transactions）：

  • 岛内交易概览（In-Island Transactions Overview）——了解如何用岛内交易实现岛屿变现。
  • 创建物品与报价（Creating Items and Offers）——使用 Verse 创建物品、报价与捆绑包报价，在岛屿上售卖玩法内容。
  • 交易最佳实践与调试（Transaction Best Practices and Debugging）——查看在岛屿中设置与调试岛内交易的最佳实践。
  • 岛内交易设备模板（In-Island Transactions Device Template）——学习如何使用岛内交易设备模板，快速上手岛内交易。
  • 岛内变现指南（Guidelines for In-Island Monetization）——了解在变现岛屿体验时该做与不该做什么。
  • 为岛内交易构建自定义 UI（Building Custom UI for In-Island Transactions）——为岛内交易构建自定义 UI。
